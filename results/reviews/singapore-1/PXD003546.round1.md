## Findings (all minor)
1. **minor - design/annotation gap** - location: file level, `comment[label]`. The run used 8plex reagents (113 exists only in 8plex; the file name says `8plex`; PX lists MOD:01549 iTRAQ8plex), but only 113/114/116/117 are annotated. The paper never says whether 115/118/119/121 were empty. It also does not say which channels the 6-protein calibration mix used or whether that mix was in this run. Leaving these channels out is the safe choice: no stated sample to map. Correction criterion: add a note in the report that the unused channels are unassigned or unknown. Add rows only if a source assigns them.
2. **minor - spec convention** - location: `assay name`, all rows. Each channel has its own assay name (`...-iTRAQ113`, etc.). The spec README says multiplexed rows should share one assay name per MS run. The validator accepts this, and it is the campaign-wide convention (for example PXD000588 and PXD000499). Correction criterion: optional; use one assay name per run if the batch convention changes.
3. **minor - formatting** - location: `comment[modification parameters]` (3 columns). `MT=Fixed` is capitalised, while the spec examples use `MT=fixed`. The validator accepts it. Correction criterion: optional lowercase.
4. **minor - inference** - location: `characteristics[cell type]` = epithelial cell and `characteristics[developmental stage]` = adult. These are inferred: Cellosaurus gives no cell type, and adult is derived from 30Y6M. The producer report should list cell type among its INFERRED values. Correction criterion: label it as inferred in the report; no change to the SDRF is needed.
5. **minor - provenance conflict** - location: file level. The file name says `2ul` but Methods says 5 uL was injected. No SDRF column is affected. It is already noted in the producer report.

No blocker or important findings.
