## Design consistency

- 3 conditions (sgGal4 control, MIR sg22, MIR sg23) x 4 biological replicates = 12 samples, split over 2 TMT6plex runs. This is balanced: each run holds BR(n) and BR(n+1) of every condition, so condition is not confounded with run.
- No fractionation: fraction identifier = 1, fractionation method = not applicable. This fits one pooled run per set.
- Technical replicate = 1 on every row. There is a single factor (`factor value[treatment]`) and it matches `characteristics[treatment]`.
- The paper's Results contrast the ESC MIR-proteome with RA-differentiated cells, but the deposit has no RA sample or RA channel. The SDRF correctly annotates only what was deposited.

## Findings

No blocker or important findings.

1. **minor**: `comment[alkylation reagent]`, all rows = `iodoacetamide (IAA)`.
   - Evidence: the paper and the PRIDE protocols name no alkylation reagent. The value is inferred from the submitter's PX modification term MOD:00397 "iodoacetamide derivatized residue" and from the S-Trap manufacturer's protocol. MOD:00397 is the conventional PX-tool choice for any carbamidomethylation, which can also come from chloroacetamide.
   - Correction criterion: keep it only if the cited CAPTURE2.0 protocol (paper ref. 119) or the manufacturer protocol confirms IAA. Otherwise `not available` is the stricter value. This does not block, because a submitter-supplied CV term supports it.
2. **minor**: `characteristics[treatment]` / `factor value[treatment]` wording.
   - Evidence: the dCas9-biotin pull-down is an enrichment step shared by all samples. The variable that differs between samples is the stable sgRNA expression.
   - Correction criterion (optional): express the sgRNA as a genetic-modification characteristic, and/or add `comment[enrichment process]` for the biotin pull-down. The current factor still separates the three conditions correctly.
3. **minor**: `comment[dissociation method]` = not available, and there is no collision-energy or scan-range column.
   - Evidence: no source states the activation type. The 0.6 Da MS2 tolerance hints at ion-trap MS2 but does not prove it.
   - Correction criterion (optional): fill these from the RAW instrument method if it is ever read. Leaving them unfilled is the correct conservative choice.
4. **minor**: recommended cell-lines column `characteristics[cellosaurus name]` is absent.
   - Correction criterion (optional): add `ES-E14`.
5. **minor**: cell line identity ES-E14 (CVCL_C320) vs ES-E14TG2a (CVCL_9108).
   - Evidence: the paper and the metadata say only "E14", with no supplier. CVCL_C320 is the literal match, and Cellosaurus lists "E14" as its synonym.
   - Correction criterion: no change unless a source names E14TG2a.
