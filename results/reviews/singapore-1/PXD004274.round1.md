## Findings
No blocker or important findings.

- **M1 (minor), column `characteristics[strain or breed]` / `factor value[strain or breed]`.**
  - Evidence: in TERMS.tsv the column is licensed only for vertebrates, invertebrates and plants, not for ms-proteomics alone. The validator does not flag it, and the column carries the study's primary contrast, for which no licensed alternative exists.
  - Criterion: keep the column as a documented exception (corpus precedent for microbes). If a microbe/fungi template becomes available, re-declare under it.
- **M2 (minor), all rows, `characteristics[biological replicate]`.**
  - Evidence: the Methods call the two biofilm samples per strain "technical replicates", while the Fig. 1 title says "biological replicates". They are separately grown biofilms in separate channels, so the encoding as distinct sources with bio rep 1/2 is defensible and supported by the figure.
  - Criterion: none required. Keep the conflict noted in the report.
- **M3 (minor), `comment[dissociation method]` = beam-type CID (MS:1000422).**
  - Evidence: the paper does not name the fragmentation mode, only "rolling collision energy". The value is inferred from the TripleTOF (QqTOF collision cell), which is accurate for the instrument class.
  - Criterion: acceptable as is. Optionally confirm it from the mzML `<activation>` header when EBI is reachable (MS:1000133 CID would also be acceptable).
- **M4 (minor), `assay name` (8 values RAW-iTRAQ113..121 for one run).**
  - Evidence: spec README row-uniqueness says multiplexed rows typically share one assay name per MS run, and base says "assay name must be unique per data acquisition run". Per-channel assay names do not fail validation and are common in the corpus (112 of 200 sampled isobaric SDRFs).
  - Criterion: optionally set a single shared assay name (e.g. `run 1` / `RAW`) for all 8 rows.
- **M5 (minor), `comment[fractionation method]` = not available.**
  - Evidence: SCX with the iTRAQ method development kit is stated. There is no fraction count, and only one mzML is deposited, so `not available` is honest.
  - Criterion: none required.
