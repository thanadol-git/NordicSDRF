## Findings

### F1. important: culture medium is stated in the paper but annotated as "not available"
- **Location:** `characteristics[culture medium]`, rows 1-4. This is a recommended column in the cell-lines template.
- **Evidence:**
  - PMC3945915 Methods state that HCT116 was kept in modified McCoy's 5A medium with L-glutamine and 10% FBS.
  - The producer report wrongly says "base medium not named, only 10% FBS".
  - The value "not available" asserts that the information is absent, which is false.
- **Correction criterion:** Set all 4 rows to the McCoy's 5A medium, for example `McCoy's 5A medium` or the NCIT term for McCoy's 5A if one resolves in NCIT (the template asks for NCIT, warning level). Correct the report text.

### F2. minor: assay name differs per channel for one data file
- **Location:** `assay name`, rows 1-4 (`...-iTRAQ113` through `...-iTRAQ117`).
- **Evidence:** spec README.adoc, "Row Uniqueness", says each data file MUST have a unique assay name, and that multiplexed rows share the same assay name. Many accepted BigBio datasets use per-channel assay names, and the validators pass, so this is not blocking.
- **Correction criterion (optional):** use `121019_JG_Andro_1DLC_8plex_ITRAQ_2ul` as the assay name on all 4 rows.

### F3. minor: dissociation method is inferred, not stated
- **Location:** `comment[dissociation method]`.
- **Evidence:** the paper does not state the fragmentation type. Beam-type CID is the only MS/MS mode of the TripleTOF 5600 collision cell, so the value is safe. The producer report discloses that it was inferred.
- **Correction criterion:** none required. Optionally confirm it from the mzML header (activation cvParam).

### F4. minor: iTRAQ8plex fixed-modification parameters are inferred
- **Location:** `comment[modification parameters]` columns 37-38.
- **Evidence:** the paper lists only "MMTS" and "biological modifications" for Paragon. The iTRAQ8plex K/N-term Fixed values come from how a ProteinPilot iTRAQ sample type works, and they agree with PX MOD:01549. The report discloses this.
- **Correction criterion:** none required.

### F5. minor: the data file is a peak list (mzML), not vendor raw
- **Location:** `comment[data file]`.
- **Evidence:** the FTP listing has no .wiff, so the mzML is the only spectral file deposited. The CI advisory `peak_list_data_file` applies.
- **Correction criterion:** none. Optionally mention the peak-list-only deposit in the report.
