## Findings (all minor)

### M1 (minor): the PTF vs piNSC contrast spans two files
- **Location:** file level. `factor value[cell line]` exists only in the pinsc file.
- **Evidence:** the paper's central PTF→piNSC comparison uses rows from both files. A naive merge leaves `factor value[cell line]` empty for PTF rows.
- **Correction criterion:** none required, because the split is structurally justified. Optionally, the contribution README or report can state that the two files form one experiment and are to be merged on `factor value[cell type]`.

### M2 (minor): NG passage 21 differs from the paper's wording
- **Location:** pinsc file, 12 NG rows, `characteristics[passage number]` = 21.
- **Evidence:** the PROXI description says "piNSCs-NGs; passage 21". The paper says passage-20 piNSCs were differentiated for 14 days.
- **Correction criterion:** none required, because the value is sourced. Optionally cite the PROXI description as its provenance.

### M3 (minor): sex is recoverable from the karyotype
- **Location:** `characteristics[sex]`, all 30 rows (`not available`).
- **Evidence:** PMC8790232 reports a "38, XX" karyotype for the derived lines. It does not state the donor's sex in words.
- **Correction criterion:** optional. Keep `not available` (conservative), or set `female` with the karyotype as the cited evidence. The current value is not wrong.

### M4 (minor): round-1 minors F4, F5 and F6 remain as accepted choices
- **F4:** organism part is `not applicable` on the derived lines. `characteristics[sampling site]` = tail is now licensed by cell-lines and could be added.
- **F5:** treatment is free text.
- **F6:** the archive holds Mascot `.dat` files, while the paper reports MaxQuant.
- **Also missing:** the recommended `characteristics[cellosaurus name]`. It could be `not available`.
- **Also a warning only:** `developmental stage` "neonate stage" is a UBERON label, while the vertebrates template prefers EFO.
- **Correction criterion:** optional.
