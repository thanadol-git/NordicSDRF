## Add MDM2 co-IP sandbox SDRF for PXD020812

Dataset: [PXD020812](https://www.ebi.ac.uk/pride/archive/projects/PXD020812) · new file `sandbox/PXD020812/PXD020812-ip.sdrf.tsv`, 90 rows × 39 columns

This PR adds the MDM2 co-immunoprecipitation runs of PXD020812 as a second sandbox SDRF, and appends an update section to `sandbox/PXD020812/BRIEF.md`. The existing `PXD020812.sdrf.tsv` (in vivo SILAC epiWAT proteome, #3334) is unchanged. Nothing changes under `datasets/`.

### What it covers
- **45 RAW files:** 3 MDM2 antibodies (4B2 = `IP_Cyt_*`, 2A10, SMP14) × 15 SDS-PAGE gel bands.
- **2 SILAC channels per run.** The specimen is 3T3-L1 adipocytes (CVCL_0123). Templates: ms-proteomics, vertebrates, cell-lines v1.1.0.

### Label → condition evidence
- **Labels.** The PRIDE data protocol states double labels Arg6/Lys4 and Arg10/Lys8, recorded as `SILAC medium` and `SILAC heavy`.
- **Which label is the IP.** In the deposited `MDM2_proteinGroups.txt`, the bait Mdm2 has H/L = 1419 (4B2), 269 (2A10) and 28 (SMP14), against global medians of about 1. So heavy is anti-MDM2 and medium is nonspecific IgG.
- **Raw files → experiments.** The `MDM2_evidence.txt` `Raw file` / `Experiment` columns match all 45 deposited file names.
- **Digestion.** Trypsin: the evidence has many R-terminal peptides.

### Still not annotated: MORC2 IP / RIME (22 RAW files)
- **Label map is known.** The paper's Table S3 against `MORC2_proteinGroups.txt` gives L = IgG, M = anti-MORC2 (siGFP) and H = anti-MORC2 (siMdm2). `aMORC2/IgG` tracks M/L (r = 0.95); `siMdm2/siGFP` tracks H/M (r = 0.98).
- **Why they are still out.** The deposited MORC2 raws (2018-05 and 2018-06) are not the runs in the deposited search (2017-07 and 2018-01/02 runs), so they cannot be tied to a layout.
