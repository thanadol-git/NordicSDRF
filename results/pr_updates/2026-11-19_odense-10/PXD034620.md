### Study
Beltrán-Camacho L, Bhosale SD, …, Larsen MR, Moreno-Luna R, Durán-Ruiz MC. "Cardiovascular-related proteomic changes in ECFCs exposed to the serum of COVID-19 patients". Int J Biol Sci 2023;19(6):1664-1680, doi:10.7150/ijbs.78864, PMC10092762 (full text read via NCBI efetch; the title matched). MS was run at SDU Odense (Larsen lab). Human endothelial colony-forming cells (ECFCs, from subcutaneous white adipose tissue) were incubated for 24 h in EBM-2 with 10% serum from COVID-19-negative donors (Neg), asymptomatic PCR+/IgG- (PCR+) or PCR-/IgG+ (IgG+) donors, or critical COVID-19 patients (Crit); n = 8 sera per group. Label-free diaPASEF on a timsTOF Pro.

### Scope (deposited vs annotated)
`files/all`: 5 files: 4 RAW-category 7z archives (one per group, 23–30 GB each) and the Spectronaut report. Each archive holds 8 Bruker `.d` folders. The 7z header of `ECFCs_Critical.7z` was range-read and LZMA-decoded: 8 `.d` folders named exactly like the Spectronaut report columns (`ECFCs Crit    C1.d` … `C8.d`, four spaces kept). For the other three archives the run names come from the 32 `PG.Quantity` columns of the deposited Spectronaut report (8 per group). 32 rows, one per `.d` run. `comment[data file]` = the `.d` folder name; `comment[file uri]` = the archive that contains it.

### Sample / file mapping evidence
Group from the run name (Crit/IgG+/Neg/PCR+) and archive. The trailing code (C1…C8, 001, 011_repeat, …) is the serum-donor code, used in `source name`. biological replicate = 1–8 within each group (each serum donor is a distinct biological replicate). `011_repeat` and `169_1` are the only runs for those donors and are kept as replicate rows.

### Judgement calls for reviewers
Using `.d` folder names inside archives as `comment[data file]`; treatment vs disease modelling; the unverified run names in three archives.
