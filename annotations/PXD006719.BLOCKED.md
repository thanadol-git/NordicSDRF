# PXD006719 — blocked: no raw-file-to-tumour mapping

## Sources checked

- PRIDE project record: https://www.ebi.ac.uk/pride/ws/archive/v2/projects/PXD006719
- PRIDE file manifest: https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD006719/files/all

## Evidence available

PRIDE describes an overlapping set of paired local and distant breast-cancer metastases and identifies human lymph-node material analysed on an LTQ Orbitrap XL. The manifest contains 96 vendor RAW files with numeric patient-like identifiers and acquisition/fraction suffixes.

## Blocking gap

The PRIDE record has no linked publication, DOI, or sample table. It does not map any RAW filename to primary/local/distant metastasis status, matched-pair identity, individual, tissue site, fraction, or technical replicate. Filename patterns alone cannot establish these clinical assignments.

## Unblock requirement

Provide the deposited sample annotation sheet or an authoritative patient/pair-to-RAW mapping, including tumour site/status and fraction/replicate metadata.
