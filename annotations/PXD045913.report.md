## Design

- Groups (factor value[disease status], submitter labels): active, remission, remission Marsh 1, incomplete remission, post gluten challenge, no duodenal inflammation control, other duodenal inflammatory condition, H.pylori positive. Cohorts (characteristics[cohort]): biobank, 14-day challenge, validation cohort.
- Disease mapping: CeD groups -> celiac disease; controls -> normal; "other duodenal inflammatory condition" -> duodenitis; H.pylori positive -> Helicobacter pylori infectious disease.
- Two custom characteristics columns (`disease status`, `cohort`) carry the submitter groups; the factor value duplicates `disease status`.
- Technical replicates: A1-B8 / S1-S4 pairs (file and file_timestamp), N1-L3 (_1/_2), and 1a/1b pairs are treated as technical replicates of one source. s54 was run on both instruments (EH11105 QE, S54 .d) = technical replicate 1 and 2.

## Limitations

- Paper full text not available (Europe PMC abstract only, PMID 38467384); no age, sex, ancestry; stated not available.
- Source naming and technical-replicate pairing are inferred from file/experiment names; N/L series _1/_2 and Anette timestamp pairs could instead be serial sections or H&E vs unstained sections (the paper evaluates these), so some "technical replicates" may be biological/section replicates. Biological replicate is 1 for all rows.
- Individual: `P#` (validation cohort pairing) where given, else `TE#` (technical-evaluation patient ID); the two ID schemes may overlap for the same person but cannot be reconciled from the deposit. Rows without either = not available.
- C5-C60 .d file names do not match their Experiment labels (e.g. C10_... = C5); the deposit's mapping was followed as given.
- timsTOF fragment tolerance 40 ppm is the MaxQuant TOF default, not directly confirmed; tims dissociation and collision energy not available. Search used Trypsin/P; digestion annotated as Trypsin per protocol. mqparS1-5.xml is empty (0 bytes) and was not used.
- Search modifications taken from MaxQuant mqpar files (identical across those checked: 1a-4b, S1-4, S121-S154, EH8662-70, others read for tolerances/enzyme only).
- The .d data files sit inside ZIPs (data file = folder name with .d).
