# PXD047461 — annotation blocked

## Blocking issue

The deposit combines de-novo antibody sequencing, XL-MS, and HDX-MS in 33 Thermo RAW files. The ten `de_novo_seq_*.raw` acquisitions are not mapped to the four proteases used for overlapping antibody digestion (trypsin, chymotrypsin, elastase, and pepsin). A complete accession-wide SDRF therefore cannot assign the required per-run cleavage agent without guessing.

## Evidence checked

- PRIDE project record and complete file inventory (`scratchpad/PXD047461/evidence/pride.json`, `files.json`)
- Open-access Methods for PMID 38701337 / PMCID PMC11154737
- Deposited `Tang_HDExaminer_layout_SLO.csv`, `Tang_DB_search_psm.csv`, and pLink2 cross-link export
- All 33 RAW filenames, which distinguish HDX and DSS/DSG cross-linking runs but do not identify the de-novo protease used

## Evidence needed

A run-design table mapping every `de_novo_seq_*.raw` file to its digestion enzyme, or separate search settings/results that preserve that mapping. With that table, the accession should be represented as separate de-novo, HDX, and XL-MS SDRFs.
