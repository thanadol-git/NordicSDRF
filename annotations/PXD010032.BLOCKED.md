# PXD010032 BLOCKED: SILAC light/heavy-to-treatment map not recoverable

Status: blocked annotation; no SDRF produced. Independent review not applicable.

## Dataset
Institute of Biomedicine, Aarhus University (lab PI Lei Cheng). "Rapid Aldosterone Effects in Mouse Kidney Distal Convoluted Tubules Cells": mpkDCT cells, SILAC (Lys/Arg light vs 13C6 Lys / 13C6 15N4 Arg heavy), 30 min 1 nM aldosterone vs DMSO, light+heavy lysates pooled per biological replicate, high-pH fractionation, TiO2 phosphopeptide enrichment, Q Exactive, PD 2.1 SEQUEST/Mascot. Paper: Cheng L et al., JASN 2019, PMID 31253651, DOI 10.1681/ASN.2018101025, PMC6683706 (four biological replicates).

## Why it cannot be annotated
Every RAW file contains both SILAC channels, so a row needs (file x channel) -> treatment (aldosterone vs vehicle). The PRIDE protocol says only that "differentially labelled control or hormone-treated samples were pooled"; it does not say which of light/heavy was aldosterone in each of the four replicates (a label swap is typical and was not ruled in or out). The paper Methods defer to "Supplemental Appendix 1" and a previous study. Ladder checked:
1. PRIDE record and 104-file list (96 RAW: `AcuteAldo_<rep 1-4>_<fraction 1-7>` in three file series (plain, timestamped, `_3`) plus `AcuteAldo_FT_<rep>_<1-7>` flow-through; 4 `.msf` of 6.5-7.1 GB; 4 `.pep.xml`): no sample sheet.
2. PMC6683706 main text (read via WebFetch): states four biological replicates, no label assignment, no technical replicate description.
3. PMC supplementary PDF/XLSX (`ASN.2018101025SupplementaryData1-3`): not retrievable (PMC and Europe PMC serve a bot-check page to scripted clients; Europe PMC fullTextXML returned HTTP 500).
4. The `.msf` files were not range-read (PD SILAC quantification nodes normally carry only Heavy/Light ratio definitions, not sample names).
Assigning heavy = aldosterone to every replicate would be invention.

## Verified facts (for a future annotation once the map is found)
Mus musculus, mpkDCT (immortalised mouse distal convoluted tubule cell line); Q Exactive; HCD NCE 29%, top 10, 17,500 MS2 resolution; precursor 10 ppm, fragment 0.02 Da; Trypsin after Lys-C pre-digestion; carbamidomethyl C fixed; variable acetyl protein N-term, oxidation M, Label:13C(6) K, Label:13C(6)15N(4) R, phospho STY; fractions 1-7 per replicate in the phospho-enriched series and a flow-through series.
