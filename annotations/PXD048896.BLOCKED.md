# PXD048896 — BLOCKED

## Exact blocker

The deposited design maps 30 MaxQuant LFQ intensity labels to biological conditions, but it does not map those labels to the 31 deposited RAW files. The RAW names include duplicate/reacquisition-like suffixes, so neither numeric ordering nor basename matching gives a safe one-to-one sample map.

## Evidence checked

- PRIDE project record: `https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD048896`
- PRIDE file inventory: `https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD048896/files/all`
- Publication: `https://pmc.ncbi.nlm.nih.gov/articles/PMC11948581/` (DOI `10.1172/jci.insight.181481`)
- Deposited `experimental_design.txt`

PRIDE lists 31 Q Exactive RAW files and declares MS1-intensity label-free quantification. `experimental_design.txt` maps `LFQ intensity 01` through `LFQ intensity 30` to `KO_5w`, `WT_5w`, `KO_8w`, `WT_8w`, `KO_old`, or `WT_old`, with replicates 1-5. It has no RAW-file or experiment-name column. The RAW inventory contains 31 files, including both `..._08_230min.raw` and `..._08_230min_2.raw` plus other suffixed names such as `_1`, `_2`, `_3`, and `_2xmore`; therefore positional matching would invent which acquisition is the primary run or a repeat. The publication establishes the biological design but not this run-level join.

The file inventory also advertises a roughly 2.85 GB search-output archive, but the campaign's timebox and no-giant-download rule preclude treating an uninspected large archive as evidence. No mapping is claimed from it.

## Evidence needed to unblock

A MaxQuant `experimentalDesignTemplate.txt`, `summary.txt`, `mqpar.xml`, or equivalent exported table that explicitly joins each deposited RAW basename to the corresponding experiment/LFQ-intensity label and marks any repeated or excluded run.
