## Caveats
1. Per-file antibody identity (clone C11 / 9D11 / murine IgG; individual chimeras vs pools) is not recoverable from the deposit or paper text. The factor is therefore at set level. The paper's Source Data or Fig. 7 could supply the mapping; none was inferred from iBAQ profiles.
2. PRIDE lists instrument as "Q Exactive HF"; the paper and the RAW header (range read) say Q Exactive HF-X, which is used.
3. Variable modifications (Oxidation M, Acetyl protein N-term) are inferred from the "Modifications included in protein quantification" parameter; the exported file lists only the fixed Carbamidomethyl.
4. `not available`: precursor tolerance, dissociation method, disease, developmental stage, cell type.
5. File `Y2008-Degn-June-7.raw` appears as `Y2008-Degn-June-(7of25uL)_7` in proteinGroups; the Y2008-June-9 run is a separate file.
