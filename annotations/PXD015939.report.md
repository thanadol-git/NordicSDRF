# PXD015939 annotation report

Status: validated annotation; independent review pending.

## Result

44-row x 38-column label-free DDA SDRF (22 mouse microglia samples x 2 technical replicates; one raw file per row, no fractionation). Templates: `ms-proteomics` v1.1.0 + `vertebrates` v1.1.0. Factors: `factor value[genotype]` (wild type vs miR-146a knockout) and `factor value[treatment]` (cuprizone vs normal chow). Four groups: WT-CTL (2 samples), WT-CPZ (8), KO-CPZ (5), KO-CTL (7).

No existing PXD015939 directory in `sdrf-annotated-datasets` (Step 0.5), so annotated from scratch.

## Evidence

- PRIDE PXD015939 (Stensballe, Aalborg University, Denmark); paper Martin et al. 2020, Front Immunol (PMID 32582192, PMC7292149).
- 44 RAW files plus FASTA and `Maxquantcombinedtxt.zip`. Modifications, enzyme and MS/MS tolerance were read from `txt/parameters.txt` and `txt/summary.txt` inside the zip by HTTP range reads; no RAW file was downloaded.
- File name `<n><a|b>_<M|S>_<CTL|CPZ><WT|KO>_<rep>`: n = sample (22), a/b = technical duplicate, which matches the paper's "technical duplicates (n=2)".

## Caveats / conservative choices

- `Trypsin` (MS:1001251) is declared because the deposit says trypsin; the MaxQuant search used Trypsin/P with 2 missed cleavages. Only one cleavage-agent column, since only one protease was used.
- `comment[precursor mass tolerance]` is `not available` (absent from parameters.txt). Fragment tolerance 20 ppm.
- Sex and developmental stage are `not available`: the paper says female 7-8 weeks for CPZ experiments but pups for MACS/shake-off sorting, and does not link either to the proteomics samples.
- The `M` / `S` file-name token is undocumented in the record. It is kept only as an opaque label in `comment[sample preparation batch]`; do not read it as a method (MACS vs shake-off is a guess). It may confound with group (S = 6 samples, in CPZWT and CTLKO only).
- `characteristics[biological replicate]` is a running index within each genotype x treatment group (file-name replicate numbers are not unique, e.g. `CPZWT_2` and `CPZWT_2b`). The 22 sample numbers are the source identity.
- Disease left `not available` (cuprizone demyelination model; no disease in the deposit).
- Microglia were CD11b-enriched; no `enrichment process` term was added.
- Treatment values `cuprizone`/`normal chow` and strain `C57BL/6` are free text (validator warnings only).

## Validation

- `python -m tools structure`: OK. `python -m tools check --offline`: CLEAN (0 hallucinated). `python -m tools reconcile`: all values agree with the record (after fixing a cleavage-agent mismatch). `python -m tools score`: 100/100.
- Independent adversarial review: not performed (subagents not permitted in this run); review-gate not run.
