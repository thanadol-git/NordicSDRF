# PXD053974 annotation blocked

PXD053974 is the MS-CETSA (isothermal dose-response thermal shift) dataset of Nardella et al., Cell Chem Biol 2025, 32:926-941 (doi:10.1016/j.chembiol.2025.06.003, PMID 40628257, PMC12406260). The study is about compound 12 (YLIU-06-026-1), a type II human kinase inhibitor that targets PfPK6 in *Plasmodium falciparum* 3D7. The paper's data availability statement cites PXD053974.

**Design (from STAR Methods):** there are two arms, trophozoite lysate and intact trophozoites. Each arm has 10 samples: 9 drug concentrations (lysate dilution series from 100 uM, intact-cell series 4-fold from 10 uM) plus 1 DMSO control. Each sample was heated at 37, 53, 59 or 65 C. Peptides were TMT-labelled, with the plex not named. Each set was fractionated by high-pH RP into 20 concatenated fractions and run on a Q Exactive HF (DDA top 12) using a 70 min gradient. The search was Proteome Discoverer 2.5 with Mascot 2.6.1.

The channel -> sample map is not available:
- **Paper STAR Methods (PMC12406260):** they give no TMT plex, no channel -> concentration/temperature table and no replicate count. Ten samples per temperature suggest TMT10plex, one set per arm x temperature. That is INFERRED, and it still gives no channel order.
- **Expected vs cached file count:** the campaign cache says 8 RAW / 16 files. 8 sets (2 arms x 4 temperatures) x 20 fractions would be 160 RAW, so the cache does not match the Methods as written. I could not re-derive the deposited file list, so this conflict is unresolved.
- **Supplementary tables** (`Supplementary_file_2.xlsx`, `Supplementary_file_3.xlsx`, Supplemental_information.pdf): PMC served a reCAPTCHA page, which was not bypassed. The Europe PMC `supplementaryFiles` endpoint returned a server error, and the PDF was rate-limited twice. These were not read.
- **Zenodo 15636573** (the authors' R analysis package): the record page was rate-limited twice and the API is robots-disallowed. It was not read. It may hold an example channel annotation.
- **ProteomeCentral PROXI record and PRIDE FTP folder:** these were not read, because no cloud-browser window was available to this agent. So the RAW file names, the instrument from the RAW header, any submitter sample-metadata file and any PD study/result headers were not checked.

Search parameters are recoverable from the Methods: LysC + trypsin, 30 ppm / 0.06 Da, up to 3 missed cleavages, Carbamidomethyl C fixed, Oxidation M + Deamidated NQ + Acetyl N-term variable, TCEP / chloroacetamide. But with no channel identities and no verified file list, no SDRF is emitted.
