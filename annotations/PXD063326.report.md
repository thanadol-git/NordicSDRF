## Limitations

- Raw data are inside archives (LCMS_rawfile.zip, _2.7z, _3.zip, _4.zip). Run names (.d folders) were read from the zip central directories and the 7z header by range requests: 3 + 3 + 4 + 2 = 12 .d runs. comment[data file] uses the .d folder names, not the archive names. mqpar files list further runs (e.g. 3_, 5_, 7_, rama4, Rama_1) that are not in the deposited archives; they were not annotated.
- No deposited map from run to biological sample. Only rIG_Slot1-46 is identifiable (recombinant hIgG3 positive control; PRIDE description and mqpar_2). All other runs are assumed to be mouse serum IgG from the 10-month-old Vlambda2 315m+/- TCR-TG+/- cohort per the PRIDE description; this is inferred. C_Rama_Slot1-6 may be a control: its genotype is set to not available. Whether some runs are 9A8 (anti-Vlambda) IPs rather than protein G only IPs is unknown.
- Source names are ours (one source per run, biological replicate 1, technical replicate 1); runs may be technical repeats of the same mouse. Sex, individual age and disease state per run not given (sex/disease not available). Age not included; developmental stage adult from the 10-month cohort description. Strain BALB/c from the paper (lymphomas had a BALB/c background); mapped to the cohort by inference.
- characteristics[genotype] is a non-template custom column kept because it carries the main design information. No factor value column: no comparison can be assigned to runs.
- Digest was AspN then trypsin; the cleavage column is single-valued so only Trypsin is recorded (mqpar_2 searched Trypsin/P + AspN; the others Trypsin/P only). This is the reconcile "Asp-N" finding.
- rIG: recombinant protein (human IgG3 constant, mouse VH+VL); organism and others not applicable, organism part not available (reconcile finding).
- Dissociation method not stated (PASEF; left not available). Alkylation/reduction reagents not named. MS1 range m/z 100-1700 in the prose could not be encoded (pattern rejected by validator) so omitted.
- Mass tolerances from mqpar_1 (main search 10 ppm; TOF fragment match 40 ppm, MaxQuant default); first search 20 ppm. Mods from mqpar: Carbamidomethyl (C) fixed; Oxidation (M), Acetyl (Protein N-term) variable.
- Instrument timsTOF fleX from PRIDE and protocol text; analysis.tdf not inspected. PRIDE lists experiment type as top-down; contradicted by the bottom-up digest protocol, ignored.
