## Study

## Templates

## Scope: deposited vs annotated
97/97 runs (43 liver + 54 plasma). PRIDE holds only 2 .d.zip files, each a container of many .d runs (44-min liver set R0833 in one, 21-min plasma set R0831 in the other); data file = the .d name inside the ZIP, container in comment[file container].

Every .d in the two ZIPs is in exactly one design table. Tissue per run set from the deposited quantity tables (44-min R0833 = liver, 21-min R0831 = plasma) - note the deposited table names are swapped ('aih_liver_diann' is a Spectronaut report and vice versa), matching the record's 'liver Spectronaut / plasma DIA-NN'.
