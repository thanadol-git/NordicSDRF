# PXD040434 — annotation blocked

## Dataset

- **Title:** Human adipose tissue proteomics reveal adaptations to exercise and type 2 diabetes
- **PRIDE record:** PXD040434
- **Publication:** none linked in PRIDE

## Evidence recovered

116 RAW: 92 DIA runs numbered _1 ... _92 (Exploris 480) + 24 high-pH library fractions (Fr1-24); only a DIA-NN pg_matrix is deposited besides the RAW files.

## Why no SDRF was emitted

No sample information anywhere: nothing maps run numbers 1-92 to subject, group (lean / obese / type 2 diabetes) or time point (pre / post 8-week HIIT). The RAW-internal acquisition names also differ from the deposited names (e.g. deposited _1 was acquired as _S96), so even plate order cannot be trusted.

## Sources checked

PRIDE record and protocols; pg_matrix header; RAW header of the first run.

## Unblocking requirement

A run -> subject, group, time point table (and the deposited-name vs acquisition-name correspondence).
