# PXD071583 annotation report

Filipino early-stage NSCLC LUAD phosphoproteomics: paired tumor and normal adjacent tissue (NAT), TMT10plex in three batches (TMTB03/TMTB04/TMTB05), IMAC enrichment, Orbitrap Fusion Lumos DDA. Paper: *J Proteome Res.* 2026, 25(9):4957–4972 (DOI 10.1021/acs.jproteome.6c00453, PMID 42695893; closed access, no PMCID). Methods taken from the PRIDE protocols plus ACS SI on Figshare (Tables S1, S2, S6). Not in the community corpus (`sdrf-annotated-datasets/datasets/PXD071583/` missing) — new annotation.

## Templates

`ms-proteomics` v1.1.0, `human` v1.1.0, and `oncology-metadata` v1.0.0.

MS tissue study of human LUAD (not DIA, not cell-line, not single-cell). Oncology-metadata supplies the clinical columns used (age, sex, ancestry, smoking).

## Rows and files

1430 rows × 44 columns covering all **143** deposited Thermo `.raw` files (10 TMT10 channels each). File names `YYYYMMDD_Philippine_LC_TMTB0[345]_prot_Fxx-R[12].raw`.

- **TMTB03:** 47 files (F01–F24 × R1/R2 except undeposited `F01-R1`); 470 rows.
- **TMTB04:** 48 files; 480 rows.
- **TMTB05:** 48 files; 480 rows.

R1/R2 are technical replicate injections of the same hpHRP fraction. `comment[fraction identifier]` is the Fxx integer from the file name. TMTB03 R1 therefore uses identifiers **2–24** (gap at 1) rather than compacted 1–23, so F02-R1 and F02-R2 share fraction 2.

PRIDE protocol says 96 high-pH RP fractions concatenated into 12; deposited F01–F24 names outrank that sentence.

- Per-patient sex and smoking from Table S6 headers. Biological replicate is `1` for patients and `pooled` for both controls. Controls are numbered technical replicates 1–6 across the three batches × R1/R2 so the row coordinate stays unique.

## Technical values

From Proteome Discoverer 2.5 SEQUEST HT (`workflow.xml` in `20240301_B03_Phospho_CIT30MCO100.msf`), not inferred from the paper:

- Instrument: Orbitrap Fusion Lumos (MS:1002732).
- Acquisition: DDA (PRIDE:0000627), HCD (MS:1002481), Top10.
- Search enzyme: Trypsin (MS:1001251). Wet-lab also used Lys-C then trypsin; only the search enzyme is recorded.
- Tolerances: 10 ppm / 0.1 Da.
- Fixed: Carbamidomethyl C; TMT6plex K and Any N-term.
- Variable: Oxidation M; Deamidated N,Q; Phospho STY; Acetyl Protein N-term.
- Reduction/alkylation: DTT / IAA. Fractionation: hpHRP. Enrichment: IMAC.
