# PXD003932 — BLOCKED

## Exact blocker

All 143 RAW files are iTRAQ 4-plex runs (channels 114/115/116/117, deposited search: iTRAQ4plex K and N-term variable). The deposit contains no channel-to-sample map, so no per-channel sample identity (developmental stage / brain region / fraction) can be assigned without inventing it. Run basenames (Obv*/Obvb*) are opaque instrument counters and do not encode sample or channel.

Europe PMC has no full-text hit for PXD003932. Web search found no accessible design description.
- No Data/Code Availability repository links (Zenodo/figshare) were reachable since full text is unavailable.
