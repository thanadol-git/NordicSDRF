# PXD029937 — BLOCKED

## Exact blocker

The run manifest resolves TMT sets and fractions, but none of the checked evidence resolves the reporter-channel-to-sample mapping within those sets. Assigning treatment, organ region, time point, or biological replicate to a reporter would therefore require inference.

## Evidence checked

- PRIDE project record: `https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD029937`
- PRIDE file inventory: `https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD029937/files/all`
- Publication: `https://pmc.ncbi.nlm.nih.gov/articles/PMC11242497/` (DOI `10.3390/ijms25137480`)
- Publication supplement `ijms-3048391-supplementary.pdf`
- Deposited `raw_files.xlsx`

PRIDE lists 120 RAW files and declares TMT quantification. `raw_files.xlsx` provides exact acquisition labels such as `3183 TMT Set1 Fr01`, so RAW-to-set/fraction mapping is available. The publication describes recombinant α1-microglobulin experiments and the kidney/bone-marrow/cortex/medulla material, but neither it, its checked supplement, nor the deposited workbook states the exact reporter assignment for each set. Sequential RAW numbers encode acquisition order, not channel identity.

## Evidence needed to unblock

An authoritative TMT design matrix listing set, reporter, sample identifier, treatment/exposure, organ or kidney region, time point, biological replicate, and any pool/empty channel, joinable to the set names in `raw_files.xlsx`.
