# PXD043757 annotation report

Signalomics (multiplexed inhibitor bead, MIB, kinase-affinity enrichment) of *Staphylococcus aureus* ATCC 29213 treated with BTP-001, JK-274 or their combination. NTNU. Paper: Front Microbiol 2023, PMC10564113 (open access).

## Templates
`ms-proteomics` v1.1.0 (no organism template applies to bacteria).

## Rows and files
There are 69 rows, one per timsTOF run.
- **Raw data** is a single 207 GB `Raw_data.zip` holding 69 `.d` folders. The `comment[data file]` column uses the `.d` folder names inside that zip.
- **Design** comes from deposited files:
  - `summary.txt` maps each raw folder to an experiment name (`R1_180_BTP_1` …).
  - `Sample_groups.txt` maps each experiment name to condition, biological replicate and sampling time.
  - Untreated, BTP-001 0.5 or 1 µM, JK-274 5 µM, and BTP-001 0.5 µM + JK-274 5 µM were sampled at 10, 25 and 50 min (BR1–3).
  - At 180 min there were BR1–4, plus an extra JK-274 7.5 µM arm.

## Values
- **Sample:** organism `Staphylococcus aureus`, strain `ATCC 29213`, material type `cell`, enrichment `multiplexed inhibitor bead kinase enrichment`.
- **Factors:** `treatment` and `time` (minutes).
- **Instrument:** timsTOF Pro 2, from `analysis.tdf` inside the zip. PRIDE says only "timsTOF series".
- **Sample prep:** DTT and iodoacetamide; on-column trypsin.
- **Search** (MaxQuant 2.1.3.0, deposited `parameters.txt`/`summary.txt`):
  - Carbamidomethyl C fixed.
  - Oxidation M, Acetyl protein N-term and Deamidation NQ variable.
  - TOF MS/MS tolerance 25 ppm. Precursor tolerance is not in `parameters.txt`, so it is set to `not available`.

## Validation
- `parse_sdrf` (CI style, warnings only) and the review gate pass.
- `tools reconcile`: every annotated value agrees with the deposit record.
