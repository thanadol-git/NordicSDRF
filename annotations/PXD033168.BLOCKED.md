# PXD033168 — BLOCKED

## Exact blocker

The deposit does not provide a source-sample-to-RAW-file map for the 343 RAW files. The RAW names are acquisition identifiers such as `QEHF_200403_156.raw` and do not identify the patient/control source. The project describes 78 cardiac-amyloidosis patients, 12 donor controls, triplicate injections, and some additional technical replicates, but those cohort counts are insufficient to assign any individual RAW file to a source without inventing the mapping.

## Evidence checked

- PRIDE project record: `https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD033168`
- Complete PRIDE file listing: `https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD033168/files/all`
- Linked publication metadata: PMID 36209425; DOI `10.1080/13506129.2022.2127088`. No open full text or supplementary sample map was available through Europe PMC.
- All 14 non-RAW deposited files. They are Proteome Discoverer `.msf`/`.pdResult` databases ranging from about 3.3 GB to 141 GB; there is no deposited sample sheet, file list, spreadsheet, or text mapping file.
- Community annotation directory: absent (GitHub directory returned 404).

## Why an SDRF was not written

Assigning the numeric RAW filenames to patients, controls, injection replicates, or amyloid subtype from cohort totals would be an invented sample/run mapping. A supportable annotation requires an accession-specific export from Proteome Discoverer or a sample sheet that explicitly links each RAW filename to the source sample and condition.
