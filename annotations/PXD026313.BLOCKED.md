# PXD026313 — BLOCKED

## Exact blocker

The accession contains both TMT and label-free acquisitions, but no checked source provides the exact reporter-channel-to-biological-sample mapping for the TMT sets. Creating TMT SDRF rows would require guessing which biological replicate occupies each reporter channel. Producing only the label-free subset would silently omit a substantial part of the accession.

## Evidence checked

- PRIDE project record: `https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD026313`
- PRIDE file inventory: `https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD026313/files/all`
- Publication: `https://pmc.ncbi.nlm.nih.gov/articles/PMC8713813/` (DOI `10.1073/pnas.2112836118`)
- Deposited `RAW_File_List_4strains.pdf`
- Deposited TMT result workbooks `3316_TMT_Set1_Spombe_Proteins.xlsx`, `3316_TMT_Set2_Scerevisiae_Proteins.xlsx`, `3316_TMT_Set3_Pstipitis_Proteins.xlsx`, and `3316_TMT_Set4_Kmarxianus_SProteins.xlsx`
- Deposited LFQ result workbooks for the same four yeasts

PRIDE lists 177 RAW files and declares both TMT and MS1-intensity label-free quantification. The RAW-file PDF separates acquisitions by species/experiment and the TMT result sheets expose biological ratio names such as organism replicates versus a reference. Neither the PDF, the publication, nor the checked result sheets state the reporter assignment needed to join those sample names to exact TMT channels. RAW acquisition numbers do not encode that missing mapping.

## Evidence needed to unblock

An authoritative experimental-design table or acquisition manifest that maps, for every TMT set, each reporter channel to the exact organism/sample/biological replicate and reference pool. The mapping must also identify the RAW files belonging to each set. Without that table, channel rows cannot be written safely.
