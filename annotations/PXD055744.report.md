# PXD055744 annotation report

*Pseudomonas aeruginosa* clinical ST235 strain 6378/09 (imipenem-resistant, VIM-2) vs reference strain ATCC 27853, each challenged with imipenem at 0, 0.1×, 0.25×, 0.5× and 1× MIC. SINTEF/NTNU. Paper: Front Cell Infect Microbiol 2025, PMC12571913 (open access).

## Templates
`ms-proteomics` v1.1.0.

## Rows and files
There are 30 rows, one `.d.tar` per sample, named `sample-<strain><x>-<y>`.
- **Strain letter:** A = clinical strain and B = ATCC 27853 (paper: "ST235 (A1-A5) and ATCC 27853 (B1-B5)").
- **Interpretation (please check):** the first digit `x` (1–3) is read as the biological replicate and the second digit `y` (1–5) as the dose level, with 1 = untreated, 2 = 0.1×, 3 = 0.25×, 4 = 0.5× and 5 = 1× MIC.
  - The paper has three biological replicates and five dose levels, which is the only reading consistent with 3 × 5 files per strain.
  - The deposited MaxQuant `summary.txt` only repeats the file tags.
- **Technical replicates:** the paper mentions two technical replicates per condition, but only one run per sample is deposited.

## Values
- **Sample:** organism `Pseudomonas aeruginosa`; `strain or breed` is the strain.
- **Dose:** `characteristics[dose]` is the absolute imipenem concentration. MIC is 16 mg/L for the clinical strain and 2 mg/L for ATCC 27853, so 1.6–16 and 0.2–2 mg/L, as in the paper.
- **Factors:** `strain or breed` and `dose`.
- **Instrument:** timsTOF Pro 2, from `analysis.tdf`. PRIDE lists timsTOF Pro.
- **Search** (MaxQuant 2.0.3.0, deposited `summary.txt`):
  - Carbamidomethyl C fixed.
  - Oxidation M, Acetyl protein N-term and Deamidation NQ variable.
  - Tolerances are not stated, so they are set to `not available`.

## Validation
- `parse_sdrf` (CI style, warnings only) and the review gate pass.
- `tools reconcile` flags trypsin as not named in the PRIDE record. The paper and the deposited MaxQuant search name trypsin (Trypsin/P) only as the search enzyme; the digestion step itself is not described. Trypsin is kept as the evident digest enzyme.
