# PXD030529 - Viking Age fur palaeoproteomics (Brandt et al., PLoS One 2022)

## Study
Fur from Danish Viking Age high-status graves analysed by PMF (MALDI) and LC-MS/MS; keratin species identification (beaver, sheep, squirrel, Mustela). PRIDE submission is PARTIAL.

## Templates
ms-proteomics v1.1.0 + vertebrates v1.1.0 (animal samples, non-model; no cell-line, clinical or DIA templates apply).

## Scope: deposited vs annotated
Annotated: all 8 RAW files (8 rows x 36 columns) (4 Exploris 480 files F1, F2, F3, F8; 4 QE HF-X files: Fyrkat Urea, Fyrkat GuHCl, Urea blank, GuHCl blank), 8 rows x 34 columns, label free, one fraction each. Not annotated: MALDI PMF zip, MaxQuant output archives, FASTA.

## Key decisions
- Extraction method (urea vs GuHCl) is the factor value (with a backing characteristics column). Source names carry site + inventory number + fragment (S1 File Table S6 Lab ID map). The two Fyrkat extractions share one source (Fyrkat_Grave4_D158-1966, biological replicate 1 Urea / 2 GuHCl).
- Collision energy: 30 NCE (Exploris 480 files), 28 NCE (QE HF-X files), from S1 File.
- Reduction/alkylation reagents per protocol (urea: TCEP+iodoacetamide; GuHCl: TCEP+chloroacetamide), written per row.
- Dissociation HCD (MS:1000422). Cleavage Trypsin (protocol), MaxQuant used Trypsin/P semispecific; modifications and 20 ppm fragment tolerance from MaxQuant summary/parameters.
- Blanks: sample type `negative control`, organism/part not applicable.

## Not available values
Precursor tolerance, organism part of F2, developmental stage, strain, sex; disease not applicable.
