# PXD010364 — BLOCKED

## Status

No SDRF was retained.  The submitted raw files cannot be assigned safely to the
reporter-channel sets from the public evidence.

## Public evidence checked

- PRIDE project `PXD010364`, *Preeclampsia causes sex-specific transcriptional
  and proteomic changes in foetal erythroid cells*: 20 raw files,
  `QEHF_170807_05.raw` through `QEHF_170807_24.raw`, and one Proteome
  Discoverer `.msf` result file.
- Masoumi et al. (2019), PMID `31027199`, PMCID `PMC6514549`, DOI
  `10.3390/ijms20082038`.
- The open supplementary workbook (`Supplementary Table S2.xls`, sheet `All
  detected proteins`) identifies ten reporter channels and samples: five
  `Ctrl`/normotensive samples and five `Test`/preeclampsia samples.
- The open supplementary methods state that the labelled samples were combined
  into **two separate TMT sets**, each with five samples and a reference, then
  fractionated for LC-MS/MS.

## Blocking ambiguity

The 20 deposited raw filenames only identify one contiguous fraction series.
Neither PRIDE metadata, the paper, nor the accessible supplement says which raw
files belong to each of the two TMT sets, which reference channels were used,
or which set-specific reporter channels occurred in each file.  Repeating all
ten reporter channels over every raw file would invent that mapping.

The deposited `.msf` result file is 4.7 GB and is the only possible remaining
public place to resolve this; it was not downloaded blindly.  A submitted
channel-to-raw/fraction map or an exported set design is required before an
SDRF can be produced.
