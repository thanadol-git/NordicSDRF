Three subpopulations (CSC spheroids, migrating CSCs, serum-differentiated cells) of patient T78 (WHO grade IV GBM) were compared with 3-plex dimethyl labeling, Orbitrap Fusion, Proteome Discoverer 2.0/Mascot, with and without SuperQuant. Not in the community corpus (no directory), so no existing-annotation audit was needed.

- **Replicate -> raw file (inferred)**: the paper does not name files. PD exports list spectrum files Rep1_2Da.raw / Rep2_2Da.raw / Rep3_2Da.raw inside GBM-2Da1/2/3 exports respectively, so Replicate N = GBM-2DaN.raw.
- **Label values**: `NT=DIMETHYL0/4/8;AC=PRIDE:0000848/0000850/0000852` (light/medium/heavy), matching convention already used in other annotations here. `sdrf-tools build` only recognises TMT/iTRAQ/SILAC channels, so the table was built with SILAC light/medium/heavy placeholders (assay name set explicitly to `GBM-2DaN-DIMETHYLx`) and the `comment[label]` values were substituted by `sed` on the build output. No other edit was made to the built file.
