## Limitations and calls to attack in review

- The B/G/L → group mapping is an inference from group sizes (unique solution), not stated in the deposit — highest-risk call.
- Per-subject age/sex not available (cohort summaries only).
- The file mixes DDA (library) and DIA runs; sdrf-tools structure recommends one SDRF per acquisition method. Kept in one file to match the tracker's one-SDRF-per-PXD convention.
- Acetylation site (protein N-term) assumed from Spectronaut defaults; PRIDE says only 'acetylation'.
- Early-stage OA is the authors' label for degenerative meniscal tear patients; disease annotated as 'osteoarthritis, knee' for both OA groups.
