# PXD047218 annotation review

The 24-run draft passed the official SDRF validator, and all run names, dose labels, and repeated injections matched the deposited `Sample_overview.xlsx` and `AllRawFiles.zip`. Independent review failed because the PRIDE sample-processing protocol states an on-bead **Trypsin/Lys-C mix**, while the draft's required `comment[cleavage agent details]` column contained only Trypsin. The DIA-NN Trypsin/P setting is a search setting, not proof that the physical digestion omitted Lys-C.

The active SDRF template and table builder allow one ontology-backed cleavage-agent value per row. A trial with two pipe-separated agents built successfully but silently retained only the first agent. The draft has therefore been moved to the accession-scoped ignored scratchpad (`scratchpad/PXD047218/draft.sdrf.tsv`); it is **not approved for contribution or commit**. The independent report is `scratchpad/PXD047218/independent_review.json`. The deposited workbook also documents a 24-hour exposure, which remains to be represented if a suitable field is available.

Resolution requires a validator-compatible way to record both Trypsin and Lys-C without misusing another field. The template or builder may need an explicit multi-enzyme extension before this accession can be approved.
