# PXD060087 annotation report

## Result

Annotated all 99 deposited RAW files from the diabetic-wound proteomics study.

The project was returned by the Roskilde search because the affiliation/search metadata contains the term, but the annotation is based on the deposited file set and publication evidence. Human HaCaT in-vitro samples and mouse skin samples are separated by the date/model naming in the raw filenames; the original sample codes are retained as source names.

## Evidence

- PRIDE: https://www.ebi.ac.uk/pride/archive/projects/PXD060087
- Publication: PMCID PMC12685990; PMID 40897924
- Instrument: LTQ Orbitrap Velos (PRIDE: MS:1001742)
- Sample codes and technical-injection suffixes are preserved from PRIDE filenames.
- Where the filename did not resolve a more specific biological label, the SDRF retains `not available` rather than inventing one.
