Status: blocked; no SDRF written. No existing annotation was found in sdrf-annotated-datasets (Step 0.5).

## Exact blocker

The TMT10plex channel-to-sample map is not recoverable from accessible evidence. The study (Zucker diabetic fatty rat heart, ZDF fa/fa vs lean fa/+, 6/12/24 weeks) was labelled with TMT-10plex, and the deposit holds only the 24-week validation run set (20 RAW files: 1952-1970 "24w-1..10-re" and 1974-1992 "24w-1..10-re-excl", i.e. 10 IEF fractions each measured twice, the second time with an exclusion list). Which of the 10 reporter channels is which rat/genotype (and how many of each) is not stated in the PRIDE record, file names, or the deposited Proteome Discoverer .msf. Inventing the channel identities is forbidden by the skill (Step 6.1).
