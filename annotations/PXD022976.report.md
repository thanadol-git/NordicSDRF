# PXD022976 annotation report

Status: validated annotation; independent review pending.

## Result
24-row, 48-column SDRF (one row per RAW file). Templates: `ms-proteomics` v1.1.0, `crosslinking` v1.0.0, `human` v1.1.0. Not previously annotated in `sdrf-annotated-datasets` (no PXD022976 directory).

Dataset: Aarhus University (Enghild lab); Nielsen et al., J Biol Chem 2021, PMID 34097874. DSSO cross-linking MS (MS2-MS3 on an Orbitrap Eclipse) of recombinant human TGFBIp (wild type, R124H, R555W, A546T) from SDS-PAGE monomer and dimer bands, three replicates each (4 variants x 3 replicates x 2 bands = 24 RAW files). The three `.pdResult` files are search outputs and have no rows.

## Design
- Source name: `TGFBIp_<variant>_rep<n>_<band>`. `characteristics[biological replicate]` = 1-3 from the run names.
- Factors: `factor value[protein variant]` (wild type, R124H, R555W, A546T) and `factor value[gel band]` (monomer band, dimer band).
- File code mapping WT/RH/RW/AT to wild type/R124H/R555W/A546T is inferred from the paper's variants and the file codes; it is not stated in the deposit.

## Technical values
- Instrument Orbitrap Eclipse: confirmed from the RAW header (range read, 256 KB) and PRIDE.
- Digest: trypsin (18 h) then GluC (4 h). Recorded as two `comment[cleavage agent details]` columns; `parse_sdrf` accepts this. `build` does not support repeating this column (the contract marks it single), so the second column was inserted into the built file by script and the result re-validated.
- Cross-linker DSSO `XLMOD:02126` (verified in OLS; the template YAML example `XLMOD:02010` is actually EDC and was not used). 155 uM DSSO, about 50:1 over 3.1 uM protein, 30 min, quenched with Tris-HCl.
- Modifications from the deposited PD result (wild-type file): Carbamidomethyl C fixed; Oxidation M, Deamidated N, DSSO hydrolyzed and DSSO Tris monolinks on K variable. The two monolinks are mapped to `UNIMOD:1878` (Xlink:DSSO[176]) and `UNIMOD:1880` (Xlink:DSSO[279]) by mass and definition. The paper mentions only Carbamidomethyl and Oxidation.
- Tolerances 10 ppm / 20 ppm (paper and pdResult). The 0.5 Da MS3 tolerance cannot be expressed.

## Caveats
- Sample is a purified recombinant protein: `organism part`, `cell type` and `disease` are `not applicable`; `material type` is `synthetic`, `sample type` `study sample` (modelling choices); `age` `not available`, `sex` `not applicable`. Expression host Freestyle 293-F is not recorded as a sample cell type.
- `collision energy` is `not available`: the paper says 20% CID (MS2) / 35% (MS3) while the method file is named CID25/CID35, and the template pattern needs NCE/eV.
- `crosslinking temperature` is `not available` (room temperature, not numeric). `crosslink enrichment method` is `not available`.
- Acquisition method DDA is inferred from the MS2_MS3 triggered method.
- Only the wild-type pdResult was inspected; the other three search results were not opened.
- Supplementary tables were not read.

## Validation
- `parse_sdrf validate-sdrf -t ms-proteomics -t crosslinking -t human`: "Everything seems to be fine" (full ontology run).
- `python -m tools structure`: OK. `python -m tools check --offline`: CLEAN (0 hallucinated).
- `python -m tools reconcile` findings, both judged false positives: (1) organism "contradicted" because the record names only Sus scrofa, which comes from porcine pancreatic trypsin; the protein is human (PRIDE NEWT:9606, human cDNA, 293-F cells). (2) cleavage agent "incomplete" because the reconcile tool reads only the first cleavage column; the file has both trypsin and glutamyl endopeptidase.
- Independent adversarial review not run (not permitted in this run); review gate not enforced.
