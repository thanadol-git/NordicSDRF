# PXD021266 — annotation blocked

## Dataset

- **Title:** Structure dynamics of ApoA-I amyloidogenic variants in small HDL increase their ability to mediate cholesterol efflux (HDX-MS)
- **PRIDE record:** PXD021266
- **Publication:** Nilsson O. et al., J Lipid Res 2021, DOI [10.1194/jlr.RA120000920](https://doi.org/10.1194/jlr.RA120000920), PMCID [PMC7890215](https://pmc.ncbi.nlm.nih.gov/articles/PMC7890215/)

## Evidence recovered

- 45 RAW files (Q Exactive Plus in all RAW headers; PRIDE says Q Exactive) of recombinant ApoA-I WT, L75P, L174S in POPC nanodiscs and lipid-free WT, labelled in D2O for 0/30/300/3000/9000 s, duplicate runs (`HDX_Exp_table.csv`).
- RAW method headers: 8 undeuterated t=0 runs use `se_HDX_180404.meth` (Full MS / dd-MS2, used for PEAKS peptide ID); the other 37 use `HDX_180529_SIM.meth` (full-MS only).

## Why no SDRF was emitted

The HDX measurements are full-MS-only acquisitions. `comment[proteomics data acquisition method]` is required, forbids reserved words, and PRIDE:0000659 has no descendant for MS1-only acquisition (checked on OLS: DDA, DIA, SWATH, MSE, HDMSE, PAcIFIC, AIF, SONAR, PRM, SRM, diaPASEF). SDRF also has no column for deuterium exchange time. Annotating only the 8 DDA identification runs would misrepresent the dataset as a label-free proteomics study.

An SDRF acquisition-method term for full-scan MS1 acquisition (or an HDX-MS template) in the proteomics-sample-metadata spec. If a partial SDRF of the 8 undeuterated DDA runs is wanted, it can be built from the same evidence.
