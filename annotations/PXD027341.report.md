# PXD027341 annotation report

## Evidence used

- PRIDE project metadata describes one TMT10 set containing seven primary and three non-matched recurrent glioblastoma tumour samples; one primary sample is marked highly necrotic.
- Deposited `GBM_tumour_tissue__TMT10plex_HiRIEF_3-10_labelling_scheme.txt` supplies each TMT channel’s laboratory ID and submitted tumour-type label.
- The project protocol specifies Lys-C/trypsin digestion, TMT labeling, HiRIEF pH 3–10 fractionation, and Q Exactive HF data-dependent acquisition.

## Annotation scope

The SDRF represents the 40 deposited RAW fraction files crossed with the 10 TMT channels (400 assay rows). It retains **primary**, **recurrent**, and **primary - necrotic** exactly as reported in the deposited channel map; the source samples are not paired or otherwise related beyond that information.
