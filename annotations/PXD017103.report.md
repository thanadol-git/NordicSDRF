# PXD017103 annotation report

## Study
"Hypoxia response in barley - proteomics analysis" (Andrzejczak et al., Int J Mol Sci 2020, doi:10.3390/ijms21041546, PMC7073221). Barley (Hordeum vulgare cv. Golden Promise) wild type (WT) and phytoglobin-overexpressing (HO) 8-day-old seedlings, 24 h hypoxia (WT24, HO24) vs normoxia; leaves; TMT 10plex (8 tags + 126 pool channel), 2D-LC-MS/MS (high-pH RP, 5 fractions), Q Exactive HF, Proteome Discoverer 2.1 + Mascot. Not in community corpus.

## Templates
ms-proteomics v1.1.0 + plants v1.1.0 (MS; plant). No extra experiment template needed (TMT is a label column, DDA).

## Scope
Deposited: 10 RAW (2 TMT mixes x 5 fractions), 2 PD/pepXML-protXML result files, a text file explaining the TMT layout. Annotated: all 10 RAW x channels = 90 rows x 40 columns (2 mixes x 9 channels x 5 fractions). Not annotated: search outputs.

## Key decisions
- Channel map from the deposited `Explaningrawfilessetupandnames.txt` (Mix 1 = biological replicates 1+2, Mix 2 = replicates 2+3). Channel 126 in each mix is a pooled reference (MixS1, MixS2): annotated as pooled sample, biological replicate "pooled", factors not applicable.
- Biological replicate 2 is labelled once and present in both mixes: same source name (WT-2 etc.), measured twice, so technical replicate 1 (Mix 1) and 2 (Mix 2).
- Factors: genotype (wild type / phytoglobin overexpression) and treatment (normoxia 24 h / hypoxia 24 h); matching characteristics[genotype] and [treatment] columns.
- Modifications from the deposited PD/Mascot workflow header in the pepXML: Carbamidomethyl C fixed, TMT6plex K and N-term fixed, Oxidation M variable; tolerances 20 ppm / 0.05 Da (same). TMT10plex tags have the same mass as TMT6plex (UNIMOD:737).
- Instrument Q Exactive HF (protocol text; PRIDE metadata only says Q Exactive); HCD NCE 30; MS1 range 300-2000; DTT reduction (extraction buffer), iodoacetamide alkylation; ms2 analyzer orbitrap (MS2 resolution 60000).
- disease not applicable (healthy plants; hypoxia is the treatment).

## Not available
Cell type, growth condition and genotype/treatment for the pooled reference rows.

## Inferred vs stated
- Inferred: WT-1 = TMT127C. The deposited text file omits WT-1 from the Mix 1 list; the paper states replicate 1 used 127C, 127N, 128C, 128N for the four treatments in the order WT, HO, WT24, HO24 (consistent with Mix 2 and HO-1=127N).
- Inferred: file-to-mix mapping from file names ("replicates 1 and 2" vs "2 and 3"); fraction number from the "-fractionN" suffix.
- Inferred: sample composition of the 126 channel is not stated; only "MixS1/MixS2" in the text file.
- Stated: everything else (paper, PRIDE, deposited PD header).

## Conflicts
- Instrument: PRIDE metadata "Q Exactive" vs protocol "QExactive HF"; the protocol text was used (RAW headers not read).
- Labelling: paper says TMT 10plex; Mascot search used TMT6plex mods (same mass).
