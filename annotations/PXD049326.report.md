# PXD049326 SDRF annotation report

## Study
High-throughput targeted (PRM) sex estimation from acid-etched human dental enamel (AMELX/AMELY peptides), applied to archaeological (Jordan, St. Poelten) and modern (dental school, Raton Perez deciduous teeth) samples, with DDA discovery runs and synthetic peptide standard curves (PMID 39324540).

## Templates
ms-proteomics + human v1.1.0

## Scope: deposited vs annotated
538/538 RAW.

## Sample map
Deposited MetadataTable.xlsx (raw file, specimen, type, cohort, method) used for the 24 Jordan DDA runs (run number -> SM specimen) and checked against file names; all other specimen codes are in the file names. 11 runs absent from the table (Dentist PRM F10-F14/M9/M12/M14/M15, two blanks) follow the same naming and were annotated from their names.

## Key decisions
No protease: enamel is acid-etched (10% TFA) and the endogenous peptides analysed directly -> unspecific cleavage, no reduction/alkylation. Sex is filled only for the modern cohorts whose codes carry F/M (known-sex reference teeth); archaeological sex is the study's output and left 'not available'. Standards (synthetic peptides) and blanks carry organism 'not applicable'. Re-injections numbered as technical replicates.

## Not available / not applicable
Age, ancestry, tooth type; standard concentrations per level.

## Inferred vs stated
Raton Perez PRM sex not taken from DDA codes (different code space).

## For the reviewer to attack
