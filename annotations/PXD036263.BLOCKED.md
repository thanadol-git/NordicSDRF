# PXD036263 — annotation blocked

The deposited MS_file_info.xlsx workbook supplies species, tissue, sample, and
run mapping, but it conflicts with the species suffixes of multiple deposited
RAW filenames. For example, the workbook maps run Fusion_181221_40 to a tufted
duck sample while the public RAW file is Fusion_181221_40_C.raw. Similar
discrepancies prevent an evidence-backed mapping of every RAW file.

A corrected run manifest from the depositors is required before an SDRF can be
created.
