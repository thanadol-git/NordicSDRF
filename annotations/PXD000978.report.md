## Limitations and calls to attack in review

- Multiplexed rows of one RAW file share one assay name (the file name without extension), as the spec README requires for TMT runs; comment[label] distinguishes the channels.
- The paper states a 10 ppm precursor tolerance, but the deposited Proteome Discoverer search summaries (the searches behind the deposited results) use 5 ppm; 5 ppm is annotated.
- Samples were alkylated with iodoacetamide, yet the deposited searches use Methylthio (C) as a variable modification and no carbamidomethylation; the searched modifications are annotated as-is.
- Table I is an image; the channel map was transcribed from the rendered page (screenshot saved). Set N in the pepXML folder names is taken to be Pool N in Table I; no file states this equivalence explicitly.
- The internal standard (126) mixes both muscles and both genotypes of its set: organism part 'skeletal muscle tissue', disease/genotype/factor values 'not applicable', biological replicate 'pooled', pooled sample lists its four source names (the validator warns on SN= values, which the spec allows).
- The order of the three MS runs in the paper (run 3 used an exclusion list) cannot be tied to the dates: folder names mark both the 2012-02 and 2012-05 runs as exclusion runs. Technical replicates are numbered chronologically.
- Each MS2 cycle has both HCD (quantification) and CID scans, so both dissociation methods are annotated and no single collision energy column is given (HCD 50%, CID 30%).
- Sex and strain background of the dy3K mice are not stated.
