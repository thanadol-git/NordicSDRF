# PXD050767 SDRF annotation report

Status: validated annotation; independent review pending

Dataset: "Non-canonical RNA-binding of the histone lysine demethylase KDM5 through interactions with G-quadruplex sequences" (Aarhus University, Ørom lab; MS by D. Meierhofer, MPIMG). Paper: PMC12241816 / PMID 40642767.

## Result
- File: PXD050767.sdrf.tsv, 6 rows x 41 columns (6 RAW files; txt.zip and proteinGroups.txt are search outputs, not rows).
- Templates: ms-proteomics v1.1.0, human v1.1.0, cell-lines v1.1.0.
- Design: KDM5A immunoprecipitation from K-562 lysate, +/- RNase A/T1, 3 replicates each, in-gel tryptic digest, label-free DDA on Q Exactive Plus, MaxQuant.
- Groups: 3 rows "RNase A/T1 treatment" (silver_plus_1-3), 3 rows "no RNase treatment" (silver_minus_1-3). factor value[treatment] is the only factor.
- Existing annotation in sdrf-annotated-datasets: none, so annotated from scratch.

## Validation
- `parse_sdrf validate-sdrf` (online OLS, all three templates): no errors, warnings only: treatment values ("RNase A/T1 treatment", "no RNase treatment") are free text not in NCIT/EFO; "K-562" is not matched in CLO/BTO/EFO (identity is carried by the Cellosaurus columns CVCL_0004).
- A `--use_ols_cache_only` run reports an error for characteristics[sample type]="study sample" not in the PRIDE cache; this is a cache gap (the online run accepts it).
- `python -m tools structure`: OK. `tools check --offline`: CLEAN (0 hallucinated). `tools reconcile`: values agree with the record.

## Caveats (flag for review)
1. The plus/minus RNase mapping is inferred from file names ("silver_plus" = RNase-treated); the paper does not state it explicitly. If reversed, swap characteristics[treatment] and the factor.
2. sex = female and disease = chronic myeloid leukemia come from the K-562 cell line identity (Cellosaurus), not from the deposit; age is `not available`.
3. Instrument: PRIDE metadata says "Exactive Plus" (MS:1002526); the paper and the RAW header (range read of 4 MB of one file) say Q Exactive Plus, which is used (MS:1002634).
4. Modifications come from the PRIDE/paper text (MaxQuant 1.5.0.0); mqpar.xml is not deposited and txt.zip was not opened.
5. Reduction/alkylation reagents `not available` (prep cites an external protocol). Collision energy written "25 NCE"; HCD is inferred from the platform.
6. Single protease (trypsin), so one cleavage-agent column; the two-protease option did not apply.
7. Independent review (Step 9.5) was not performed: no subagent was allowed in this run, and the review-gate was not run. Do not treat as approved.
