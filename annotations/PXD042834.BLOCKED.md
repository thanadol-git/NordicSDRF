# PXD042834: run-to-condition key required

The [ProteomeXchange record](https://proteomecentral.proteomexchange.org/cgi/GetDataset?ID=PXD042834) and [paper](https://link.springer.com/article/10.1038/s44319-024-00142-5) describe a Col-0 versus `atg2-1` experiment, each exposed to ethanol vehicle or NAA. Twelve deposited Bruker `.d.zip` RAW archives are numbered S1–S12, but no accessible source assigns any number to a genotype and treatment. Three runs per combination would be plausible but is not an accession-specific mapping. No sample-level SDRF is approved.

Checked the accession-scoped PRIDE file list, the article and its [figure 5 source-data ZIP](https://static-content.springer.com/esm/art%3A10.1038%2Fs44319-024-00142-5/MediaObjects/44319_2024_142_MOESM5_ESM.zip), and the deposited `DIANNoutput_dir.zip` central directory and processing log. The figure 5 package has microscopy images and two numerical workbooks but no proteomics run key. The [DIA-NN log](../scratchpad/PXD042834/diann-report.log.txt) lists all twelve S1–S12 input paths, with no condition assignment. The paper's Data Availability statement points to PRIDE for the mass spectrometry data and to BioImage Archive for microscopy; it does not identify a separate proteomics sample sheet.

The paper's LC-MS Methods describe an Exploris 480 and a mesenteric-artery-derived library, whereas the deposited RAW archive names identify timsTOF `.d` DIA acquisitions. This apparent cross-study methods inconsistency needs source clarification before using the paragraph for instrument or search settings. An author/depositor run-to-condition table is required to annotate the 2 × 2 comparison safely.
