# PXD057996 — annotation blocked

## Dataset

- **Title:** Map of the neuronal tissue O-glycoproteome reveals specific traits in the secretogranin family
- **PRIDE record:** PXD057996
- **Publication:** PMID 40449597

## Evidence recovered

11 ZIPs (Rat, CAD, N2A, SY5Y, CSF, Synaptosome, Pig, Prostate, STC, TDM_5xSec, sushi_stim; 0.9-41 GB) holding mostly "subHCD" MGF files split by glycan composition, plus a PSM key (Key_for_PRIDE_Database.xlsx) linking PSMs to spectrum files and tissue (11 sample types, 4 species). PRIDE lists no RAW category files.

## Why no SDRF was emitted

Several sets are TMT10plex (e.g. rat brain "WT_T2_T9_T18_T19") but no channel -> genotype/sample layout is deposited or in the record; the secretome ZIPs (TDM_5xSec, sushi_stim) are not covered by the key at all. The data files are derived, glycan-split peak lists rather than one file per acquisition, which does not fit the one-row-per-run SDRF model.

## Sources checked

PRIDE record, PSM key (unique spectrum file / tissue / ZIP / taxon pairs), ZIP central directories.

## Unblocking requirement

Per-set TMT channel layouts and a list of the original acquisitions per sample (or the original RAW files).
