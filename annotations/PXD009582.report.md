# PXD009582 annotation report

## Scope

All 29 deposited mzML files are represented as label-free Synechocystis assays.

## Evidence and decisions

- PRIDE describes a Synechocystis PCC 6803 turbidostat study testing light and carbon limitation. Each raw filename identifies a submitted culture-condition token and biological replicate; both are retained exactly.
- The archive contains several naming series (`co2-*`, `Cyano-*`, `*glc`, `*dcmu`, and `*-ja8`) without a deposited crosswalk translating every submitted code to physical concentration or treatment units. The SDRF deliberately preserves those literal identifiers rather than inferring units.
- PRIDE specifies Lys-C/Trypsin digestion, label-free maXis acquisition, fixed cysteine carbamidomethylation, and variable methionine oxidation.
