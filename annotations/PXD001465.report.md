# PXD001465 SDRF annotation report

Status: validated annotation; independent review pending

Dataset: Effect of TGF-beta 2 on pig gut epithelial cells (Aarhus University, Denmark). Paper: Nguyen et al., PLoS One 2015, PMID 25668313.
Existing community annotation: none found in sdrf-annotated-datasets (checked at start).

## Result
- 160 rows x 38 columns; templates ms-proteomics v1.1.0 + vertebrates v1.1.0.
- Design (paper Table 1): PsIc1 porcine intestinal epithelial cells, CON / TGF-b2 / LPS / TGF-b2+LPS, biological triplicates (A-C), 4 iTRAQ 4-plex sets (114 = common reference pool), each SCX-fractionated into 10 fractions: 4 plexes x 4 channels x 10 fractions = 160 rows. 12 sample sources + 4 reference-pool sources (one per plex).
- Technical: TripleTOF 5600 (from wiff header), DDA, CID, trypsin, SCX, 15 ppm / 0.2 Da, DTT/MMTS, modifications Methylthio(C) fixed, iTRAQ4plex (K, N-term fixed; Y variable), Oxidation(M), Deamidated(N,Q) (from the deposited Mascot search output). One cleavage-agent column only (single protease).
- Factor value: treatment.

## Validation
- parse_sdrf validate-sdrf: no errors; warnings only: treatment values "Transforming Growth Factor Beta 2", "... and Lipopolysaccharide" not found in NCIT/EFO lists.
- tools check --offline: CLEAN. tools structure: OK.
- reconcile: 1 BLOCKER cleavage_agent_unsupported. Trypsin is stated in the paper ("trypsin digestion overnight") but not in the PRIDE prose; kept, evidence in paper.

## Caveats
- Raw data is a single 5.4 GB zip (sus_TNF.zip); file names were taken from its ZIP central directory by range read. The file-to-plex/fraction assignment is inferred from file names: plex 1 = 2013-08-19 "Plex1- 1..4" + 2013-08-30 "plex1-5..10"; plex 2-4 = 2013-08-30 "plex N-1..10". The file names say "TNFa", not TGF, and no deposited file states the mapping.
- 15 other wiff files (2013-09-06 EBX plex 1-1..5 plus an empty plex 1-6; 203-09-20 DTH TNFa Plex 1-1..10) are not annotated: they do not fit the 4x10 design and have no mgf/search evidence. Possibly a separate TNF experiment or repeat runs.
- Instrument conflict: PRIDE and the wiff header say TripleTOF 5600; the paper says Q-Star Elite. Raw metadata used. Only one small .wiff metadata file (~390 KB compressed) was fetched; no .scan data.
- Carbamidomethyl is mentioned in the PRIDE processing text but not seen in the search output; omitted. Only 6-of-10 style mgf files exist for some fractions.
- Sex, strain/breed, developmental stage (cells from a 6-month-old pig, passaged 5-25) left as not available. Disease set to "normal" (untransformed IEC line). Doses/time (3 ng/mL TGF-b2, 1 ug/mL LPS, 24 h) are in the paper but not encoded in the treatment values.
- Gel-based (2DE/MALDI) part of the paper has no deposited raw data; not annotated.
- Independent adversarial review not performed here (no subagents allowed); review-gate not run.
