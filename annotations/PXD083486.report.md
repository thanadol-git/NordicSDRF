# PXD083486 SDRF annotation report

## Study
"Proteomic profiling of mouse tissues by data-independent acquisition (DIA) on Thermo Scientific Orbitrap Astral". Four mouse tissues (brain, heart, liver, lung), label-free DIA, Orbitrap Astral + Evosep One (60 SPD), SDC lysis, TCEP/chloroacetamide, trypsin digestion. Submitter: Bharath Nair, SDU (PI Rogowska-Wrzesinska). No publication or DOI in the PRIDE record (not searched beyond the record fields), so the PRIDE protocols are the narrative source.

## Templates
ms-proteomics v1.1.0 + vertebrates v1.1.0 (mouse) + dia-acquisition v1.1.0. No cell-lines/clinical/oncology template (healthy/disease status not stated).

## Scope: deposited vs annotated
PRIDE file list read over all pages (page 0 = 37 files, page 1 empty). Deposited: 4 spectrum files (.mzML, categorised RAW; converted by ThermoRawFileParser 1.4.4 from original .raw), a submitter-provided metadata_sdrf.tsv (not used as a source; the SDRF was rebuilt from raw headers/protocol), and 32 DIA-NN report .tsv files (astral_* and qef_*: 4 spectral-library strategies x foreign-species/random-shuffling entrapment x precursor/protein). All 4 mzML files are annotated (4 rows). The qef_* DIA-NN outputs refer to runs QExHF03753/03755/03757/03761 (Q Exactive HF), which are NOT deposited as data files; they are out of scope and not annotated.

## Key decisions
- One source per tissue (Brain01, Heart01, Liver01, Lung01), one run each. biological replicate = 1 is a placeholder (only one run per tissue; replicate structure not stated).
- factor value[organism part] = tissue (the only compared variable; tissues come from the project design).
- Instrument Orbitrap Astral (MS:1003378): matches PRIDE structured field, protocol and mzML headers of all 4 files.
- Cleavage agent Trypsin (MS:1001251), as the protocol names plain trypsin.
- Dissociation HCD (MS:1000422), 30 NCE (protocol: NCE 30%, HCD; mzML header reports collision energy 30, consistent).
- DIA: NT=Data-independent acquisition;AC=PRIDE:0000450; isolation width 2 m/z, MS2 scan window 400-1000 m/z, MS1 400-1000 m/z (protocol; mzML precursor targets start at 401 +/-1, consistent).
- Reduction TCEP (PRIDE:0000609), alkylation chloroacetamide (PRIDE:0000600), from the lysis buffer. Fixed modification Carbamidomethyl (C) (UNIMOD:4) from the processing protocol (DIA-NN, no variable modifications); chloroacetamide gives the same adduct.
- Acquisition date 2025-02-25 (mzML startTimeStamp of all four files).
- fraction identifier 1, fractionation method not applicable: no fractionation described (single injection, 100 ng peptide).
