# PXD000616 — annotation blocked

PXD000616 has 40 deposited vendor RAW files: two measurements for each of 20 sarcoma samples. PRIDE's protocol and the linked publication (PMID: 25069693) establish that the cohort contains leiomyosarcoma and high-grade undifferentiated pleomorphic sarcoma samples, but the deposited raw-file names use only numeric identifiers such as `Sarcoma_68` and `Sarcoma_26`.

Neither the PRIDE project record nor its companion deposit files provide a table mapping those numeric identifiers to the histological subtypes. This mapping is required for the study's disease/subtype factor. Inferring it from filenames or cohort totals would create unsupported sample annotations, so no SDRF is emitted.

Evidence checked: PRIDE PXD000616 project record, protocols, and complete file manifest; Kirik *et al.*, *Molecular Cancer Research* (2014), DOI 10.1158/1541-7786.MCR-14-0072 / PMID 25069693.

Unblock with the original sample sheet, a deposited design table, or author confirmation mapping every raw-file sample ID to its histological subtype.
