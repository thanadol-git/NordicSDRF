# PXD000319 SDRF annotation report

## Study
Manipulating root water supply elicits major shifts in the shoot proteome (rice split-root drought). Mirzaei M, ..., Salekdeh GH. J Proteome Res 2014;13(2):517-526, PMID 24266738, doi:10.1021/pr400696u (ACS, closed; only the PubMed abstract and MeSH were readable; no PMCID). Lab head: Royan Institute, Tehran; MS at Macquarie University.

## Scope, evidence and decisions
Status: **sandbox**. 9 rows x 32 cols, templates ms-proteomics + plants.

- **Deposited vs annotated:** PROXI `datasetFiles` (re-derived 2026-11-27) lists 9 RAW archives (`WW1-3.zip`, `WD1-3.zip`, `DD1-3.zip`) and 9 GPM/X!Tandem `.xml` search outputs with the same stems. All 9 archives are annotated, one row each; the xml files are not data-file rows. PRIDE v3 API, PRIDE FTP and OLS (EBI) all returned upstream connect errors today, so the zip contents (expected 16 gel-slice runs each, per the PX description) and raw headers were NOT inspected. One row per archive with `fraction identifier` = 1 follows the PXD001870/PXD002147 precedent.
- **Groups (INFERRED from file tokens + abstract):** WW = both root compartments watered ("wet" roots), WD = water withheld from one compartment ("wet" and "dry"), DD = withheld from both ("dry"). The token decoding is obvious but not stated anywhere I could read. Digits 1-3 = biological replicate (INFERRED).
- **Organism part:** shoot system (PO:0009006, verified on Ontobee): the title and abstract say shoot proteome; the abstract mentions leaves in passing, so the exact harvested tissue (whole shoot vs leaf) is unconfirmed.
- **Cultivar conflict:** PubMed abstract says cv. IR64; the PX description says cv. Nipponbare. The paper abstract was followed (precedence paper > PX fields); unresolved without Methods.
- **Instrument:** LTQ (MS:1000447) from the PX record only; the raw headers could not be read. The Haynes lab often used LTQ Velos instruments, so this is a known PRIDE risk. Dissociation CID is INFERRED (an ion trap).
- **Search (PX description, GPM 2.1.1 X!Tandem):** trypsin, 2 missed cleavages; MS 2 Da / MS/MS 0.2 Da; Carbamidomethyl C fixed (UNIMOD:4); Oxidation M variable (UNIMOD:35). The PX `modifications` field (MOD:00425 monohydroxylated, MOD:00400 deamidated) likely reflects X!Tandem refinement mods. They are not annotated because the deposited xml was not opened.
- **Fractionation:** SDS PAGE (PRIDE:0000568): 16 gel fractions per experiment are stated in the PX description, and the MeSH terms include PAGE.
- **Paper cites PXD?** This could not be verified: the full text is closed. The PX record links the paper, and the title, authors, design and journal match the dataset exactly.
