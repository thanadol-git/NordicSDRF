# PXD000617 — annotation blocked

PXD000617 deposits the vendor RAW files for eight TMT sarcoma runs and four pooled SCX-fraction sets. PRIDE's project description confirms the TMT design, and the shared study protocol establishes the sarcoma cohort and instrument method. However, the complete PRIDE manifest contains no sample/design table, and neither the project record nor the deposited companion files maps TMT channels to individual tumors or histological subtypes.

Writing one row per TMT channel without that map would fabricate the core sample-to-assay relationship. No SDRF is emitted.

Evidence checked: PRIDE PXD000617 project record, protocols, and complete file manifest; Kirik *et al.*, *Molecular Cancer Research* (2014), DOI 10.1158/1541-7786.MCR-14-0072 / PMID 25069693.

Unblock with the original TMT channel map, a deposited sample/design sheet, or search-output metadata that assigns every channel in each run to a source sample.
