Dataset: Stensballe lab (Aalborg University, Denmark); Poulsen et al., Sci Rep 2021 (PMID 34453079). The PRIDE deposit holds the mass spectrometry part only: commercial fibrinogen (Cayman Chemical), native or citrullinated in vitro with PAD2 or PAD4, digested by FASP/trypsin, analysed on a timsTOF Pro.

Caveats and inferences
- File names are the deposited archives (.d.rar / .d.ZIP, Bruker .d folders); these are not raw files per se but are the only deposited run files.
- Condition coding comes from file-name prefixes (N = native, 2 = PAD2, 4 = PAD4) matched to the Methods; biological replicate 1/2 is by GC number order, an assumption (no replicate statement in the deposit).
- Donor-level sample properties (organism part, age, sex, ancestry, individual, developmental stage) are `not available`: the material is a purchased protein and the source (human plasma) is not stated in the deposit. Disease and cell type are `not applicable`.
- Acquisition method DDA (PRIDE:0000627) is inferred (timsTOF Pro, PEAKS DB search, shotgun); the paper does not state DDA/PASEF. Not verified from the .tdf files.
- Modifications: Carbamidomethyl (C, fixed) is inferred from the chloroacetamide alkylation in the protocol; citrullination is encoded as Deamidated UNIMOD:7 on R (variable) as stated. Oxidation(M) and other PEAKS defaults are not stated and were omitted. The PEAKS project in the 45.7 GB search zip (file listing read by HTTP range) was not parsed for parameters.
- Alkylation reagent is `not available`: no MS/PRIDE term for chloroacetamide was found (ChEBI only). Reduction reagent TCEP = PRIDE:0000609.
- Tolerances and dissociation method are `not available` (not reported).
- Only one cleavage agent (trypsin); no second protease in the protocol.
- PRIDE metadata lists MaxQuant as software but the protocol states PEAKS 10.5; the protocol was followed.
- No independent adversarial review was run (no further subagents permitted); review-gate not run.
