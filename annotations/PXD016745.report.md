# PXD016745 annotation report

## Study
"Community-intrinsic properties enhance keratin degradation from bacterial consortia" (Nasipuri et al., PLoS One 2020, doi:10.1371/journal.pone.0228108, PMC6994199). Secretome (day 2 culture supernatant) of Xanthomonas retroflexus (X) alone, dual cultures with Microbacterium oxydans (M), Paenibacillus amylolyticus (P) or Stenotrophomonas rhizophila (S), and the four-species consortium (All), grown on keratin liquid medium. Label-free DDA on a Q Exactive, MaxQuant. Not in community corpus.

## Templates
ms-proteomics v1.1.0 + metaproteomics v1.0.0 (MS; defined multi-species bacterial co-culture, microbiome-style sample scheme). Chosen because several rows contain more than one organism, which the single-organism layers cannot express.

## Scope
Deposited: 21 RAW, MaxQuant output tables (summary, parameters, evidence, etc.), FASTA/EMBL of X. retroflexus. Annotated: all 21 RAW (21 rows x 30 columns), one injection each, unfractionated. Mapping: MaxQuant summary.txt (raw file -> experiment "<replicate>_<culture>"). summary.txt lists 40 runs (A1-D4), but only 21 RAW (B8-B12, C1-C12, D1-D4) are deposited; the other 19 are not annotated.

## Key decisions
- Source name = summary.txt experiment name (e.g. A_X, Y_XS); replicate letters A-F, X, Y mapped to biological replicate 1-8 in that order (PRIDE protocol: eight replicates A-F, X and Y). This integer coding is inferred.
- Organism: `Xanthomonas retroflexus` for monoculture; `synthetic metagenome` for the co-culture rows (several species in one sample; organism is single-valued). Inferred representation.
- Organism part: `culture supernatant` (secretome) from paper; no ontology check beyond the cache validator.
- Factor value[culture composition] with a matching characteristics[culture composition] (free text, custom column) = X alone / X+M / X+P / X+S / four-species consortium.
- Modifications from deposited parameters.txt (fixed Carbamidomethyl C; modifications included in quantification Oxidation M, Acetyl protein N-term) and PRIDE/paper (variable Ox M, Acetyl protein N-term). Tolerances 4.5 ppm / 20 ppm from PRIDE/paper (parameters.txt has none).
- Cleavage Trypsin (paper/PRIDE; summary says Trypsin/P). HCD, NCE 32, MS1 range 350-1500, Orbitrap MS2 from PRIDE protocol.
- Software version conflict: PRIDE/paper say MaxQuant 1.5.5.1, deposited parameters.txt says 1.6.1.0; not encoded in SDRF.
