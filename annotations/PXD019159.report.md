# PXD019159 SDRF annotation report

Status: validated annotation; independent review pending (no isolated reviewer available; not self-approved).

Dataset: Protein composition of subretinal fluid (SRF) in rhegmatogenous retinal detachment vs 2-day post-mortem vitreous humor; Aarhus, Denmark. PMID 33117608. No prior annotation existed in sdrf-annotated-datasets or NordicSDRF.

Templates: ms-proteomics v1.1.0 + human v1.1.0. 44 rows x 33 columns (24 SRF, 20 vitreous; label-free, DDA, unfractionated). One row per .wiff file (.wiff.scan companions not listed).

## Validation
- parse_sdrf validate-sdrf (cache-only OLS): no errors; 1 warning: `subretinal fluid` not found in UBERON/BTO (no suitable term located; kept as the bare descriptive value).
- python -m tools check: CLEAN (15/15 terms). structure: OK. reconcile: no disagreement with record. score: consistency/standards/design 100.
- The first online validation was cut by network loss; the final one used the OLS cache.

## Key decisions and caveats
- Group assignment of files is inferred (ELN174 = SRF n=24, ELN207 = vitreous n=20) from counts and SI Table 4 numbering; not stated explicitly.
- Instrument TripleTOF 6600 from paper and .wiff header; PRIDE field says 5600.
- Modifications from the paper/PRIDE protocol, not the deposited MaxQuant files (large 7z archives not opened). Oxidation of proline written as UNIMOD:35 on P. Fragment tolerance 0.2 Da is the Mascot value.
- Age and sex are `not available` per row: SI Table 1 has them but the patient-number to file mapping is not given. Cohort: SRF 6F/18M mean 68 y; vitreous 11F/9M mean 83 y. Could be filled if authors confirm mapping.
- Factor value[disease] (retinal detachment vs normal) is fully confounded with organism part (SRF vs vitreous), and with age.
- `characteristics[sample type]` omitted: `study sample` was not resolvable in the offline PRIDE cache.
- Recommended columns cell type, ancestry category, developmental stage are not supplied (no evidence).
- Independent adversarial review (Step 9.5) not performed; no review-gate receipt.
