- Sex is 'not available' for all donors: the paper says only male HD lines were used for MS, but the file donor codes (HD1, HD4, HDKP, …) cannot be matched to the paper's HD1–HD10 table (its HD4 is female), so sex is not transferred.

- HCD written as MS:1000422 (beam-type collision-induced dissociation), the spec-canonical term.
- File donor codes (C11, CBS, HDKP, …) cannot be linked to the paper's C1–C7 / HD1–HD10 table, so age, sex (controls) and CAG repeats are not annotated per donor.
- iNs are annotated with CL 'neuron' (directly converted from the same donors' fibroblasts; conversion length for the MS samples is not stated).
