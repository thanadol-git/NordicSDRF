# PXD013676 annotation report

Status: parser validated; independent review failed. Glycan labeling and acquisition method need resolution.

Five Orbitrap Fusion Lumos RAW files cover three FcgRIIa reporter variants and two engineered HEK293 released N-glycan preparations. Sample-specific cleavage records chymotrypsin for reporter glycopeptides and trypsin for total-cell glycan preparations. PRIDE also describes Asp-N digestion for a MUC1 reporter workflow, but no MUC1 RAW appears in this accession. The generic reconciliation check flags this as missing Asp-N; the file-level mapping does not support assigning Asp-N to these five files.

Sources: [PRIDE project](https://www.ebi.ac.uk/pride/archive/projects/PXD013676) and [file list](https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD013676/files/all). Official parser, structure and offline term checks passed. No factor column is declared because the deposit combines different reporter and glycan profiling workflows. Independent review found the `label free sample` entry for two Rapifluor-derivatized glycan runs ambiguous and the DDA entry unsupported for the three files named `targ_N_O`; these fields need file-specific evidence or a defensible supported representation before approval.
