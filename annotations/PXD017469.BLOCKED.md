# PXD017469 - BLOCKED (producer)

Study: TMT 10-plex phosphoproteomics and sialiomics (TiSH: TiO2/SIMAC enrichment, HILIC fractionation) of mouse (C57BL/6J WT and db/db) pancreatic islets, Orbitrap Fusion Lumos (RAW headers of LUM2_01188: "Orbitrap Fusion Lumos", HCD, NCE 38 in paper). Paper: Kang et al., MCP 2020, PMID 32265294 / PMC7261816 (read from the PMC HTML page; Europe PMC full-text XML returns "not open access", and NCBI efetch XML is withheld by the publisher).

## Deposit (all pages enumerated: page 0 = 90 files, page 1 empty)
30 RAW (LUM2_01188..01217_MRL.raw), 30 mzML, 30 MS-GF+ mzid.gz. No MaxQuant/MSF parameter files, no SDRF-like table, README.txt only lists files.

## What is missing (cannot be built without inventing)
1. TMT channel-to-sample map: the paper says only "TMT 10plex" (and iTRAQ 4plex for another, unrelated set), with groups N (WT), D (db/db fresh) and DG (db/db after 12 h 5.6 mM glucose) and 2 biological replicates for phospho/sialiomics. Which of the 10 channels carries which group/replicate is shown only in Fig. 1A (image) and is not stated in text, mzid or any deposited file. The mzid files do not carry channel identities.
2. Run-to-fraction / run-to-enrichment map: the 30 RAW files comprise HILIC fractions (pooled by UV peak) of phosphopeptide, sialylated-glycopeptide (and possibly non-modified/multi-phospho) fractions across replicates. The paper does not state how many fractions per fraction type or which run number belongs to which type, replicate or fraction index. File order would be pure guesswork (lesson 1/9).
3. Plex/enrichment-to-file grouping, i.e. how many independent TMT mixtures exist (2 biological replicates x 2 modification types is implied, not stated per file).

Ladder checked: paper text (PMC HTML), PRIDE record, PRIDE file list, README, mzid header, RAW header. Not accessible: supplementary tables S1-S4 and figures (docx/xlsx behind PMC) were not retrieved; they are quantification tables and would not map RAW files to fractions in any case, but a human could check Supplementary Fig. S1 / Fig. 1A.

## What would unblock it
The submitter (Taewook Kang / Martin R. Larsen, SDU) supplying a table: RAW file -> modification enrichment type, replicate, HILIC fraction number, and the TMT channel -> condition map.

## Verified facts (for a future annotation)
Organism Mus musculus; C57BL/6J WT and db/db, 14-16 weeks of age (unless stated); islets of Langerhans; cleavage trypsin (2% w/w; paper also says trypsin/LysC in Fig. 1 legend); Fixed carbamidomethyl C, TMT K and N-term; variable oxidation M, phospho STY, deamidation N; 20 ppm precursor tolerance; HCD NCE 38; Lumos for PTMomics (PRIDE also lists Q Exactive HF, which per the paper is for the separate proteomics set PXD010265; none of the 30 deposited RAW files was checked beyond LUM2_01188, prefix LUM2 suggests Lumos).
