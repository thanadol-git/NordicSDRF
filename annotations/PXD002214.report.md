# PXD002214 annotation report

**Study.** Preil et al., Circ Cardiovasc Genet 2015 (PMID 26371159): iTRAQ 8-plex proteomics of formalin-fixed non-atherosclerotic repair arteries from 30 patients with type 2 diabetes (DM) and 30 age/sex-matched controls (non-DM), Q Exactive, Odense. Full text is not open access and was not read.

**Result.** 1712 rows x 36 columns (214 RAW files x 8 iTRAQ channels). `parse_sdrf` validation: see the Validation section. `sdrf-tools reconcile`: no disagreement with the record.

**Templates.** `ms-proteomics` v1.1.0 + `human` v1.1.0 + `clinical-metadata` v1.0.0. Human tissue patient study (clinical-metadata adds disease-related columns). `oncology-metadata` not applicable. No cell-line or DIA template. Chosen without user confirmation (non-interactive).

## Scope: deposited vs annotated
- 214 RAW files (10 mixes), all annotated, each x 8 channels. 10 `.msf` search files are search outputs, not runs, and were not annotated.
- Mixes: 1-4, 6-8, 10 have 19 fractions each (wells A4, A6-A12 and B1-B8, B10-B12 are named; A5 and B9 are absent); Mix5 has 24 files (numeric 2-24 + a duplicate `Mix5_24_130910170646`); Mix9 has 38 files (two full 19-file sets, one with timestamp suffixes).

## Key decisions
- **Channel map (stated once in the PRIDE sample protocol):** 113 pool non-DM, 114 pool DM, 115 non-DM 1, 116 DM 1, 117 non-DM 2, 118 DM 2, 119 non-DM 3, 121 DM 3. Applied to all 10 mixes (10 x 3 pairs = 30 pairs = 60 patients, consistent). Pools: `pooled sample = pooled`, `sample type = pooled`, individual `pooled`, age `not available` (validator rejects `pooled` for age).
- **Source names** are `Mix<n> <channel label>` (e.g. `Mix3 DM2`). The mapping of these slots to individual patients/IDs is NOT available (paper supplement not accessible).
- Disease: `type 2 diabetes mellitus` vs `normal` (control); factor value[disease] copies it. Metformin use (second comparison in the paper) is per-patient and not in the deposit, so not annotated.
- Organism part `artery`: the specific artery (e.g. radial) is not stated.
- Modifications from PRIDE processing prose (Carbamidomethyl C fixed, iTRAQ8plex K/N-term fixed, Oxidation M variable); the deposited .msf files were not read (0.6-1 GB SQLite), so they are unverified against the search.
- Instrument confirmed from RAW header: Q Exactive (matches PRIDE).
- Enzyme: search used Trypsin/P, digest was trypsin (Promega); annotated as Trypsin MS:1001251.
- Reduction DTT (100 mM in extraction buffer) and alkylation iodoacetamide stated in protocol.
- HILIC fractionation is stated but `comment[fractionation method]` was omitted (no verified accession); dissociation method `not available`.

## Values left not available and why
cell type, ancestry category, age, sex, individual (per-patient data not in the deposit; the matched design is a cohort-level statement), dissociation method (not stated).

## Inferred vs stated
Stated: channel map, disease groups, instrument, modifications, tolerances, reagents. Inferred: fraction order (A4..A12, B1..B12 / numeric), mix membership from file name prefix, same channel layout in every mix, treatment of duplicates below.

## Points for a reviewer to attack
1. Same channel layout for all 10 mixes is assumed (layouts can flip between runs); the paper supplement was not available to confirm.
2. **Mix9**: the timestamped 19-file set is annotated as technical replicate 2 (un-stamped = replicate 1); nature of the two sets (re-injection, different gradient, failed run: un-stamped `Mix9_A8.raw` is only 105 MB) unknown.
3. **Mix5**: duplicate `Mix5_24_130910170646.raw` appended as fraction 24; could be a re-injection of fraction 24 instead.
4. Fraction numbering follows file-name order; wells A5 and B9 are absent from the deposit, so numbers are ordinal, not plate positions.
5. Modifications not verified from .msf.

## Validation
`parse_sdrf validate-sdrf -t ms-proteomics -t human -t clinical-metadata --use_ols_cache_only`: one ERROR remains, `Term: study sample in column characteristics[sample type] is not found in the given ontology list pride`. `study sample` is a listed value for this column in TERMS.tsv (children of PRIDE:0000895) and is used in other annotations here; the error appears to be a miss in the offline OLS cache (the network was unavailable and the online run hung on DNS failure). A full online validation was not completed. No independent adversarial review was run (no isolated reviewer dispatched in this non-interactive run); the file is a draft until reviewed.
