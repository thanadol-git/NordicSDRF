# PXD001462 SDRF annotation report

Status: validated annotation; independent review pending

Dataset: Identification of alpha-synuclein interacting synaptosomal proteins (Jensen lab, Aarhus). Paper: Betzer et al., PLoS One 2015 (PMID 25659148). Existing annotation in sdrf-annotated-datasets: none found.

## Result
- 36 rows x 30 columns, templates ms-proteomics v1.1.0 + vertebrates v1.1.0, one row per RAW file (36 RAW), label free, unfractionated.
- Design: 4 porcine synaptosomal fractions (LP1, LS1, LP2, LS2) x 3 baits (buffer, alpha-synuclein monomer, alpha-synuclein oligomer) x 3 biological replicates (Co-IP). Source names look like `LP1_monomer_rep1`.
- Bait is recorded in `characteristics[spiked compound]` (CT=protein;QY=2 ug;CN=...; buffer = not applicable) and mirrored in `factor value[spiked compound]`. The synaptosomal fraction is encoded only in the source name (no suitable column in the templates).
- Technical: LTQ Orbitrap XL, DDA, CID, ion-trap MS2, trypsin (single protease, so one cleavage column), Carbamidomethyl (C, fixed), Oxidation (M, variable).

## Validation
- parse_sdrf validate-sdrf (both templates, --use_ols_cache_only): pass.
- python -m tools check: CLEAN; structure: OK; reconcile: no disagreements.

## Caveats
1. Condition mapping from file names: M = monomer is clear; P = oligomer is inferred by elimination (the third condition) and buffer = unlabelled runs 01-03. Not confirmed by the deposit text. Reviewer should verify (e.g. against the paper's supplementary data).
2. Disease, developmental stage, strain, sex, cell type are `not available`. PRIDE's Parkinson's disease tag was deliberately not applied to the pig tissue.
3. Precursor/fragment tolerances `not available` (only instrument accuracy given). Modifications reflect the X!Tandem search only; the ProteinPilot biological-modification search is not enumerated.
4. UniProt P37840 for the recombinant human alpha-synuclein bait was left out of the spiked compound value because `tools check` flags AC= there as a label mismatch.
5. Dissociation CID is inferred from the ion-trap MS/MS on an LTQ; RAW headers were not parsed. Human brain tissue mentioned in the paper (one 80-year-old male) is validation only and is not in the deposited files.
6. Independent adversarial review (Step 9.5) has not been done; review-gate not run.
