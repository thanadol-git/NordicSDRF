# PXD004341 BLOCKED

Study: Larsen et al., J Biol Chem 2017, "Mammalian O-mannosylation of cadherins and plexins is independent of protein O-mannosyltransferases 1 and 2" (PMID 28512129; PMC5500819, full text read from the OSTI author manuscript, since Europe PMC/PMC XML is not open access). 51 files in PRIDE: 42 RAW (CHO ZN-GS-/- wild type and POMGnT1 / POMT1 / POMT2 / triple KO clones; ConA lectin weak affinity chromatography glycopeptide fractions; LTQ Orbitrap Velos Pro or Fusion; HCD/ETD) and 9 Proteome Discoverer .msf search results. Label free; no dimethyl-labelled run is among the RAW files that could be tied to a sample.

Annotation was not produced because the run-to-fraction map (a required integer, `comment[fraction identifier]`, with no reserved-word escape in the ms-proteomics contract) cannot be traced to the paper or to any deposited file.

## What is missing
- The paper says only that glycopeptide fractions were eluted from the 2.8 m ConA column in "5 CVs, 1-ml fractions" and that "glycopeptide-containing fractions" were desalted. It never says which fractions were analysed per genotype, nor how fractions were numbered.
- The only fraction-like information is a numeric token inside RAW names (`F17`-`F21`, `E2`-`E6`, `LWAC_21`-`25`, `ConA_19`-`26`, `ConA_29`-`34`, `LWAC11`). No deposited file defines these tokens as fraction numbers. The .msf files (read: 150507 triple-KO ETD msf, FileInfos) list only the RAW paths, not fraction or sample assignments. Reading the token as a fraction number would be inference from naming habits, which the run rules forbid. `sdrf-tools build` also numbers fractions by position in the `files` list, so tokens starting at 17/19/21/29 could not be encoded as written anyway.
- `140527_..._E2toE6.raw` is a single run apparently covering E2-E6 together (name only); its relation to the five E2-E6 runs is not documented.
- Several genotype groups have two injections of the same token (for example POMT2 KO SC `ConA_22`/`23` at 90 min HCD and at 2 h HCD/ETD), so replicate versus fraction semantics cannot be settled from the record.
- Biological replicate / clone identity is not stated (the paper lists clones in supplemental Table S1, not deposited).

## Other gaps found (would also need limitations notes)
- Instrument is not uniform: RAW headers read for 20 of 42 files give LTQ Orbitrap Velos Pro for most, but the wild-type files `130828_Ida_CHO_wt_F17`/`F21` report `LTQ Orbitrap XL MS`, which the paper and PRIDE (Velos / Fusion) do not mention. Headers of the other 22 files could not be fetched from the PRIDE FTP (zero-byte responses).
- Cleavage/modification parameters would come from PD (Sequest HT, 10 ppm, 0.02 Da, Carbamidomethyl C fixed; Oxidation M, Deamidated N, Hex S/T variable; max 2 missed cleavages), but the .msf files were only partly parsed.
- Dissociation differs per file (HCD, ETD, HCD+ETD) and would need per-run assignment.

## What would unblock
A statement from the submitters (or a supplementary table) mapping each RAW file to genotype, clone, LWAC fraction number and injection/replicate, plus the Fusion/Velos assignment per file.
