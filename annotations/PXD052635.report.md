## Key decisions
- Instrument from raw headers (precedence raw > paper > PRIDE): Q Exactive HF-X for _1313-_1316, _1606, _1608; Orbitrap Exploris 480 for _1962, _1963. PRIDE lists Exploris 480 + "Q Exactive HF" (wrong model; header says HF-X). Paper says Exploris for CMNFV59632, but the tusk file _1608 (2019, "QE7") header reports HF-X; raw header used for that file.
- Organism: Stephanorhinus genus (NCBITaxon:2003758, species not stated) for Fontana Ranuccio; Rhinocerotidae (NCBITaxon:9803) for Haughton because Epiaceratherium has no NCBITaxon entry. Blanks: not applicable.
- Organism part: enamel (UBERON:0001752); cell type not available.
- Modifications from deposited MaxQuant summary.txt of the Standard run (Fixed: none; Variable: Oxidation M/P/W, Deamidated N/Q, Arg->Orn UNIMOD:372, Gln->pyro-Glu UNIMOD:28, Glu->pyro-Glu UNIMOD:27, Phospho S/T). No Carbamidomethyl (paper: no fixed modifications). Paper prose says phospho STY; the deposited label is "Phospho (ST)", deposit used. The additional Aromatic/His/TryptOx searches (Trp/His oxidation variants) are separate searches with custom modifications and are not encoded; custom-mass mods lack UNIMOD entries for several.
- Cleavage agent: `not applicable` -- no enzymatic digestion was performed (peptides hydrolysed in vivo); MaxQuant used unspecific mode. `sdrf-tools reconcile` flags this as BLOCKER cleavage_agent_unsupported because the sentinel is not a reagent in the record; this is a tool false positive for a sentinel, the record text explicitly says "no enzymatic digestion was performed".
- Tolerances: precursor 10 ppm (PRIDE protocol; not in parameters.txt); fragment 20 ppm from deposited parameters.txt (MS/MS tol. FTMS) while PRIDE prose says 0.05 Da. Conflict, deposit used.
- Factor value[treatment]: demineralization acid (HCl vs TFA), the only within-study comparison on the sample side; written with NCIT terms Hydrochloric Acid / Trifluoroacetic Acid (10% concentration not carried). Blanks: not applicable.
- sample type: study sample / negative control (blanks).
