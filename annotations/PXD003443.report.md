# PXD003443 SDRF annotation report

## Study
Changes in proteome upon deletion of UBE2S/UBE2C in HCT116 cells (Copenhagen CPR, Choudhary lab; submitter Thomas Wild). Wild-type HCT116 grown in light SILAC medium (Arg0/Lys0) and UBE2S, UBE2C or UBE2S/UBE2C knockout HCT116 grown in heavy medium (Arg10/Lys8, "10/8"). Equal protein amounts of the two lysates were mixed, then fractionated either as proteins by SDS-PAGE (in-gel digestion) or as tryptic peptides by SCX. Q Exactive, MaxQuant 1.5.0.38. No publication is linked in PRIDE (`references` is empty); no paper was used.

## Templates
ms-proteomics v1.1.0 + human v1.1.0 + cell-lines v1.1.0 (human HCT116 cell line, MS, SILAC; no DIA, clinical or oncology layer).

## Scope: deposited vs annotated
189/189 RAW files annotated (search.zip is a search-output archive, not a data file). 378 rows = 189 files x 2 SILAC channels (`SILAC light` = wild type, `SILAC heavy` = knockout), 41 columns + 2 extra `comment[modification parameters]` repeats = 43 columns. 12 sources (6 wild-type reference, 6 knockout).

## Key decisions
- Instrument: Q Exactive (MS:1001911) from the PRIDE record; file prefixes QE1/QE2/QE4 are individual instruments of the same model. RAW headers not checked (techsdrf not installed).
- Cell line: HCT116 (EFO:0002824, the form that validates in CLO/BTO/EFO), Cellosaurus HCT 116 (CVCL_0291); organism part colon, disease colon carcinoma (MONDO:0002032, from Cellosaurus NCIt C4910), male, 48Y are Cellosaurus donor values.
- Modifications from deposited `parameters.txt`/`summary.txt`: Carbamidomethyl (C) fixed; Acetyl (Protein N-term) and Oxidation (M) variable; the Arg10/Lys8 labels are listed as Label:13C(6)15N(4) (R) and Label:13C(6)15N(2) (K), as `sdrf-tools search-params` emits them. Because `build` writes one value for all rows, they appear on the light rows as well.
- Fragment tolerance 20 ppm (MaxQuant FTMS MS/MS tolerance; Q Exactive fragments are read in the Orbitrap).
- Acquisition = DDA: not stated in the record; inferred from MaxQuant's standard LC-MS run type and MS/MS sequencing statistics in `summary.txt`.

## Not available / not applicable
`comment[precursor mass tolerance]` (main-search tolerance is not in `parameters.txt`/`summary.txt`; no mqpar.xml or .apar deposited), `comment[dissociation method]` (not stated; HCD likely but not evidenced), cell type, ancestry category, individual, passage number, culture medium (the record gives "SILAC medium" only, no base medium), sample storage temperature.

## Conflicts / overrides
- MaxQuant used `Trypsin/P`; the PRIDE protocol says "tryptic peptides". I wrote `Trypsin` (MS:1001251) for the digest, which also clears the `reconcile` BLOCKER that fires for Trypsin/P versus a Trypsin record.
- PRIDE organism part "cell culture" replaced by the cell line's tissue of origin (colon), per the cell-lines convention.
- PRIDE experiment type "Gel-based experiment" is only partly right: SCX series are not gel-based; each file is annotated by its own fractionation method.

## Judgement calls (for the reviewer to attack)
1. **Genotype decoding.** "d2S", "d2Sd2C", "d2C(blast)" were read together with the MaxQuant experiment names (Ube2SKO, Ube2CKO, 2S/2CKOcl*) and the PRIDE description ("deleted of UBE2S and/or UBE2C"). The clone number in the Ube2SKO file code (c15) and Ube2CKO code (c1) is not in the Experiment name and is not annotated.
2. **Replicate structure.** Series of one experiment are treated as technical replicates of one biological sample (same lysate mix; the protocol says the mix was fractionated "either" way), although the record does not state that one mix was split. The four double-KO clones (cl3, cl4, cl8, cl12) are biological replicates 1-4 of that genotype, numbered in clone order. The wild-type reference gets a source per experiment with the paired knockout's replicate number; whether those wild-type lysates are independent cultures is unknown.
3. **Filename tokens.** `urea_scx`, `ingel`, `mes`, `mops`, `2ndrun` are kept verbatim in `comment[sample preparation batch]`. Their meaning (MES vs MOPS gel running buffer; urea lysis; repeat run) is not defined in the record, so it is not otherwise encoded. `ingel` is mapped to SDS PAGE and `scx` to strong cation exchange.
4. **Disease** is attached to every row (cell-line property of HCT116, wild type included).
5. Fixed carbamidomethyl is from `parameters.txt`; the paper's protocol was not available to check for a different alkylation.
