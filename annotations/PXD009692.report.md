## Evidence summary

- Instrument: Q Exactive Plus, read from the raw file header (HTTP range read of the first 200 KB of 1657-MariaS-syn-HC-F3.raw); PRIDE structured field says only "Q Exactive".
- Search settings read from the deposited Proteome Discoverer 1.4 .msf (SQLite, read via HTTP range requests, no full download): Mascot + Percolator, trypsin, precursor 7 ppm, fragment 10 mmu (0.01 Da), fixed TMT6plex (K, any N-term) and Carbamidomethyl (C), variable Oxidation (M), HCD, TMT 10plex reporter quantification.
- Reduction TCEP, alkylation iodoacetamide, trypsin overnight, TMT10plex labelling, MCX fractionation into 8 fractions, MS1 380-1800 m/z, 90 min gradient: paper Methods (Paternoster et al. 2018, Neurobiol Dis, PMID 30590179; accepted manuscript from King's College London repository).
- Sex female, age 6-8 weeks, Brd1 +/- vs wild-type littermates, hippocampus: paper Methods.
- Single trypsin digestion, so a single cleavage-agent column.

## Limitations

- TMT channel -> sample/genotype map is NOT available: not in the PRIDE record, paper text, or the .msf (the PD quantification method has no sample names). Sources are named HC-syn-<channel>; genotype (Brd1+/- vs WT), disease, and any factor value are not annotated (disease, strain, developmental stage, cell type = not available). Do not infer 5 vs 5.
- Synaptosome enrichment is not capturable in a template column (no cellular-compartment column in the templates); it is stated here and in the dataset title only. Brain region = hippocampus (organism part).
- Fraction identifiers are the deposited F-numbers (F2-F8; F1 not deposited; the exclusion and long-gradient re-injections cover F4-F8 only). Fractions were set by a scripted patch of the built file because build numbers fractions by list position.
- Technical replicate: 1 = standard run F2-F8, 2 = "lang-gradient" (long gradient) F4-F8, 3 = "exclusion" F4-F8. The paper says the third analysis used an exclusion list, which fits this order, but the file run numbers show the exclusion runs (1680-1688) were acquired before the long-gradient runs (1692-1700); the order of replicates 2 and 3 is therefore an inference. Long-gradient length is not stated.
- The 10 channels are coded as 10 biological replicates (separate animals assumed from the TMT10plex design; the paper confirms 10 samples pooled, "minimum 3 samples per group"). One FrC-syn sample was removed in the paper's analysis, which concerns a different PXD.
- Fractionation method (MCX mixed-mode cation exchange) has no matching ontology term chosen; recorded as not available.
- Search tool used TMT6plex (UNIMOD:737) for the TMT10plex reagent (same mass); recorded as searched.
- Related Brd1 datasets deposited together: PXD009688-PXD009691, PXD009961.
