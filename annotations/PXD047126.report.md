## Key decisions
- Sample map from the deposited `Raw_file_key.txt` (specimen 1-6, Cortical/Trabecular; P0439 Blank). Source = specimen x bone type; `biological replicate` = specimen number (pair index).
- organism part: cortical = `compact bone tissue` (UBERON:0001439), trabecular = `trabecular bone tissue` (UBERON:0002483), verified in OLS. `factor value[organism part]` is the compared variable; blank = not applicable.
- organism `Caprinae` (PRIDE NEWT:9963; description says Caprinae). Goat vs sheep is unresolved in the record (search used Bos+Sus+Capra+Ovis fasta) so not asserted.
- Blank: sample type `negative control`; organism/part/etc. `not applicable`; biological replicate 1 (placeholder required integer; it is not specimen 1).
- Modifications read from the deposited MaxQuant `parameters.txt`: variable Oxidation (M), Oxidation (P; MaxQuant "Hydroxyproline"), Deamidated (N,Q), Gln->pyro-Glu, Glu->pyro-Glu; no fixed mods. Note: PRIDE prose lists 'oxidation (PM)' (which already covers Oxidation on P) but not hydroxyproline by name, and says Capra hircus + Ovis aries only; the deposited "Second search (Bos, sus, capra, ovis)" differs. Deposited result wins; only this search is deposited.
- Cleavage: Trypsin (MS:1001251) from the wet-lab protocol; search was Trypsin/P semispecific (stated here, not encoded).
- Instrument confirmed by RAW header (Orbitrap Exploris 480), matching PRIDE.
- Fragment tolerance 20 ppm from the search (FTMS).
