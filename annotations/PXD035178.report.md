# PXD035178 — annotation report

**Outcome: BLOCKED. No SDRF written.** Independent review (Step 9.5): not run, because there is no SDRF to review.

## Study
"Selective inhibition of soluble tumor necrosis factor signaling reduces abdominal aortic aneurysm progression" (Griepke et al., Front Cardiovasc Med 2022, PMID 36186984, PMC9523116). The proteomics part is an exploratory TMT 11-plex study of mouse abdominal aortic wall 7 days after PPE-induced AAA: XPro1595 (n=7) vs vehicle (n=6). Orbitrap Eclipse with FAIMS, Proteome Discoverer 2.4. Per PRIDE, `Lasse_Stubbe_A-_1_.pdResult` is the only search output.

## Deposit
14 RAW files = 2 plexes x 7 fractions (LJ_1_4..10, LJ_2_4..10; PD fraction numbers F1.1-F1.7, F2.1-F2.7), plus the 8.4 GB `.pdResult`. All PRIDE v3 entries carry PXD035178.

## Template that would apply (not built)
`ms-proteomics` + `vertebrates` (mouse); no cell-line, clinical or oncology template. TMT11plex, trypsin, Orbitrap Eclipse.

## Why it is BLOCKED
Each RAW file holds 11 TMT channels, and the SDRF needs a sample identity per channel. Sources exhausted:
1. Paper Methods and Results: 131C = pool of all AAA samples; the rest "randomly labeled"; 13 samples (7 XPro1595, 6 vehicle). No channel assignment, no plex composition.
2. Europe PMC supplementary files: Tables 1-2 are cytokine data. Table 3 has 13 unlabelled `EA` columns, so there are no channel names to map on.
3. `.pdResult` (read by HTTP range over SQLite): `AnalysisDefinition` has the default sample names (`LJ_x_ - [channel]`), no factors, no groups.
4. Data Availability lists only PRIDE; no external repository.

Inferring the map from the order of the Table 3 columns or from missingness patterns would be fabrication and is not done. Even then the unused channels per plex (13 samples + pools in 22 slots) would stay unknown.

## What would unblock it
A channel/sample sheet from the submitters (H. C. Beck, Odense), or a Table 3 with plex/channel headers.

## Values established, for a future annotator
Organism Mus musculus; organ part abdominal aorta (aneurysm wall, day 7 after PPE); treatment XPro1595 vs vehicle; instrument Orbitrap Eclipse (PD instrument field and paper agree; PRIDE record lists Orbitrap Fusion Lumos, which is wrong); label TMT11plex; software PD 2.4. Modifications were not extracted from the Workflows XML in this run (the workflow XML was saved in scratch only).
