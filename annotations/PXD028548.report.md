## Templates

## Scope: deposited vs annotated

Source = mouse x leg x workflow (proteome and phospho sources kept separate because their characteristics differ). Note: for ZAK KO the stimulated leg is R in the proteome file names but L in the phospho names (and vice versa for the control leg); each run is annotated as named.
