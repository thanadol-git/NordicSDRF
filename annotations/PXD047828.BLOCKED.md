# PXD047828 — annotation blocked

## Blocking issue

The 127 DIA RAW files include full plasma, pooled GPS mixtures, negative controls, and captures named `CIMS1` through `CIMS31`. Neither PRIDE nor the accessible publication metadata maps the CIMS identifiers and GPS mixtures to the corresponding single-chain antibody capture targets. Treating the filename identifiers as biological sample identities would discard the experimental comparison and would be unsupported.

## Evidence checked

- PRIDE project record and complete file inventory (`scratchpad/PXD047828/evidence/pride.json`, `files.json`)
- DOI 10.1002/PMIC.202400049 metadata; no open full text or deposited sample sheet was available
- Filenames for all 127 RAW acquisitions
- Three deposited DIA-NN result archives (`DIANN_spike-ins.zip`, `DIANN_individual_plasma.zip`, `DIANN_multiplexed.zip`), each approximately 0.55 GB; PRIDE exposes no separate design file

## Evidence needed

A capture design/sample sheet mapping each CIMS/GPS run to plasma source, antibody target or mixture, control status, and replicate.
