# PXD004540

Status: validated annotation; independent review pending.

## Dataset

"Multiple sclerosis biomarker discovery in cerebrospinal fluid using glycopeptide enrichment, TMT labeling and LC-MS/MS". Proteomics Unit (PROBE), Department of Biomedicine, University of Bergen, Norway (submitter Astrid Guldbrandsen, PI Frode S. Berven). Paper: Kroksveen AC, Guldbrandsen A, et al. "In-depth cerebrospinal fluid quantitative proteome and deglycoproteome analysis; presenting a comprehensive picture of pathways and processes affected by multiple sclerosis." J Proteome Res 2017;16(1):179-194, doi:10.1021/acs.jproteome.6b00659, PMID 27728768. The paper is not open access at ACS. The accepted manuscript was read from the University of Bergen archive (hdl.handle.net/1956/23324).

PXD004540 is the deglycoproteome arm of the study. The global-proteome arm is PXD004572 and is not covered here. Six CSF pools (3 RRMS, 3 OND controls, 7 donors each) were labelled with TMT 6-plex and combined. N-glycopeptides were enriched on hydrazide beads and released with PNGase F. The peptides were fractionated into 15 mixed-mode fractions and analysed on a Q Exactive HF.

- The channel map comes from the paper's Table 1, row "TMT label deglycoproteome analysis" (Pool 1–6 = 128, 130, 127, 126, 129, 131). The global-proteome arm used a different layout, and that row was not used.
- Factor value: `factor value[disease]`, RRMS vs OND controls.
- Every raw file carries all six channels. There are 25 RAW files, and all are claimed. The paper's count matches: "n = 25: 15 fractions + 9 re-runs of late eluting fractions + 1 prefractionation sample".
  - `20150311_CSF_TMT_SPEG_MM_1..15.raw`: fractions 1–15, technical replicate 1.
  - `20150311_CSF_TMT_SPEG_MM_7..15_Rerun.raw`: fractions 7–15, technical replicate 2. These are the 105 min reruns of the late-eluting fractions. The raw-header method is `TMT_sensitive_105min_AG_Late_Elution_Update2.meth`.
  - `20150309_TMT_SPEG_50cm_90min.raw`: the unfractionated 5% prefractionation aliquot. This file was identified from its name: no `MM_` prefix and dated two days before the fraction runs. It is encoded as follows:
    - `comment[fractionation method]` = `not applicable`, which marks it as unfractionated.
    - Fraction identifier 1, the spec convention for an unfractionated run. The 1 does not come from the file name.
    - Technical replicate 3. This gives it its own group, separate from both mixed-mode series. Technical replicate 1 would collide with `MM_1` on the (source, biological replicate, technical replicate, fraction) coordinate.
- The 144 fractionated rows carry `comment[fractionation method]` = `NT=mixed mode chromatography;AC=MS:1003586` (Sielc Promix MP column, Methods).
- `comment[elution conditions]` = `105 min gradient` on the 54 rerun rows, from the Methods and the rerun raw method name `TMT_sensitive_105min_...`. It is `not available` on the other 96 rows.
- Fraction identifiers for the rerun rows (54 rows) were set by a deterministic post-build script, `scratchpad/PXD004540/patch_fractions.py`, keyed on the fraction number in the file name. `build` numbers fractions by list position, which would have labelled the reruns 1–9.

## Technical values

- Instrument: Q Exactive HF (MS:1002523). The raw headers of MM_6, MM_12_Rerun and 50cm_90min read "Q Exactive HF - Orbitrap MS", and the Methods agree. The PRIDE structured field "Q Exactive" is wrong and was not used.
- Search settings come from the deposited mzIdentML (PeptideShaker 1.12.2, SearchGUI with X!Tandem, MyriMatch and Comet):
  - Enzyme: Trypsin (MS:1001251), 2 missed cleavages.
  - Tolerances: precursor 10 ppm, fragment 10 ppm.
  - Fixed modifications: Carbamidomethyl on C, TMT6plex on K, TMT6plex on the peptide N-terminus.
  - Variable modifications: Oxidation on M, Deamidated on N, Acetyl on the protein N-terminus, and Glu->pyro-Glu, Gln->pyro-Glu and Ammonia-loss on the peptide N-terminus (E, Q and C respectively).
- Acquisition settings, from the paper's Methods: DDA top-12, HCD at 32% NCE, Orbitrap MS2, MS1 scan range 375–1500 m/z.

## Validation

- `parse_sdrf validate-sdrf -s PXD004540.sdrf.tsv -t ms-proteomics -t human --use_ols_cache_only` (timeout 900):
  - Round 1: 2 errors. `pooled` was rejected in `characteristics[age]` and `characteristics[sex]`. The human template sets `allow_pooled: true`, but sdrf-pipelines 0.1.6 does not enforce that flag.
  - Fix: age set to `not available`, sex set to `not applicable` (the pools are mixed-sex). The file was rebuilt and re-patched.
  - Round 2: "Everything seems to be fine. Well done." No errors, no warnings.
- **Review repair** (independent review FAIL, one important finding): the prefractionation run was indistinguishable from a third injection of mixed-mode fraction 1.
  - Fix: added `comment[fractionation method]` and `comment[elution conditions]` to `samples.tsv`. Rebuilt with `sdrf-tools build` and re-applied `patch_fractions.py` (54 rerun rows).
  - Diff against the previous SDRF: the only change is the two new columns. The other 40 columns of all 150 rows are byte-identical, and the (source, biological replicate, technical replicate, fraction) coordinate is unique.
  - Re-validated (`-t ms-proteomics -t human --use_ols_cache_only`): "Most seems to be fine. There were only warnings." 0 errors, 1 warning: `NT=mixed mode chromatography;AC=MS:1003586 in column 'comment[fractionation method]', is not found in the given ontology list pride`.
  - The warning is expected. The template's ontology check accepts only PRIDE children of PRIDE:0000550, and none of them is mixed-mode. MS:1003586 was confirmed in live OLS: label "mixed mode chromatography", not obsolete, under MS:1002271 liquid chromatography separation.
  - Technical replicate 1 for the unfractionated run was considered and rejected, because it collides with `MM_1` on the row coordinate and would merge it into the mixed-mode series.
- `sdrf-tools structure`: OK.
- `sdrf-tools check --offline`: CLEAN. 15 terms checked, 0 hallucinated, 0 UNIMOD swaps.
- `sdrf-tools score`: 97/100. The only gaps are the recommended columns `cell type` and `developmental stage`, which are absent.
- `sdrf-tools reconcile --record project.json`: one BLOCKER, `cleavage_agent_unsupported`. This is a false positive. The PRIDE protocol says only "in-solution digestion", but the paper states "in-solution trypsin digested" and the mzIdentML records Trypsin (MS:1001251).

## Limitations

- **Channel map**: taken from the paper's Table 1 (deposited publication table), not from PRIDE. The deposit has no sample sheet. Reporter's channel assignment is not in the mzid, and the generated mzTab could not be downloaded (HTTP 404), so the map could not be cross-checked against a second artifact.
- **Paper source**: the accepted manuscript, not the publisher version. Supplementary Tables S1–S3 (per-donor details, gradients, fraction collection) were not available.
- **Control disease**: the OND controls are annotated as `nervous system disorder` (MONDO:0005071). This is inferred from the paper's description "controls with other neurological diseases". Their individual diagnoses are in the unavailable Table S1.
- **Age**: `not available`. Only per-pool mean (SD) ages are reported (34–38 years). `pooled` would be more accurate but the validator rejects it.
- **Sex**: `not applicable`. Each pool is 1 male and 6 female (Table 1), so no single sex applies.
- **Ancestry category**: `not available`, as it is not reported.
- **Developmental stage and cell type**: omitted. The mean ages suggest adults, but no age range is available.
- **Prefractionation run**: modelled as fractionation method `not applicable`, fraction 1 (spec convention for an unfractionated run, not taken from the file name), technical replicate 3 (its own series). It was identified from the file name and the paper's file count.
- **Reruns**: modelled as technical replicate 2 of fractions 7–15. The fraction numbers come from the file names and were applied by the post-build script.
- **Fractionation method**: uses PSI-MS MS:1003586 rather than a PRIDE term, which causes one validator warning.
- **Elution conditions**: the gradient length is recorded only for the reruns (105 min). For the original fraction runs and the prefractionation run it is `not available`: the text does not state it and Table S3 is unavailable. A `90min` method name was not taken as the gradient length.
- **Omitted column**: `characteristics[enrichment process]` (hydrazide N-glycopeptide capture), because no fitting PRIDE or EFO term was found.
- **Reduction and alkylation reagents**: omitted. The paper cites a previous protocol rather than stating them for this experiment.
- **N-terminal refinement mods**: Acetyl, pyro-Glu and Ammonia-loss come from the mzid search parameters and are not mentioned in the Methods prose.
