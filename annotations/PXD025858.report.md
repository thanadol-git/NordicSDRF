# PXD025858 annotation report

## Result

Codex-curated SDRF with 180 rows: 60 deposited RAW files × 3 SILAC channels. Total-proteome and phospho-enriched files are retained separately through sample type and filename. SILAC channel identities follow the paper: D492M light, D492 medium (R6K4), and D492HER2 heavy (R10K8). Ten high-pH fractions are represented for each of three biological replicates.

## Evidence

- PRIDE project record: PXD025858.
- Publication: Wang et al., Molecular and Cellular Proteomics (2022), PMID 34923141, DOI 10.1016/j.mcpro.2021.100185; open-access full text PMC8803663.
- PRIDE FTP directory: 60 RAW files, SEARCH_SILAC.zip, SEARCH_SILAC_iBAQ.zip, and three MaxQuant parameter files.
- The publication and PRIDE protocol report LTQ-Orbitrap Velos Pro, high-pH reverse-phase fractionation, TiIMAC phosphopeptide enrichment, DDA, trypsin, and the R6K4/R10K8 SILAC design.

## Conservative choices

The cell-line factor is the primary experimental factor. Cellosaurus accessions were omitted because the deposit does not provide a verified mapping for all three model labels. Phospho is represented as a variable modification and sample-type distinction; exact site-level enrichment metadata is not inferred beyond the protocol.

## Validation

Run parse_sdrf validate-sdrf once per declared template and perform the standard review/adversarial-review gate before contribution. Raw-file refinement was not run because the raw files are multi-gigabyte remote files.
