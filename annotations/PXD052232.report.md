# PXD052232: mixed experiments lack run-level design map

The accession lists 18 associated RAW files in three naming groups: six 2019 `Mathias_*` runs, ten 2023 DDA `IPMS_MathiasDT_S1`–`S10` runs, and two `TMT9_fr1`/`fr2` runs. The PRIDE project protocol describes LysC digestion followed by Trypsin and label-free processing, while the TMT filenames indicate a separate labeled arm. The names do not identify which ECT/ALBA constructs, controls or biological replicates correspond to each run or TMT channel.

No SDRF was added. The ten 2023 RAW filenames identify DDA mode but not sample condition; treating `S1`–`S10` as biological replicate numbers would be unsupported. The TMT arm needs a reporter-channel map, and the current builder has only one cleavage-agent field for the documented two-enzyme digestion.

Required evidence: an accession-specific run-to-construct/condition design for the label-free arms, the TMT channel sheet, and a reviewed representation of the LysC/Trypsin workflow. Sources: [PRIDE project record](https://www.ebi.ac.uk/pride/ws/archive/v2/projects/PXD052232), `scratchpad/PXD052232/pride.json`, and accession-scoped `scratchpad/PXD052232/files.json`.
