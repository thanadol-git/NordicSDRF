# PXD025431

Status: validated annotation; independent review pending.

- Atopic dermatitis epidermis PCT-DIA (Koch et al., J Invest Dermatol 2022, PMID 36108803). DTU, Lyngby.
- SDRF: `annotations/PXD025431.sdrf.tsv`; Rows: 33; columns: 38
- SHA-256: `409edcb8aa7a88168e7750730931b22720bffd0cc4e3ca9c062e6578a705bc9b`
- Evidence manifest: `annotations/PXD025431.evidence.json`
- Templates: ms-proteomics + human + dia-acquisition (v1.1.0). Human tissue DIA; no cell-line, clinical or oncology layer since no per-patient clinical data is deposited.
- Groups: 10 healthy controls (Ko), 10 AD patients x lesional (L) and non-lesional (NL) = 20, plus 3 pooled library runs (one each L, NL, Ko) = 33 RAW files, each claimed once. One injection per sample, no fractionation.
- Factor value: `factor value[lesional status]` (healthy control / non-lesional / lesional), with a matching custom `characteristics[lesional status]`. `characteristics[disease]` is atopic dermatitis for L and NL, normal for controls.

## Validation

- `parse_sdrf validate-sdrf -t ms-proteomics -t human --use_ols_cache_only`: passes.
- With `-t dia-acquisition` added: one error, "Invalid value 'NT=Data-independent acquisition;AC=PRIDE:0000450'". This is the documented recommended form (template text and the same failure on the existing PXD009048-dia example); kept as is, validator limitation.
- `characteristics[age]` = `pooled` is documented as allowed (TERMS.tsv) but the validator rejects it; pool rows use `not available`.
- tools structure OK; tools check 3 terms verified, CLEAN.
- reconcile: one MAJOR finding (Lys-C missing). False positive: Lys-C is declared as a second `comment[cleavage agent details]` column (the build tool collapsed the pipe form, so the column was added by script; the validator accepts the repeat).

## Limitations

- Ko = healthy control and the donor/pool parsing come from file names (inference); paper not open access, not read.
- Age, sex, cell type not available. Reduction/alkylation reagents not stated, so omitted.
- Modifications are Spectronaut BGS Factory defaults, assumed, not read from the (7.5 GB, not downloaded) .sne archive.
- Tolerances not available (Spectronaut dynamic). Acquisition date is from file-name prefix.
- Pool composition inferred; it is unknown whether pool runs belong to the quantitative comparison.
- Deposit is PARTIAL; PRM validation data are not in the file list.
