# PXD019679 evidence status

The deposited `MSSampleInfo.xlsx` maps all 14 RAW run suffixes (`UL170` through `UL197`) to photoaffinity probe SBV3 and 5-HDC competitor doses. The `SBV3` value `600nM` is a merged cell spanning UL171–UL197; UL170 has 0 probe and 0 competitor. The competitor column is labeled `5´-OH-DF` in the workbook, while the paper identifies 5-hydroxydiclofenac (5-HDC). The source material is rat hippocampal membranes and the PRIDE acquisition protocol explicitly states Q Exactive HF Top10 DDA/HCD.

**Unapproved / not yet built.** The PRIDE processing protocol reports modifications but not the cleavage agent or source-level biological replicate structure. The main paper places the detailed methods in a supporting PDF, which was not available from the tested open-access endpoints. These details need verification before a complete SDRF is built. No trypsin or replicate assignment has been inferred from MaxQuant defaults.

Sources: [PRIDE project](https://www.ebi.ac.uk/pride/archive/projects/PXD019679), deposited `MSSampleInfo.xlsx` (local copy in `scratchpad/PXD019679/`), and [paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC8346900/).
