# PXD004541 annotation report

## Scope

All 48 deposited RAW files are represented as 480 channel-aware TMT assay rows.

## Evidence and decisions

- PRIDE specifies duplicate DMSO and TH1579 CETSA experiments in BJ Ras SV40 cells. Each TMT10 set maps its ten channels to 37, 41, 44, 47, 50, 53, 56, 59, 63, and 67 C.
- RAW names identify the four sets and 12 basic-reversed-phase fractions. Each temperature channel is represented per fraction rather than collapsed into a generic pooled run.
- The method used sequential Lys-C/trypsin digestion; the SDRF cleavage field records terminal trypsin specificity.
