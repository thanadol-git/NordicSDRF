## Design (IP arm, annotated)
Triple SILAC, Kit225 T-cells. PRIDE sample protocol: control (Arg0/Lys0, light), IL-2-treated (Arg6/Lys4, medium), IL-15-treated (Arg10/Lys8, heavy), mixed 1:1:1; immunoprecipitation with an anti-IL-2R beta or anti-IL-2R gamma antibody; SDS-PAGE; in-gel trypsin; peptides analysed either directly (total) or after TiO2 phosphopeptide enrichment. The deposited MaxQuant mqpar.xml/summary.txt confirm multiplicity 3 with labels Arg6;Lys4 and Arg10;Lys8.
Per receptor, two biological replicates:
- IL2RG: replicate 1 = IP8 (MaxQuant experiment silac_1), replicate 2 = IP10 (silac_2), from the deposited experimentalDesignTemplate.txt.
- IL2RB: replicate 1 = IP11 (folder "IP11_IL2RB_rep1"), replicate 2 = IP26 (file names "IL2RBrep3", RAW header title "031214_IP26_TiO2_n"). The submitter calls the second one "rep3"; the PRIDE text says duplicate experiments, so it is numbered 2 here. Raw headers prove the 11 `Qex03022`-`Qex03032` files are IP26 TiO2 runs (titles read for 03022 and 03032; the 11-file sequence is assumed consecutive).
Per replicate, two injection sets from the same IP: total (gel-slice fractions) and TiO2-enriched (gel-slice fractions). These are separate rows via `source name` suffix `_total` / `_TiO2` and `characteristics[enrichment process]`. 12 sources: 2 receptors x 2 replicates x 2 sets, each x 3 channels = 24 sources.
- Fractions (gel slices) numbered from the numeric suffix of the file names, in order. IL2RB: total 12 (rep1) / 15 (rep2); TiO2 9 (rep1) / 11 (rep2). IL2RG: total 13 / 11; TiO2 9+1 / 9+1.
- Two extra TiO2 files are listed as technical replicate 2: `20130623_NO_IP8_TiO2_1BIS.raw` (re-injection of fraction 1, reasonably safe) and `20130719NO_VA1_0617_IP10_TiO2_1and2.raw` (name says fractions 1 and 2 combined; it is **assigned to fraction 1, tech rep 2 as a convention, not a verified identity**; the MaxQuant design file does not resolve it).
Factor value: treatment (control / interleukin-2 / interleukin-15). `characteristics[treatment]` = `not applicable` for the unstimulated control.

## Blocked arm: phosphopeptide pull-downs (41 RAW, not annotated)
Four pull-downs (IL2RB pS431, pT476; IL2RG pY325, pY357) use biotinylated phospho- vs non-phospho peptide baits with 2-plex SILAC (Arg0/Lys0 vs Arg10/Lys8), and "swapping the SILAC labels for replicate experiments". The deposit has no label-to-bait map: MaxQuant experimentalDesignTemplate.txt files only carry EXP1/EXP2 for replicates (none for pS431), mqpar (pT476) lists labels but not the bait, and the paper is paywalled. File names (`3pS_S`, `7S_pS`; `1T_pT`, `5pT_T`; ...) swap the order between the two replicates and probably encode light-heavy order, but that is an inference I did not write. Also the Methods use an on-bead LysC + trypsin digest for these (the reconcile check flags Trypsin/Lys-C versus my Trypsin/P, which applies to this arm only). Sources checked: PRIDE record, file inventory, search-file designs/parameters, RAW headers (Orbitrap Velos Pro). Would unblock: the paper's supplementary table or a submitter map giving the heavy/light bait per replicate and file.
