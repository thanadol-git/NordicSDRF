# PXD011008 — annotation blocked

## Dataset

- **Title:** Early Pleistocene enamel proteome sequences from Dmanisi resolve Stephanorhinus phylogeny (palaeoproteomics)
- **PRIDE record:** PXD011008
- **Publication:** PMID 31511700

## Evidence recovered

62 RAW (2013-2019, Q Exactive / Plus / HF) from 23 Dmanisi fauna specimens, medieval ovicaprine controls, extraction blanks and a synthetic-peptide run. Per-specimen MaxQuant txt ZIPs (16486, 16626-16642, 16856-16861) give a reliable run -> specimen-number map (summary.txt), and NegContr ZIPs identify the blanks.

## Why no SDRF was emitted

The specimen-number -> taxon / skeletal element (enamel, dentine, bone) table needed for characteristics[organism] and [organism part] is only in READ_ME.pdf, which is image-based and not machine-readable here; the run -> extraction protocol (A FASP, B GuHCl, C digestion-free acid demineralisation) is also not stated per file. Guessing taxa for ancient specimens is not acceptable.

## Sources checked

PRIDE record and protocols; summary.txt of all 28 MaxQuant/control ZIPs (run -> specimen map recovered); READ_ME.pdf (image tables).

## Unblocking requirement

A text table: specimen number -> taxon, element, extraction protocol per run (e.g. from Extended Data of the paper).
