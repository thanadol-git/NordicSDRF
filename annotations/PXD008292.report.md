## Design and file mapping

Per the PRIDE sample-processing protocol:

- Muscle was collected 45 min post mortem from three pigs per genotype and digested in solution.
- The four genotypes were labelled iTRAQ-114 (normal/control), 115 (RN mutant), 116 (HAL mutant) and 117 (RN/HAL double mutant), then mixed equally.
- There were three biological replicates.
- Phosphopeptides were enriched with TiO2. Both the phosphopeptide fractions and the non-modified (flow-through) peptides were analysed on a Q Exactive Plus.

The deposit itself shows the run structure:

| Plex (RAW header comment) | Phospho runs (header "Phosphopeptides with iTRAQ from HAL/RN pigs-X") | Flow-through runs (header "FTfrom Phosphopeptides ... pigs-X") | Deposited PD search |
|---|---|---|---|
| A, biological replicate 1 | Qex02115-Qex02128 (14) | Qex02156-Qex02168 (13) | PhosphoA-RLA15-28.msf, FTARLA56-68.msf |
| B, biological replicate 2 | Qex02129-Qex02142 (14) | Qex02169-Qex02181 (13) | PhosphoB-RLA29-42.msf, FTBRLA69-81.msf |
| C, biological replicate 3 | Qex02143-1, Qex02143-Qex02155 (14) | Qex02182-Qex02194 (13) | PhosphoCRLA43-55.msf, FTCRLA82-94.msf |

- Each plex is one 4-plex mix: one source per genotype. That gives 12 sources: `PXD008292_<WT|RN|HAL|RNHAL>_pig<1-3>`. `characteristics[biological replicate]` is 1-3 within each genotype and equals the plex.
- Within a source, `comment[fraction identifier]` is 1-14 for the phospho runs and 15-27 for the flow-through runs, in acquisition order (file number order). `characteristics[enrichment process]` separates the two sets: `enrichment of phosphorylated protein` on phospho rows, `not applicable` on flow-through rows.
- `Qex02143-1.raw` is not a re-injection. Its RAW header gives the original name `D:\Qex02142_140807175417.raw` (Xcalibur's name-collision suffix, so it was acquired after Qex02142) and vial RE5. That is the first-vial position of plex C, matching RC5 for plex B's first fraction. Qex02143 is vial RE7. The plex C phospho search lists Qex02143-1 as an input, so it is annotated as phospho fraction 1 of plex C, and Qex02143 to Qex02155 are fractions 2-14.
- All 81 deposited RAW files are in the SDRF. No file was left out.

## Technical values and sources

- Instrument: `Q Exactive Plus` (MS:1002634), taken from every RAW header (`Q Exactive Plus - Orbitrap MS`) and the PRIDE protocol. The PRIDE instrument field says `Q Exactive` (MS:1001911); the RAW headers take precedence.
- Dissociation: HCD (MS:1000422), from the method name `90mingradient_HCD31.meth` in every RAW header and the PD search-node `Instrument` setting ("HCD plus a, Immo ..."). MS2 analyzer: orbitrap, because the Q Exactive Plus has no other MS2 analyzer.
- Acquisition: DDA (PRIDE:0000627). The runs were searched with Mascot and Sequest HT on PD 1.4 (spectrum-centric DDA search).
- Modifications, precursor 10 ppm, fragment 0.05 Da, trypsin: read from the Mascot and Sequest HT node parameters in the deposited `.msf` files. They were read by HTTP range requests over the first 0.5-2 MB, because the files are 3-4 GB.
  - Parameter values were readable for PhosphoA, PhosphoB, PhosphoC and FTA, and all four are identical.
  - FTB's range-read chunk held its input-file list (Qex02169 onward) but not its parameter values.
  - FTC could not be range-read: the server returned an error page.
  - Mascot: Acetyl (N-term), Acetyl (K), Oxidation (M), iTRAQ4plex (K), Phospho_STY, Deamidated (NQ), iTRAQ4plex (N-term), Carbamidomethyl (C).
  - Sequest HT: iTRAQ4plex K and any N-terminus, Phospho STY, Oxidation M, Deamidated NQ, Acetyl K, Carbamidomethyl C.
  - All of these are dynamic (variable), so Carbamidomethyl is written `MT=Variable`.
  - Enzyme: Trypsin (Full), 2 missed cleavages.
- Labels: `iTRAQ114`-`iTRAQ117` channel shortcuts, as emitted by `sdrf-tools build`.

## Limitations

- **Channel map.** Taken from the PRIDE protocol: 114 = normal/control, 115 = RN, 116 = HAL, 117 = RN/HAL. It is given once for the whole design. I assume it holds for all three plexes; no per-plex table was available, because the paper's Figure 2 and Supplemental Table 1 are behind the paywall.
- **One pig per channel (inference).** The text "three pigs per genotype ... three biological replicates" with three deposited plexes is read as one pig per genotype per plex (A/B/C = replicates 1/2/3). It is not known which animal ID went into which plex; Supplemental Table 1 was unavailable. Source names are synthetic (`PXD008292_<genotype>_pig<n>`).
- **Fraction identifiers (inference).** These follow acquisition (file number) order. Autosampler vials run 5/6, 7..12, then the next row 1..4, 7, 11, then vial 1 last. The physical fraction order is not documented, so "fraction 1" may not be the first-eluting fraction. Flow-through fractions are numbered 15-27 so the (source, replicate, fraction) coordinate stays unique alongside the phospho fractions 1-14.
- **`comment[fractionation method]` = `not available`.** The deposit shows 14 phospho and 13 flow-through fractions per plex. The fractionation chemistry is not stated in PRIDE and the Methods were unavailable.
- **`characteristics[sex]`, `developmental stage`, `strain or breed` = `not available`.** Per-animal gender and weight are in the unavailable Supplemental Table 1. PubMed MeSH (Muscle, Skeletal; Swine; Genotype; Mutation; ...) carries no sex or breed heading. Age was omitted.
- **`characteristics[disease]` = `not available`.** The validator requires the column. The record describes meat-quality genotypes and states no disease status. HAL (RYR1) is associated with porcine stress syndrome, but the deposit does not state a phenotype per animal.
- **`characteristics[organism part]` = `skeletal muscle tissue`.** The specific muscle is not named in the available record. PRIDE's structured field says "Skeletal muscle fiber" (BTO).
- **`characteristics[sampling time]` = `45 minute`.** This is minutes post mortem, from the PRIDE protocol.
- **Genotype labels.** These are the protocol's wording; the causal alleles (e.g. PRKAG3 / RYR1 variants) are not stated in the available record and were not added.
- **Cleavage agent.** Trypsin rests on the data-processing protocol and the deposited fully specific trypsin searches (Mascot and Sequest HT). The digest reagent is not named in the sample-preparation prose. A per-run C-terminus check is not independent here, because a fully specific search can only return tryptic peptides.
- **Acetyl (N-term).** Mascot's `Acetyl (N-term)` is written as `PP=Any N-term` per the deposited search. The PRIDE text says "acetyl (protein N-terminus)". Sequest HT did not search N-terminal acetylation.
- **Reduction/alkylation reagents.** Not stated. The columns are omitted; carbamidomethylation was searched as variable only.
- **FTCRLA82-94.msf.** Never range-read successfully; the server returned an HTML error. Its file set (Qex02182-Qex02194) is inferred from its name and the RAW header comments ("FTfrom ... pigs-C").
- **FTB and FTC search settings.** Assumed identical to the four readable searches; the PRIDE data-processing protocol describes a single search setup.
- **`.msf` input-file lists.** The full list was read only for PhosphoC (14 files, including Qex02143-1). For the others, the readable part of the list agrees with the RLA run ranges in the `.msf` names (RLAnn = Qex021nn).
