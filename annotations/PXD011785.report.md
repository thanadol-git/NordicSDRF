## Limitations

- Disease assignment from file prefix (MS vs K) is inferred; paper reports 13 patients/14 controls but deposit has fewer files (some excluded, CD8 purity). Paper Table 1 patient IDs (MS1..13) do not map to file IDs.
- Age: only 5-year category per anonymised patient in the paper; set `not available`.
- Ancestry "European" is the parent of the stated self-declared Nordic ancestry.
- `individual` derived from file names (suffixes a, _2, _Batch1, ny stripped); one donor assumed per ID across CD4/CD8.
- Modifications, tolerances taken from PRIDE protocol/paper; the MaxQuant zips (1 GB each) were not opened. N-term acetylation not stated, not added. Reduction/alkylation reagents not named (DTT stated in paper but not annotated).
- Dissociation CID with NCE 35 from paper (stated "35 eV"); fragment analyser (ion trap) not annotated.
- Cell counts: 1e6 cells per sample, FASP, no fractionation (fraction 1).
