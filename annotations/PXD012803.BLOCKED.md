# PXD012803 — BLOCKED

## Exact blocker

The accession aggregates 30 generically numbered label-free RAW files used across multiple linked yeast studies, but no deposited design file joins each RAW basename to a biological condition/sample and technical replicate. The two result workbooks summarize three technical replicates without exposing the RAW-level join.

## Evidence checked

- PRIDE project record: `https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD012803`
- PRIDE file inventory: `https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD012803/files/all`
- Linked open publications: `https://pmc.ncbi.nlm.nih.gov/articles/PMC7171132/`, `https://pmc.ncbi.nlm.nih.gov/articles/PMC7132131/`, and `https://pmc.ncbi.nlm.nih.gov/articles/PMC7474676/`
- Deposited `2827YEASTproteinsAllPeptQuan3TRs.xlsx`
- Deposited `2827UPS2proteinsAllPeptQuan3TRs.xlsx`

PRIDE declares MS1-intensity label-free quantification and lists 30 RAW files named only by instrument/date/acquisition number. The protein workbooks contain abundance columns `Techn Repl 1`, `Techn Repl 2`, and `Techn Repl 3` for yeast and UPS2 analyses, but no RAW filenames. The linked papers describe several yeast growth/nutrient experiments; matching those conditions to acquisition numbers by date, order, or paper association would be speculative.

## Evidence needed to unblock

An acquisition/experimental-design export mapping every RAW basename to the exact study arm, culture condition, biological source, biological replicate, technical replicate, and whether the UPS2 standard was present. It must also identify which linked experiment each run belongs to.
