## Scope, evidence and decisions
Status: **annotated**. 9 rows (3 mzML x 3 iTRAQ channels), 43 columns.

- **Assay name model:** there is one assay name per multiplexed run (`iTRAQ_osm1`, `iTRAQ_osm2`, `iTRAQ_osm3`). Each is shared by the 3 channel rows of its file, and `comment[label]` tells them apart. This follows spec README Row Uniqueness: channels of one multiplexed run share an assay name. (source name, assay name, label) is unique on all 9 rows.

- **Deposited files:** 7 files on the PRIDE FTP/HTTPS listing (`ftp.pride.ebi.ac.uk/pride/data/archive/2015/08/PXD002661/`), plus the PX PROXI record (Page URL checked as PXD002661):
  - `iTRAQ_osm1_peaklist.mzml` (675 MB), `iTRAQ_osm2_peaklist.mzml` (643 MB), `iTRAQ_osm3_peaklist.mzml` (657 MB), typed RAW in README.txt;
  - `iTRAQ_osm{1,2,3}_protein.xml` (PRIDE XML search results; each maps to its mzML in README.txt);
  - `README.txt`.
  - PRIDE v3 `files/all` returned "upstream connect error" (one try).
- **Campaign cache was wrong.** It listed "3 RAW / 6 files, TripleTOF 5600, .wiff + .wiff.scan". **No .wiff or .wiff.scan is deposited.** The 3 "RAW" files are mzML peak lists, so they are the `comment[data file]` values (CI advisory `peak_list_data_file`). The PX record is flagged "Unsupported dataset by repository" (PARTIAL submission).
- **SWATH:** the paper's SWATH confirmation runs are **not deposited** (no SWATH files in PRIDE, and none in MTBLS214, which holds metabolomics .wiff only). So there is no SWATH SDRF and no file split; the only acquisition type is iTRAQ IDA.
- **Deposited vs annotated:** all 3 spectra files are annotated (3 channels each, 9 rows). The 3 protein.xml files are search outputs, not runs.
- **Channel to sample map (STATED, PRIDE sample protocol, read through the OmicsDI mirror of the PRIDE record):** "iTRAQ reagents 114, 115 and 116 were added to control, T1 and T2 samples respectively."
  - iTRAQ 4plex (ProteinPilot "sample type: iTRAQ 4plex (peptide labeled)"). Channel 117 is unused and gets no row.
- **T1/T2 definition (STATED, MetaboLights MTBLS214 sample-collection protocol, same paper and authors, read through the OmicsDI mirror):** "control – unadjusted KFSM media at 277 mOsm/l, T1 and T2 – KFSM media adjusted to 377 mOsm/l 477 and mOsm/l respectively". The media were adjusted with 2 M NaCl in PBS, and cells were incubated for 24 h in keratinocyte serum-free medium. MTBLS214 says "Cells for all experiments were treated using the same procedure".
  - The abstract and the PX description give the nominal values 280 (control), 380 and 480 mOsm. The SDRF treatment text gives the measured value with the nominal one beside it, e.g. `377 mOsm/L (nominal 380)`, so readers of the PRIDE record can match the conditions.
- **Replicates:** the data protocol says significance needed "at least two out of three replicates". MTBLS214 says each set was three parallel sub-cultures (control/T1/T2) of cells.
  - So each iTRAQ mixture (file) is one set, which is a biological replicate. `osm1/2/3` then maps to biological replicate 1/2/3, by file-name index. That index is a numbering convention; it does not affect any condition assignment.
- **Sample:** IOBA-NHC, CVCL_9Y68 (Cellosaurus, checked live): spontaneously immortalized, normal conjunctiva (UBERON:0001811), conjunctival epithelial cell (CL:1000432), male, 49Y. Developmental stage `adult` is derived from the age. Disease `normal` (PATO:0000461). PRIDE/OmicsDI tag the project with "Dry Eye Syndrome", but that is the modelled clinical context, not the state of the sample. The cells come from normal conjunctiva (Cellosaurus; the abstract says "normal human conjunctival cell line"). The hyperosmotic stress is encoded as the treatment, and no donor or sample has dry eye.
- **Prep (stated, PRIDE protocol):** FASP; 50 ug protein, SDS + TCEP at 60 C for 1 h, IAA for 20 min in the dark; trypsin (AB Sciex) 1:25 for 16 h at 37 C; iTRAQ labelling, pooling, desalting.
  - No fractionation is mentioned (pooled, then desalted, then nano-LC-MS/MS), so fraction identifier = 1 and there is no fractionation-method column.
- **MS (stated):** Ultimate 3000 nano-LC, 75 um x 15 cm Acclaim PepMap RSLC, 105 min. TripleTOF 5600, IDA (top 30), MS1 350-1250 m/z, MS2 100-1800 m/z, charge 2-5, 12 s exclusion, rolling CE.
  - Instrument: the PX record, the protocol and the ProteinPilot setting agree.
- **Search (stated):** ProteinPilot 4.5 against UniProt (Sep 2010, 40,516 proteins), iTRAQ 4plex, cys alkylation iodoacetamide, trypsin, "biological modifications" ID focus, 1% FDR.
  - Encoded: Carbamidomethyl C (UNIMOD:4) fixed; iTRAQ4plex (UNIMOD:214) on K and any N-term fixed.

## Values left not available / not applicable / omitted
- `precursor/fragment mass tolerance` = not available: ProteinPilot Paragon takes no user tolerances, and none are stated.
- `ancestry category` = not available: Cellosaurus gives none.
- `individual` = not available: there is a single donor with no identifier.
- `culture medium` is omitted. The cell-lines template needs an NCIT growth-medium term, and none was verified for KSFM, the medium at harvest; maintenance medium was DMEM/F12 + 10% FBS. KSFM is recorded in the treatment text instead.
- `collision energy` is omitted: only "rolling CE" is stated.
- `passage number` and `sample storage temperature` are not stated and are not used.
- The PX modification MOD:00397 (iodoacetamide derivatized residue) is encoded as Carbamidomethyl. ProteinPilot "biological modifications" (probabilistic, unspecified) are not encoded; the protein.xml files (762-817 MB) were not read.

- Osmolarity: 280/380/480 (abstract, PX) vs 277/377/477 (MTBLS214 measured). These are the same conditions at nominal vs measured values; the measured values are used.
- PX `datasetHistory` contains an unrelated PXD083400 (HEK293T itaconylation, Fusion Lumos). This is a ProteomeCentral record artifact and was ignored.
