# PXD036306 — BLOCKED

## Exact blocker

The deposited spreadsheet lists reporter assignments for seven TMT sets, but it does not map any set to the 139 deposited RAW filenames. The RAW files span three acquisition dates and do not contain a set identifier. In addition, most spreadsheet channels are labelled only `S`, without a source-sample ID, so their biological identity is unresolved even before attempting a run mapping.

## Evidence checked

- PRIDE project record and protocols: `https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD036306`
- Complete PRIDE file listing: `https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD036306/files/all`
- Deposited `TMT-labels_healthy-women.xlsx`: `https://ftp.pride.ebi.ac.uk/pride/data/archive/2022/09/PXD036306/TMT-labels_healthy-women.xlsx`
- Open-access publication and supplements: `https://doi.org/10.3389/fmed.2022.952827` (PMCID `PMC9622934`).
- The only other deposited non-RAW file is a 25.1 GB Proteome Discoverer `.pdResult` database; there is no standalone study/file table or acquisition export.
- Community annotation directory: absent (GitHub directory returned 404).

## Mapping facts that were resolved

- The workbook specifies TMT126-TMT131C layouts for sets 1-7, including reference channels `ref1` through `ref7`, selected `K...` sample IDs, and two explicitly empty channels in set 7.
- The project and publication identify human term placenta, Orbitrap Fusion TMT analysis, trypsin digestion, basic reversed-phase fractionation, and MS3 HCD reporter quantification.

## Why an SDRF was not written

Assigning acquisition-date blocks or sequential groups of 20 RAW files to sets 1-7 would be an inferred set/run map, and expanding channels marked only `S` into individual placenta sources would invent sample identities. A supportable SDRF requires a Proteome Discoverer study/file export or sample sheet that maps each RAW filename to its TMT set and resolves every non-empty channel to a source sample.
