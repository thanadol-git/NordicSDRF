# PXD052229

Status: validated annotation; independent review pending.

- Influenza A (swH1N1 / huH1N1) infection of pig upper/lower trachea, label-free DIA (Orbitrap Exploris 480 + FAIMS, Evosep 10SPD), DTU Lyngby.
- SDRF: `annotations/PXD052229.sdrf.tsv`; evidence: `annotations/PXD052229.evidence.json`
- Templates: ms-proteomics, vertebrates, dia-acquisition (v1.1.0). Rows: 144; columns: 44.
- Rows: 84 sample runs (MS1-MS84), 40 fractionated library-pool runs (4 pools x 10 high-pH fractions), 20 unfractionated library-pool runs (4 pools x 5 injections). All 144 RAW files claimed once.

## Key limitations

- **No file-to-sample mapping.** Neither PRIDE, the paper nor the deposited files say which MS1-MS84 run is which pig, tissue (upper/lower) or group (control / swH1N1 / huH1N1). 84 runs do not equal 22 pigs x 2 tissues (44), so duplicates or extra runs are likely but undocumented. Each run is therefore its own source (`MS<n>`), disease/treatment/developmental stage are `not available`, and no factor value column is written. Project-level disease (influenza) was deliberately not broadcast, since controls exist.
- Sex not stated; age (seven-week-old pigs at inoculation, sacrificed 3 dpi) not encoded as there is no per-file link and no clean developmental stage term.
- Pool names: poolCTR/SWINE/HUMAN/MEXI; "MEXI" is unexplained in the deposit. Sample type for pools set to `study sample`, pooled sample = `pooled`.
- Cleavage agent: protocol uses LysC then trypsin; column is single-valued, Trypsin/P recorded.
- Modifications taken from the PRIDE processing text; the 14 GB Spectronaut .sne archive was not opened. Mass tolerances `not available`. `comment[dia method]` `not available`. Collision energy "32% NCE" assumes normalized energy.
- Unfractionated pool injections are labelled as technical replicates 1-5 of the pool (inferred from file names `_1`..`_5`).

## Validation

- `parse_sdrf validate-sdrf -t ms-proteomics -t vertebrates -t dia-acquisition` (full ontology run): exit 0, one warning (`strain or breed` free text "Danish Landrace crossbred" not found in ncbitaxon; free-text column, warning only).
- `tools structure`: OK. `tools check` (earlier build): 14 terms verified, 0 hallucinated.
- `tools reconcile`: one MAJOR remaining, `cleavage_agent_incomplete` (record says Trypsin + Lys-C; `comment[cleavage agent details]` is single-valued, `build` collapses a second value, so only Trypsin recorded). Not fixable within the template.
- **Validator rejection:** the recommended `NT=Data-independent acquisition;AC=PRIDE:0000450` form in `comment[proteomics data acquisition method]` was rejected by the dia-acquisition union ("must be one of the allowed values"); the template documents plain `Data-independent acquisition` as allowed and that passes, so the plain form is used (differs from other examples in this repo).
- Cleavage agent in the file is Trypsin (MS:1001251), not Trypsin/P as stated in the evidence manifest claim; Lys-C is not representable. `characteristics[sample type]` `study sample` is flagged in cache-only mode but passes the full run.
