## Limitations

- The deposited raw data is a single archive LCMS_files.zip; contents not unpacked or listed. Six .d run names were taken from the deposited MaxQuant mqpar_2.xml/proteinGroups and claimed in place of the zip.
- Run-to-condition mapping (which IP is SYTL5-EGFP vs EGFP) is not in any metadata; it was inferred from bait (SYTL5) protein intensities in the deposited proteinGroups. IP2/4/6 = SYTL5-EGFP, IP1/3/5 = EGFP.
- Biological replicate numbers 1-3 within each group follow run order (IP1/IP2 = 1, IP3/IP4 = 2, IP5/IP6 = 3); pairing is an assumption, not documented.
- Age 15Y and sex female are Cellosaurus values for U2OS, not sample-specific. Cell line is U2OS Flp-In T-REx per the paper; annotated as parent U2OS (CVCL_0042), the engineered derivative not separately resolved.
- Dissociation method, MS2 analyzer, reduction and alkylation reagents are not stated explicitly: not available. Organism part and cell type not available (osteosarcoma line; no CL/BTO term assigned).
- Doxycycline induction (100 ng/ml, 24 h) applies to all samples and is not annotated as a treatment column. characteristics[transgene] is a non-template extra column.
- Protocol text states 6 ppm main search error while deposited mqpar_2.xml has 10 ppm; the file value was used.
- SANDBOX ONLY (independent review FAIL): row 6 names 'Ana IP 6 repeated_Slot1-24_1_247.d', the run searched in mqpar_2.xml/proteinGroups, but the deposited zip (283 entries, central directory read) contains instead 'IP6 Ana_Slot1-24_1_227.d' (not searched); the _247 repeat is NOT deposited.
