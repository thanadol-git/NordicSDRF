# PXD027901 - SDRF annotation report

## Study
Jakobsen et al., Glia 2021 (doi:10.1002/glia.24072, PMID 34378239): phosphoproteomics of primary mouse (NMRI) cortical astrocytes (DIV 21) treated 6 min with the soluble adenylyl cyclase inhibitor 2-OHE (50 uM) or DMSO vehicle (n=3 each). Samples were digested with trypsin, labelled with TMT 6plex (controls 126/127/128; treated 129/130/131), pooled, TiO2-enriched, fractionated by high-pH reversed phase and measured on a Q Exactive HF-X (DDA, HCD).

## Templates
ms-proteomics v1.1.0 + vertebrates v1.1.0. cell-lines was not used because these are primary cultures, not an established cell line.

## Scope: deposited vs annotated
Deposited: 14 RAW files (QEHFX_00334..00347_MRL.raw), plus a Proteome Discoverer .msf, mzid, mgf and mzML (one combined search). Annotated: all 14 RAW files x 6 TMT channels = 84 rows x 39 columns (single pooled TMT experiment, one SDRF).

## Key decisions
- One row per (RAW file, channel); each of the 6 sources spans all 14 files.
- Fraction identifier assigned by RAW file-number order (1-14). This is an assumption: the protocol states 12 concatenated high-pH fractions but 14 RAW files are deposited, and no deposited file maps run to fraction (the mzid/mzML/mgf are merged searches).
- Instrument Q Exactive HF-X: protocol text and file prefix QEHFX; PRIDE structured field says Q Exactive HF (overridden).
- Modifications read from the protocol and cross-checked against mass deltas in the deposited mzid (229.1629 TMT6plex, 79.9663 Phospho, 0.9840 Deamidated, 57.0215 Carbamidomethyl): TMT6plex K and N-term fixed, Carbamidomethyl C fixed, Deamidated N variable, Phospho STY variable. Tolerances 10 ppm / 0.05 Da and 2 missed cleavages from the protocol.
- Factor value[treatment] = treatment (2-OHE vs DMSO); treatment text is the free-text description of the dose and time.
- organism part "cerebral cortex" (cortical astrocyte cultures), cell type astrocyte, disease "normal", material type "cell".

## Values left not available
developmental stage (cells sampled at DIV 21 from P7 pups; per-sample stage not asserted), sex, reduction reagent, alkylation reagent (carbamidomethyl is stated but the reagent is not named).

## Conflicts
- 12 fractions (text) vs 14 RAW files.
- Instrument HF (PRIDE field) vs HF-X (protocol, file names).
- Organisms in PRIDE include Acyrthosiphon pisum (pea aphid), which is not supported by the protocol; ignored.

## Inferred vs stated
Stated: organism, strain, cell type, treatment, dose, time, labels and channel map, instrument, enzyme, mods, tolerances, NCE 32, fractionation. Inferred: organism part (cerebral cortex from "cortical astrocytes"), disease "normal", fraction order, "2-OHE" kept unexpanded.

## Validation
`parse_sdrf validate-sdrf --use_ols_cache_only` (templates ms-proteomics, vertebrates): no errors; 4 warnings (treatment values and enrichment process "phosphopeptide enrichment" not found in the allowed ontologies; strain "NMRI" not an NCBITaxon term, free text). `sdrf-tools structure` OK. `sdrf-tools reconcile`: all values agree with the record. Paper full text not available in Europe PMC (not open access); PRIDE protocol text used in its place. Raw file headers not inspected.
