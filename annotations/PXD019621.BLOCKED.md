# PXD019621 — BLOCKED

## Exact blocker

49 RAW files are deposited in two unrelated experiments. For 25 of them (the 2014 SILAC time-course runs `20140621_SL_qe2g140_Hep2_SP_b1_{EGF,EPI,HB,Ta}_{0_2,0_30,2_15,6_15,30_6}.raw`, 20 files) there is no defensible file-to-sample/channel map: the paper is not retrievable, and nothing deposited states which SILAC label (light / medium / heavy: Arg0/6/10, Lys0/4/8) carries which stimulation time point or condition in each run. The numeric suffixes (e.g. `0_2`, `2_15`, `30_6`) look like pairs of time points, but their units, which pair maps to which label, and whether a third channel is a further time point are not recorded anywhere that was reachable. Writing a channel map would be invention. (The remaining 29 files are the 2015 PRM label-free set, which is mappable, but the project cannot be annotated half-way: every acquisition must be annotated.)

Secondary uncertainty for the 2015 set: file names use ligand x {15,45} x replicate 1-3 (the MaxQuant mqpar.xml also lists 90, not deposited); time unit not stated (the abstract says 30 s to 15 min).

## Evidence checked

- PRIDE project record and the full file list (pageSize=100, page 0 = 51 files; pages 1-3 empty): 49 RAW + 2 SEARCH zips (`MaxQuant_searches_for_PRM.zip`, `Mascot_search_files_for_MSQuant.zip`).
- PRIDE protocols: SILAC (PRIDE:0000315) declared, variable mods Label:13C(6) R6, 13C(6)15N(4) R10, 2H(4) K4, 13C(6)15N(2) K8; no label-to-condition table.
- Publication: Akimov et al., J Mol Biol 2021, "Magnitude of Ubiquitination Determines the Fate of Epidermal Growth Factor Receptor Upon Ligand Stimulation", PMID 34508725, doi 10.1016/j.jmb.2021.167240. PubMed abstract only; not in PMC/Europe PMC full text (no supplementary files); ScienceDirect and linkinghub return 403/JS redirect; Crossref lists the TDM API only (needs an API key). Methods and supplements could not be read.
- Zip contents read by HTTP range: MaxQuant `mqpar.xml`/`summary.txt`/`parameters.txt` (2015 PRM runs only: multiplicity 1, label-free, 44 files incl. undeposited 90 groups, experiments BEADS/CONTROL/EGF15/.../tgf90) and the Mascot/MSQuant report header for Egf1 (`..._EGF_0_30.mgf`; shows labels used in the search but not which channel is which time point). The Mascot reports (20 htm files, ~50 MB each) were not mined further because MSQuant ratio assignments are not in them.

No deposited SDRF was used.

## Evidence needed to unblock

The paper's Methods/supplement (or submitter) stating, for the Hep2 SILAC time-course, the label-to-time-point/ligand assignment per run (and the time unit for the PRM 15/45 groups), or the MSQuant quantification files that carry it.
