# PXD052956: channel map required

The accession contains 46 full-proteome RAW fractions and six phosphopeptide RAW runs from a pooled TMTpro mixture. PRIDE names the occupied reporter channels as 126, 127N, 128N, 129N, 130N and 131N, but does not assign the six channels to individual control or MASH sources. The deposited MaxQuant parameters and the paper's supplementary tables do not supply that key. A channel-to-source map is required before a sample-level SDRF can be written without guessing.

The phosphopeptide RAW list has two names labelled fraction 2 (one with a timestamp suffix) and none labelled fraction 4. The experimental protocol describes six concatenated phosphopeptide fractions, but does not explain whether the second fraction-2 file is a replacement, repeat or separately fractionated acquisition. That identity also needs confirmation.

Checked: [PRIDE PXD052956](https://www.ebi.ac.uk/pride/archive/projects/PXD052956), [published Methods](https://pmc.ncbi.nlm.nih.gov/articles/PMC11744578/), and the [Europe PMC supplementary package](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC11744578/supplementaryFiles), including both Word supplements and all seven supplementary Excel tables. No SDRF is approved for this accession.

The paper's Data Availability statement offers other supporting data only from the corresponding author upon request; it does not cite a public external repository with a sample layout. The missing six-channel map and identity of the second fraction-2 acquisition would need author or depositor clarification.
