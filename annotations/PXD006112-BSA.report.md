## Why three SDRFs

The deposit holds three experiments that differ in sample, organism, gradient, MS settings and data processing:
- BSA: 30 min method, top-5, MaxQuant search against BSA P02769.
- HeLa: 140 min method, top-12, MaxQuant search against human UniProt.
- Synthetic isoaspartyl peptides: 40 min method, dynamic exclusion 0, no database search (Xcalibur peak areas).

Each experiment has its own MaxQuant output zip (or none) and its own section of the deposited Readme. This file covers the 39 BSA RAW files.

## Templates

`ms-proteomics` v1.1.0 only. The sample is a commercial tryptic digest of one purified bovine protein (Bruker), not a vertebrate tissue or organism sample, so the `vertebrates` layer does not fit. DDA, so no DIA layer.

## Design and file mapping

- Study design: the same BSA digest (10 fmol/µl, 5 µl loaded) was run under 11 column-temperature methods. The apparatus controls three temperature zones of a precolumn + analytical column setup. Each method was run in triplicate. Two methods were also run with the sample loaded in 0.1% TFA.
- Source = digest x temperature method (x TFA loading), e.g. `BSA digest, temperature method 0-50 25 25`. There are 13 sources x 3 injections. `characteristics[biological replicate]` = 1 (one commercial digest, no biological replicates). `comment[technical replicate]` = 1-3 within each source, in run-number order. Fraction 1 throughout.
- Factor: `factor value[elution conditions]` mirrors `comment[elution conditions]` (OBI:0302905, free text). Each value is a description of the run's temperature method, e.g. `column temperature method DTF 0 25 25: zone 1 (precolumn) 0 °C, zone 2 25 °C, zone 3 25 °C`. TFA runs add `; sample loaded in 0.1% TFA`.
- How the mapping was established: three sources were compared and agree for all 39 runs.
  - The RAW-header sample comment (HTTP range read of the first 16 KB of every RAW file), e.g. `50 fmol Proxeon Orange BSA DTF 0-50 25 25 30min`.
  - The deposited `Readme.pdf` pictogram table: three boxes per method; white = 25 °C, blue = cold, red = 50 °C, split box = change during the run, green outline = TFA loading.
  - The run names (`_BSA_TFA_` for TFA).
- The original acquisition names in the headers equal the deposited names, apart from `QE6+` -> `QE6` and an acquisition timestamp suffix on BSA_37 and BSA_38.

## Technical values (all rows)

- Instrument `NT=Q Exactive Plus;AC=MS:1002634`. All RAW headers say "Q Exactive Plus - Orbitrap MS" and the protocol says Q Exactive Plus. The PRIDE structured field says Q Exactive, which is less specific.
- DDA (`PRIDE:0000627`). Dissociation is HCD (`NT=beam-type collision-induced dissociation;AC=MS:1000422`) with collision energy `25 NCE`. MS2 is acquired in the orbitrap (MS:1000484).
- MS1 scan range is `300m/z-1750m/z` (protocol).
- Label free (`MS:1002038`).
- Cleavage agent `NT=Trypsin;AC=MS:1001251`. Evidence: the protocol describes tryptic digests, MaxQuant was set to Trypsin/P specific, and about 99% of peptide C-termini in the first 6,334 rows of the deposited `evidence.txt` are K or R.
- Modifications from the MaxQuant `summary.txt` and `parameters.txt` (MaxQuant 1.5.1.2): Carbamidomethyl C fixed (UNIMOD:4), Acetyl protein N-term variable (UNIMOD:1), Oxidation M variable (UNIMOD:35).
- Tolerances: precursor `4.5 ppm` (MaxQuant main search; the first search used 20 ppm) and fragment `20 ppm` (MS/MS tolerance), both stated in the protocol.

## Limitations
- **Revised after independent review:** the DTF DTF rows now quote the RAW-header code as written (`DTF DTF`, previously misquoted as `DTF DTF DTF`); curator notes about undocumented code suffixes were removed from data values (kept here and in the evidence manifest); organism part broadened from `blood serum` to `blood` because commercial BSA may come from serum or plasma.


- **Paper not read.** The full text is paywalled, so all Methods facts come from the PRIDE protocol text, the abstract and the deposited files.
- **Temperature zones.** Zone 1 is identified as the precolumn from the abstract and protocol (0 °C loading, precolumn raised to 50 °C after loading). The physical position of zones 2 and 3 on the analytical column is not documented in the accessible evidence, so they are written as "zone 2" and "zone 3".
- **"DTF DTF" methods.** The cold temperature of the zones that change during the run is not stated in the headers, so it is written as "cold then 50 °C", following the Readme pictogram.
- **Letter suffixes.** The suffixes in the RAW-header method codes (`5A`, `0-50B`, `0-50C`) are kept verbatim; their meaning is not documented. The Readme pictograms for 0-50B and 0-50C differ only in the shape of the split.
- **Organism part.** `characteristics[organism part]` = `blood serum` is inferred from the protein's identity (serum albumin); it is not stated as a sample property. `cell type` and `disease` = `not applicable` (purified commercial protein).
- **Undeposited runs.** The BSA MaxQuant search also contains runs that were not deposited (e.g. BSA_01, 05, 11, 13, 20, 21, 25, 32, 36, 43). Only the 39 deposited RAW files are annotated.
- **Stray header string.** Every RAW header also carries a `50 fmol BSA` string in a separate field. This is consistent with the BSA load (50 fmol) and is not annotated separately.
