# PXD034342 — annotation blocked

PXD034342 cannot be annotated into a scientifically faithful SDRF from the evidence currently accessible to Codex. The PRIDE deposit contains 16 files named `210719_FS1_JR_AK_TMTPro_01.raw` through `_16.raw`; the publication and PRIDE metadata identify these as TMTpro data with chromatographic fractionation. Each RAW therefore contains multiplexed WT, mtRF1-KO1, and mtRF1-KO2 material, rather than one independently attributable biological sample.

The project record and paper establish the sample groups (HEK293T WT, mtRF1 KO1, and mtRF1 KO2), three independent experiments, TMTpro labeling, trypsin digestion, Orbitrap Fusion SPS-MS3 acquisition, and MaxQuant processing. However, the channel-to-sample assignment is only cited as “Supplementary Table 6” in the paper and is not present in the accessible PRIDE project metadata, FTP directory listing, or deposited filenames. Assigning TMT channels or biological replicates without that table would fabricate sample identity.

## Unblock with

Recover Supplementary Table 6 (or an equivalent sample sheet) containing the TMTpro reporter-channel assignment for WT, mtRF1 KO1, and mtRF1 KO2, plus the independent-replicate mapping. Then generate one SDRF row per TMT channel × fraction with the shared source name, channel-specific `comment[label]`, fraction identifiers 1–16, and the verified biological-replicate assignments.
