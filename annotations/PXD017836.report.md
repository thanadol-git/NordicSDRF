# PXD017836 annotation report

Ancient proteins from 16th-century dental calculus of individual SK92 (Library site, Trondheim). MS was done in Copenhagen (GLOBE / NNF CPR) on a Q Exactive HF. Paper: Phil Trans R Soc B 2020, PMC7702802. Not in the community corpus.

**Scope note:** the Trondheim link is the archaeological origin of the sample and the NTNU sampling. The proteomics lab is in Copenhagen.

## Templates
`ms-proteomics` v1.1.0 and `human` v1.1.0.

## Rows and files
There are 2 rows, mapped from the deposited `mqpar.xml`, which lists Experiment `SK92` for `…_932_01.raw` and `Blank` for `…_944_01.raw`:
- **SK92 dental calculus:** the individual is female (osteological sex estimate, paper). Organism part is `dental plaque` (UBERON:0016482); UBERON has no "dental calculus" term, and calculus is mineralised plaque. Disease is `leprosy`, based on recovery of a 6.6-fold *M. leprae* genome and *M. leprae* peptides; skeletal lesions were possible but not definitive.
- **Extraction blank:** a tube with no calculus. Organism part and disease are `not applicable`, following corpus convention for blanks.

## Values
- **Digestion:** Lys-C, then trypsin. Both are listed as cleavage agents.
- **Search:** from the deposited `mqpar.xml`: Carbamidomethyl C fixed; Oxidation M, Acetyl protein N-term and Deamidation NQ variable; main-search tolerance 4.5 ppm; FTMS MS/MS 20 ppm.
- **Search vs protocol:** the protocol has no reduction or alkylation step, but the deposited search still declared Carbamidomethyl fixed (the MaxQuant default). The modification column records what was searched, and no reagent columns are written.
- **Not stated:** age at death is not in the Methods, so age is `not available`.

## Validation
`parse_sdrf` passes for both templates. `tools reconcile` reports a "Lys-C instead of Trypsin" blocker. It reads only the first `cleavage agent details` column; the file declares both enzymes, so this is a false positive.
