## Key decisions
- Organism: `Homininae` (NCBITaxon:207598, also PRIDE's organism). Australopithecus / A. africanus has no NCBI Taxonomy entry (esearch: 0 hits; only VTO:9032168 exists, which the NCBITaxon-bound column rejects: validator error "not found in ncbitaxon"). The species is kept in `source name` and here. This is a deliberate loss of specificity.
- Organism part: `enamel` (UBERON:0001752; PRIDE lists the same).
- Sex `male`: from paper (AMELY identification) - stated, not inferred.
- developmental stage `not available` (molar fragment; age-at-death not stated); disease `not available` (not assessed/stated); cell type and strain `not applicable` (acellular enamel matrix; fossil specimen); factor value: none (single specimen plus blank, no designed comparison; advisory `no_factor_value` expected).
- Instrument Orbitrap Exploris 480 (MS:1003028): paper + file name "EXPL7" + raw header (first 256 KB decoded, "Orbitrap Exploris 480"). PRIDE's `LTQ FT` is wrong; overridden.
- Dissociation HCD (`beam-type collision-induced dissociation`, MS:1000422): taken from the raw header string "HCD" only; paper silent. Judgement call.
- Acquisition DDA (file names "DDA", paper).
- Cleavage agent: `not applicable` - no protease was added (non-digestive acid etch). The MaxQuant search used unspecific (enzymeMode 4, no enzymes). `sdrf-tools reconcile` reports BLOCKER `cleavage_agent_unsupported` for this; this is a tool false positive (it treats the reserved word as an enzyme name; same flag appears for any value because the record names no digest reagent). Alternative `unspecific cleavage` (MS:1001956) was considered and also flagged; reviewer may attack.
- No reduction/alkylation reported and no fixed mods in the search (`mqpar.xml` fixedModifications empty): reagents not written (columns optional, left blank by build).
- Modifications read from deposited `mqpar.xml` (search wins over prose), all Variable, no fixed: Arg->Orn UNIMOD:372 (R), Deamidated UNIMOD:7 (N,Q), Gln->pyro-Glu UNIMOD:28, Glu->pyro-Glu UNIMOD:27 (both PP=Any N-term), Oxidation UNIMOD:35 (M,P,W), Phospho UNIMOD:21 (S,T,Y).
- Tolerances: precursor 4.5 ppm (mqpar mainSearchTol), fragment 20 ppm (FTMS MS/MS tol, parameters.txt).
