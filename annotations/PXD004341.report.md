# PXD004341: heterogeneous CHO run map needs verification

The accession deposits 42 RAW files across CHO wild type, POMGnT1 knockout, POMT1 knockout, POMT2 knockout and combined knockout naming groups. The project protocol names both LTQ-Orbitrap Velos and Fusion instruments, HCD and sometimes ETD fragmentation, and multiple ConA/LWAC enriched fractions. The filenames identify some groups and instrument families, but do not establish a complete source-to-fraction, biological-replicate and acquisition-method map for all 42 runs. The analysis protocol also says that either a CHO-specific or human reference proteome was searched without mapping that choice to each file.

No SDRF was added. A valid annotation can be built as verified subsets, but assigning `ConA_21`–`26` or `F17`–`21` to fraction or replicate coordinates solely from their numeric suffixes would be an unsupported inference. Required evidence: the experiment's fraction ledger or per-run search/design outputs, especially for the mixed instrument and HCD/ETD arms.

Sources: [PRIDE project record](https://www.ebi.ac.uk/pride/ws/archive/v2/projects/PXD004341), [published study](https://pubmed.ncbi.nlm.nih.gov/28512129/), `scratchpad/PXD004341/pride.json`, and accession-scoped `scratchpad/PXD004341/files.json`.
