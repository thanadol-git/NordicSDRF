# PXD011558 annotation blocked (duplicate of PXD011693)

PXD011558 ("Shotgun Proteomic Analysis of ESBL and non ESBL Producing Klebsiella Pneumoniae Clinical Isolates", Suez Canal University, Egypt) is a re-deposit of PXD011693. It has the same submitter, title, species (K. pneumoniae KP5-1, taxid 1199150), instrument (TripleTOF 5600) and modification list. Its 18 files have exactly the same names: 6 `.wiff` files (`180502-Bacteria{2,4,39,69,75,90}.wiff`), 6 `.mgf` files and 6 `Newproteinidentificationsummary_Bacterial*.xls` files. PXD011558 was announced later (2022-02, FTP `2022/02`) than PXD011693 (2021-04, FTP `2021/04`).

The publication, Enany et al., Microbiol Res 2020;234:126423 (doi:10.1016/j.micres.2020.126423, PMID 32078895, not in PMC), cites only **PXD011693** in Section 2.6. PXD011558 is not cited. PXD011693 should be annotated, and this accession should be skipped.

**Byte identity is NOT verified.** The PRIDE FTP and the PRIDE v3 API both returned upstream connection errors on 2026-11-27, so file sizes and checksums could not be compared. The duplicate call rests on the identical file names, the identical metadata, and the paper citing only PXD011693.

**Also relevant to PXD011693:**
- The paper labels samples ESBL-1..3 and Non-ESBL-1..3. MLST (Table 3): ESBL-1 is ST39, Non-ESBL-1 is ST1634, and the other four are ST627.
- PLoS One 2022;17:e0265884 names the four ST627 isolates as K04, K69, K75 and K90. It does not give the ESBL status of each one.
- So the run → ESBL/non-ESBL map for files 4/69/75/90 is not stated, and neither is the map for 2/39. The MLST only suggests it.
- Methods: in-solution DTT/IAA/trypsin with C18 stage tips. No SDS-PAGE and no fractionation (one run per isolate).
- Acquisition: TripleTOF 5600+ in DDA mode, top 40 precursors, MS1 400-1250 m/z, MS2 170-1500 m/z.
- Search: X!Tandem/PeptideShaker 1.16.26, 20 ppm / 10 ppm tolerances. Carbamidomethyl C fixed. Variable: oxidation M, acetyl protein N-term and K, pyro-carbamidomethyl C.

**Evidence checked:** PROXI full records of PXD011558 and PXD011693; the Microbiol Res 2020 article page (ScienceDirect); the PubMed record; PLoS One 2022 e0265884. A PMC article was checked and rejected: PMC11536433 is a different study (PXD046166). The PRIDE FTP and the v3 API were tried but could not be reached.

**To unblock / close:**
1. Compare checksum.txt/file sizes of both FTP folders to confirm byte identity.
2. Annotate PXD011693 instead. Its isolate → ESBL map needs the deposited `.xls` headers, the paper's Table 1/2 or the authors. Without one it can only be a flagged sandbox.
