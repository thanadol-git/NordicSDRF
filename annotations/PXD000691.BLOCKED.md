# PXD000691 — annotation blocked

PXD000691 deposits 430 vendor RAW files and describes seven breast-derived cell lines, with one SILAC-labelled cell line used as a common reference. The raw filenames contain abbreviated prefixes including `JIMTp`, `MCF10Ap`, `LumC`, `LumD`, `adipoc`, and `fibrob`, but the PRIDE record and complete manifest provide no table identifying every prefix as a specific cell line or assigning the SILAC reference channel to the biological sources.

The linked publication abstract confirms the broad design but not the run-level mapping. Expanding `LumC`/`LumD` or assigning labels from convention would be unsupported, so no SDRF is emitted.

Evidence checked: PRIDE PXD000691 project record, protocols, and complete file manifest; Cifani *et al.*, *Journal of Proteome Research* (2015), DOI 10.1021/acs.jproteome.5b00375 / PMID 26055192.

Unblock with the original experimental-design table, a MaxQuant parameter/design file, or source material that maps every raw-file prefix and SILAC channel to an identified cell line.
