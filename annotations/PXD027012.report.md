## Design and file mapping
48 RAW files = 24 patients × 2 laser-microdissected compartments: `KF_T<n>` = tumor epithelium and `KF_S<n>` = tumor stroma. The meaning S = stroma / T = tumor epithelium is confirmed by the deposited MaxQuant zips (`Microdissected_TumorStroma_MaxQuant-txt.zip` contains the `KF_S*` runs). The same number `n` is taken to be the same patient in both compartments (**inferred** from the paired file names). Sources `patient<n>_epithelium/_stroma`, individual `patient<n>`, biological replicate = index of the patient. Factor: `factor value[cell type]` (compartment).

## Technical values
Q Exactive HF, 180 min gradient, DDA (PRIDE protocol; acquisition mode not stated explicitly but label-free MaxQuant). Trypsin (FFPE-FASP; "enzymatic digestion"; enzyme not named in the PRIDE text, MaxQuant default). Deposited MaxQuant 1.6.0.16 `parameters.txt` (read by HTTP range from the stroma zip): fixed Carbamidomethyl C; Oxidation M and protein N-term Acetyl for quantification. Dissociation/tolerances not stated.
