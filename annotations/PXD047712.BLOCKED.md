# PXD047712 — annotation blocked

## Dataset

- **Title:** Epitope mapping of human polyclonal antibodies to fHbp (4CMenB) by HDX-MS - part 2
- **PRIDE record:** PXD047712
- **Publication:** PMID 38342408

## Evidence recovered

Waters Synapt G2-Si HDX-MS runs (.raw directories) packed into 15 multi-run ZIPs (ZIP1-ZIP15, 3-15 GB each) plus 3 single-run ZIPs; Overview_of_raw_data_part2.xlsx maps each run to antigen amount, Ag:Ab ratio, D2O exposure time and buffer.

## Why no SDRF was emitted

Out of scope for the ms-proteomics SDRF: hydrogen/deuterium exchange of one recombinant antigen (pepsin, no reduction/alkylation, deuterium uptake per labelling time), not a proteome sample. Each data file is a ZIP holding many runs, so the one-row-per-raw-file model and bigbio processing (quantms) do not apply.

## Sources checked

PRIDE record, Overview_of_raw_data_part2.xlsx, file list.

## Unblocking requirement

A decision from bigbio on whether HDX-MS deposits should be annotated at all (and with which template); the run map itself is complete in the overview sheet.
