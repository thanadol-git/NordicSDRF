## Design and file mapping
Conditioned media (48 h, serum-free) of gingival fibroblasts from six periodontitis patients (aged 46-72 y, stage III/IV; paper) and from periodontally healthy subjects used as the reference group (PRIDE title). Twelve RAW files `D1…D13` (no `D12`; `D4_ny`, `D7_ny`, `D10_ny` are "new" re-runs). **The files are not mapped to periodontitis vs healthy donors anywhere** (no sample sheet), so disease is `not available` for every sample and the design factor is absent. Donor IDs `D<n>` are the file numbers. This is a deliberate honest blank, not a guess.
