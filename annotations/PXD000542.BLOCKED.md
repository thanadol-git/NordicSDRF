# PXD000542 — blocked annotation

The deposited evidence is internally contradictory. The title and all 97 RAW names describe label-free HiRIEF proteomics of the A431 cell line, whereas the sample-processing protocol describes clinical vulvar squamous-cell carcinoma specimens and the data-processing protocol specifies iTRAQ 8-plex quantification. No deposited sample sheet resolves which metadata belong to the RAW files.

An SDRF would require selecting between incompatible biological material and acquisition-labeling designs, so the dataset is held pending clarification or a valid sample map.
