- Each RAW file appears on two rows (light and heavy halves of the 1:1 mixture); the SDRF builder cannot place one file under two sources, so the heavy rows were created by scripted copy of the light rows.
- Age 30Y6M and sex female are Cellosaurus values for HeLa, not stated in the deposit. Organism part, cell type and disease set to not available (the deposit says only 'Hela cell').
- Biological replicate is 1 for both labeling versions; whether the 13C and 2H experiments used the same lysate batch is not stated. Technical replicate = injection number in file name. No factor value column: the two labeling versions are separate RAW sets and differ in comment[label].
- Precursor tolerance, reduction and alkylation reagents are not stated. Full text of the paper (PMID 26377011) was not open in Europe PMC and was not read; no claim cites it.
- The deposit also contains PXD001256_community_annotated.sdrf.tsv; it was not used as a source for this annotation.
