# PXD033377 — BLOCKED

## Exact blocker

The deposited sequence workbook maps each RAW file to TMT set and fraction, but neither it nor the quantitative result workbook maps reporter channels to worm treatment/genotype/sample and biological replicate. Reporter identities therefore cannot be assigned without inference.

## Evidence checked

- PRIDE project record: `https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD033377`
- PRIDE file inventory: `https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD033377/files/all`
- Publication: `https://pmc.ncbi.nlm.nih.gov/articles/PMC10199892/` (DOI `10.1038/s41467-023-38568-5`)
- Deposited `3036_sequence_Fusion_181127.xlsx`
- Deposited `3036_TMTSets_combined_normalized_0miss_Uniprot_celegansOnly.xlsx`

PRIDE lists 40 Orbitrap Fusion RAW files and declares TMT quantification. The sequence workbook provides exact entries such as `3036 TMT Set1 Fr 02` and the corresponding Set 2 series, including the acquisition sequence. The quantitative workbook contains combined normalized protein results. Neither workbook exposes the channel design for the two sets, and the publication's *C. elegans* cisplatin/p38-ATF-7 biology does not provide an accession-level reporter matrix joinable to the sequence sheet.

## Evidence needed to unblock

The TMT set design specifying, for Set 1 and Set 2, every reporter channel, exact worm sample/condition/genotype, biological replicate, reference pool, and unused channel. The set identifiers must match those in `3036_sequence_Fusion_181127.xlsx`.
