# PXD073925 annotation report

## Study
"Recombinant dimeric PICK1 protein inhibitors for long-term relief of chronic pain by AAV therapeutics" (Noes-Holt et al., Cell Rep Med 2026, doi:10.1016/j.xcrm.2026.102800, PMC13293952). Phosphoproteomics (Fe-NTA enriched, TMTpro 32plex, 16 high-pH fractions, Orbitrap Ascend RTS-MS3) of L3-L5 dorsal root ganglia from male spared-nerve-injury (SNI) mice treated with AAV8-Di-C5 (AAV8-hSyn-GCN4-HWLKV) or AAV8-tdTomato, ipsilateral vs contralateral. Companion global proteome is PXD074049 (not annotated here). Not in community corpus.

## Templates
ms-proteomics v1.1.0 + vertebrates v1.1.0 (MS; mouse).

## Scope
Deposited: 16 RAW (Fr1-Fr16, one TMTpro 32plex set), 16 RTS search TSVs, experimental_design.tsv, PD_Output_Phospho.zip (12 GB). Annotated: 16 RAW x 32 channels = 512 rows x 37 columns. Not annotated: search outputs, PD zip.

## Key decisions
- Channel map: from deposited experimental_design.tsv (channel -> group + replicate index); cross-checked with the Proteome Discoverer study definition (TMTpro 32plex quan method, 32 channels) in the zip. 16 non-deuterated channels = 16 samples (2 treatments x ipsi/contra x 4). 16 deuterated channels (names prefixed D_) are, per the paper, technical replicates of the same samples ("two technical replicates, using either deuterated or non-deuterated labels"); annotated as the same source with technical replicate 2.
- Fraction: taken from the `_FrN` token in each RAW file name (Fr1-Fr16, all 16 present), not file order.
- Labels written as NT=TMT<channel>;AC=PRIDE:xxxxxxx for all 32 (including deuterated TMT127D ... TMT135ND, PRIDE:0000861-0000876). `sdrf-tools build` only accepts bare non-deuterated channel names, so the 16 deuterated channels were built with unused placeholder labels and the label and the assay-name suffix were then mapped back by a deterministic script (relabel.py + placeholder_map.json in scratch). No other cell was edited.
- Cleavage Trypsin (MS:1001251): PD study node says Trypsin (Full), KR, inhibitor P; paper says Trypsin and Lys-C digestion (only one value allowed). reconcile flags Trypsin as unsupported by the PRIDE record text (which says only "digested ON"); the evidence is the deposited search parameters and the paper, so kept.
- Modifications, tolerances from the PD Sequest HT node in the deposited .pdStudy: 10 ppm, 0.6 Da; Carbamidomethyl C fixed; Oxidation M, Phospho STY, TMTpro K and N-term variable (as the paper states). The separate RTS/Comet node (20 ppm, 0.5 Da, TMTpro fixed) is the on-instrument search and was not used.
- Dissociation: CID (MS2, ion trap, per paper); the HCD MS3 quantification scan is not representable in the single column. ms2 analyzer: ion trap.
- Disease: neuropathic pain (all mice have SNI). Contralateral DRGs are internal comparator but come from the same injured animals.
- Factors: treatment (AAV8-Di-C5 vs AAV8-tdTomato) and laterality (ipsi vs contralateral to injury).
- Treatment mapping: the deposit's group "GCN4" is taken as AAV8-Di-C5 (AAV8-hSyn-GCN4-HWLKV), "tdT" as AAV8-tdTomato, from Fig 6 text.

## Not available / omitted
developmental stage (`not available`: 7-12 weeks stated only generically); age; sampling time (73-74 days after injection, a range, not encodable as number+unit; stated in treatment context only); sample type (`study sample` not in the offline PRIDE cache; column omitted); enrichment process (no EFO child term for phosphopeptide enrichment; only protein-level term; omitted); collision energy.

## Conflicts
- PRIDE says non- and deuterated labels; paper methods say only non-deuterated TMTpro-16plex were used and only non-deuterated samples retained for analysis, while the deposit contains both. Annotated per deposit.
- Paper search says TMTpro fixed (RTS) vs variable (PD); deposited Sequest node followed.
- Strain: "C57BL6/J" in the MS methods; Animals section lists several C57BL/6 substrains in general.

## Inferred vs stated
Inferred: pairing of D_<group> n with <group> n as the same mouse/sample (paper states technical replicates; index pairing from deposited names only); biological replicate index n is the deposit's index (ipsi n and contra n are not stated to be the same mouse); GCN4 group = AAV8-Di-C5.
