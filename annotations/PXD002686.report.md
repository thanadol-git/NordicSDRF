# PXD002686 SDRF annotation report

Status: validated annotation; independent review pending

Dataset: Short Term Immune Response to IL6 inhibition (Tocilizumab), Aalborg University (Stensballe), Denmark. Q Exactive Plus, label-free DDA, MaxQuant 1.5.1.2.

Step 0.5: no existing PXD002686 annotation in sdrf-annotated-datasets; annotated from scratch. Mode: online, no publication available (PRIDE record has no DOI/references).

## Result
- File: annotations/PXD002686.sdrf.tsv, 30 rows x 38 columns, one row per RAW file (30/30 RAW files mapped; MaxQ.zip is a search file, not a row).
- Templates: ms-proteomics v1.1.0, human v1.1.0, clinical-metadata v1.0.0 (patient treated with a drug, pre/on-treatment design).
- Design: 1 patient (59Y, rheumatoid arthritis) x 5 enriched cell populations (CD14 monocytes, CD4 T, CD8 T, CD19 B, CD56 NK) x 2 time points (baseline, 4 months on tocilizumab) x 3 runs = 30. Factors: cell type, treatment status.
- Modifications read from the deposited MaxQuant parameters.txt/summary.txt (HTTP range read of MaxQ.zip members only; no RAW downloaded): Carbamidomethyl C fixed; Acetyl protein N-term, Oxidation M, Deamidated N/Q/R (MaxQuant Deimidation NQR, covering deamidation and citrullination), Phospho STY variable. Fragment tolerance 20 ppm.
- Cleavage: one column, Trypsin (protocol: overnight trypsin). No second protease, so no second cleavage column. MaxQuant enzyme setting was Trypsin/P, 2 missed cleavages (search parameter only).

## Validation
- parse_sdrf validate-sdrf (ms-proteomics + human + clinical-metadata, --use_ols_cache_only): exit 0, "only warnings". Warnings: TCEP (PRIDE:0000609) and iodoacetamide (PRIDE:0000599) not found in the offline OLS cache for reduction/alkylation reagent; these accessions are the ones used throughout the community corpus. A networked run was not completed (first attempt hung/was slow).
- python -m tools structure: OK. python -m tools check --offline: CLEAN (11 terms, 0 hallucinated).
- python -m tools reconcile: one BLOCKER, organism_contradicted ("record names only Mus musculus"). FALSE POSITIVE: the protocol mentions goat-anti-mouse Dynabeads (a secondary antibody for CD56 capture); PRIDE organism is NEWT:9606 and the search used the human UniProt database. Retained Homo sapiens. An earlier cleavage_agent finding was resolved by using Trypsin instead of Trypsin/P.
- Independent review (Step 9.5) not run: I was instructed not to spawn subagents, so the adversarial gate is unavailable and nothing is claimed as approved.

## Caveats and judgement calls
- Baseline vs treated is inferred from run names (no "4month" = pre-treatment/baseline; "4month" = on tocilizumab). No paper or sample table confirms this.
- The _01/_02/_03 suffix is treated as technical replicate 1-3 of one biological sample (single patient, single draw); biological replicate = 1. The submitters may have meant otherwise.
- Cell type CL mapping is inferred from markers: CD4/CD8 -> alpha-beta T cell, CD19 -> B cell, CD56 -> natural killer cell. Organism part set to "blood" (PBMC origin).
- Sex: not available (not stated). Ancestry not annotated. Precursor mass tolerance: not available (not recorded in parameters.txt).
- Instrument is Q Exactive Plus (protocol text) rather than the archive dropdown "Q Exactive"; PRIDE experiment type "Top-down proteomics" is contradicted by the bottom-up protocol and was ignored.
- Instrument/acquisition not verified from RAW headers.
