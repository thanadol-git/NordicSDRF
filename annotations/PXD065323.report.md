# PXD065323 annotation report

Status: validated annotation; independent review pending.

THSD7A interactome (co-IP/DIA-MS) in native mouse glomeruli, Rinschen lab, Aarhus University (submitter at UKE Hamburg). Paper: Huang et al., JCI Insight 2026, PMID 41746732 (PMC13135397). PXD065323 is the co-IP experiment (2 of 3 related PRIDE projects).

## Templates
`ms-proteomics` v1.1.0, `vertebrates` v1.1.0 and `dia-acquisition` v1.1.0.

## Rows and files
9 rows (37 columns), one per `.raw`, label free, one fraction. The group of each run comes from the deposited Spectronaut `apms_thsd7a_ConditionSetup.tsv`:
- 5 runs (-7, -8, -9, -10, -11) = control human IgG pulldown (`wt_ctrligg`), replicates 1-5.
- 4 runs (-1, -3, -5, -6) = anti-THSD7A IgG pulldown (`wt_thsd7aigg`), replicates 1-4. Runs -2 and -4 were not deposited.
- Factor: `factor value[immunoprecipitation antibody]`. The bait antibody was anti-THSD7A IgG purified from MN patients; the control was human IgG (Aviva OASB01433), both on protein G agarose (paper Methods).

## Values
- Mus musculus, `renal glomerulus`, material type `organism part`.
- Instrument: Orbitrap Exploris 480 with FAIMS (PRIDE record and protocol text). Raw-file header read by HTTP range (Thermo Xcalibur, method `2022May_2h_2CVs_400nL_DIA`) agrees.
- DIA: 15 windows over 400-1000 m/z, so isolation width 40 m/z, scan window 400-1000.
- Prep: TCEP/chloroacetamide, trypsin only (one cleavage agent column), so no two-protease case.
- Search (Spectronaut 19 directDIA+, from PRIDE data-processing text): Carbamidomethyl C fixed; Oxidation M and Acetyl protein N-term variable. Spectronaut ran at "standard settings", and no tolerance is given in the record.

## Not available (no evidence)
Sex, strain, developmental stage, cell type (whole glomerular lysate) and disease. The co-IP lysate is described only as "native" WT glomeruli, so a disease or healthy status is not stated. The MN model used only male mice, but that is not tied to this lysate.
Precursor and fragment tolerance (Spectronaut standard), dissociation is set to beam-type CID (HCD) from the Orbitrap DIA method but not stated in the text (inferred), DIA method name.
