# PXD012902 SDRF annotation report

Status: validated annotation; independent review pending

- Dataset: Corneal proteome of transgenic TGFBI R124H mouse model (Aarhus, Enghild lab); PMID 32558206.
- File: `PXD012902.sdrf.tsv`, 18 rows x 37 columns (18 RAW files, label-free, DDA, no fractionation). Templates: ms-proteomics v1.1.0 + vertebrates v1.1.0. No existing annotation was found in sdrf-annotated-datasets.
- Design: 3 genotypes (WT, heterozygous, homozygous TGFBI R124H) x 3 mice x 2 technical runs. Factor: genotype.
- Digest: CNBr then trypsin, recorded as two `comment[cleavage agent details]` columns (parse_sdrf accepts this).
- Search settings from deposited MaxQuant mqpar.txt; instrument verified by HTTP range read of a RAW header (Q Exactive Plus; PRIDE's "Q Exactive" is less specific).

## Validation
- parse_sdrf validate-sdrf (--use_ols_cache_only): passed. tools check --offline: CLEAN. tools structure: OK.
- tools reconcile: 2 findings on cleavage agent (BLOCKER/MAJOR) are a tool limitation: it reads only the first of repeated cleavage columns; the Trypsin column is present.

## Caveats
- Replicate mapping is inferred: in file names `<genotype>_A_B`, B is treated as the mouse and A as the technical run. Evidence: LFQ correlation (same B across A r about 0.99; same A across B lower, Het 0.91-0.92) and the protocol (3 mice, technical duplicates). Not stated by the authors.
- sex, strain, developmental stage, cell type: `not available` (only "different genders", "age-matched" given). Paper not open access; Methods read from the PRIDE protocol.
- disease: `normal` for WT; `not available` for Het/Hom (no corneal deposits observed, disease status is a judgement).
- `characteristics[genotype]` is not in the selected templates (extra column, accepted by validator).
- HCD inferred from NCE 28 on a Q Exactive.
- Independent review (Step 9.5) not performed here (no subagents allowed): review pending.
