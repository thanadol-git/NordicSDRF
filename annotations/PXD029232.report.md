# PXD029232 annotation report

Status: validated annotation; independent review pending.

L-lysine treated Dahl salt-sensitive rat kidney shotgun proteome (Aarhus, Krueger/Rinschen labs). Paper: Rinschen et al., Nat Commun 2022, PMID 35835746 (PMC9283537). Not in the community corpus (no existing PXD029232 directory in sdrf-annotated-datasets).

## Templates
`ms-proteomics` v1.1.0 and `vertebrates` v1.1.0.

## Rows and files
36 rows x 34 columns, one per deposited `.raw` (210511_FD_LFQ_L-Lys-Opt_N.raw, N = 1-37 except 26). Each raw was acquired with FAIMS at two CVs (-45 and -65 V) and deposited also as two mzXML files; these are derived peak lists of the same injection, so each raw is one row (fraction 1, technical replicate 1).
Sample N maps to raw file N via the deposited `L-Lysine_Rat_Proteome_SampleKey.xlsx` (same numbering; sample 26 is in the key but has no raw file in the deposit).

## Design
Eight diet groups (n per group): 8% NaCl 3 wk (7), 8% NaCl 2 wk (4), lysine+8% NaCl 3 wk (3), lysine+8% NaCl 2 wk (4), 0.4% NaCl 2 wk (4), lysine+0.4% NaCl 2 wk (3 of 4 in key), 4% NaCl 3 wk (5, female), lysine+4% NaCl 3 wk (6, female). Males for the others. `factor value[treatment]` = the diet group. Sex is confounded with the 4% NaCl groups.

## Values
- Organism/strain: Rattus norvegicus; SS/JrHsdMcwi (paper Methods); rats were 8 weeks old at experiment start.
- Organ part: kidney (PRIDE/protocol; the paper does not say cortex vs whole kidney for proteomics).
- Instrument: Orbitrap Exploris 480, confirmed from the RAW header (HTTP range read); FAIMS used.
- Acquisition DDA; HCD with Orbitrap (FTMS) MS2 read from the first rows of the deposited MaxQuant msms.txt.
- Digest: trypsin only (Trypsin/P, 2 missed cleavages in mqpar.xml). The Lys-C digest in the paper belongs to the separate mouse 13C6-lysine experiment, so only one cleavage-agent column is recorded.
- Reduction TCEP, alkylation chloroacetamide (CAA).
- Search (mqpar.xml/parameters.txt, MaxQuant 1.6.17): Carbamidomethyl C fixed; Oxidation M and protein N-term Acetyl variable; main search 4.5 ppm, MS/MS 20 ppm.

## Not available / caveats
- `disease` is `not available`: the paper describes a hypertension model, but per-group disease status (especially lysine-protected rats and the 4% NaCl females) is not stated per sample.
- `developmental stage` and `cell type` are `not available`.
- Treatment strings are free text normalised from the sample key; they are not ontology terms, hence parse_sdrf warnings.
- Sample key to raw mapping assumes the shared numbering; no raw-level confirmation possible.

## Validation
- `parse_sdrf validate-sdrf -t ms-proteomics -t vertebrates`: passes with warnings only (treatment values and strain not found in ontology lists; one OLS connection error during the run).
- `python -m tools structure`: OK. `python -m tools check --offline`: CLEAN (3 of 10 terms verified offline). `python -m tools reconcile`: every value agrees with the deposit record.
- Independent adversarial review not run (subagents not permitted in this task).
