## Limitations and calls to attack in review

- Multiplexed rows of one RAW file share one assay name (the file name without extension), as the spec README requires for TMT runs; comment[label] distinguishes the channels.
- The PRIDE file list has 93 RAW files; the FTP directory has 99 (Velos_120203_48, 120210_03, 120210_12, 120323_07, 120323_32, 120323_33 are FTP-only). All 99 are annotated; the submitter's README maps all of them to a set.
- PRIDE and the paper call Methylthio (C) variable; the deposited Mascot search set it fixed, which is annotated.
- Each channel is the medium of 8 explants pooled from two horses (biological replicate 1, pooled sample 'pooled'). The reference pool channels have biological replicate 'pooled' and pooled sample = SN= list of all 14 study samples (PRIDE: 'reference pools consisting of an aliquot from each sample'); whether the three sets used one shared pool or three separately made pools is not stated. Breed and sex are not stated. Age 2.5 years = 2Y6M.
- The three MassPrep QC runs are in PXD004993-lfq; organism, material and search settings of the commercial standard are not stated, so they are 'not applicable'/'not available'.
- Set 2 has no exclusion rerun of fraction 1; set 1 fraction 16 rerun (Velos_120210_18) used the 1-15 exclusion method file but is named '#16 EXCL', and fraction 16 is annotated.
- Culture medium was changed at each harvest, so the sampling time is the day the medium was collected (3–22); the day-0 medium was not analysed. The analysed material is the conditioned explant medium; organism part names the tissue that released it, and material type is 'tissue' (the template has no value for culture medium).
- Velos_120203_60 is named 'set 1 #9 ACN frac' in its RAW header; it is annotated as a third injection (technical replicate 3) of fraction 9, but what 'ACN frac' means is not documented.
- The Mascot searches were semi-tryptic (CLE semiTrypsin); SDRF has no column for enzyme specificity, so only Trypsin is annotated.
