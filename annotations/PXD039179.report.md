# PXD039179 annotation report

Palvimo lab (University of Eastern Finland, Kuopio). AR and SUMO2/3 RIME in VCaP cells ± DHT ± ML792, on Bruker timsTOF Pro. Not in the community corpus.

## Templates

- `ms-proteomics` v1.1.0
- `human` v1.1.0
- `cell-lines` v1.1.0 (VCaP / CVCL_2235)

The PRIDE experiment type is crosslinking; that is chromatin fixation for RIME, not XL-MS, so `crosslinking` was not used.

## Rows and files

10 data rows, one per deposited `.d.zip`. Zip names encode `rep1-3`; FragPipe spectral-count columns confirm three biological runs inside each archive. Inner `.d` folder names were not range-listed (PRIDE locations are FTP-only), so each zip is one row with `characteristics[biological replicate]=pooled` rather than invented member names.

## Factors

- `factor value[antibody]`: AR / SUMO2/3 / IgG / NRS
- `factor value[androgen]`: DHT / ethanol
- `factor value[SUMO inhibitor]`: ML792 / DMSO (`SUMOi` / `CTRL` in the zip name)

IgG is ethanol-only and NRS is DHT-only, as deposited.

## Conservative choices

- Disease `prostate carcinoma` on every row: VCaP is a cancer line; `CTRL` means DMSO vehicle, not a healthy control (reconcile `disease_on_control_runs` is a false positive).
- FragPipe search mods: Oxidation M, Acetyl protein N-term, Biotin K / N-term variable. No carbamidomethyl in the search write-up.
- DDA-PASEF; dissociation CID (`MS:1000133`).
