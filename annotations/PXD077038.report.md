# PXD077038 annotation report

Label-free proteomics of CT26 (colorectal) and KPC (pancreatic) mouse tumours: control, microbubbles only, or focused ultrasound + microbubbles. NTNU. Paper: Sci Rep 2026, doi 10.1038/s41598-026-68589-1. It is not in Europe PMC, and the full text could not be retrieved.

## Templates
`ms-proteomics` v1.1.0 and `vertebrates` v1.1.0.

## Rows and files
There are 83 rows, one `.d.zip` per tumour.
- **Submitter SDRF:** the deposit includes one, which gives the tumour model (CT26/KPC) and group (`C`, `MB`, `USMB`) for every run. Those two fields are carried over.
- **Groups:**
  - CT26: C 10, MB 17, USMB 15.
  - KPC: C 9, MB 18, USMB 14.
- **Group labels:** `C` = control, `MB` = microbubbles and `USMB` = focused ultrasound + microbubbles. This follows the project description; the group-code definitions themselves are only in the submitter SDRF.
- **Biological replicate:** each run is a different tumour, numbered from the run name.
- **Missing:** the three independent experiment batches mentioned in the abstract cannot be assigned to runs.

## Values
- **Cell line:** CT26 → CT-26 (CVCL_7254), `colon adenocarcinoma`. KPC → `pancreatic ductal adenocarcinoma`; the KPC line is not identified, so no Cellosaurus accession.
- **Not available:** mouse strain, sex, age and tumour site.
- **Factors:** `disease` (tumour model) and `treatment`.
- **Instrument:** timsTOF Pro 2, from `analysis.tdf`.
- **Sample prep:** SDC/TCEP/chloroacetamide.
- **Search** (deposited MaxQuant 2.4.0.0 `parameters.txt`/`summary.txt`; the submitter SDRF says 2.7.0.0):
  - Carbamidomethyl C fixed.
  - Oxidation M, Acetyl protein N-term and Deamidation NQ variable.
  - TOF MS/MS tolerance 25 ppm.
- **PXD059683:** the processing protocol cites PXD059683. That is the SpLICe immune-cell reference used for deconvolution, not part of this sample set.

## Validation
- `parse_sdrf` (CI style, warnings only) and the review gate pass.
- `tools reconcile` flags the instrument: the PRIDE protocol says timsTOF Pro. `analysis.tdf` reports timsTOF Pro 2, so the raw header is followed.
