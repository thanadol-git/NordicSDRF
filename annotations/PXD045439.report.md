# PXD045439 annotation report

Carfilzomib-sensitive AMO1 multiple myeloma cells compared with the carfilzomib-resistant derivative AMO1-CFZ, label-free (Slupphaug lab / PROMEC, NTNU). Paper: J Transl Med 2024, PMC11162064 (open access). The paper's super-SILAC patient data are a separate deposit (PXD006458). Not in the community corpus.

## Templates
`ms-proteomics` v1.1.0, `human` v1.1.0 and `cell-lines` v1.1.0.

## Rows and files
There are 15 rows, one per `.d.tar`. The runs are numbered 1–15, and the deposited `txt.tgz` contains a MaxQuant `Groups.txt` that maps each run to a group:
- `WT` (runs 1, 2, 3, 9, 10): AMO1 with vehicle.
- `CFZR` (runs 4–8): AMO1-CFZ kept in 90 nM carfilzomib.
- `DMSO` (runs 11–15): AMO1-CFZ moved to vehicle-only medium for 1 week.

Biological replicates are numbered 1–5 within each group in run order.

Two cross-checks support the mapping:
- **Supplementary Table 3** (the AMO1-CFZ vs AMO1 comparison) uses only runs 1, 2, 3, 9, 10 and 11–15. That fits the paper's Methods, which say AMO1-CFZ was grown without carfilzomib for a week before harvest.
- **Paper markers:** in Table 3, runs 11–15 have IGKC at about 9–15 log2 vs about 24 in runs 1/2/3/9/10, ABCB1 is high, and MYC is detected only in runs 11–15. That matches the paper's description of the resistant cells.

The 90 nM maintenance and the 1-week vehicle washout are from the PRIDE description.

## Values
- **Cell line:** `AMO1` (Cellosaurus CVCL_1806). AMO1 was derived from ascites (`ascitic fluid`, UBERON:0007795) of a 64-year-old woman with `plasma cell myeloma`. Cell type is `plasma cell`.
  - `AMO1-CFZ` has no Cellosaurus entry, so its rows carry the parent's accession, with `cell line` = `AMO1-CFZ`.
- **Treatment:** free text, so parse_sdrf warns that these are not NCIT/EFO terms. Factors are `cell line` and `treatment`.
- **Instrument:** `timsTOF Pro 2`, from `analysis.tdf` InstrumentName (serial 1875087.10477, acquired 2023-03-18). PRIDE and the paper both say timsTOF Pro. Acquisition was DDA-PASEF.
- **Sample prep:** SDC lysis with TCEP and chloroacetamide, then trypsin.
- **Search** (`summary.txt`/`parameters.txt`, MaxQuant 2.3.1.0):
  - Carbamidomethyl C is fixed.
  - Oxidation M, Acetyl protein N-term and Deamidation NQ are variable.
  - TOF MS/MS tolerance is 25 ppm. The precursor tolerance is not in `parameters.txt`, so it is `not available`.

## Validation
- `parse_sdrf` (CI style) and the review gate both pass.

  - "disease on control arm" is a false positive: the controls are untreated myeloma cells.
