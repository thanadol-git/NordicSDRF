# PXD022668 — BLOCKED

## Exact blocker

The two RAW files are TMTpro 16plex TAILS runs (Proteome Discoverer template "Mouse_TAILS_16-plex"), so each file needs a 16-channel to sample map (genotype/model, DSS day or healthy state, mouse replicate). No such map is available:

- The PRIDE protocol says only "N = 4 biological replicates ... per time point" and "16plex TMT". It does not list the time points/states or the channel order.
- The two file codes `..._DSS_PO_500ng.raw` and `..._DSS_NPO_500ng.raw` are not explained anywhere (probably preTAILS vs TAILS, but which is which is unconfirmed).
- The deposited PD outputs do not carry sample names. The `.pep.xml` and `.msfView` of the PO run contain the workflow (TMTpro 16plex quantifier) and PSMs but no channel/sample labels. The `.pdResult` files (500-700 MB) were not downloaded.

Channel identities would have to be invented, which the skill forbids.

## Evidence checked (ladder, Step 6.1)

1. Paper and supplementary: the open bioRxiv versions v1-v4 and accepted-version PDF (10.1101/665653) describe only the label-free ECM proteomics (days 0/4/10 DSS, IL-10-/-) and contain no TAILS/TMT text. The published Matrix Biol 2021 paper (10.1016/j.matbio.2020.11.001, PMID 33246101) is paywalled and not open in Europe PMC; its TAILS section could not be read. The preprint cites PXD004740 as its data accession, not PXD022668.
2. Deposited PRIDE files (8 files: 2 RAW plus pdResult, msfView and pep.xml per run, README): no sample sheet. PO pep.xml and msfView checked, no channel names.
3. Europe PMC supplementary: none (hasSuppl = N, no PMCID for the published article).
4. External repositories: no Data/Code Availability statement accessible for the published paper.
5. Cross-validation: not possible without a map.

## What is known (for a future annotation)

Mus musculus colon (C57BL/6 and IL-10-/- models, DSS colitis); Q Exactive HF (EASY-nLC 1200); DDA, HCD; TMTpro 16plex; Sequest HT in PD 2.4; semi-Trypsin/R; fixed Carbamidomethyl (C) and TMTpro (K); variable Acetyl (N-term), Gln->pyro-Glu (N-term), TMTpro (N-term), Oxidation (M), Deamidated (N/Q); 10 ppm / 0.02 Da.
PRIDE structured fields list ulcerative colitis and Crohn's disease, but the model is mouse colitis, so those fields were not used.
