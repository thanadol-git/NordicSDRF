## Templates
`ms-proteomics` v1.1.0 + `human` v1.1.0. DDA on a TripleTOF 5600. No `clinical-metadata`: only sex and group are known per individual.

## Why the deposit is split into two SDRFs
The deposit holds two quantitative arms of the same 14 tissue samples: area-based XIC label-free runs (`120615_…` to `2012-10-05-…Control-3-4.wiff`, 56 files) and an iTRAQ 4plex arm with SCX fractionation (150 files `2013-*`). Labels, fractionation and the Mascot search settings differ, so each has its own SDRF.

## Design and file mapping
- Sources P1–P10 (late-onset FECD; P1–P5 female, P6–P10 male) and C1–C4 (secondary bullous keratopathy controls, all female). Sex per group comes from the paper Methods ("five females and five males", "four female patients") and Figure 1 (P1–P5 females, P6–P10 males, C1–C4 females).
- File → individual: `*_ETP_Fuchs_<n>_<r>.wiff` = patient n, replicate r (r = 1–4 → `comment[technical replicate]`); `*Control_<n>_<r>` / `Control-<n>-<r>` = control n. **Inferred from file names**; the paper states 10 patients and 4 controls and Figure 1 numbers them P1–P10 / C1–C4, which matches the file numbering, but no table links files to individuals.
- All 56 deposited XIC .wiff files are annotated (the `.wiff.scan` companions are not listed as runs). The paper text says XIC quantification used 10 patients and "three control samples", but all four control sets are deposited and annotated.
- Factor: `factor value[disease]` (FECD vs bullous keratopathy control).

## Technical values
- Instrument TripleTOF 5600 (MS:1000932): paper Methods and PRIDE agree. The .wiff headers were not read (download timed out).
- Cleavage: Trypsin (MS:1001251). Samples were also cleaved with CNBr (0.66 M in 70% TFA) before digestion, but the search enzyme was trypsin only and `cleavage agent details` is single-valued.
- Reduction DTT, alkylation iodoacetamide (sample protocol).
- Mascot 2.3.02 search (PRIDE data processing protocol): Carbamidomethyl (C) fixed; Oxidation (M) and hydroxylation of proline (written as Oxidation UNIMOD:35 on P) variable; 10 ppm / 0.2 Da. No search parameter file is deposited (`.dat` Mascot results only), so modifications come from prose.
- Dissociation CID: not stated in the text; set from the instrument type (TripleTOF beam-type CID, Mascot "ESI-QUAD-TOF"). Flag for review.

## Validation
- `sdrf-tools build -t ms-proteomics -t human`: 56 rows × 33 columns.
- `parse_sdrf validate-sdrf … --use_ols_cache_only`: 0 errors. `check --offline`: CLEAN. `structure`: OK.
- `sdrf-tools reconcile`: 2 BLOCKER findings, **both false positives for this file**: (1) `disease_on_control_runs` says every row asserts 'bullous keratopathy'; in fact the 16 control rows (C1–C4) say bullous keratopathy and the 40 patient rows say Fuchs' endothelial dystrophy (verified by counting). (2) `labelled_annotated_as_label_free` fires because the record also registers iTRAQ; the iTRAQ runs are annotated with channels in `PXD000746-itraq.sdrf.tsv`.

## Limitations
- Age is `not available`: only group means are given (FECD 72.5 y, range 56–83; controls 69 y, range 51–88).
- Controls are not healthy: they are non-FECD secondary bullous keratopathy tissue, annotated with that disease.
- Organism part is written as two values (`Descemet's membrane`, `corneal endothelium`) because tissue was the Descemet's membrane/endothelial layer; cell type `corneal endothelial cell` from the PRIDE record.
- Technical replicate numbers 1–4 come from the file suffix; the runs were done on different days (see acquisition dates in file names) and may not be strict injection replicates.
- The deposited fractions of FECD patient 1–10 all appear once; nothing excluded.
