# PXD023033 — BLOCKED

## Exact blocker

The deposited workbook gives an exact row-level map for all 108 RAW files, but the primary technical evidence is internally incomplete for 28 runs. The PRIDE protocol and registered instrument specify a Q Exactive HF, whereas 28 mapped RAW files are named `Lumos_201104_13.raw.gz` through `Lumos_201104_46.raw.gz`. No deposited acquisition method, search configuration, or publication is linked to the partial submission to establish whether those 28 files were acquired on an Orbitrap Fusion Lumos or merely carry a misleading filename prefix. An instrument cannot therefore be assigned to every run without inference.

## Evidence checked

- PRIDE project record and protocols: `https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD023033`
- Complete PRIDE file listing: `https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD023033/files/all`
- Deposited workbook `List_LCMS_Rawfiles_MassSpectrometryProteotyping-BasedDetectionandIdentificationofStaphylococcusaureusEscherichiacoliandCandidaalbicansinBlood.xlsx`. It maps sample number, exact MS filename, cell concentration, cleanup protocol, incubation time where applicable, and sample composition for all 108 RAW files.
- The PRIDE submission is marked `PARTIAL` and has no publication reference. Its only non-RAW file is the mapping workbook; no instrument method or search parameter file is deposited.
- Community annotation directory: absent (GitHub directory returned 404).

## Mapping facts that were resolved

- The workbook accounts for all 108 RAW files and identifies the pathogen spike as *Staphylococcus aureus*, *Escherichia coli*, or *Candida albicans* in a mixed human/horse blood matrix.
- It records pathogen concentration, cleanup protocol, and incubation time at run level.
- The project protocol supports overnight trypsin digestion, data-dependent Top10 acquisition, a 5 ppm precursor tolerance, and a 20 ppm product-ion tolerance for the Q Exactive HF workflow.

## Why an SDRF was not written

The mass spectrometer is a required technical field. Applying the registered Q Exactive HF to all files would ignore the unresolved `Lumos_*` subset, while assigning an Orbitrap Fusion Lumos from the filenames would infer a technical fact that no primary source confirms. A supportable SDRF requires the acquisition method or instrument/file export that identifies the instrument used for those 28 runs.
