## Design and file mapping
In-vivo pulse-chase: wild-type mice fed 13C6-lysine; serum collected at 0, 1, 2 or 3 weeks. File names `<date>-13CLys-pulseChase_Serum-HUNTER-DIA_<8|40>PT_<n>w-R<k>[_FS_<CV>V].raw` encode time point (n w), mouse/replicate (R<k>), and the C18 spin-column step-elution fraction (8% or 40% ACN) of the HUNTER N-terminal enrichment. Samples (9): 0w-R2; 1w-R2, R3, R4; 2w-R5, R7, R8; 3w-R1, R3. R2 and R3 each appear at two time points, which fits repeated bleeding of the same mouse (**inferred**; `individual` = `mouse_R<k>`). The PRIDE text says feeding for 1 or 2 weeks; files also contain 0 w and 3 w samples.
- 54 RAW files = 9 samples × 2 fractions × 3 file variants: the original acquisition and two `_FS_-45V` / `_FS_-65V` files, which are the FAIMS-CV-split copies of the same acquisition (the deposited FragPipe zip contains the mzML of the `_FS_` files only). All 54 are annotated: variants are written as `technical replicate` 1 (original), 2 (-45 V) and 3 (-65 V). **This numbering is a device to keep the file rows distinct, not three real injections.**
- Basic-pH C18 fractions 8PT / 40PT = `fraction identifier` 1 / 2.
- Two label rows per file (plexDIA channels `SILAC light` and `SILAC heavy` = pre-existing 12C-Lys vs newly synthesised 13C6-Lys proteome of the same serum sample), as separate sources `<time>_R<k>_light` / `_heavy`. In the 0 w sample no heavy lysine is expected but the channel was searched; the row is kept for consistency (**judgement call**).
- Factor: `factor value[sampling time]`.

## Technical values
Orbitrap Exploris 480 (PRIDE record; raw header of `…40PT_0w-R2.raw` shows the same and the DIA method `2022May_2h_2CVs_400nL_DIA_G1pickup.meth`). DIA, MS1 350-1350 m/z, 40 × 25 m/z windows between 400 and 1000 m/z (PRIDE protocol; 40 × 25 m/z does not fit 400-1000, so the scan window 400-1000 and isolation width 25 are written as stated). Trypsin (1:100, SP3). FragPipe 21.1 / DIA-NN plexDIA (PRIDE protocol): fixed Carbamidomethyl C, fixed dimethylation (+34.0631 = Dimethyl:2H(4)13C(2), UNIMOD:510) on K and N-termini, variable Label:13C(6) K and Oxidation M. Dissociation, collision energy, tolerances and the fractionation method are not stated: `not available`.
