## Design and file mapping

- Design: 2 cell lines (HeLa, U2OS; both stably expressing K0-SUMO) x 2 conditions (standard growth "Control" vs CDK1/CDK2 inhibition "CDKi") x 4 independent cell-culture replicates = 16 sources. Each source was measured once as a single-shot run (`*_All.raw`) and once as 7 high-pH reversed-phase fractions (`*_F0.raw` to `*_F6.raw`). That gives 16 x 8 = 128 runs.
- Evidence for the design: the PRIDE sample protocol ("HeLa and U2OS ... standard growth conditions, and CDKi treatment ... biological quadruplicate ... fractionated at high-pH, or otherwise analyzed as single-shot"), the data processing protocol ("RAW files were grouped as one of the 16 experimental replicates ... Fraction numbers 0-6 were used to indicate fractionated samples, with fraction number 8 used for single-shot samples"), and the Supplementary Figure 6D legend ("n=4 cell culture replicates ... analyzed by mass spectrometry as single-shots as well as fractions").
- Source names: `<line>_<control|CDKi>_<n>`, for example `HeLa_CDKi_3`. `characteristics[biological replicate]` is n (1-4), numbered within each cell line and condition.
- File mapping came from the deposited file names and was cross-checked against the RAW headers. For each of the 128 RAW files, the first 64 KB were range-read from the PRIDE FTP. The original acquisition name (`20161012_QE6_LC12_IAH_SUMO_QQ_<line>[_CI][_F<n>]_R<rep>_TR1.raw`) matches the deposited name on cell line, CDKi flag, replicate and fraction for all 128 files, so no files were renamed or swapped. All originals are `TR1`. The instrument methods agree: the `_All` runs use a 160 min gradient method, and the fractions use 50 min (F0) or 80 min (F1-F6) methods with fraction-specific gradients.
- Fractions F0-F6 have `comment[fraction identifier]` 1-7, `comment[technical replicate]` = 1 and `comment[fractionation method]` = `NT=High-pH reversed-phase chromatography (hpHRP);AC=PRIDE:0000564`.
- Single-shot runs have `comment[fraction identifier]` = 1 (the spec gives 1 for unfractionated runs), `comment[technical replicate]` = 2 and `comment[fractionation method]` = `not applicable`. This makes them distinguishable from the fractionated series and keeps the (source, biological replicate, technical replicate, fraction) coordinate unique. Both are measurements of the same purified, trypsin-digested SUMO-peptide sample. MaxQuant also grouped them into one experiment.
- PRIDE file list: 130 entries, all with `projectAccessions` = PXD005296 (128 RAW, 1 FASTA, 1 SEARCH). All 128 RAW files are in the SDRF exactly once. No RAW file was left out.

## Technical values

- Instrument: `NT=Q Exactive HF;AC=MS:1002523`. The model string "Q Exactive HF" appears in all 128 RAW headers and agrees with PRIDE.
- Acquisition: DDA (`PRIDE:0000627`). Dissociation: HCD (`NT=beam-type collision-induced dissociation;AC=MS:1000422`). Label: `label free sample` (MaxQuant LFQ; PRIDE quantification "Label free").
- Cleavage: two `comment[cleavage agent details]` columns, `NT=Lys-C;AC=MS:1001309` and `NT=Trypsin;AC=MS:1001251`. The protocol describes sequential digestion: proteins with LysC, then SUMO peptides repurified and digested with trypsin. A head read of the deposited `allPeptides.txt` shows K/R C-termini.
- Modifications (from the data processing protocol and the `allPeptides.txt` head):
  - Fixed: Carbamidomethyl C (UNIMOD:4; +57.02 seen on C).
  - Variable: Oxidation M (UNIMOD:35), Acetyl protein N-term (UNIMOD:1), Phospho S/T/Y (UNIMOD:21), QQTGG K (UNIMOD:2082, the SUMO remnant), Pyro-QQTGG K (UNIMOD:2083).
  - The two QQTGG terms were confirmed in live OLS (UNIMOD).
- Tolerances: precursor 4.5 ppm (stated in the protocol); fragment 20 ppm (MaxQuant FTMS default, inferred; see Limitations).

## Post-processing

`sdrf-tools build` emits one `comment[cleavage agent details]` column, because the contract does not mark it as a multiple-value column. The script `scratchpad/PXD005296/postprocess.py` inserts a second `comment[cleavage agent details]` column, `NT=Trypsin;AC=MS:1001251`, directly after the Lys-C column. A diff check confirmed that the output equals the `build` output with only that one column inserted (128 rows; 40 to 41 columns).

## Limitations
- **Revised after independent review:** U2OS `characteristics[ancestry category]` set to `European ancestry` (HANCESTRO:0005; Cellosaurus 'Caucasian' is an exact HANCESTRO synonym) and `characteristics[sampling site]` to `tibia` (UBERON:0000979; Cellosaurus 'Bone, tibia').


- **CDK inhibitor not named.** The accessible text says only "CDK1- and CDK2 inhibition (CDKi)", and the Online Methods are paywalled. The treatment is therefore the NCIT class term `Cyclin-Dependent Kinase Inhibitor` (NCIT:C2185), not a specific compound. Dose and duration are not captured. Source: PRIDE protocol and Supplementary Figure 6D legend.
- **Fragment mass tolerance 20 ppm is inferred.** It is the MaxQuant 1.5.3.30 FTMS MS/MS default, and the protocol says "Default MaxQuant settings were used" with listed exceptions. It was not read from `parameters.txt`/`mqpar.xml`, because these are inside a 1.9 GB `search.tar.gz` after multi-GB tables.
- **Single-shot runs as technical replicate 2** is an encoding choice. They are a second measurement of the same prepared sample, according to the deposit's design statements (above), not a re-injection of one vial. Their deposited MaxQuant fraction number (8) is not reused, because the spec gives fraction 1 for unfractionated runs.
- **Pairing between conditions is unknown.** Replicate n of control and of CDKi are separate sources; whether they came from the same culture batch is not documented.
- **Cell-line donor fields come from Cellosaurus, not the paper:**
  - HeLa (CVCL_0030): 30Y6M, female, cervical adenocarcinoma, sampling site uterine cervix, African American, epithelial cell.
  - U2OS (CVCL_0042): 15Y, female, osteosarcoma, sampling site bone, cell type `not available`. Ancestry is `not available` because Cellosaurus "Caucasian" has no exact HANCESTRO term.
- **Organism part** is `not applicable` on all rows (cultured cell lines); the origin tissue is in `characteristics[sampling site]`.
- **Not captured** because they are not in accessible evidence: passage number, culture medium, K0-SUMO construct and SUMO purification details, reduction/alkylation reagents (the fixed Carbamidomethyl search implies alkylation, reagent unstated), collision energy, LC batch.
- The `_F0` to `_F6` to fraction 1-7 mapping follows the file names and MaxQuant fraction numbers 0-6. Fraction-level details (pooling scheme, buffer) come from the per-fraction instrument method names only.
