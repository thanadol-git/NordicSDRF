# PXD026243 SDRF annotation report

- **Accession:** PXD026243
- **Title:** Human primary endometrial stromal cells (proliferative vs secretory) LC-MSMS - proteins and phosphosites
- **Scope:** The SDRF contains the 12 deposited raw files: six deposited sample-code groups, each represented by a full-proteome file and an EasyPhos phosphoproteome file.
- **Sample map:** `ESC399_ESC349` and `ESC404_ESC376` are represented as pooled samples because the PRIDE processing protocol states that one independent experiment used pooled cells from two patients. `ESC290`, `ESC296`, `ESC482`, and `ESC485` are represented as individual sample-code groups. The full-proteome/EasyPhos pairing is taken directly from the raw-file names in the PRIDE FTP manifest.
- **Biology:** Homo sapiens, uterine endometrium, stromal cell of endometrium, female. Disease and age are `not available`; no disease state was inferred from the project title.
- **Methods:** PRIDE records 4% SDS/Tris/DTT lysis, Lys-C pre-digestion followed by trypsin, C18 StageTips, EasyPhos phosphoproteome preparation, Q Exactive acquisition, and MaxQuant processing. The SDRF records the explicitly documented fixed carbamidomethylation and variable methionine oxidation and protein N-terminal acetylation.
- **Important limitation:** The accessible PRIDE project record, publication, and FTP manifest establish the proliferative/secretory study design but do not expose the exact proliferative-versus-secretory assignment for each ESC code. No factor value was invented; the phase assignment should be added only after recovering the deposited README or an equivalent sample sheet.
