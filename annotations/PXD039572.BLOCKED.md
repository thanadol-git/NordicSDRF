# PXD039572 — BLOCKED

- **Evidence:** The previous Uppsala assessment found that the deposited RAW files use opaque `MS-16-043` run codes.
- **Why blocked:** No deposited source maps those run codes to biological condition, replicate, or other sample metadata. An SDRF would therefore invent source-to-assay relationships.
- **Unblocking requirement:** A run sheet or sample manifest resolving every `MS-16-043` RAW-file code to its biological sample and condition.
