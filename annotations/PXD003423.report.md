## Key decisions

- Instrument: raw headers say `Q Exactive` (IP, StUbEx) and `Orbitrap Velos Pro MS` (pull-down). PRIDE lists `LTQ Orbitrap Velos`; raw header wins -> `Orbitrap Velos Pro` (MS:1003096).
- Modifications read from each deposited mqpar.xml: Carbamidomethyl fixed; Oxidation(M), Acetyl(protein N-term), Deamidated(N,Q) variable; plus Phospho(S,T,Y) for IP and StUbEx; plus GlyGly(K) for StUbEx only. The pull-down search had no Phospho/GlyGly, so those two repeated columns carry `not applicable` (padding so all rows share one header; judgement call). SILAC labels are not written as modification columns.
- Cleavage: Trypsin (MS:1001251) in all rows; second repeated cleavage column = Lys-C for StUbEx (protocol: LysC+trypsin), `not applicable` elsewhere. Search enzyme was Trypsin/P, max 2 missed cleavages. `sdrf-tools reconcile` still reports MAJOR cleavage_agent_incomplete because it reads only one cleavage column per row and the record's Lys-C applies to the StUbEx arm only - judged a tool limitation (the second column is present on all 132 StUbEx rows).
- Tolerances: 6 ppm precursor (mqpar mainSearchTol); fragment 20 ppm (HCD/FTMS) or 0.5 Da (CID/ITMS), from parameters.txt and the allSpectra file types.
- Fractionation: SDS PAGE for IP and pull-down (in-gel digestion per protocol); `not available` for StUbEx ("pH gradient" is not specific enough for a PRIDE term). StUbEx fraction numbers follow the deposited ExpDesign order (10,20,25,30,35,40,55,70,80,B,FT), not a verified elution order.
- Reduction/alkylation reagents `not available` (stated only as "reduced, alkylated"); Carbamidomethyl is Fixed in the search, so it is kept.
- HeLa: CVCL_0030 (parental) used; subline not stated. Age 30Y6M / female are Cellosaurus values, not deposit-specific. Organism part `uterine cervix` is the HeLa tissue of origin (PRIDE only says "HeLa cell"). Disease = cervical adenocarcinoma (tissue of origin, MONDO:0005153), cell type = epithelial cell (round 1 fix); passage, medium omitted. Pull-down caveat: the deposited design file is named ExpDesign_PullDown_hMSCs.txt and the companion record mentions Skov3/Hep2, so the HeLa identity of the pull-down lysates is unconfirmed; cell line cannot be a reserved word under cell-lines, so rows stay HeLa. HeLa is assumed for all three sub-experiments (project title/protocol); companion record mentions Skov3/Hep2 cells in other experiments, but none are named in this deposit.
- Biological replicate: IP and pull-down = MaxQuant experiment number; StUbEx SILAC1/2 = 1 and SILAC3/4 = 2 (file names UBI_1/UBI_2 vs Rep2-Ubi/Rep2-Ubi_S2; interpretation).
