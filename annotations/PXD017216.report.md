# PXD017216 SDRF annotation report

## Study
Divalent Metal Transporter 1 Knock-Down Modulates IL-1β Mediated Pancreatic Beta-Cell Pro-Apoptotic Signaling Pathways through the Autophagic Machinery. Int J Mol Sci 2021;22(15):8013, doi:10.3390/ijms22158013, PMID 34360779, PMC8348373 (Methods read). SDU Odense. Rat INS-1E β-cells: untransfected control, scrambled siRNA, or DMT1 (Slc11a2) siRNA, each ± IL-1β (50 pg/mL, 24 h); TMT 11plex (6 channels used) × 3 biological replicates; phosphopeptide enrichment, with the flow-through used as the proteome; Q Exactive HF, PD.

## Templates
ms-proteomics v1.1.0 + vertebrates v1.1.0 (`cell-lines` not declared: INS-1E's Cellosaurus accession wasn't verified live; the cell line is recorded by name).

## Scope: deposited vs annotated
`files/all`: 108 files: 106 RAW (`Replicate<r>_{Flowthrough,Phospho}_<k>.raw`) + 2 PD `.msf`. All 106 annotated × 6 channels = 636 rows. The deposited files were renamed; each RAW header (range read, 95 of 106 resolved directly; the rest follow the same contiguous pattern) gives the original name `QEHF3_0xxxx_TK.raw` (kept in `comment[original file name]`), which links each file to the `.msf` FileSets `Proteome_R1-3` / `DMT1 KD_Phospho_R1-3` and their FractionNumber (= `<k>`). `Replicate1_Flowthrough_5` (original 07064) is deposited but absent from the PD FileSet (fraction 5 gap).

## Sample map
Channel layout from the paper ("Control (126), Scrambled (127N or 127C), DMT1 KD (128N or 128C), Control+IL-1β (129N or 129C), Scrambled+IL-1β (130N or 130C), DMT1 KD+IL-1β (131N or 131C)") and the `.msf` study factors (`Group`, `Cell`=Replicate): Replicate 1 and 3 use the N series; Replicate 2 uses the C series. The other 5 channels are `Blank` in PD and not annotated. One conflict: the Proteome_R2 PD study definition places DMT1 KD on 128N, while DMT1 KD_Phospho_R2 (same labelled mixture) places it on 128C; the C-series assignment (phospho + paper pattern) is used for both arms of Replicate 2.

## Key decisions
- Instrument Q Exactive HF (RAW headers); DDA, HCD. Trypsin; DTT 10 mM; iodoacetamide 20 mM (paper).
- Modifications: fixed Carbamidomethyl C, TMT6plex K + N-term; variable Oxidation M, Phospho STY (phospho arm search).
- `genetic modification`: untransfected / scrambled siRNA / DMT1 siRNA; `treatment`: IL-1β vs none; both are factors.
- Cell line INS-1E (BTO:0003317), rat insulinoma (MONDO:1013585), type B pancreatic cell (CL:0000169), pancreas.
