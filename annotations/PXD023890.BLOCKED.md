## Evidence recovered

- 12 RAW files `160226_TV_cntrl_bov_1…12b.raw` (Q Exactive in RAW headers; PRIDE says Q Exactive HF-X).
- `porcine_articular_cartilage_by_depth.xlsx` reports abundances for 12 depth bins (0–50 µm … 2000–2200 µm) but does not name the RAW file behind each bin.
- PRIDE, the paper and the searched database (Sus scrofa UP000008227) say porcine cartilage, while every RAW file is named `cntrl_bov`.

## Why no SDRF was emitted

Assigning depth bin k to file k is plausible but not stated anywhere, and the species naming conflict is unresolved. Depth is the only experimental variable, so an SDRF without it has no factor.
