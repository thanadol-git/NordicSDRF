# PXD003165 annotation report

Primary neonatal porcine Leydig cells exposed to 3-methylsulfonyl-DDE (10 µM, 48 h), with and without luteinizing hormone (LH) stimulation. NMBU, Ås. Paper: J Proteomics 2016, PMID 26691841 (not open access).

## Templates
`ms-proteomics` v1.1.0 and `vertebrates` v1.1.0.

## Rows and files
There are 24 rows: 12 samples × 2 MED-FASP digests.
- **Experiment names:** the deposited MaxQuant `mqpar.xml` lists the raw files in order with these experiment names:
  - `A-`, `B-`, `C-`, `A+`, `B+`, `C+`
  - `AL-`, `BL-`, `CL-`, `BL+`, `CL+`, `BLCL+`
- **Digest per file:** the parameter-group index alternates 0/1. Group 0 is LysC/P and group 1 is Trypsin/P, so the first file of each pair is the Lys-C digest (fraction 1) and the second is the tryptic digest (fraction 2). Each row has its own `cleavage agent details`.
- **Interpretation (please check):**
  - `A/B/C` = cell preparations (biological replicates 1–3).
  - `L` = LH-stimulated.
  - `+`/`−` = 3-MeSO2-DDE-exposed vs vehicle.
  - This matches the abstract (unstimulated and LH-stimulated cells, 48 h exposure to 10 µM), but the closed-access paper could not be checked.
  - There is no `AL+`. `BLCL+` is annotated as a pooled B+C LH+DDE sample (biological replicate `pooled`).
