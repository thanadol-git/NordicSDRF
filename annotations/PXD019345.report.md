# PXD019345: annotation evidence blocker

The accession has 16 deposited Thermo RAW files in two naming groups: four 2018 `Iris_IP_Sample*` files and twelve 2019 `EV_LHB_Iris_*` files. The filenames do not state which immunoprecipitation condition or biological replicate each file represents. The two deposited Proteome Discoverer `.pdResult` files are search outputs, but their filenames also do not supply a complete sample-to-condition map.

The PRIDE sample-processing protocol explicitly describes sequential LysC digestion for three hours followed by overnight Trypsin digestion for the immunoprecipitation samples. The current `sdrf-tools build` contract has a single `comment[cleavage agent details]` column and does not emit both enzymes from duplicate technical rows. Listing only one enzyme would omit documented preparation. No SDRF was added for this accession.

To proceed, recover an accession-specific experiment design mapping all 16 raw filenames to conditions and replicates, and use a builder/schema representation that retains both digestion enzymes. The title of the paper or a generic IP protocol is insufficient to assign per-file conditions.

Sources: [PRIDE project record](https://www.ebi.ac.uk/pride/ws/archive/v2/projects/PXD019345), `scratchpad/PXD019345/pride.json`, and accession-scoped `scratchpad/PXD019345/files.json`.
