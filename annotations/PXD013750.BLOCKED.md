# PXD013750 — annotation blocked

## Dataset

- **Title:** Conformational dynamics of the human serotonin transporter during substrate and drug binding (HDX-MS)
- **PRIDE record:** PXD013750
- **Publication:** PMID 30976000

## Evidence recovered

Waters Synapt HDX-MS data of purified hSERT (Na+/K+, 5-HT, S-citalopram, cocaine, ibogaine; 0.25-480 min D2O labelling) packed into dataset ZIPs (DatasetNaK5-HT, DatasetNaS-citalopram, DatasetNacocaineibogaine, MSMS) with a DynamX state file and an overview sheet; PRIDE lists no RAW-category files.

## Why no SDRF was emitted

Out of scope for the ms-proteomics SDRF: hydrogen/deuterium exchange of one purified protein (deuterium uptake per labelling time and ligand state), not a proteome sample; each data file is a ZIP holding many runs. Same reason as PXD047712 in copenhagen-6.

PRIDE record and protocols; file list.
