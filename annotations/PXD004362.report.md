## Design and file mapping
Juvenile Atlantic cod (mixed sex, 260–530 g), four tanks of n=10, injected i.p. with vehicle (20% acetone / 80% soybean oil) or PCB 153 at 0.5, 2 or 8 mg/kg body weight (split into two injections on day 1 and day 7); sacrificed at day 14, liver dissected (PRIDE sample processing protocol). One label-free injection per individual liver, unfractionated.

| Group | Run files | Source names | dose (factor) | compound |
|---|---|---|---|---|
| Control (vehicle) | `OAK_K_1..10.raw` | `cod_liver_ctrl_1..10` | 0 mg/kg | not applicable |
| PCB 153 0.5 mg/kg | `OAK_05_1..10.raw` | `cod_liver_PCB153_0.5_1..10` | 0.5 mg/kg | 2,2',4,4',5,5'-hexachlorobiphenyl |
| PCB 153 2 mg/kg | `OAK_2_1..10.raw` | `cod_liver_PCB153_2_1..10` | 2 mg/kg | 2,2',4,4',5,5'-hexachlorobiphenyl |
| PCB 153 8 mg/kg | `OAK_8_1..10.raw` | `cod_liver_PCB153_8_1..10` | 8 mg/kg | 2,2',4,4',5,5'-hexachlorobiphenyl |

- Factor value: `factor value[dose]` (0 / 0.5 / 2 / 8 mg/kg). Compound is not a separate factor because it is confounded with dose (control = 0 mg/kg).
- `characteristics[biological replicate]` = the fish index in the file name (1–10 within each group).
- Mapping established from the **file names**: the dose token in `OAK_<token>_<n>.raw` (`K`, `05`, `2`, `8`) matches the four protocol groups, and 10 files per token matches n=10/group. The `K` = control reading is supported by the deposited Progenesis peptide export (`PCB153_Ensembl_MSGF_Amanda_Xt_Peptides.csv`), whose quantification columns are grouped as Control / PCB 153 0.5mg / 2 mg / 8 mg with 10 replicates each, and by the deposited Skyline SRM sheet, which names control fish `K-1..K-10` alongside `2_n` and `8_n`. There is no deposited table mapping file → Progenesis column name explicitly.
- All 40 `.raw` files in PRIDE are mapped, each to exactly one source.

**Excluded from scope:** `20130705_SAmples.wiff` / `.wiff.scan` (QTRAP 5500 SRM verification of GSTT1 and ST2B1 with spiked SIS peptides). It is a single multi-sample SCIEX file; the Skyline results list 29 replicates in it (K-1..10, 2_1..10 without 2_7, 8_1..10), with a different instrument, acquisition method (SRM) and sample prep (spiked heavy peptides). It cannot be represented as one file per sample row in this SDRF and was left out rather than forced in. Search/peak-list/FASTA files (`.csv`, `.mgf`, `.fasta`, `.xlsx`) are not data files.

## Technical values and their sources
- Instrument `NT=Orbitrap Velos Pro;AC=MS:1003096`: read from the embedded instrument method in the raw file headers (`Creator: Orbitrap Velos Pro`), checked in `OAK_K_1`, `OAK_K_10`, `OAK_05_1`, `OAK_2_10`, `OAK_8_5`. It agrees with the protocol ("LTQ-Orbitrap Velos Pro"). The PRIDE dropdown says "LTQ Orbitrap Velos" (MS:1001742) and was overridden.
- DDA (`PRIDE:0000627`), CID (`MS:1000133`), `35 NCE`, ion-trap MS2 (`radial ejection linear ion trap`, MS:1000083), MS1 scan range `300m/z-2000m/z`: all from the raw-file method ("Nth Order Double Play"; FTMS full scan 300–2000; ITMS MS/MS, Activation Type CID, NCE 35.0; top 7). It was identical in all five files checked.
- Trypsin, 10 ppm precursor, 0.5 Da fragment tolerance, Carbamidomethyl C fixed, Oxidation M variable: from the PRIDE data processing protocol (SearchGUI 1.18.1 with X!Tandem, MS Amanda and MS-GF+; PeptideShaker 0.28).
- Additional variable modifications (Acetyl protein N-term; Gln->pyro-Glu; Glu->pyro-Glu; Pyro-carbamidomethyl): these are reported in the deposited PeptideShaker/Progenesis peptide export (`acetylation of protein n-term` 47, `pyro-glu from n-term q` 56, `pyro-cmc` 29, `pyro-glu from n-term e` 1 peptides; `oxidation of m` 469). They are X!Tandem's built-in refinement modifications, so they were part of the effective search space even though the Methods text names only Oxidation. No search parameter file (`.par`/SearchGUI settings) was deposited, so `sdrf-tools search-params` could not be run.
- Reduction/alkylation reagents: `not available`. Carbamidomethyl is a fixed search modification, but the protocol only refers to Berle et al. 2013 for digestion and does not name the reagents.

## Limitations
- **Sample → file mapping is inferred from file names** (dose token + fish index), corroborated by the deposited Progenesis group labels and the Skyline SRM replicate names. No deposited table links each `.raw` to a Progenesis column (`Ctr_n`, `PCB153_0.5mg_n`, …) explicitly. Also assumed: fish index *n* in a file name is the same individual as replicate *n* elsewhere; the SDRF only uses it as a per-group replicate number.
- `characteristics[sex]` = `not available`: the protocol says "mixed gender" and gives no per-fish sex.
- `characteristics[strain or breed]` = `not available`: the source population/stock of the cod is not given in the accessible record.
- `characteristics[developmental stage]` = `juvenile stage`: from the cohort-level statement "Juvenile Atlantic cod" (it applies to all fish).
- `characteristics[disease]` = `not applicable`: this is a toxicant-exposure study of non-diseased fish with no disease variable. `normal` was not asserted for exposed fish.
- `characteristics[compound]` = `not applicable` for controls: they received vehicle only (acetone/soybean oil), with dose recorded as `0 mg/kg`. The vehicle is not annotated as a compound.
- `characteristics[sampling time]` = `14 day`: time from the first injection to sacrifice (protocol).
- `characteristics[dose]` is the nominal total dose per kg body weight (given in two halves, day 1 and day 7).
- Reduction/alkylation reagents are `not available` (see above).
- The X!Tandem refinement modifications were inferred from the identifications in the deposited results, not from a deposited parameter file.
- The paper's full text (closed access) was not read; the per-sample details in it (e.g. sex or body weight per fish, if any) could not be checked.
- The SRM `.wiff` sub-experiment is not annotated (see "Excluded from scope").
- Raw-file method details were checked in 5 of 40 files, not all of them.
