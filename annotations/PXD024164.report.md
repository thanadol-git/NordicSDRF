# PXD024164 annotation report

## Result

Codex-curated SDRF with 19 deposited RAW files and one row per RAW file. The project record reports human breast epithelial cell-model proteomics, Q Exactive HF, label-free DDA, tryptic digestion, 10 ppm precursor tolerance, 0.02 Da fragment tolerance, HCD 29 NCE, and the deposited filenames shown in the PRIDE FTP directory.

## Evidence

- PRIDE project record: PXD024164.
- Publication: Wang et al., Molecular Oncology (2022), PMID 34942055, DOI 10.1002/1878-0261.13172.
- PRIDE FTP directory: 19 RAW files plus one XLSX, mqpar.xml, txt.zip, and README/checksum files.
- The run-name prefixes (DE, DM, ET, HE, HM, LA) were retained as source names; the cell-line identity was not expanded because the project record and deposited filenames do not provide a deterministic prefix-to-cell-line key.

## Conservative choices

Cell line, disease, and factor value are not available rather than inferred from filename prefixes. Biological replicate is taken only from the numeric run suffix. The final LA3 timestamped file is retained as technical replicate 2.

## Validation

Run parse_sdrf validate-sdrf against ms-proteomics and human after installation/update of the SDRF specification. Raw-file technical refinement was not run because the raw files are multi-gigabyte remote files.
