# PXD054549 SDRF annotation report

## Study
Micro-destructive palaeoproteomic analysis of dental enamel from 23 Homo naledi specimens (Rising Star cave system), testing for AMELY-derived male markers (Cell 2026, doi 10.1016/j.cell.2026.05.044).

## Templates
ms-proteomics v1.1.0

## Scope: deposited vs annotated
92/92 deposited RAW (mqpar.xml lists 94; 1693_Human_enamel and 1695_Human_blank were not deposited).

## Sample map
Deposited mqpar.xml: raw file -> experiment (specimen) and fraction (F1-F5 for 2422-2426 runs). Extraction step parsed from file names (Enamel20/80 = cutting protocol, Etch_2a/2b/2at = acid etch rounds, F1-F5 = sequential fractions).

## Key decisions
TFA acid extraction, no protease -> unspecific cleavage (MaxQuant enzymeMode 4), no reduction/alkylation; variable modifications as in mqpar.xml. Instrument Orbitrap Exploris 480 for all 92 RAW headers (PRIDE metadata says LTQ Orbitrap). Reruns are technical replicates of the same source. Blanks grouped by extraction batch number. Homo naledi is free text (no NCBITaxon term found). Fraction method left 'not applicable' because the F1-F5 scheme is not described in the protocol.

## Not available / not applicable

## Conflicts / overrides
