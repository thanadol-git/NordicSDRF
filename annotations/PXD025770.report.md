# PXD025770 annotation report

Oudhoff lab (CEMIR/NTNU), sister deposit of PXD020561. Paper: Nat Commun 2021, PMC8602650. Not in the community corpus.

## Templates
`ms-proteomics` v1.1.0 only. The file mixes mouse and recombinant-human rows, so an organism template is not applied.

## Rows and files
There are 9 rows, one per `.raw`:
- **`20191003_…_WT1–3` / `KO1–3`:** the same six intestinal-muscle secretome runs as PXD020561, with identical file names and byte sizes. They are annotated exactly as there: wild type vs *Mmp17*−/−, `muscle layer of intestine`, Q Exactive HF, Lys-C + trypsin, 20/20 ppm.
- **`20210321_EX2_UM7_…_MPP1–3`:** the "Recombinant MMP17–Periostin cleavage site discovery" experiment (paper Methods). Recombinant human periostin was incubated with recombinant human MMP17 for 2 h at 37 °C, run ~3 cm into an SDS-PAGE gel, and the lane cut into 3 pieces. These rows are organism `Homo sapiens` with material type `synthetic`.
  - **Inferred:** MPP1–3 are read as the three gel pieces of one lane (fractions 1–3), because the paper describes a single lane cut in three. No file states the mapping.
  - Instrument is **Orbitrap Exploris 480** (raw header), HCD 27 NCE.
  - Search: Mascot via PD 2.4, Carbamidomethyl C fixed; Oxidation M and Acetyl protein N-term variable; 10 ppm / 0.05 Da. The PD `.pdResult` files are deposited.
