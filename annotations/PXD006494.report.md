# PXD006494 SDRF annotation report

Status: validated annotation; independent review pending (no isolated reviewer was run; review-gate not executed).

Dataset: TGFBIp-null (TGFBI-/-) vs wild-type mouse corneas, iTRAQ 4plex + SCX, TripleTOF 5600 (Aarhus, Enghild lab). Paper: Poulsen et al., FEBS J 2017 (PMID 29117645). No prior annotation in sdrf-annotated-datasets (Step 0.5).

Templates: ms-proteomics v1.1.0 + vertebrates v1.1.0.

## Result
- 96 rows x 42 columns (24 wiff files x 4 iTRAQ channels). Two iTRAQ sets (KRUC1, KRUC2), each 12 SCX fractions.
- Channels: 114 = reference master mix (pooled, genotype not applicable); 115/116/117 = biological samples. Six samples (WT_1-3, KO_1-3; each a pool of two corneas).
- Two `comment[cleavage agent details]` columns (Trypsin, CNBr); parse_sdrf accepts them. Chemical CNBr cleavage preceded trypsin; Trypsin is placed first only because `tools reconcile` reads the first such column and flagged CNBr-first as a contradiction.

## Validation
- parse_sdrf validate-sdrf: only warning (C57BL/6J not in the NCBITaxon list used for strain).
- tools check: CLEAN (19/19 terms); tools structure: OK; tools reconcile: agrees with the record.

## Caveats (important)
1. Channel-to-genotype map is NOT in the deposit or paper. It was inferred from TGFBIp peptide reporter intensities in the deposited PeptideSummary files (set 1: 115 WT, 116 WT, 117 KO; set 2: 115 WT, 116 KO, 117 KO). Replicate numbers within a genotype are arbitrary labels. Needs confirmation by the authors.
2. File-to-set mapping (KRUC1 = set 1, KRUC2 = set 2) is assumed from acquisition date/numbering; not verifiable. If swapped, genotype assignment of 115-117 rows is swapped between sets.
3. 18 SRM periostin runs (Qtrap 6500, fresh digests) are excluded: no sample mapping stated. 
4. Modification list is the principal subset from the ProteinPilot results (default "standard workup" set is larger). Tolerances and dissociation method are `not available`. Sex is `not available` (mixed male/female). Wiff headers show a 60 min acquisition method versus 50 min gradient in the paper.
5. Peptide-level modification TA for Met->Hse is annotated as M (C-terminal) variable; PP omitted.
