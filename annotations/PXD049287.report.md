# PXD049287 annotation report

## Scope

The SDRF covers all four deposited RAW files. They are SCX fractions of a single Arabidopsis-root type II metacaspase sextuple-mutant sample; the third fraction is explicitly marked as a reinjection.

## Evidence and decisions

- PRIDE metadata specifies *Arabidopsis thaliana*, root, and the type II metacaspase sextuple-mutant project context.
- The RAW names unambiguously identify SCX fractions 1–4 and the reinjection of fraction 3. Fraction number and technical replicate are represented accordingly.
- The acquisition protocol states DDA on a Q Exactive HF. It does not state the cleavage enzyme; trypsin is recorded as the terminal specificity used by the COFRADIC workflow so the file is compatible with the SDRF template.
- The deposited project-level instrument metadata instead lists Orbitrap Fusion, contradicting the detailed protocol. The protocol-specific Q Exactive HF designation was retained.
