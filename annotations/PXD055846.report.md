## How values were derived

- Experimental replicate (`biological replicate` 1-4) and protease: from the RAW zip names (1st-4th submission; trypsin / chymotrypsin / AspN / chymotrypsin+trypsin), consistent with the MaxQuant mqpar files in MQPR_*_submission.zip (enzyme per search).

## Limitations (important)

- **Run-to-sample mapping is not in the deposit.** The sample description (70 mAb combinations, concentration, polyclonal IgG background) is in Supplementary Table 6 of the paper, which was not retrievable (bioRxiv supplement 404; Cell Systems paywalled). Therefore no per-row sample identity, mAb composition, input amount or IgG background is annotated, and no `spiked compound` column was written. Each RAW file is its own `source name` (file stem) and technical replicate is set to 1 only because every file is a separate source; the real 3-fold technical replication and 70-sample grouping are not encoded.
- **Blank runs are included.** The 5441 RAW files exceed the 3360 sample runs (70 x 4 x 4 x 3) because blank/cleaning injections (one between numbered samples, three between mAb spike-in groups) were deposited with the same naming (EH####.raw). They cannot be distinguished from the deposit without Supplementary Table 6; the rows are retained so every deposited RAW file is covered once. Reviewers/users should drop blanks once the map is available. A few files are duplicates by acquisition name (e.g. EH4856.raw and EH4856_211022134635.raw; EH5718_211104090749.raw is only 60 kB) and are kept as deposited.
- `organism part`, `age`, `sex` are `not available` (recombinant mAbs plus pooled donor IgG; no donor demographics). `disease` is `not applicable`.
- Two `comment[cleavage agent details]` columns are used: the second is `not applicable` except for chymotrypsin+trypsin rows (chymotrypsin 4 h, then trypsin added for 18 h). The template defines the column as single-valued; it passes validation but is a deliberate extension. MaxQuant searched chymotrypsin+trypsin runs with Chymotrypsin only (mqpar), and the SDRF follows the wet-lab protocol.
- `factor value[cleavage agent details]` (protease) is the only factor encoded; mAb input and polyclonality are the other designed variables but are unmapped.
- Precursor tolerance 4.5 ppm is the MaxQuant main search value; MS/MS 20 ppm is the FTMS match tolerance. MSFragger/Casanovo settings were not used.
- The protocol text truncates; only "normalized HCD collision energy 28%" was used. Not independently verified from RAW headers.
