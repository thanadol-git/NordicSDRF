Existing community annotation: none found in sdrf-annotated-datasets (Step 0.5).

- 94 rows x 32 columns, templates ms-proteomics v1.1.0 + human v1.1.0 + oncology-metadata v1.0.0.
- 46 SCLC baseline rows (100kB; 23 patients x 2 technical replicates; patient 11 not analysed, files absent) and 48 healthy control rows (100kCON; 24 x 2).

## Caveats
- Per-sample age, sex, ancestry, tumour stage are not in the deposit (paper Table 1 has cohort summaries only: 12M/12F per arm, mean age 67 vs 63.3; stage IIB 1, IIIA 6, IIIB 3, IV 14) and are `not available`. Cell type `not available`.
- Disease assignment rests on file-name prefixes (100kB = baseline SCLC, 100kCON = control) as defined in the PRIDE protocol text.
- Instrument taken from paper/PRIDE; the first 300 KB of a RAW file did not contain the model string, so it is not raw-verified.
- Modifications come from prose; no parameters file is deposited (Protein_ID__100k.txt is a result table). Dissociation method not stated.
- EV enrichment (differential ultracentrifugation 100,000 x g) not encoded: no suitable controlled term was confirmed.
- Treated-patient files were searched but not deposited here.
- Independent review (Step 9.5) was not performed: subagents were not permitted in this run.
