# PXD028507 annotation report

Status: validated annotation; independent review pending.

## Result

33-row, 40-column SDRF, one row per RAW file (all 33 RAW files claimed; MaxQuant zip, two multi-GB .rar search outputs, FASTA and Readme excluded). Templates: ms-proteomics v1.1.0 + vertebrates v1.1.0 + cell-lines v1.1.0. Not previously annotated (no PXD028507 directory in sdrf-annotated-datasets).

Dataset: SUMOylation proteomics in mouse mpkDCT (distal convoluted tubule) cells; Aarhus University (Qi Wu). Publication: PMC8646034 (Aroankins et al. 2021, Front Mol Biosci).

## Design

- 10 experiments: SUMO1-Exp1..4 and SUMO2-Exp1..6, taken from the deposited Readme.docx (file, experiment, enzyme, treatment).
- Each experiment yields two peptide pools from the same cells: Lys-C digest, then Glu-C digest of the remaining peptides. Source names are `SUMOx-ExpN-LysC` and `SUMOx-ExpN-LysC+GluC` (20 sources); biological replicate = experiment number.
- Two cleavage-agent columns: Lys-C, and glutamyl endopeptidase (Glu-C). Lys-C-only rows carry `not applicable` in the second column. parse_sdrf accepted the repeated column.
- Factor value[treatment]: `MG132 and PR619` vs `heat shock` (from Readme + Methods).
- characteristics[genetic modification] (non-template extra): 6xHis-SUMO1 T95K or 6xHis-SUMO2 T90K.
- Cell line mpkDCT, Cellosaurus CVCL_R773 (looked up via Cellosaurus API).

## Caveats (flag for reviewer)

1. Instrument: the paper and PRIDE say Q Exactive and raw-header range reads confirm this for 31 files. The two SUMO2-Exp3 files (`071016_*_HCD_OT_Lei_2h_50cm.raw`, acquired 2016-10-07) have Orbitrap Fusion headers; those rows are annotated Orbitrap Fusion, collision energy `not available`. DDA and HCD are assumed for them.
2. Pairs of files with and without a `_<timestamp>` suffix (and LysC_KGG1/2 in SUMO1-Exp1) are treated as technical replicates 1 and 2 of the same pool. This is inferred from the Readme listing two files per experiment and enzyme; the order (1 = no timestamp) is arbitrary.
3. Modifications come from the PRIDE processing protocol (MaxQuant 2.0.1.0). mqpar.xml was not inspected (inside multi-GB archives). Tolerances 4.5 ppm / 20 ppm are MaxQuant defaults inferred from "all other parameters default".
4. Developmental stage, sex, strain, disease (not applicable, cell line), passage, culture medium: not stated, so `not available` / `not applicable`.
5. Build limitations: `sdrf-tools build` cannot emit a second cleavage column, so the second column was inserted by a deterministic post-processing step on the built file (the tables are the source otherwise).
6. `reconcile` reports one MAJOR `cleavage_agent_incomplete` (missing glutamyl endopeptidase). This is a tool limitation: it reads only the first of the two cleavage columns; 15 rows do carry Glu-C in the second column.
