## Limitations and calls to attack in review

- Digestion: Lys-C and trypsin (two comment[cleavage agent details] columns); an earlier draft dropped trypsin.
- HCD written as MS:1000422 (beam-type collision-induced dissociation), the spec-canonical term.
- Cells are HEK293T (CVCL_0063) stably overexpressing α-syn A53T-GFP, as the PRIDE record states; the cellosaurus accession is that of the parental line because the derivative has no Cellosaurus entry.
- Inhibitor concentration for the proteomics samples is not stated — no dose column; exposure duration 48 hour is from PRIDE.
- GF109203X has no ChEBI/NCIT label in the offline cache (validator warning).
- HeLa.raw is a QC digest identified only by file name; annotated as HeLa (CVCL_0030) — HeLa S3 cannot be excluded.
- Search modifications from paper/PRIDE text; the 12 GB PD .msf files were not read.
