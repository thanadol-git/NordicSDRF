# PXD028930 — annotation blocked

## Dataset

- **Title:** Proteomic Analysis on Paraffine-Archived Melanoma
- **PRIDE record:** PXD028930
- **Publication:** Szadai L. et al., Cancers 2021, DOI [10.3390/cancers13236105](https://doi.org/10.3390/cancers13236105), PMCID [PMC8657028](https://pmc.ncbi.nlm.nih.gov/articles/PMC8657028/)

## Evidence recovered

- 93 RAW files named by internal pathology numbers (e.g. `20210409_133A319_R1.raw`); RAW headers say Q Exactive HF-X (PRIDE lists LTQ Orbitrap).
- The deposited `File_number_in_PD_and_raw_file_names.xlsx` maps each RAW file only to a Proteome Discoverer file number (F1…F101).
- The deposited PD exports use `Abundance: Fn: Sample` columns with no study factors.
- The paper describes 90 FFPE samples from 77 patients (53 primary, 37 metastases: lymph node / cutaneous; 8 primary–metastasis pairs). Supplementary Document S1 lists per-sample QC by 'Pilot-N' IDs, again without RAW names or sample type.

## Why no SDRF was emitted

No deposited or published table says which RAW file is a primary tumour or a metastasis, which patient it comes from, or which files are re-injections (93 files for 90 samples). The primary-versus-metastasis and pairing design therefore cannot be annotated per row.

## Unblocking requirement

A table mapping each RAW file (or PD file number / Pilot-N ID) to patient, sample type (primary, lymph node or cutaneous metastasis) and, for repeated runs, which injection was used.
