## Design and file mapping

Immunodeficient mice were treated with bortezomib (BTZ), temozolomide (TMZ), both, or nothing. Most carried intracranial human glioblastoma (GBM) spheroid xenografts; two groups had no tumour. Plasma was collected at sacrifice and analysed by label-free LC-MS/MS (Supplementary Fig. 1E–G). The paper reports doses as human-equivalent doses: mouse TMZ 25 mg/kg = 82 (main text: 84) mg/m², TMZ 50 mg/kg = 164 mg/m², BTZ 0.5 mg/kg = 1.3 mg/m². The SDRF uses the mouse doses actually given.

- **How the mapping was established: from a deposited table.** `txt/summary.txt` inside the deposited `MaxQuantResults_txt.7z` assigns every raw file to a MaxQuant experiment named `<group> <cage><animal>`, e.g. `10_C6A1ny` → `TMZ 50 C6A1`. All 25 raw files are claimed exactly once. The animal code in each experiment name matches the code in the file name. The 7z was checked against PRIDE's SHA-1 (`8298e66c…850b`).
- **Group label → treatment and tumour status** is an interpretation of the MaxQuant labels against the paper. "TMZ 25/50" match the mouse doses 25/50 mg/kg in the paper's Drugs section; "BTZ" is the only BTZ dose used (0.5 mg/kg). "T" marks tumour-bearing animals, so "CTR"/"BTZ" without "T" are the non-tumour-bearing groups. This gives exactly the eight groups in the Supplementary Fig. 1F legend. The TMZ arms are tumour-bearing ("+T") per that legend.
- Source names are `mouse <cage><animal>` (e.g. `mouse C6A1`), taken from the MaxQuant experiment names. `characteristics[biological replicate]` is the animal's index within its group. `assay name` is the raw file stem.
- Factors: `factor value[treatment]` (drug regimen) and `factor value[disease]` (tumour-bearing vs not). Supplementary Fig. 1F/G compares LFQ intensities across these eight groups.

## Technical values and sources

- **Instrument: `NT=Orbitrap Elite;AC=MS:1001910`, from the raw files.** The instrument-ID block of all 25 `.raw` files (read by HTTP range request) says model "Orbitrap Elite", serial 04000B, software 2.7.0 SP1. Every embedded method is `05b_TOP12CID_240K_..._Preview.meth` (instrument "Orbitrap Elite MS", tune file `Elite_nano`), and the data folder is `2017-06-13_OrbitrapElite_Plasma-mus`. The paper and PRIDE protocol say "LTQ-Orbitrap Velos Pro", and PRIDE's structured field says "LTQ Orbitrap Velos" (MS:1001742). The only "Orbitrap Velos Pro" strings in the files are in the method's audit trail, so the raw data overrides both. `sdrf-tools reconcile` flags this as `instrument_contradicted` (MAJOR); it is kept deliberately.
- From the raw method header: data-dependent acquisition (PRIDE:0000627) with top-12 MS/MS; CID (MS:1000133) in the linear ion trap (ITMS; MS:1000083); 35 NCE; FTMS MS1 300–2000 m/z. Runs were acquired 13–19 June 2017.
- Cleavage agent: `Trypsin` (MS:1001251), the wet-lab digest ("modified porcine trypsin V5111, Promega"). MaxQuant searched with `Trypsin/P`, specific, with 2 missed cleavages (`summary.txt`). An earlier build used `Trypsin/P`, which the reconciler flagged as a BLOCKER against the record's "trypsin", so it was switched to the enzyme actually used.
- Modifications come from the deposited search: `parameters.txt` gives fixed Carbamidomethyl (C, UNIMOD:4), and `summary.txt` gives variable Acetyl (Protein N-term, UNIMOD:1) and Oxidation (M, UNIMOD:35). These agree with the PRIDE protocol.
- Fragment mass tolerance: 0.5 Da. This is MaxQuant's ITMS MS/MS tolerance from `parameters.txt`; MS2 was acquired in the ion trap.

## Limitations

- **Treatment encoding:** `characteristics[treatment]` is free text with mouse doses, because no NCIT/EFO term covers a dosed combination regimen. That is the source of the 7 validator warnings.
- **Schedules are not encoded.** BTZ was given i.p. on days 1, 4, 8 and 11 for two cycles; TMZ by oral gavage 5 days/week for 5 weeks. Sacrifice timing differs between groups (non-tumour BTZ mice were killed 2 days after the last dose; tumour-bearing mice at humane endpoints or study end), so `sampling time` is not given.
- **Tumour status** (`characteristics[disease]` = `glioblastoma` / `normal`) is inferred from the "T" in the MaxQuant group names together with the Supplementary Fig. 1F legend (−T / +T groups). The "glioblastoma" label describes a human GBM xenograft in the host mouse; the plasma itself is mouse.
- **Xenograft line not annotated.** The paper used P3 (MGMT-unmethylated) and BG7 (methylated) xenografts. The 82 mg/m² arms exist only in the P3 study, but the paper does not say which line each plasma donor carried. No `xenograft` column was added; per the spec, that column would describe the patient tumour.
- **Sex:** `not available` for all rows. The paper says both sexes were used but gives no per-animal sex.
- **Developmental stage:** `adult` for tumour-bearing mice is cohort-level inference: they were implanted at 7 weeks and sampled weeks later. It is `not available` for the non-tumour-bearing mice (CTR, BTZ), whose age is not stated.
- **Strain:** `NOD-SCID` for tumour-bearing mice, as the paper names the xenograft hosts ("NOD-SCID mice (C.B.-Igh-1b/lcrTac-Prkdc)", Janvier Labs). That nomenclature is ambiguous between NOD-SCID and CB17-SCID, so the paper's own label was used. It is `not available` for the non-tumour mice, whose strain is not stated explicitly.
- **Cell type:** `not applicable` (cell-free plasma).
- **Precursor mass tolerance:** `not available`. The PRIDE protocol says "MaxQuant's default settings", and the deposited `parameters.txt` (MaxQuant 1.5.1.2) does not record the main-search tolerance. The default (4.5 ppm after recalibration) was not assumed.
- **Software version mismatch, not encoded:** PRIDE and the paper say MaxQuant 1.5.2.8; the deposited `parameters.txt` says 1.5.1.2 (written 22 June 2017). The FASTA was mouse reviewed canonical+isoforms (2016-01-06).
- **Reduction/alkylation reagents** are not described (only urea denaturation and trypsin digestion), so those columns are omitted. The fixed carbamidomethyl search implies alkylation.
- **Heat map vs deposit:** Supplementary Fig. 1E shows 19 animals in six groups (Control, BTZ, TMZ 82, TMZ 164, BTZ+TMZ 82, BTZ+TMZ 164). The deposit and MaxQuant search hold 25 runs in eight groups. All 25 deposited runs are annotated as the MaxQuant table assigns them.
- The `ny` suffix on four file names (`1_C15A1ny`, `4_C2A1ny`, `7_C1A1ny`, `10_C6A1ny`) is not explained. Each animal has exactly one deposited run, and MaxQuant used those files.
