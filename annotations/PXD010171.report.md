## Design

There are 3 extraction methods × 2 subcellular fractions × 3 biological replicates, giving 18 runs with one raw file each. There are no peptide fractions and no technical replicates.

| extraction method | membrane fraction | cytosolic fraction |
|---|---|---|
| ProteoExtract kit (Calbiochem) | 3 | 3 |
| ProteoPrep kit (Sigma) | 3 | 3 |
| conventional laboratory method | 3 | 3 |

The run names encode the design directly (`<Method><MF|CF><replicate>raw.raw`). All 18 RAW files are mapped exactly once. The MGF peak lists and PD `.msf` search files are not listed as data files.

The factor values are `factor value[protein extraction method]` and `factor value[subcellular fraction]`, each mirroring a characteristics column with the same name. Both are free-text extensions, following the spec's PXD005969 example for extraction methods. No exact ontology term exists for "membrane fraction" or for the kit-based extraction methods.

`source name` is `<Method>_<MF|CF>_<replicate>`. The record does not say whether the MF and CF with the same replicate number came from the same parasite culture, so each is treated as its own source.

## Omitted or uncertain (please review)

- **`comment[dissociation method]` and `comment[collision energy]` are omitted.** Every run acquires two ion-trap MS2 scans per precursor: HCD at 28% NCE and CID at 30% NCE. The PD search did not filter by activation type. Both columns are single-valued in ms-proteomics v1.1.0. A single value (`build` would have kept only HCD) would misdescribe half the spectra, so the columns were left out. The protocol text confirms both: "fragmented by CID and HCD at a normalised collision energy of 30% and 28%".
- **`characteristics[cell type]` = `not available`.** Axenic HM-1:IMSS cultures are normally trophozoites (BTO:0001397), but no available source states it. Fill this in if the full paper confirms it.
- **Acquisition batches (reviewer finding, minor).** Membrane-fraction replicates 1–2 of all three methods were acquired in April and June 2017. All cytosolic runs and membrane replicate 3 were acquired between 2018-02-21 and 2018-03-05 (raw header timestamps). The subcellular-fraction factor is therefore partly confounded with acquisition batch. Optional `comment[acquisition date]` / `comment[lc batch]` columns were not added; consider adding them before contributing.
- The paper's full Methods were not available. All sample-level values come from the PRIDE record, the run names and the deposited files.
