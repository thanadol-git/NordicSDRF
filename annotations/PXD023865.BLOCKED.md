# PXD023865 - BLOCKED (no defensible TMT channel-to-sample map)

Study: Radzisheuskaya et al., Mol Cell 2021 (PMID 33657400), "[TMT11plex whole proteome analysis]" of THP-1 (leukemia) cells after CRISPRi knockdown. Deposit: 33 RAW files (30 high-pH fractions plus `fr1_test`, `fr2_test`, `br`), one `.pdResult`, one `.pep.xml`, one FASTA (PRIDE v2 files endpoint, 36 files, pages 0-1; page 1 empty).

## What is missing
One TMT 11-plex set (channels 126, 127N, 127C, 128N, 128C, 129N, 129C, 130N, 130C, 131N, 131C). Which channel holds which sample is not stated anywhere I could reach:

- **Paper (PMC8056186, full text via NCBI efetch; EPMC full text is not open access):** only the group sizes: "3 replicates of the cells transduced with NegCtrl sgRNA, 3 replicates with sgRNAs against KANSL2 and KAT8 and 2 replicates with the sgRNA against KANSL3, total 11 samples". The sentence is ambiguous (3 KANSL2 + 3 KAT8 would be 12, so the split between KANSL2 and KAT8 is unclear), and no channel assignment is given. Supplementary Table S2 is not reachable (article not open access in EPMC; supplementary endpoint refused).
- **Deposited `.pdResult` StudyDefinition (SQLite, first 30 MB read by HTTP range):** samples are only named `<fileset> - [126]` ... `[131C]`; channel 126 is typed "Control", the rest "Sample"; no factors, no condition names.
- **Deposited `.pep.xml`:** workflow text only (Mascot, Static: Carbamidomethyl C, TMT6plex N-term and K; dynamic: Oxidation M; TMT 11plex; MS3 HCD reporter quantification); no sample names.
- PRIDE record (title/description/protocol): no channel map.

Writing any channel assignment (for instance "126-128 = NegCtrl") would be invention, so no SDRF was built.

## Second unresolved item: fraction map
The deposited file names carry `frN` tokens (fr1..fr30, with 02081 absent), but the `.pdResult` StudyDefinition assigns FractionNumber 1..33 in file order, treating `fr1_test`, `fr2_test` and `br` as extra fractions. The two numberings disagree and no deposited document says that the `_test` files are repeat injections of fr1/fr2 or what `br` is. A required-integer fraction identifier cannot be taken from either without guesswork.

## What would unblock it
The channel-to-sample table for this TMT11 run (paper Table S2 / supplementary methods, or from the authors), plus the meaning of the `_test` and `br` files.

## Other findings for a future annotator (verified, not applied)
- Cell line used in the knockdown experiments: THP-1 (CVCL_0006, male) per the paper; PRIDE structured organism part "Blood" and disease "acute leukemia" are plausible for THP-1 but not stated in the deposit.
- Instrument Orbitrap Fusion Lumos (PRIDE, paper); MS3 SPS reporter quantification, HCD; RAW headers not read because the study is blocked.
- Search: PD 2.2/2.3 Mascot, trypsin, 2 missed cleavages, 10 ppm / 0.6 Da, fixed Carbamidomethyl (C), TMT6plex (K, N-term), variable Oxidation (M) (the PRIDE protocol also lists Deamidation NQ; the PD workflow in the pep.xml does not).
