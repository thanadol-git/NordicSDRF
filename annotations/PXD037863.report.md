# PXD037863 annotation report

*Rhytidoponera metallica* (ant) venom, analysed top-down and bottom-up. The lab is Queensland, with an NTNU co-author. Paper: BMC Biology 2023, PMC9827630. TripleTOF 5600, ProteinPilot. Not in the community corpus.

## Templates
`ms-proteomics` v1.1.0 and `invertebrates` v1.1.0.

## Rows and files
There are 7 rows, one per `.wiff`. All come from one venom pool (100 workers, one colony, UQ St Lucia). Rows differ by preparation, which is encoded as source name and `characteristics[treatment]` (the factor):
- `Rmet_Native`: intact venom, not reduced, not digested (top-down). Cleavage agent and modifications are `not applicable`.
- `Rmet_RA`: reduced and alkylated, not digested (top-down). Cleavage agent is `not applicable`.
- `Rmet_tryp`: reduced, alkylated and trypsin-digested.
- `RAtrp_28/36/48/90kDa`: four SDS-PAGE bands, reduced and alkylated in gel and digested with trypsin. These are fractions 1–4 with fractionation method SDS PAGE (PRIDE:0000568).

## Values
- **Sample:** sex is `female` (workers); developmental stage `adult`.
- **Reduction and alkylation:** gas-phase, with triethylphosphine and 2-iodoethanol. Neither reagent has a PRIDE term, so the reagent columns are omitted and this report records them.
- **Modification:** `Ethanolyl` C (UNIMOD:278) is declared Fixed on all alkylated rows. The deposited ProteinPilot peptide summaries confirm Ethanolyl(C) as the dominant cysteine modification.

## Validation
`parse_sdrf` passes for both templates; the only warnings are free-text treatment values. `tools reconcile` flags "cleavage agent not applicable but record names trypsin". That is expected: the Native and RA runs are undigested top-down samples, and the record's trypsin refers to the other runs.
