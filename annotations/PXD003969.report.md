## Study
Kempf SJ et al., *Chronic low-dose-rate ionising radiation affects the hippocampal phosphoproteome in the ApoE-/- Alzheimer's mouse model*, Oncotarget 2016 (PMC5342125, doi:10.18632/oncotarget.12376). Female ApoE-/- (B6.129P2-Apoe tm1Unc/J) mice, 8 weeks at start, 137Cs gamma irradiation at 0 / 1 mGy/day / 20 mGy/day for 300 days (0, 0.3, 6.0 Gy cumulative); whole hippocampus; TMT 9-plex; TiSH enrichment (TiO2-SIMAC-HILIC) into phospho / sialo-deglyco / unmodified pools; Proteome Discoverer 1.4 (Mascot + Sequest HT).

## Templates and why
- `ms-proteomics` (MS, DDA, TMT) + `vertebrates` (mouse). No `cell-lines`, `clinical-metadata` or `oncology-metadata`: tissue from model animals, no patients. No `dia-acquisition` (DDA).

## Scope: deposited vs annotated
- PRIDE `files/all`: 76 files (all `projectAccessions` = PXD003969): 70 RAW + 6 `.msf` search results. File list taken from the v3 API (not the truncating MCP tool).
- **All 70 RAW files annotated**, 9 TMT channels each = 630 rows. The six `.msf` are search outputs (not sample data files) and are not SDRF rows; they were used as evidence.
- Each `.msf` lists the RAW files searched together (FileInfos table, read by HTTP-range SQLite): phospho_glyco_A 16, phospho_glyco_B 17, unmodified_A 10, unmodified_B 11, unmodified_pH_A 8, unmodified_pH_B 8 = 70, covering every RAW exactly once. So the design is 2 TMT sets (A, B) x 3 peptide pools (PG = phospho/glyco enriched, HILIC fractions; UN = unmodified on Q Exactive HF; PH = unmodified, high-pH fractions, Orbitrap Fusion).

## Channel map (the critical point)
Stated in the paper Methods: TMT126/127N/127C = sham; 128N/128C/129N = 0.3 Gy (1 mGy/day); 129C/130N/130C = 6 Gy (20 mGy/day); six biological replicates per condition. Same layout applied to sets A and B (the paper gives one layout for the study; no per-set exception is mentioned). Not applied from any deposited PD study file (not read).

## Key decisions
- **Sources**: `<cond>_rep<N>_<pool>` (e.g. `sham_rep1_PG`). Replicates 1-3 = set A, 4-6 = set B. INFERRED: six replicates over two 3-per-condition sets; which animal is which number is labelling only. The pool suffix is a structural device: PG/UN/PH are separately processed peptide pools from the same labelled sets, and sharing one source name would collide on the (source, replicate, technical replicate, fraction) coordinate. The same animals underlie all three pools of a set.
- **Fractions**: `comment[fraction identifier]` = order of the file in the msf FileInfos (acquisition order). Within the PG msf the files include several HILIC series (mono-phospho, multi-phospho, deglyco pools); the deposit does not say which file belongs to which sub-pool, so fraction numbers across such pools are positional only.
- **Instrument**: from raw headers: QHF* = Q Exactive HF (MS:1002523); FUS* = Orbitrap Fusion (MS:1002416). PRIDE lists both, consistent with paper (Fusion only for high-pH unmodified).
- **Modifications** (from deposited .msf, set A read; set B assumed identical): Carbamidomethyl C fixed; TMT6plex (UNIMOD:737) K and any N-term fixed (the 9-plex uses the TMT6/10 mass 229.163, search method "TMT 6plex"); Phospho STY and Deamidated N variable in the PG pool only. UN and PH pools were searched without dynamic modifications, written `not applicable` to keep the repeated-column count equal.
- **Tolerances** 10 ppm / 0.02 Da; trypsin; DDA; HCD (paper: HCD).
- **Fractionation method**: HILIC (PRIDE:0000554) for PG; high-pH RP (PRIDE:0000564) for PH; `not available` for UN (paper does not describe how the unmodified QHF pool was fractionated).
- **Factor**: `factor value[treatment]` = radiation arm, mirrors `characteristics[treatment]`.

## Values left as sentinels
- `characteristics[disease]` = `not available`: PRIDE says Alzheimer's disease, but every arm (including sham) is the ApoE-/- model; per-animal disease status is not reported. Judgement call for the reviewer (alternative: `Alzheimer disease` on all rows).
- `comment[fractionation method]` = `not available` for UN pool.
- Not annotated (not licensed or unsupported): age (only 8 weeks at start; sacrifice age not stated), collision energy (34 V stated, unit ambiguous), cell type.

## Stated vs inferred
Stated: organism, sex, strain, tissue, treatment arms, channel map, instruments (paper+raw), modifications/tolerances (msf), HILIC / high-pH fractionation. Inferred: `adult` (age ~1 year at sacrifice), replicate numbering across sets, set B parameters = set A, fraction order = msf order.

## Conflicts
PRIDE modifications listed `TMT6plex-126` MOD term; paper says TMT9-plex; resolved with UNIMOD:737 as in the .msf (same mass for 6/9/10-plex). PRIDE `submissionType` PARTIAL; no conflict in instruments.
