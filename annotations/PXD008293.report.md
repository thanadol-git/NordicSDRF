# PXD008293 annotation report

SILAC proteome of Jurkat (T-ALL) and SU-DHL-5 (DLBCL) cells treated with the HDAC inhibitor SAHA. Slupphaug lab, NTNU. Paper: J Transl Med 2020, PMC7137348 (open access).

## Templates
`ms-proteomics` v1.1.0, `human` v1.1.0 and `cell-lines` v1.1.0.

## Rows and files
There are 28 rows: 14 raw files × 2 channels.
- **Channel orientation** is stated in the paper (Fig. 1a: "log2 heavy (control)/light (SAHA)"):
  - Heavy (Lys8/Arg10) = DMSO vehicle.
  - Light = SAHA 2 µM for 24 h.
- **Replicates:** the deposited MaxQuant `Groups.txt` assigns the 150820 `TECH4–6` runs to biological replicate 1 (technical 4–6, numbering kept) and the 151124 runs to Biol2/Biol3 (tech 1–2).

## Values
- **Cell lines:**
  - Jurkat (CVCL_0065): male, 14Y, blood, T cell, `T-cell acute lymphoblastic leukemia`.
  - SU-DHL-5 (CVCL_1735): female, 17Y, lymph node, B cell, `diffuse large B-cell lymphoma`.
- **Instrument:** Q Exactive, from the raw header; HCD at 30 NCE.
- **Sample prep:** DTT and iodoacetamide, trypsin (paper).
- **Search** (deposited `mqpar.xml`/`summary.txt`, multiplicity 2 with Arg10;Lys8):
  - Carbamidomethyl C fixed.
  - Oxidation M, Acetyl protein N-term and Deamidation NQ variable.
  - Main search 4.5 ppm; FTMS MS/MS 20 ppm.

## Validation
- `parse_sdrf` (CI style) and the review gate pass.
- `tools reconcile` raises three false positives:
  - It claims the record names only mouse. The record's organism is human; the description mentions a mouse line, CH12F3, used only for western blots.
  - It flags cell-line names in the run names.
  - It flags trypsin.
