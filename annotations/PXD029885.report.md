# PXD029885 evidence status

The 34 deposited RAW files mix intact O-glycodomain mass analysis and bottom-up glycopeptide analyses across multiple mucin reporters, HEK293 glycoengineered cell states, native ovine submaxillary mucin, instruments, and cleavage workflows (Lys-C, trypsin, Glu-C, Asp-N, StcE, BT4244). A single homogeneous SDRF would incorrectly broadcast instrument, digestion, and organism values. The deposited `Supporting_File_1.xlsx` tabulates deconvoluted masses and figure data; it does not supply a unified run-to-sample design table.

**Evidence blocked / not yet annotated.** The run names identify some reporters and enzymes, but they do not consistently identify the reporter source, exact glycoengineered cell state, treatment, and workflow for all 34 runs. Neither the deposited workbook nor the paper provides a complete RAW-to-sample design map. Splitting by method would prevent broadcasting technical values but would not resolve those source assignments. None of the 34 runs has been marked approved. A submitter run manifest with RAW name, reporter, biological source, glycoform/cell state, treatment, and acquisition workflow is needed.

Sources: [PRIDE project](https://www.ebi.ac.uk/pride/archive/projects/PXD029885), [published paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC8980628/), deposited `Supporting_File_1.xlsx` (local copy in `scratchpad/PXD029885/`).
