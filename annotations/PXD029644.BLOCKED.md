# PXD029644 — outside current proteomics SDRF scope

The [PRIDE record](https://www.ebi.ac.uk/pride/archive/projects/PXD029644) identifies this as released O-glycan profiling of human cells. Its sample protocol immobilizes proteins, releases O-glycans by non-reductive beta-elimination, labels the glycans with 2-aminobenzamide, and analyzes them by C18 nanoLC-MS/MS. The data-processing protocol assigns glycan compositions using GlycoWorkbench and Skyline's Molecule Interface. The [paper](https://doi.org/10.1021/acs.analchem.1c05068) likewise describes O-glycan isomer profiling. The accession has 71 deposited `.raw` files and one `SEARCH.dat` file, but these acquisitions measure released glycans rather than digested peptides or proteins.

The installed SDRF template set has `ms-proteomics` and related protein/peptide templates, but no glycomics template. Applying `ms-proteomics` would misstate the measured analyte and force peptide-search metadata that is not applicable. No proteomics SDRF was produced or reviewed. This accession needs a suitable glycomics metadata schema or an explicit repository decision to annotate glycomics separately.
