# PXD003550 annotation report

Status: validated annotation; independent review pending.

## Result

72-row, 32-column SDRF (templates `ms-proteomics` v1.1.0 + `human` v1.1.0). Human adipose-derived stem cells (Aalborg University; Riis et al., Stem Cell Res Ther 2016, PMID 27075204), label-free DDA on a Q Exactive Plus. Design: 3 donors x 2 oxygen conditions (20% vs 1% O2, 24 h) x 3 compartments (cell-lysate proteome, secretome >30 kDa, peptidome 3-30 kDa) x 4 biological replicates, one RAW file each. Factor: `factor value[oxygen level]`.

Not previously annotated (no PXD003550 directory in sdrf-annotated-datasets; no earlier file in annotations/).

## File mapping (from the three deposited MaxQuant summary.txt files)

- `P<g>_<r>.raw` proteome, `TF<g><r>.raw` secretome, `<g>_<r>.raw` peptidome; g = group 1-6, r = replicate 1-4.
- 72 RAW files, each claimed once; the 3 MaxQuant zips are not data files.

## Inferred values (not stated in the deposit) - please review

- **Group to condition and donor.** The deposit does not say what groups 1-6 are. From proteome proteinGroups LFQ intensities, hypoxia-responsive proteins (LDHA, PGK1, ENO1, SLC2A1, BNIP3L, PLOD2, HK2, LOX, P4HA1/2) are higher in groups 2, 4, 6, so odd = normoxia and even = hypoxia. Donors were taken as pairs (1,2), (3,4), (5,6). Mapping to ASC12/ASC21/ASC23 is unknown, so `characteristics[individual]` is donorA/B/C.
- **Sex.** RPS4Y1/DDX3Y are detected only in groups 3-4, so donorB is `male`. Other donors are `not available` (absence of Y proteins does not prove female).
- **Biological replicate** = file-name suffix 1-4.
- Secretome/peptidome/proteome of the same group and replicate may or may not come from the same culture flask; they are separate sources.

## Caveats

- `characteristics[cell compartment]` is a non-template custom column.
- Precursor tolerance is not in the deposited parameters.txt (`not available`); fragment 20 ppm (FTMS). Alkylation reagent (chloroacetamide) has no suitable PRIDE/MS term; left `not available` while Carbamidomethyl (C) is recorded.
- Modifications are constant across rows: Carbamidomethyl (C) fixed, Oxidation (M) variable. The peptidome search also had a Deamidation (NQ) site table (so deamidation was probably searched there) and proteome quantification listed Acetyl (Protein N-term); neither is stated as a search modification, so not recorded.
- Single enzyme (trypsin); no Lys-C step, so one cleavage-agent column.
- Disease, age, ancestry: not available (no donor information beyond ethics statement). Developmental stage omitted.
- The 1D SDS-PAGE short-gel (proteome) and MWCO filtration (secretome/peptidome) steps are not encoded as fractions; each sample is one injection (fraction 1).
- No RAW files downloaded; only HTTP range reads of zip members.
