## Limitations

- KEY GAP: the deposit and paper give no mapping of RAW files (numbered 1-163) to donor, disease group (RRMS vs healthy control) or condition (unstimulated vs anti-CD3/CD28). Raw headers (folder 2020-04-23_QExHF_P19-73-80-83, same method for all) contain no sample names. So disease, treatment and age are `not available`; no factor value column was added because values cannot be assigned. A mapping from the submitters would allow filling disease, treatment, age and a factor value.
- Sex female for all rows: MS patients are all female and controls are stated as sex-matched (inferred for controls).
- Source name `sample N` is the file number; files with a/b suffix and 102_Extra are treated as technical replicates 1/2 of the same sample (88-8 = 80 = 40 donors x 2 conditions); this is inference from names.
- Two LC method variants (1 mm vs 2 mm spray-head, IT5e4, 195 min) appear in RAW headers; not recorded as columns.
- Modifications/tolerances read from the protocol text only; PD result files not inspected. Ancestry (self-declared Nordic) not encoded.
- Peak file 1-_2_.mzML and Identification_PD24.mzid.gz not annotated as data files.
