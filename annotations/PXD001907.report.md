# PXD001907 annotation report

**Study:** SuperQuant: a Data Processing Approach to Increase Quantitative Proteome Coverage (Gorshkov, Verano-Braga, Kjeldsen; Anal Chem 2015, PMID 25978296). Dimethyl-labelled (3-plex) HeLa digest, mixed 10:4:1, on Orbitrap Fusion with 1/2/4 Th isolation windows, Orbitrap or ion-trap MS/MS, each in triplicate.

**Outcome:** ANNOTATED, 36 rows x 43 columns, validated with `parse_sdrf validate-sdrf -t ms-proteomics -t human -t cell-lines` ("Everything seems to be fine"). Not independently reviewed (see Caveats).

## Templates
`ms-proteomics` v1.1.0 + `human` + `cell-lines` (HeLa cell line, human). Not `dia-acquisition` (DDA), not `clinical-metadata`/`oncology-metadata` (technical benchmark, no patients).

## Scope (deposited vs annotated)
76 PRIDE entries: 12 RAW (OT-1Da1-3, OT-2Da1-3, OT-4Da1-3, IT-2Da1-3), the rest pdResult/mgf/export derivatives, plus the `c` (SuperQuant-processed) variants which re-process the same RAW files. All 12 RAW files annotated x 3 dimethyl channels = 36 rows. Peak lists and search results are not listed as data files. No annotatable run excluded.

## Key decisions
- **Channel map:** every channel is the same HeLa lysate labelled differently, so sample identity is unambiguous; channels are separate sources `HeLa_dimethyl_light/medium/heavy` with channel-specific dimethyl mods per row.
  - Light = C2H4 (UNIMOD:36); medium = C2D4 (Dimethyl:2H(4), UNIMOD:199); heavy = 13C2D6 (Dimethyl:2H(6)13C(2), UNIMOD:330, +8, verified in OLS; not UNIMOD:510, which is +6). Confirmed against PD PSM export (Dimethyl, Dimethyl:2H(4), Dimethyl:2H(6)13C(2), Carbamidomethyl, Oxidation).
  - `comment[label]` is `Dimethyl Labeling` (PRIDE:0000513) for all rows, since no per-channel dimethyl label term exists in the contract; the channel is encoded in the source name, assay name and modification columns.
- **Built by script, not `sdrf-tools build`:** `sdrf-tools` is not installed here and `build` refuses several sources claiming one non-channel-label file. Rows were generated by `scratchpad/PXD001907/gen_PXD001907.py` (plain TSV writer, repeated headers kept).
- **Technical replicate** = running injection index 1-12 per source (each RAW is its own injection of the same mix; conditions are not replicates of each other, and the coordinate must be unique). Biological replicate = 1 (single HeLa digest).
- **Factors:** `factor value[isolation window]` (1/2/4 Th) and `factor value[ms2 mass analyzer]` (orbitrap vs ion trap): the compared variables. The label ratio is fixed, not a factor.
- **Tolerances:** precursor 5 ppm; fragment 0.02 Da (OT files), 0.5 Da (IT files), per PRIDE data processing text.
- **Instrument:** Orbitrap Fusion, confirmed in RAW headers of one OT and one IT file.

## Conflicts
- PRIDE `diseases` = "disease free" is wrong for HeLa; used `cervical adenocarcinoma` (MONDO:0005153, Cellosaurus: HPV-related cervical adenocarcinoma).
- Label ratio: PRIDE abstract says 10 heavy : 4 medium : 1 light, the sample protocol says 10:4:1 light:medium:heavy. Unresolved; the SDRF does not encode the ratio.
- PRIDE lists MaxQuant among software; the deposited search is Proteome Discoverer 2.0/Mascot.

## Inferred vs stated
- Stated: organism, HeLa, dimethyl 3-plex, instrument, CID, tolerances, file naming.
- Inferred: **Trypsin** (enzyme not named anywhere in the record; 99.8% of PSM C-termini are K/R; `reconcile` raises `cleavage_agent_unsupported` for this reason; the contract forbids `not available` here). Age 30Y6M, female, organ part uterine cervix, cell type epithelial cell: Cellosaurus HeLa donor values, not from the paper. HeLa = parental `CVCL_0030`; no sub-clone is stated.
- `not available`: ancestry category, individual, passage number, culture medium, storage temperature, reduction and alkylation reagent (Carbamidomethyl is in the search as Fixed, reagent unstated, so not `not applicable`).

## Caveats for the reviewer to attack
1. Trypsin inference. 2. Channel label encoding (single PRIDE:0000513 label, channel in mods and source). 3. Treating RAW replicates as technical replicates numbered 1-12. 4. Cellosaurus-derived age/sex. 5. Paper full text was not retrieved; the Methods used are PRIDE's protocol fields. 6. The independent adversarial review (SKILL Step 9.5) was not run; this annotation is a draft until reviewed. 7. `parse_sdrf` does not check column licensing or truth; `reconcile` run, one finding (above).
