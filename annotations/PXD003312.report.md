## Scope (deposited vs annotated)
105 RAW files deposited (+ 9 `.msf` search results, not annotated). All 105 are annotated, each x 8 iTRAQ channels = 840 rows. Every raw file was assigned to exactly one (replicate, enrichment class) by the msf `FileInfos` tables and the sample label in the raw header (QHF0272-0274 assigned by label `Neutral A1/A2/A3`; they are in no msf).

Design: one iTRAQ-8plex mixture per biological replicate (3), each holding 4 brain regions x 2 genotypes. The mixture was split by TiSH enrichment into 5 peptide classes (Multi P: 3 files; Mono P: 32; Neutral: 3; Glyco, deglycosylated: 36; Unmod flow-through: 31). Each class x replicate is a separate fractionation series, so source names include the class (`hippocampus_APPPS1_rep2_monoP`, 24 samples x 5 classes = 120 sources). Fractions are numbered within a class series by file order.

## Key decisions (stated vs inferred)
- Channel map: stated in paper Methods (113 hippo WT, 114 hippo AD, 115 ctx WT, 116 ctx AD, 117 OB WT, 118 OB AD, 119 BS WT, 121 BS AD). Labels written as `NT=ITRAQ113;AC=PRIDE:0000531` ... `ITRAQ121 PRIDE:0000538` (build emitted bare iTRAQ113; replaced by a deterministic column substitution after build).
- Instrument: raw headers say Q Exactive HF; PRIDE field says Q Exactive; raw/paper win.
- Modifications read from the deposited PD `.msf` (Mascot and Sequest HT nodes, identical in all 9): Carbamidomethyl C fixed; iTRAQ8plex K and N-term fixed; iTRAQ8plex Y variable (Mascot node only); Phospho S/T/Y variable; Deamidated N variable. Trypsin, 1 missed cleavage, 10 ppm / 0.02 Da.
- Disease: AD mice `Alzheimer's disease`; wild-type littermates `normal`. Factors: disease and organism part.
- Organism part: hippocampus written as `hippocampal formation` (UBERON:0002421), others neocortex, olfactory bulb, brainstem.
- Sex male, strain given for transgenic only (stated: line 85, B6.Cg-Tg(APPswe, PSEN1dE9)85Dbo/Mmjax). WT strain `not available` (paper says only "littermate wild-type").
- Developmental stage `adult`: INFERRED from age 12 months (stated), not stated as a stage.
- Enrichment process: Multi P and Mono P `enrichment of phosphorylated protein` (closest allowed term; the peptide-level TiO2/SIMAC); Glyco `enrichment of glycopeptides`; Unmod `not applicable` (TiO2 flow-through); Neutral `not available` (fraction not described in paper).
- Fractionation method: HILIC (PRIDE:0000554) for Mono P, Glyco, Unmod (paper); Multi P `not applicable` (not HILIC-fractionated per Methods); Neutral `not available`.
- Cell type `not available` (bulk tissue; mixed cells).

## Conflicts and caveats for the reviewer
1. `QHF0266_150403205520.raw` is a re-injection of the same HILIC fraction as `QHF0266.raw` (same label `Mono P A3 G4`, both in Phospho3.msf). To keep the row coordinate unique it was inserted as its own fraction position in rep 3 Mono P, shifting later fraction numbers by one; strictly it is a technical replicate of that fraction.
2. Replicate to mouse identity is not stated (6 mice, 3 per group); replicate 1-3 follows raw labels A1/A2/A3 and msf names 1/2/3.
3. The "Neutral" runs (QHF0272-0274, 134 min gradient like Multi P) are an undocumented fraction; QHF0274 is only 38 KB (truncated deposit). Row kept but class assignment rests on the raw label alone.
4. Phospho is written `TA=S,T,Y`; other corpus files use `TA=STY`. iTRAQ8plex Y variable comes from the Mascot node only.
5. Enrichment process uses the closest listed term for phosphopeptides (list names "phosphorylated protein").
6. `reconcile` BLOCKER cleavage_agent_unsupported: PRIDE fields never name trypsin; it is stated in the paper (Lys-C then trypsin) and both PD search nodes. Only Trypsin is recorded (single column); Lys-C pre-digest is not.
7. Validator warnings: `enrichment of glycopeptides` not found in OLS lists (it is in the spec's allowed list) and the strain string is not an NCBITaxon term (free text column).
8. Raw files for the 9 msf search outputs were not annotated; the MS-run identity of PXD003312 as PARTIAL submission means mRNA/miRNA qPCR and imaging data are not in this deposit.
