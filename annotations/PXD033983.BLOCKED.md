# PXD033983 — blocked SDRF annotation

## Evidence checked

- PRIDE: https://www.ebi.ac.uk/pride/archive/projects/PXD033983
- Publication: DOI `10.3389/fimmu.2023.1190018`; PMCID `PMC10239926`
- Deposited `search.csv`, project metadata, and complete file inventory

The publication establishes the study design: healthy-donor monocytes were polarized using pooled juvenile idiopathic arthritis synovial fluid. The 24 deposited RAW filenames are anonymous, and neither the publication nor deposited metadata maps those filenames to condition, donor, or replicate.

## Exact blocker

There is no evidence-backed RAW-file-to-sample crosswalk. Assigning condition or donor from file order would be unsupported, so no SDRF was written.

## Evidence that would unblock the accession

A sample manifest listing each RAW filename with polarization condition, donor or pool identity, biological replicate, and any technical replicate.
