# PXD033115 — blocked SDRF annotation

## Evidence checked

- PRIDE: https://www.ebi.ac.uk/pride/archive/projects/PXD033115
- Publication: DOI `10.1016/j.redox.2022.102343`; PMCID `PMC9157258`
- Deposited MaxQuant archive, including the summary and parameter files
- Deposited file inventory and project metadata

The evidence establishes an H9 human embryonic stem-cell redox experiment using sequential iodoTMT reporter-ion MS3 acquisition. It does not provide the reporter-channel assignment needed to connect thiol state/sample identity to each iodoTMT channel.

## Exact blocker

The reporter channels cannot be assigned to the biological samples and thiol states without inventing a channel map. Because that mapping is fundamental to every multiplexed row, no SDRF was written.

## Evidence that would unblock the accession

A submitter design table or instrument-method/sample manifest listing, for each acquisition, the iodoTMT reporter channel, sample identity, replicate, and thiol/redox state.
