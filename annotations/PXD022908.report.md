## Design

Each RAW file is a 1:1 mix of 100 ug light sample lysate and 100 ug heavy-SILAC (Arg10/Lys6) lysate of the same cell line; so two rows per file (SILAC light = the sample, SILAC heavy = reference cells). Factor value is treatment (dimethyl sulfoxide vs G007-LK). Heavy rows carry treatment/time `not available`.

## Limitations and caveats

- Experiment-to-cell-line mapping (S1 COLO 320DM, S2 ABC-1, S3 UO-31, S4 OVCAR-4, S8 RKO) and the order .1,.2 = DMSO, .3,.4 = G007-LK come from column positions in the authors' R script (github MartinFStrand/TNKSiRes), not from an explicit sample key in PRIDE. Needs author or reviewer confirmation.
- Experiments S5, S6, S7, S9 (16 files, 32 rows) and the .W/.X/.Y/.Z runs of every set (24 files) are not described in the paper or PRIDE text. S5-S7/S9 cell line is a placeholder "unidentified cell line (set Sn)" with Cellosaurus fields `not available` (cell line column does not allow a reserved word); .W-.Z treatment/time are `not available` and biological replicate is set to 1 as a required-column filler. (Silacfull.txt hints that W-Z also contain treated samples, but it is not conclusive.)
- Age, sex, ancestry, individual left `not available` (not stated in the deposit). Culture medium, passage not captured (SILAC runs used RPMI SILAC medium; paper lists differing media for standard culture).
- Dissociation HCD inferred; alkylation not reported. Deposited search labels Arg10/Lys6 are recorded as Variable modifications on all rows (single MaxQuant search with SILAC multiplicity 2), including light rows.
- PRIDE processing text says MaxQuant 1.3.2.8, which looks wrong for this mqpar format; not captured.
- Project sample metadata lists disease terms for four lines; per-line disease taken from the paper (RKO colon carcinoma).
