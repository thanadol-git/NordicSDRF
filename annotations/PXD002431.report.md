## Templates and why

- **ms-proteomics v1.1.0:** Thermo LTQ Orbitrap Velos DDA LC-MS/MS runs.
- **vertebrates v1.1.0:** the samples are rat tissue. This template adds `characteristics[developmental stage]`, `characteristics[strain or breed]` and `characteristics[sex]`.
- **Not chosen:** dia-acquisition (the RAW method is Top10 HCD DDA), cell-lines (tissue, not cultured cells), clinical/oncology (no patients), immunopeptidomics (these are endogenous neuropeptides, not MHC-eluted peptides).

## Design and file mapping

- **Design:** a single-condition study. All 32 rats were treated the same way (perfused with isotonic saline plus protease inhibitors, brains dissected and heat-stabilised at 95 °C in a Denator T1 cartridge, hypothalami sub-dissected). The paper treats the 32 runs as biological replicates ("Biological replica had an overlap … of 68±4%").
- **Sources:** 32 sources, `rat hypothalamus S01` … `rat hypothalamus S32`, one per rat and one RAW file each. `characteristics[biological replicate]` = 1–32, the rat number.
- **Factor value:** none. There is no compared variable in this deposit, so no `factor value[...]` column was added (the prompt allows omitting it for a genuinely single-condition study). The validator did not object.
- **Source of the mapping:** the deposited MaxQuant `evidence.txt` (inside `evidence.zip`, 22 MB downloaded and summarised by script). Its `Raw File` column holds exactly the 32 deposited file stems, and each one is assigned to its own Experiment: file `…_S1` → `S01`, `…_S2` → `S02`, … `…_S32` → `S32`. That is a 1:1 file-to-experiment map with every experiment number equal to the file-name suffix. `Gel Slice` is 1 for all evidence rows, so there is no fractionation.
- **RAW headers:** the first 128 KB of `…_S1.raw`, `…_S17.raw` and `…_S32.raw` were range-read. All three say "LTQ Orbitrap Velos MS" (instrument name VELOS3), use the method `220min_Top10HCD_JESPER_Special.meth`, and give the original acquisition path `C:\Xcalibur\Data\20100805_Velos3_AnSe_Batch12faste_hypot_S<n>.raw`, identical to the deposited name. Files were not renamed.
- **Count check:** 32 rats in Methods ("In the main study, 32 rats were perfused…") = 32 RAW files = 32 MaxQuant experiments.

## Technical values and where they came from

- **Instrument:** `NT=LTQ Orbitrap Velos;AC=MS:1001742` — RAW headers, Methods and PRIDE all agree.
- **Acquisition:** DDA (`PRIDE:0000627`): RAW method "Top10HCD"; Methods "top10 higher-energy collisional dissociation (HCD) fragmentation method".
- **Dissociation:** HCD as `NT=beam-type collision-induced dissociation;AC=MS:1000422`. **Collision energy:** `40% NCE` (Methods). **MS2 analyzer:** orbitrap (`MS:1000484`; Methods: HCD-MS/MS recorded at resolution 7,500). **MS1 scan range:** `350m/z-1750m/z` (Methods).
- **Cleavage agent:** `not applicable`. These are endogenous peptides: tissue was sonicated in 8 M urea and passed through Microcon YM-30 cut-off filters, with no digestion step. The search used "no enzyme specificity". The `evidence.txt` peptide C-termini confirm this (L 82,275, A 38,144, F 29,610, V 28,757, Y 24,873 … K 13,521, R 15,112; no tryptic K/R bias). The spec README says to use `not applicable` for undigested samples.
- **Reduction / alkylation reagent:** `not applicable`. Methods describe no reduction or alkylation step, and the deposited search has no Carbamidomethyl (C) or any fixed modification.
- **Modifications:** all variable. Taken from the `evidence.txt` per-modification columns (`Phospho (STY)`, `Acetyl (Protein N-term)`, `Amidated (C-term)`, `Oxidation (M)`, `Gln->pyro-Glu (N-term Q)`) and the observed `Modifications` values; they agree exactly with Methods:
  - Acetyl, UNIMOD:1, Protein N-term
  - Oxidation, UNIMOD:35, M
  - Amidated, UNIMOD:2, Any C-term
  - Phospho, UNIMOD:21, S/T/Y
  - Gln->pyro-Glu, UNIMOD:28, Q at Any N-term
- **Tolerances:** precursor `7 ppm`, fragment `0.02 Da` (Methods: "initial precursor ion tolerance of 7 p.p.m. and MS/MS tolerance at 0.02 Da"). No `mqpar.xml`/`summary.txt`/`parameters.txt` is deposited, so the tolerances come from Methods only.
- **Label:** label free (Methods: "Label-free peptide quantification"). **Fractionation:** `not applicable`. **Technical replicate / fraction:** 1 for every row.

## Limitations

- **Single-condition, no factor value column:** inferred from the paper, which describes one uniform treatment for all 32 rats. If a reviewer requires a factor column, there is no honest varying variable to put in it.
- **Organism differs from PRIDE:** `Rattus norvegicus` is written, not PRIDE's `Rattus rattus`. This rests on the paper's "Sprague–Dawley rats (Crl:SD)" and the MeSH heading "Rats, Sprague-Dawley".
- **Developmental stage `not available`:** only body weight (200 g) is reported; age was not inferred from weight.
- **Rat number = file number (inference from deposited table + names):** each file is its own MaxQuant experiment, with the experiment number matching the file suffix, and the RAW headers confirm the names are original. The paper never states that run S<n> is rat n; the mapping of the 32 runs to 32 distinct rats rests on the 32-rats/32-runs count and the paper calling them biological replicates.
- **Tolerances and collision energy from Methods only:** no MaxQuant parameter file is deposited. MaxQuant 1.0.14.7 with Mascot was the search pipeline.
- **`Glutathione (C) Site IDs` column in `evidence.txt`:** the header exists, but there is no Glutathione per-modification count column and no evidence row carries it, and Methods do not list it. It was not annotated as a searched modification.
- **Cleavage agent `not applicable`:** chosen because the sample was not digested; the search setting itself was "no enzyme specificity". A reprocessing pipeline needs an unspecific search.
- **Treatment (protease-inhibitor perfusion and heat stabilisation)** is described here, not encoded as a column: it is constant across all rows and no fitting NCIT/EFO term was established.
- **RAW headers** were read for 3 of 32 files (S1, S17, S32); the other 29 are assumed to match since they share the batch name, date and naming pattern.
