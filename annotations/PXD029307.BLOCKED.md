# PXD029307 — annotation blocked

## Dataset

- **Title:** Novel tissue-specific markers revealed by in-depth proteome analysis of human myotendinous junction
- **PRIDE record:** PXD029307
- **Publication:** iScience 2022, doi 10.1016/j.isci.2022.103836

## Evidence recovered

79 RAW: 16 samples x 5 sequential extraction fractions (PBS, Buf1, Buf2, Buf3, insoluble pellet; one pellet run missing, some reruns). Deposited MaxQuant experimentalDesignTemplate files map each run to fraction/sample number 1-16 only.

## Why no SDRF was emitted

Nothing deposited or in the record says what samples 1-16 are: which donor, which region of the semitendinosus muscle-tendon complex (progressive removal of muscle towards the MTJ) and which are the patellar tendon controls. Without that, organism part, individual and the study factor cannot be assigned.

## Sources checked

PRIDE record and protocols; both experimentalDesignTemplate.txt files; MaxQuant parameters.txt.

## Unblocking requirement

A sample 1-16 -> donor, tissue region (muscle / MTJ section / tendon / patellar tendon) table.
