# PAD000040 annotation report

## Result

176-row affinity-proteomics SDRF for `dataset_all.npx.csv` (142 unique plasma samples; 34 bridging samples have a second technical-replicate row). Templates: `affinity-proteomics` v1.0.0 + `human` v1.1.0.

Not already in `bigbio/sdrf-annotated-datasets`.

## Evidence

- PRIDE: PAD000040. Milito et al., *Int J Mol Sci* 2026, PMID 42123728, PMCID PMC13164250, DOI 10.3390/ijms27094152. Fondazione Italiana Fegato / Cattinara Hospital bariatric cohort (NCT06098417).
- EDTA/plasma Olink Target 96 Inflammation on Signature Q100; NPX IPC-normalized (NPX Signature v1.13.0 / file v1.11.0). Two plates: `Inflammation F.I.F 21/03/2024` and `Inflammation PRAESIIDIUM Giraudi 04_03_2025`. Paper: 178 assays from 143 individuals, one QC failure excluded, 35 bridging replicates; deposited NPX has 142 SampleIDs of which 34 are on both plates (plus SampleID `309` duplicated on one plate, treated as a single assay).
- Sample metadata from `2025.05.08_sample_manifest.xlsx` keyed by FIF ID (NPX `308_BIS` = manifest `308 BIS`). Glycemia: 69 no diabetes, 25 prediabetes, 48 T2DM. Sex is per-sample; age is not in the deposit (cohort-level only in Table 1).

## Conservative choices

- All rows carry `morbid obesity`; the second disease column / factor is glycemic status (`normal` / `prediabetes syndrome` / `type 2 diabetes mellitus`). MASLD/MASH histology in `samplemanifest_bis.xlsx` was not added as extra disease columns.
- Age `not available`. Developmental stage `adult` from the bariatric adult cohort.
- No PSI-MS/PRIDE term for Signature Q100; instrument comment omitted. Platform is Olink Target 96.
- Sample `309` duplicate assays on one plate were not split into two technical-replicate rows.
