# PXD050580 — BLOCKED

## Exact blocker

The dataset is a single TMTpro 16-plex TAILS experiment (MDA-MB-231 wt and COSMC ko secretomes, MMP9 time course 0 h/16 h controls and 1, 2, 4, 8, 12, 16 h MMP9, which gives 16 conditions) that was pooled, split into a preTAILS and a TAILS sample, and fractionated. The channel-to-sample map (which of TMTpro 126 to 134N is wt or ko, and which time point) is not stated anywhere reachable, so each of the 16 rows per fraction cannot be assigned a sample identity without inventing it. The skill forbids inventing channel identity.

A second, lesser blocker: the meaning of the RAW name prefixes `PO` (15 files) and `NPO` (22 files) is not stated. They are most probably preTAILS vs TAILS fraction series, but this is an inference from the file counts and the msf names only.

## Evidence checked (channel-map ladder, references/channel-map.md)

1. Paper (Madzharova et al., Protein Sci 2024, PMID 39074261, PMC11285871) full text via Europe PMC: gives the design (16plex TMT-TAILS; "128C and 132C channels were excluded" from analysis) but no per-channel table. Figure 1c is an image; the text does not give the channel layout.
2. PRIDE `files/all` (39 files: 37 RAW plus two Proteome Discoverer 2.4 `.msf` files). Both search files are 4 to 7 GB. I read the PO `.msf` by HTTP range reads of its SQLite pages (Workflows, WorkflowInputFiles). The workflow template is `TAILS_16-plex`; the quantification method is "TMTro 16plex minus 128C, 132C" (14 channels); search settings are Sequest HT, Trypsin_R semi, 10 ppm, 0.02 Da, fixed Carbamidomethyl(C) and TMTpro16plex(K), variable Acetyl, pyro-Glu, deamidation, Oxidation and TMTpro N-term. No sample or condition names are stored (the PD default carries no channel labels). The NPO `.msf` was not opened, but it uses the same template per its name.
3. Europe PMC supplementaryFiles endpoint returned an HTML error page; the PMC and Europe PMC `bin/PRO-33-e5128-s00*.xlsx` links return a reCAPTCHA/403 page, so supplementary tables S1 to S10 could not be fetched.
4. Data availability cites only PRIDE (PXD050580 TAILS, PXD050581 DIA, PXD050644 PRM, PXD050647 glycoproteomics); no external repository.
5. No cross-validation possible without a map.

No deposited SDRF was used as evidence.

## Known facts, for whoever unblocks this

- Organism Homo sapiens; cell line MDA-MB-231 (breast adenocarcinoma, wt and COSMC knockout); secretome; Q Exactive HF-X with Evosep One, 44 min gradient (preset), HCD NCE 30, DDA top 20, MS2 resolution 45,000; high-pH fractionation; TMTpro 16plex; Submitter: E. Madzharova, DTU (PI C. Francavilla). The PRIDE record lists instrument "Q Exactive HF" but the RAW headers in the msf say Q Exactive HF-X Orbitrap, matching the paper.
- Expected SDRF size if unblocked: 37 RAW x 16 channels = 592 rows (or 37 x 14 if the two excluded channels are omitted).

## Evidence needed to unblock

A submitter-provided channel layout (for example Table S1 or the Figure 1c legend, or a PD study-information/sample sheet) giving the TMTpro channel for each genotype and time point, plus confirmation of what `PO` and `NPO` denote. Supplementary files of PMC11285871 would need to be retrieved by a human browser session.
