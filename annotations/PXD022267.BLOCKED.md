# PXD022267 — BLOCKED

## Exact blocker

The deposit is a single TMTpro 16-plex experiment (4 high-pH superfraction RAW files, `NSL_3rd_Fr01`-`Fr04`, one injection series) carrying 16 samples: 4 THP-1 lines (parental control, 3xFLAG-KANSL2, 3xFLAG-KANSL3, 3xFLAG-KAT8) x 4 replicates. No source resolves which TMTpro channel (126 ... 134N) holds which line/replicate. Without that map an SDRF row (file x channel -> sample) cannot be written without inventing channel identities.

## Evidence checked

- PRIDE project record and complete v3 `files/all` list (5 files: 4 RAW + `NSL_3rd.zip`; all `projectAccessions` = PXD022267).
- Contents of `NSL_3rd.zip` (HTTP-range read of the central directory and small members): the Proteome Discoverer 2.4 study `NSL_3rd.pdStudy` assigns only PD defaults (`NSL_3rd_Fr0 - [126]` ... `[134N]`, no factors, channel 126 flagged `Control` as a PD default), `InputFiles.txt`, MSstatsTMT logs, and the result tables `*_all_IP_proteins.csv` / `*_enriched_IP_proteins.csv`, whose columns are condition/replicate names (`contr_1..4`, `K2_1..4`, `K3_1..4`, `K8_1..4`) in processed order with no channel information. PSM / QuanSpectra / ProteinGroups headers carry only `Abundance 126 ... 134N`. The MSstatsTMT annotation file is not deposited.
- Publication (Radzisheuskaya et al., Mol Cell 2021, PMID 33657400, PMC8056186; full text read via NCBI efetch): Methods describe the design (four replicates, four lines) but no channel layout. Table S1 (NIHMS1674320-supplement-3.xlsx) could not be retrieved (PMC and Europe PMC supplements are behind an anti-bot challenge; Europe PMC reports the article as not open access).
- Data Availability links: PXD021943 and PXD023865 (other experiments), Mendeley doi 10.17632/v7mbmfxxy5.1 (uncropped western blots only), GitHub VGrinev/TranscriptomicFeatures (RNA-seq code only), GEO series. None holds the TMT layout.

No deposited SDRF was used as evidence.

## Evidence needed to unblock

The MSstatsTMT annotation file / channel layout from the submitter (Pavel Shliaha, Ole N. Jensen lab, SDU), or a per-channel table in a retrievable copy of Table S1. Note: group membership could be reconstructed only by inference from bait-protein reporter-ion enrichment, which was deliberately not done (it would not recover replicate identity and is not documented evidence).
