# PXD009555 BLOCKED: no animal-to-group map

Status: blocked annotation; no SDRF produced. Independent review not applicable.

## Dataset
Aarhus University (Palmfeldt lab). "Major metabolic pathway alterations in the rat myocardium during development of Type 2 diabetes mellitus, part 2". Label-free, in-gel digestion; Zucker diabetic fatty rat heart (ZDF fa/fa vs heterozygous lean fa/+ controls) at 6, 12 and 24 weeks. Paper: Edhager et al., J Proteome Res 2018, PMID 29847139, DOI 10.1021/acs.jproteome.8b00276.

## Why it cannot be annotated
84 RAW files named `<run>-jonas-<animal>-<slice>[-re].raw`: animals 1-18, slices 1-5 (18 x 5 = 90 would be expected; 84 deposited, and `3022`, `3024`, `3115`, `3117`, `3119` are each used by two different file names). The source animal -> genotype (fa/fa vs fa/+) x age (6/12/24 weeks) assignment is not stated anywhere reachable. Every sample property that matters (disease, genotype, age, factor value) would be invented from the position of the number in the file name (18 animals = 3 ages x 2 genotypes x 3 animals is the obvious design, but which animal number is which group is not evidenced).

Ladder checked:
1. Paper: closed (Europe PMC no PMCID, Unpaywall `closed`); abstract has no map. PRIDE protocol text gives the design but not the layout.
2. Deposit: MaxQuant `proteinGroups`/`peptides.txt` use the raw file names as experiment names (`Intensity 2952-Jonas-1-5` ...) with no group labels; `parameters.txt` has no sample names.
3. RAW headers: HTTP range read (first 256 KB) of `3092-jonas-1-1.raw` and `3115-jonas-12-1.raw` holds the instrument method (`CID_Dionex-Top4__110min_UDP_modified.meth`) and the instrument string `LTQ Orbitrap MS` / `Thermo Finnigan LTQ`, no sample name or comment.
4. Sibling records PXD009538 / PXD009554 (same paper): no group map either.

## Verified technical facts (for a future annotation once the map is found)
MaxQuant 1.5.3.30 `parameters.txt`: fixed Carbamidomethyl (C); quantification includes Oxidation (M) and Acetyl (protein N-term); FTMS MS/MS tolerance 20 ppm, ITMS 0.5 Da (ion-trap MS2). RAW method: CID (`Activation Type: CID`), top 4, 110 min gradient. Instrument: LTQ Orbitrap per the RAW header (PRIDE lists "LCQ Classic" and the protocol text says "LTQ XL"; both contradicted by the header). Possible unblock: author contact (johan.palmfeldt@clin.au.dk) or the paper's supplementary table.
