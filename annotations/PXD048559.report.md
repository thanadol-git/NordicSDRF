# PXD048559 SDRF annotation report

## Study
"Multi-omic analysis of guided and unguided forebrain organoids" (Ohlenschlager et al., Cell Rep Methods 2026, PMID 41643681, PMC12946753). Day-40 guided (STEMdiff Dorsal Forebrain kit) vs unguided (Cerebral Organoid kit) human forebrain organoids, 3 independent differentiations x 3 organoids per protocol (n = 9 per group), lysed, trypsin digested, TMTpro 18-plex labelled and pooled; TiO2 split into non-modified (flow-through), phospho-peptide and sialylated N-glycopeptide pools, each high-pH RP fractionated (20 / 12 / 12 fractions), nLC-MS/MS on Orbitrap Exploris 480 (DDA, HCD, 120 min gradient). Submitter Helle Bogetofte, SDU (PI M. R. Larsen).

## Templates
ms-proteomics v1.1.0 + human v1.1.0 + cell-lines v1.1.0 (organoids derived from the iPSC line IMR90 clone 4). No clinical/oncology template (healthy line).

NonMod 20 files (HpH_A1-A12, B1-B8), Phos 13 sample files (A1-A12 + A7_2), Glyco 12 files (A1-A12).

## Key decisions
- Source name = Group_D<differentiation>_FO<1-3>_<pool>. The same organoid/channel appears in three separate peptide pools (NonMod, Phos, Glyco) with overlapping fraction numbers, so the pool is part of the source name (separate peptide samples from one lysate); characteristics[enrichment process] states the pool. biological replicate = organoid index 1-9 within the protocol group (order of channels in Table S1; my numbering, not stated in the paper).
- factor value[differentiation protocol] = Guided / Unguided (custom characteristics column of the same name).
- Cell line iPS(IMR90)-4, CVCL_C437 (paper: "human iPSC line IMR90 clone 4, WiCell"); sex female and disease normal come from the Cellosaurus record of that line, not from the paper. Material type 'cell line' is the closest allowed value for organoids derived from it. organism part forebrain (UBERON:0001890, matches PRIDE field). sampling time 40 day = differentiation day.
- Fractions: NonMod HpH_A1-A12 = 1-12 and B1-B8 = 13-20 (inferred from 20 concatenated fractions and A/B naming); Phos/Glyco A1-A12 = 1-12. Phos A7_2 is a re-injection of fraction 7, written as technical replicate 2 with fraction identifier 7.
- Instrument Orbitrap Exploris 480 (MS:1003028; PRIDE field, paper, RAW headers of 8+ files incl. method 120min_45K_100ms_500bar.meth; Phos files use a 200 ms Phos method). DDA PRIDE:0000627. HCD from the protocol. Trypsin (methylated trypsin). DTT reduction, iodoacetamide alkylation (paper). Tolerances 10 ppm / 0.02 Da and modifications (Carbamidomethyl C, TMTpro K and N-term fixed; Phospho STY variable only for the phospho pool; Deamidated N variable only for the glyco pool) from the PRIDE/paper search parameters. Modification columns are four per row: the NonMod rows carry 'not applicable' in the fourth because the file's columns must align and no variable modification was stated for that pool (a merge of three separate builds, one per pool, was used for this reason).
- MS1 scan range 350-1400 m/z, ms2 analyzer orbitrap (45k resolution) from the protocol. Enrichment: phospho pool EFO:0010806 (closest EFO child; peptide-level term not found), glyco pool 'sample enrichment' EFO:0009106 (no sialylated glycopeptide term found), NonMod 'not applicable' (TiO2 flow-through).
