# PXD068559 SDRF annotation report

Status: validated annotation; independent review pending

Dataset: Eurasian common shrew (Sorex araneus) liver proteome across seasons (Aalborg University, Denmark; Bennike). Paper: Thomas et al., Genome Res 2026 (PMID 41188034, PMC12758402).

## Result
- 24 rows x 30 columns; one row per RAW file, label-free, DDA, no fractionation. Templates: ms-proteomics v1.1.0 + vertebrates v1.1.0.
- Groups: summer 2020 juvenile n=5 (J1-5); autumn 2020 juvenile n=4 (J1-4); winter 2021 (file prefix 2021_02) juvenile n=5; spring 2021 adult n=5; summer 2021 adult n=5. Factor value: season.
- Step 0.5: no existing PXD068559 directory in sdrf-annotated-datasets; annotated from scratch.

## Validation
- parse_sdrf validate-sdrf: passed with one warning (juvenile is not an EFO term for characteristics[developmental stage]; "juvenile" is PATO:0001190 / UBERON; no suitable EFO label found, kept as the accurate value).
- python -m tools check --offline: CLEAN. structure: OK. score: 100/100.
- reconcile: one BLOCKER, cleavage_agent_unsupported (Trypsin/P). Answered: the PRIDE prose and the paper never name the enzyme, but the deposited MaxQuant summary.txt (read by HTTP range from txt.zip) states Enzyme = Trypsin/P, specific, for every raw file. Retained.

## Key sources and decisions
- Technical values from txt.zip/txt/parameters.txt and summary.txt (MaxQuant 2.4.2.0): fixed Carbamidomethyl (C); variable Oxidation (M) and Acetyl (Protein N-term); MS/MS tolerance FTMS 20 ppm. The PRIDE prose and paper also list deamidation (NQ) and formylation (N-term, K) as variable modifications, but the actual search parameters do not include them; the SDRF follows the parameters. The paper cites MaxQuant 1.5.7.4, the deposit 2.4.2.0.
- Digestion: PreOmics iST kit, which normally uses a trypsin/LysC mix, but the record does not state the enzymes, so only the search enzyme (Trypsin/P) is recorded; single cleavage-agent column. Not verified.
- Dissociation HCD (NCE 27) from the PRIDE protocol: beam-type collision-induced dissociation.
- Developmental stage (juvenile/adult) and season derived from run names and the paper's group descriptions; biological replicate = the replicate number in the run name.

## Caveats
- sex, cell type, disease, strain: not available (per-animal sex is only in the paper's supplementary data, not retrieved; juveniles included 6 females, rest males per paper text).
- Precursor mass tolerance: not in parameters.txt; not available.
- The project description lists groups 2020_07, 2020_11, 2021_04, 2021_06 but the deposit also contains 2021_02 (5 juvenile files = winter group in the paper); assigned winter 2021 from the paper (n=5 winter juveniles).
- characteristics[season] is a non-template custom column (accepted by the validator); source name = RAW file stem.
- Independent review (Step 9.5) was not performed: subagent spawning was prohibited for this run. review-gate not run.
