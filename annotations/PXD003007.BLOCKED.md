# PXD003007 — blocked: RAW files cannot be assigned to study groups

## Sources checked

- PRIDE project record: https://www.ebi.ac.uk/pride/ws/archive/v2/projects/PXD003007
- PRIDE file manifest: https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD003007/files/all
- Paper: https://pmc.ncbi.nlm.nih.gov/articles/PMC6389751/ (PMID: 30806030; DOI: 10.14814/phy2.13994)
- Supplement bundle: https://www.ebi.ac.uk/europepmc/webservices/rest/PMC6389751/supplementaryFiles

## Evidence available

The PRIDE record identifies mouse kidney label-free shotgun proteomics in healthy control, STZ vehicle, and STZ liraglutide groups. The paper specifies 18 male 129SV mice: six healthy vehicle, six STZ vehicle, and six STZ liraglutide; it also states that all 18 shotgun samples were run once on an LTQ Orbitrap XL. PRIDE contains 18 vendor RAW files with numeric identifiers such as `STZ_3`, `STZ_9`, and `STZ_51`.

The paper explicitly identifies Supplementary Table S7 as the “Guide to Proteome Exchange sample names.” PRIDE result headers provide only the global run order (for example, 7/18 and 18/18) and do not label the numeric RAW identifiers with one of the three groups.

## Blocking gap

No retrievable source maps each deposited numeric RAW identifier to its biological group or individual mouse. The Europe PMC supplementary-file endpoint returned an incomplete ZIP stream, and the direct PMC supplementary-file request was challenged before returning the workbook. The missing Table S7 mapping is required to create a non-inferential SDRF.

## Unblock requirement

Provide a complete Supplementary Table S7 workbook or another authoritative numeric-RAW-to-group/mouse mapping. With that, the deposited 18 RAW files can be annotated without guessing.
