# PXD062200 annotation report

Status: approved after parser validation and independent hash-bound review.

Six RAW runs represent three bEnd.5 transformed tumor endothelial and three BALB-5023 primary normal brain endothelial conditioned-medium samples, both from BALB/c mice. The SDRF uses `ms-proteomics` and `vertebrates` v1.1.0. PRIDE's methods specify mouse material, Q Exactive Classic top-10 DDA with HCD, sequential Lys-C then trypsin digestion, and search modifications including dynamic Met-loss. The local builder extension emitted repeated cleavage-agent fields for both Lys-C and trypsin, resolving the earlier review finding. Independent review approved SHA-256 322300cdd70bef4f2467827925f58f3cf884e872cf9a06b3b22446de2523067d. The cell-lines template was not used because BALB-5023 is a primary culture without a verified Cellosaurus accession; bEnd.5 is [CVCL_2252](https://www.cellosaurus.org/CVCL_2252). The source names preserve both identities. Brain is the documented origin of both cultures.

Sources: [PRIDE project](https://www.ebi.ac.uk/pride/archive/projects/PXD062200), [file list](https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD062200/files/all), and [publication](https://link.springer.com/article/10.1186/s12964-025-02441-3). `parse_sdrf validate-sdrf` passed with both templates. Structure and offline ontology checks passed.
