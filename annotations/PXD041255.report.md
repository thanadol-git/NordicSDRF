## Key limitation: no file-to-sample map

The study has 15 participants (5 INR, 5 IR, 5 HC) with two biopsy sites each (sigmoid colon, terminal ileum) = 30 files. Neither PRIDE, the MaxQuant output (experiments are only "01".."30"), the RAW headers nor the paper text identifies which file is which participant, group or site. Run order was not used to guess. Therefore:

- `source name` = run id (MariK_DDA_NN), one source per file; biological replicate = file number (placeholder, not a true replicate index).
- `organism part`, `disease`, `age` = `not available`. No `factor value[...]` column was added because the compared variables (disease group, tissue site) cannot be assigned per file (expected no_factor_value advisory). This SDRF should be completed once the submitter supplies the map (the paper's supplementary methods may help).
- `sex` = male and `developmental stage` = adult are cohort-level statements from the paper (all participants male adults).
