## Design and file mapping (deposited table)
The deposited `Spectronaut_ConditionSampleKey.tsv` maps all 36 RAW files to condition and replicate: `hKO{1,2}-{24h,48h}-{Ctrl,TNFa-5,TNFa-50}`, replicates 1-3 (2 × 2 × 3 × 3 = 36). One RAW file per sample, no fractionation. All 36 RAW files are annotated. Factors: `factor value[treatment]` (control / TNFalpha 5 ng/mL / TNFalpha 50 ng/mL) and `factor value[sampling time]` (24 / 48 hour).
The meaning of `hKO1` vs `hKO2` is **not stated** (probably two organoid cell lines or differentiation batches); it is kept in the source name and `individual` only, with no dedicated column. The control level is written `control` because the key says `Ctrl` (the sister dataset PXD029718 calls its controls vehicle control, but this record does not).

## Technical values
Orbitrap Exploris 480 (PRIDE record; first 600 KB of `…Pellets-1.raw` read; method file `2022May_2h_2CVs_400nL_DIA_G1pickup.meth`). DIA with two FAIMS CVs (-45, -65 V) and "15 isolation windows from 400-1000 m/z" (PRIDE protocol): scan window 400-1000 m/z and isolation width 40 m/z (600/15, **derived**, assuming equal non-overlapping windows). Acquisition method is written as the plain label `Data-independent acquisition` (dia-acquisition template convention). Trypsin (SERVA; Spectronaut specificity Trypsin/P); TCEP/chloroacetamide; Spectronaut 17 directDIA+ (Deep): Carbamidomethyl C fixed, Oxidation M and protein N-term Acetyl variable. Tolerances are dynamic in Spectronaut (`not available`); dissociation method and collision energy are not stated (`not available`).
