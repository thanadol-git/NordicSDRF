## Limitations

- Publication (PMID 38997321) was not read; no claim cites it.
- Per-row comment[cleavage agent details] (two columns: Chymotrypsin then Trypsin; second 'not applicable' except for the combined digest) was patched into the built SDRF by a scripted column edit because the build tool takes only constant technical values; parse_sdrf and structure validation were run after the patch.
- Single healthy donor: age, sex, ancestry, individual identifier, cell type and developmental stage are not disclosed and set to 'not available'. biological replicate=1 for all rows (one donor).
- Source names combine Ig class and enzyme because each (class, enzyme) pair is a separate digest/injection; whether each Ig isolate was a separate aliquot per enzyme is inferred from the 4x4 file layout in the mapping sheet.
- Mapping sheet notes order Ig classes as IgG, IgA, IgM, IgK; the PRIDE protocol lists IgG, IgM, IgA, kappa with different amounts; the sheet (file level) was followed. Amounts per class are in the sheet notes only and not encoded.
- Plasma (protocol) vs serum (PRIDE field): protocol text followed. disease 'normal' derived from 'healthy donor'.
- Reduction and alkylation reagents are not stated in PRIDE text: 'not available' (carbamidomethyl fixed modification comes from the MaxQuant parameter files only).
- Extra non-template columns characteristics[immunoglobulin class] and characteristics[digestion protease] were added to carry the two factors. Enzyme 'Chymotrypsin' is the MaxQuant specificity (MS:1001306); Trypsin is MS:1001251 while MaxQuant used Trypsin/P.
- Searches used custom BCR sequence FASTA databases plus UniProt human; not encoded in the SDRF.
