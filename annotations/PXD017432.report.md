## Limitations

- Channel map comes from a figure image, not a text table; the PD study sample names are default channel names.
- Pooled reference composition not described; marked `pooled`.
- Age 30Y6M, sex female, disease cervical carcinoma, cell type epithelial cell come from Cellosaurus, not the deposit.
- Modifications read from the PD Sequest HT node in the pepXML header. Paper says deamidation (NQ), node lists N only; node followed. Label named TMT6plex in the search, TMT 10plex in quantification.
- TCEP/chloroacetamide from the paper's shared lysis sentence (fibroblasts and HeLa); the search used carbamidomethyl.
- Collision energy (28 in file name), passage number, culture medium, storage temperature not stated; omitted.
- Treatment values are free text (no NCIT/EFO match), giving validator warnings.
- RAW header not read; instrument from protocol and PD input-file record (Q Exactive Orbitrap).
