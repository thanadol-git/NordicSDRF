# PXD003138 annotation report

Super-SILAC profiling of CD138+ myeloma cells (MM and MGUS patients) and myeloma/lymphoma cell lines. This is the 2015 deposit; the same raw files reappear in PXD006458. Slupphaug lab, NTNU. Linked paper: J Transl Med 2024, PMC11162064.

## Templates
`ms-proteomics` v1.1.0 and `human` v1.1.0.

## Rows and files
There are 318 rows: 159 raw files × 2 channels. The encoding is identical to PXD006458:
- Light = patient or cell-line sample.
- Heavy = Lys8/Arg10 super-SILAC standard of 8 cell lines.
- Patient ID, diagnosis and technical replicate come from the file names, confirmed by the deposited MaxQuant `ExperimentalDesign.txt` (`SS+<sample>` names).

## Values
- Same as PXD006458.
- **t(4;14) subgroup:** the 2015 project description mentions t(4;14)-positive vs -negative MM. That status per patient is not available in the deposit, so it is not encoded; disease is MM or MGUS from the file names.
- **Search** (deposited MaxQuant 1.5.3.12 `parameters.txt` plus protocol):
  - No fixed modification in that search.
  - Oxidation M and Acetyl protein N-term variable.
  - 10 ppm precursor (protocol) and ITMS MS/MS 0.5 Da.
- **Instrument:** Orbitrap Elite, from the raw header.

## Validation
- `parse_sdrf` (CI style, warnings only) and the review gate pass.
- `tools reconcile`: every annotated value agrees with the deposit record.
