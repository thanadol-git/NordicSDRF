# PXD023249

Status: validated annotation; independent review pending.

- Pseudoalteromonas rubra S4059 (DTU, Lyngby): wild type vs GH19 chitinase deletion, grown on mannose / chitin / shrimp shells, culture supernatant and cells, label-free DDA on Q Exactive (Mar Drugs 2021, PMID 33673118)
- SDRF: `annotations/PXD023249.sdrf.tsv`; evidence: `annotations/PXD023249.evidence.json`
- Rows: 36; columns: 35; template: ms-proteomics v1.1.0 only (no bacterial organism template exists)
- Design: 3 carbon sources x 2 genotypes x 2 fractions (supernatant, cells) x 3 biological replicates; one RAW file each. Factor values: genotype, treatment, organism part.

## Where the sample map came from

PRIDE has no file-to-sample table. The three deposited `.pdResult` files (SQLite) carry the Proteome Discoverer StudyDefinition, read with HTTP range reads only (no full download). It maps Chitin_01-12 (project "mannose"), 13-24 ("chitin"), 25-36 ("shrimpshells") to labels such as `WT sup 1`, `dGH19 cells 3`. Search parameters were read from the Workflows table of the same files.

## Validation

- parse_sdrf validate-sdrf -t ms-proteomics --use_ols_cache_only: no errors; 1 warning (`shrimp shells` not in NCIT/EFO for characteristics[treatment]).
- tools structure: OK. tools check --offline: CLEAN (0 hallucinated).
- tools reconcile: 1 MAJOR, `cleavage_agent_incomplete` (Lys-C missing). Not fixable: comment[cleavage agent details] is single-valued in the template; digestion was LysC then trypsin, search enzyme was Trypsin. Kept Trypsin.
- RAW coverage: 36 of 36, each once.

## Caveats and inferences

- Third condition: the paper's proteomics Methods name only crystalline chitin and mannose. "Shrimp shells" is read from the pdResult name `shrimpshells` (the paper also uses natural shrimp shells elsewhere); treat as inferred. The "chitin" set is labelled `Chitin` (crystalline chitin per Methods 4.4).
- Deamidation (N,Q) is stated in the PRIDE protocol and paper but is not set in the deposited Sequest HT workflows; only deposited settings are encoded (plus Met-loss and Met-loss+Acetyl, which the paper omits).
- Each workflow also contains a non-search node with 20 ppm / 0.5 Da; the Sequest HT values (10 ppm / 0.02 Da) are used.
- HCD (beam-type CID) is inferred from Q Exactive with NCE 25; not stated by name. No RAW header check was done.
- Biological replicate numbers 1-3 come from the sample labels; supernatant and cell samples with the same number may or may not come from the same culture (unstated).
- Organism part values (`cell lysate`, `culture supernatant`) and `genotype` text are free-text choices; cell type and disease are `not applicable`. Extra characteristics (genotype, strain or breed, treatment) are not in the ms-proteomics contract but were accepted by the validator (precedent PXD006630).
- Genome-wide chemistry columns such as gradient (140 min, 10-60% B) and fractionation (none) are not encoded.
