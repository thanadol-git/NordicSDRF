# PXD027360 annotation blocked

PXD027360 ("Proteomic analysis of Nrf2 knocked down in HT29"; Tarbiat Modares University, Tehran) is the dataset for Cheraghi et al., BMC Cancer 22:979 (2022), doi:10.1186/s12885-022-10055-y, PMC9472369, PMID 36100939. The paper's Data availability statement cites PXD027360. The study compares an Nrf2 shRNA-knockdown HT-29 line (shRNA sc-37049-SH, puromycin-selected) with parental HT-29. The labelling sentence reads "100 μg protein of each biological replicates were labeled with TMT-130 and TMT-131". The samples were mixed and fractionated by high-pH RP into 12 concatenated fractions, then run on a Q Exactive (Easy-nLC 1000, top-20 DDA, MS1 300-1600). The search was PD 2.2 with 10 ppm / 0.02 Da, "TMT 2plex" (K, N-term) + carbamidomethyl fixed, and Met oxidation variable. The paper states "three replicates", and the ratios are HT29-Nrf2-/HT29.

The channel -> sample map cannot be established, and the file list cannot be reconciled:
- **Channel map:** the paper names TMT-130 and TMT-131, but nowhere does it say which channel carries the knockdown and which the parental line. The ratio direction (KD/parental) does not fix the channel either. Assigning one would be a guess (brief: guessed map = BLOCKED).
- **Replicate structure:** the paper states 3 replicates and 2 channels, but PROXI lists one `.msf` (`20190526_NanoCenter_TMT_plex_cell.msf`) and the file names suggest one plex. It is unknown whether the replicates are separate plexes, pooled lysates or technical runs.
- **File list:** PROXI `datasetFiles` lists only 5 RAW files (`20190526_NanoCenter_TMT_plex_cell_f07/f09/f10/f11/f12.raw`), while the paper says 12 fractions. The PRIDE FTP directory (`ftp.pride.ebi.ac.uk/pride/data/archive/2022/05/PXD027360/`) and the PRIDE v3 `files/all` API both returned upstream connection errors (twice / once) today, so the deposited set could not be verified.
- **PD `.msf`:** this file could hold the channel map (StudyDefinition / ReporterIon assignments) and the search mods, but it could not be read because the FTP was unreachable. The shell has no network.

**Evidence checked:** ProteomeCentral PROXI full record (saved to scratch); the BMC Cancer article on link.springer.com (Methods, Results, figure legends). The PMC render returned a reCAPTCHA page; Europe PMC REST was rate-limited (WebFetch) and failed with a connection error (browser). PRIDE FTP and the PRIDE v3 API were both unreachable.
