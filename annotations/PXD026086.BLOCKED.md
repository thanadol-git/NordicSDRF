# PXD026086 — annotation blocked

## Dataset

- **Title:** The Human Melanoma Proteome Atlas
- **PRIDE record:** PXD026086
- **Publication:** Betancourt LH. et al., Clin Transl Med 2021, DOI [10.1002/ctm2.473](https://doi.org/10.1002/ctm2.473), PMCID PMC8255060 (+ companion PMC8299047)

## Evidence recovered

- 404 RAW files on Q Exactive, Q Exactive Plus and Q Exactive HF-X covering 20+ sub-experiments: SCX fractionation series (`MM_835_20mM_03`), method pilots (`LysC_Tryp_FASP_*`, `*_UREA_TRYPSIN`), cell lines (SK-MEL-2/28, VMM1), acetylome (`*_AcD*`), TMT sets (`*_MSD*TM*`), tumour sets and others.
- Six Proteome Discoverer `.pdResult` files (15–437 GB) and the GitHub Supporting Information tables (rhong3/TCGA_melanoma) report proteins per sample ID, not per RAW file; no sample sheet is deposited.
- Part of this material (130715_M35 / M504 SCX series) overlaps PXD001724, which is already annotated in this repo.

## Why no SDRF was emitted

No crosswalk from RAW file to tumour/patient/cell line, TMT channel map or sub-experiment is deposited; the dataset would need a per-sub-experiment annotation effort with author input.

## Source artifacts

- `scratchpad/PXD026086/pride.json`

## Unblocking requirement

A sample sheet per sub-experiment (RAW file → sample ID, tissue/cell line, fraction, TMT channel map), or splitting the deposit's sub-experiments into separately annotatable sets.
