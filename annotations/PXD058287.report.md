# PXD058287 SDRF annotation report

## Study
"Anubis: a multi-level authentication scale for degraded milk whey using random forest classification" (PRIDE title). Controlled thermal degradation of bovine beta-lactoglobulin (BLG) for deamidation estimates: BLG alone, BLG + sugar, BLG + C8 fatty acid, BLG + sugar + C8 fatty acid; heated at 70 C, pH 7, 12 h; sub-sampled every 3 h (0, 3, 6, 9, 12 h) in triplicate; trypsin digested; Evosep One + Q Exactive HF. No publication is linked in PRIDE and Europe PMC has no hit for the accession or title, so PRIDE text, RAW method headers and deposited search tables are the evidence.

## Templates
ms-proteomics v1.1.0 + vertebrates v1.1.0 (Bos taurus; DDA, label free). No cell-line/clinical templates apply.

## Scope: deposited vs annotated
Deposited: 63 RAW files and 5 Sage/mokapot PSM tables (BLG_only, BLG_C8, BLG_sugar, BLG_sugar_C8, BLG_blank). Annotated: all 63 RAW files (60 sample runs = 4 groups x 5 times x 3 replicates, plus 3 BLANK runs) = 63 rows x 37 columns. PSM tables are not annotated as data rows.

## Key decisions
- Group codes from file names, confirmed by the PSM tables (one table per group): no code = BLG only, S = sugar, L = C8 fatty acid (lipid), LS = both. T0..T12 = hours; last number = replicate 1-3.
- Modifications read from the deposited PSM tables: Carbamidomethyl C (every Cys carries +57.0215, so treated as fixed), Oxidation M (variable; unmodified Met also present), Deamidated N/Q (+0.984, variable). The PSM tables do not state fixed vs variable explicitly; this is deduced.
- HCD with NCE 28, Orbitrap MS2 (30000 resolution), MS1 120000 resolution, MS1 range 350-1600 m/z read from the RAW method header (Q Exactive HF confirmed in RAW header).
- Cleavage agent Trypsin (PRIDE protocol; PSM peptides tryptic).
- Sage search settings were not deposited: tolerances not available.
- Added composition (sugar, C8 fatty acid) and heating are recorded in characteristics[treatment] (free text) because build cannot emit two spiked-compound values for one sample; factor value is sampling time only.
- BLANK runs: nature not documented (PSMs hit only porcine trypsin); written as a separate source with sample properties not applicable and no claim of processed buffer or digestion.
