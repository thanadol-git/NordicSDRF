## Limitations and calls to attack in review

- HCD written as MS:1000422 (beam-type collision-induced dissociation), the spec-canonical term.
- Testosterone group (low / borderline / normal) of each infertile patient is not in the PRIDE deposit (supplementary tables on figshare were not collected), so phenotype is only 'man investigated for infertility'.
- characteristics[compound] = not available for infertile patients: Table 1b reports current medication (insulin, ART) for some men, but not per patient.
- Per-subject ages not available (cohort ranges only).
- Heavy isotope-labelled reference peptides spiked into MRM samples are not encoded (no spiked-compound column).
- Time point C subjects had also received degarelix at week 0; compound column lists only the most recent drug.
- Only ~50 of 770 RAW headers were read and the extract was not saved; instrument per file family follows the paper and is assumed uniform.
- characteristics[biological replicate] = subject number within group (healthy 1–30, shared by time points A/B/C of the same man; infertile 1–75 in patient-number order).
- comment[technical replicate] numbers all runs of a sample in one series: DDA injections _01–_03 first (1–3), then MRM injections in r-number order (r1, r1b, r2, …), so MRM runs are 4–7.
- comment[modification parameters] (CAM C, Ox M) describe the DDA search and are repeated on MRM rows.
