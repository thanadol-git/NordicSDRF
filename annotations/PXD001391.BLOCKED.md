# PXD001391 — BLOCKED

## Exact blocker

The SILAC channel-to-cell-line map cannot be established from any source reachable here. The study is a two-arm SILAC design (13C6-Arg / 13C6-Lys): each of the 36 RAW runs contains a light and a heavy channel, and the SDRF needs one row per (file x channel) with a sample identity. The deposit and the reachable record never state which isogenic breast cancer cell line (metastatic vs non-metastatic) carries the heavy label, and never name the two cell lines.

- PRIDE protocol text only says "SILAC (13C6-L-arginine and 13C6-L-lysine)" and "Density based separation of nuclei, cytosol (3 biological replicates) and mitochondria (3 biological replicates)". It does not map labels to cell lines.
- Supplementarydata1part1.xlsx and Supplementarydata3.xlsx give the run layout (biological samples B1-B6; preparations Nu, Nl, C, M; MS analyses 1-3) and MSQuant ratio columns ("1/1", "2/1"; "M/NM"). They do not say whether heavy is M or NM, and the direction may be swapped between biological replicates (label-swap designs are common), so it cannot be assumed uniform.
- The Mascot PSR reports show only the search settings (Carbamidomethyl C fixed; Label:13C(6) K/R and Oxidation M variable; trypsin; 1 missed cleavage; 50 ppm / 0.2 Da; ESI-QUAD-TOF), not the sample design.
- The full paper (Lund et al., Mol Cell Proteomics 2015, PMID 26351264, PMC4638041), which would hold the Methods and SILAC design, could not be retrieved. Europe PMC fullTextXML returned HTTP 500, PMC and mcponline.org returned bot-check pages, the NCBI efetch record carries only front matter and abstract, and Unpaywall's PDF link returns HTML. Supplementarydata2.pdf returns 403 from the PRIDE FTP/HTTPS mirror.
- Cell line identities (metastatic vs dormant isogenic pair) are not named in the retrievable record, so the characteristics[cell line] values would also have to be guessed.

## Evidence checked

- PRIDE v3 project record and the full 150-file inventory (all entries carry projectAccessions PXD001391); 36 RAW zips (B1-B3 x Nu/Nl/C x MS1-3 and B4-B6 x M x MS1-3), mgf peak lists, Mascot PSR htm, FASTA, 5 supplementary xlsx and 1 pdf.
- Europe PMC abstract, NCBI efetch front matter, Unpaywall metadata; PRIDE-hosted Supplementarydata1part1.xlsx, Supplementarydata3.xlsx, PSRQP01673ecn_R_mgf.htm.
- Not checked or unavailable: paper Methods and figures, Supplementarydata2.pdf, remaining supplementary xlsx parts (their Info sheets are the same layout notes), RAW headers (SILAC labels are not recorded in instrument files). The `sdrf-tools` helper (contract/build) was also not installed in this environment, so an SDRF could not be built by the prescribed workflow.

No deposited SDRF was used as evidence (none exists for this accession in the community corpus).

## Evidence needed to unblock

The paper's Methods / SILAC experimental design (which cell line was grown in heavy medium for each biological replicate, and the cell line names and any label swaps), or a submitter-provided run manifest mapping each RAW file to light/heavy cell line. With that, annotation is straightforward: label-free-style rows replaced by 2 SILAC channels x 36 runs = 72 rows, templates ms-proteomics + human + cell-lines (+ oncology-metadata), instrument Waters Q-Tof micro/premier (to be verified), Mascot-derived modifications as above.
