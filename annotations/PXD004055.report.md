## Key decisions / judgement calls
- **Sources are per prepared sample**: one rat gives four sources (total proteome, TiO2, pTyr IP a, pTyr IP b), named `rat NN <group> lung <prep>`. `characteristics[biological replicate]` = 1-8 within each group (matches EGF_n/Ctrl_n); rat number is in the source name.
- **pTyr a/b** = two consecutive antibody incubations of the same peptide mix (Fig S1 legend), measured separately; modelled as two sources, technical replicate 1 each (not replicates, not fractions). Which of a/b was the first incubation is not stated; a = QE5 file, b = QE3 file by summary matching. The Ctrl_7b / EGF_1b tie (QE3_pTyr_15 vs _1, both 10,417 peptides) was resolved by the numbering pattern.
- **Treatment**: EGF vs saline as `characteristics[treatment]` and `factor value[treatment]` for lysate rows ("not applicable" factor on pulldown rows, whose lysate is saline). `factor value[bait peptide]` for pulldown rows ("not applicable" on lysate rows). Factor columns are bait and treatment only, so proteome / TiO2 / pTyr rows with the same treatment are not separated by a factor (an `enrichment process` factor would split them; not added to stay inside the two-round validation budget).
- **Enrichment process** values chosen from terms the validator resolves: total proteome `not applicable`, TiO2 `metal oxide affinity chromatography`, pTyr `immunoprecipitation`, pulldowns `affinity chromatography`. `bait peptide` is a custom characteristic column (bait gene, site, 7-residue flank; empty beads written as "none (empty streptavidin beads, background control)").
- **Pulldown strain/sex = `not available`**: the lysate donors are described only as "different rats treated with saline". The DBJ replicate suffixes LUNG9/11/13/15 equal the saline rat numbers of the EGF experiment, but the paper does not say they are the same animals, so no link was asserted.
- **EGFR pY998 bait**: DBJ file names say `EGFpY988`; the design file and the flank SNFYRAL give Y998. Y998 used.
- **PROTEOME_09-16** are also listed in `ExpDesign-365` as `Proteome_1-4` pulldown controls; annotated by their proteome identity (rats 9-16).
- **Instrument** Q Exactive (MS:1001911): PRIDE and every MaxQuant summary say Q Exactive; the Methods text says Q-Exactive Plus.
- **Digestion/chemistry**: lysate rows Trypsin + Lys-C, DTT, chloroacetamide; pulldown rows on-bead trypsin only (second cleavage column `not applicable`), DTT, iodoacetamide.
- **Modifications** from deposited parameters/summary: carbamidomethyl-C fixed; oxidation-M, protein N-term acetyl, Gln->pyro-Glu variable; plus Phospho(STY) variable for TiO2 and pTyr (written as a fifth column `not applicable` on the other rows).
- **Tolerances**: precursor 7 ppm for all rows (paper, stated generically); fragment 0.02 Da for TiO2/pTyr (paper + parameters.txt HCD) and 20 ppm for proteome/pulldown (parameters.txt FTMS; the paper's 0.02 Da is generic).
- Developmental stage, cell type: `not available` (only "male SD rats, 200 g" is given). Disease `normal`.
