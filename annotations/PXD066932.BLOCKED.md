# PXD066932 - BLOCKED (not annotated)

Study: "Microbial binding module employs sophisticated clustered saccharide patches to selectively adhere to mucins" (Nat Commun 2025, PMID 41083434, PMC12518865). PRIDE submission type PARTIAL.

## Why this cannot be annotated defensibly as an SDRF

1. **No raw or searchable MS runs are deposited.** The 5 files in PRIDE (checked via v2 API and FTP) are plain-text two-column peak lists (m/z, intensity; ~215-231k lines each), only labelled "RAW" by the archive:
   - 20211102_MUC5Ac293_Tn_real.txt (m/z 50-2998)
   - 20220524_MUC5AC_Tn_cleaveable_reporter1_E3_real.txt (m/z 500-4995)
   - 20220616_MUC5AC_Tn_cleaveable_reporter2_E3.txt (m/z 400-4497)
   - 20221029_MUC5Ac_cleavable1_largebatch.txt (m/z 150-3999)
   - MALDI_Combine.txt (a combined MALDI export)
   No vendor raw files, no search outputs (no MaxQuant/PD/.msf), so instrument, fragmentation, tolerances and modifications cannot be verified from files.
2. **File-to-method mapping is not stated anywhere.** The paper describes three different MS workflows (Synapt G2 direct-infusion intact MS of glycomodules; MALDI MS of synthetic glycopeptides; Orbitrap Fusion Lumos LC-MS/MS HCD/ETD of tryptic glycopeptides), and PRIDE lists two instruments (Synapt MS, autoflex). Nothing links any of the five files to an instrument, a specific glycomodule/glycoform, or a technical replicate. Assigning instrument per file would be inference from file names.
3. **The "samples" are not biological samples in the SDRF sense.** They are purified recombinant/synthetic glycomodules and glycopeptides (MUC5AC Tn-type glycoforms, cleavable reporters, 4xTn-STTT). Organism, organism part, cell type, disease etc. are not defined by the record; the only organism field (Homo sapiens) is a PRIDE dropdown. Required sample columns would all be `not available`/guessed.
4. **Workflow is intact-mass / glycopeptide composition analysis** (UniDec, SysBioWare, Proteome Discoverer Minora feature detection, 3 ppm), not an identification search, so cleavage agent, modification parameters and tolerances for an SDRF contract are not available from deposited search results. Bottom-up digestion with trypsin (Roche, 1:200, 18 h, 37 C) is in the paper but applies only to the Lumos workflow, not shown to correspond to any deposited file.

## What would unblock it
A statement or supplementary table mapping each deposited file to (a) the instrument/acquisition mode and (b) the glycomodule or glycopeptide analysed, plus the corresponding raw files if available.
