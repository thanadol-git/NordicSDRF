# PXD008648 — blocked: DNMT1 RAW files are not mapped to KO/control sample identities

## Sources checked

- PRIDE project record: https://www.ebi.ac.uk/pride/ws/archive/v2/projects/PXD008648
- PRIDE file manifest: https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD008648/files/all
- Paper: https://pmc.ncbi.nlm.nih.gov/articles/PMC6639357/ (PMID: 31320637; DOI: 10.1038/s41467-019-11150-8)
- Supplement bundle: https://www.ebi.ac.uk/europepmc/webservices/rest/PMC6639357/supplementaryFiles

## Evidence available

The paper describes proteomics of embryo-derived human neural progenitor cells with DNMT1 CRISPR knockout versus LacZ control, performed in biological triplicates. PRIDE contains 32 Orbitrap Fusion RAW files named `DNMT1_Rep1-3` with numeric suffixes consistent with fractionated runs.

## Blocking gap

No checked source maps the deposited RAW files to the DNMT1-KO or LacZ-control samples, biological replicate identity, fraction number, or acquisition batch. The file names identify DNMT1 but do not establish whether they represent knockout material, controls, or a pooled/sample-preparation label. The available supplement set contains results tables rather than a run sheet.

## Unblock requirement

Provide the proteomics sample and fraction map linking every RAW file to KO/control state, biological replicate, and fraction/acquisition order.
