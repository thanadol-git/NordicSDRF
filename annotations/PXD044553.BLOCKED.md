# PXD044553 BLOCKED: channel maps known, but file-to-experiment (proteome / phospho / flow-through) design not recoverable

Status: blocked annotation; no SDRF produced. Independent review not applicable.

## Dataset
Department of Clinical Science, University of Bergen (Vethe / Akslen groups). Sibling of PXD040662: neural cells (hESC-derived neural progenitors, midbrain neurons, 2- and 5-week matured neurons) alone or co-cultured with MCF-7 / MDA-MB-231 spheroids, and the breast cancer cells themselves, in two TMTpro16 plexes (set E = neural cells, set N = epithelial cells); proteome and phosphoproteome analyses on an Orbitrap Eclipse; 38 RAW files `ea08473…ea08544`, 38 `.mzIdentML`, and the PD export `2021-12-20_HV_2sets_FACS-2.xlsx`.

## What is established
The deposited xlsx has a complete channel key (sheet 1; channels in TMTpro order 126…134N):
- Set E (neural cells): 1-2 neural progenitor cells; 3-4 midbrain neuronal cells; 5-6 week-2 matured neurons; 7-8 week-5 matured neurons; 9 NPC + MCF-7; 10 NPC + 231; 11 midbrain + MCF-7; 12 midbrain + 231; 13 week-2 neuron + MCF-7; 14 week-2 neuron + 231; 15 week-5 neuron + MCF-7; 16 week-5 neuron + 231.
- Set N (epithelial cells): 1-2 MCF-7 spheroids; 3-4 231 spheroids; 5 MCF-7 + NPC; 6 231 + NPC; 7 MCF-7 + midbrain neurons; 8 231 + midbrain neurons; 9-10 MCF-7 + week-2 neurons; 11-12 231 + week-2 neurons; 13-14 MCF-7 + week-5 neurons; 15-16 231 + week-5 neurons.
The RAW headers carry sample names `hv_Eset_*` / `hv_Nset_*` (so set membership of each file is known), and some files use phospho methods (`n_Pro16_hrMS2_phos_FAIMS2…`).

## Why it cannot be annotated
The 38 RAW files mix high-pH proteome fractions, IMAC phosphopeptide-enriched fractions and flow-through (`hv_*set_FT`) runs, with duplicated and re-run labels (`hv_Eset_01` x6, `_ALT`, `_mix1/_mix2`, `hv_Nset_03` x3). Which file is proteome fraction n, phospho fraction n or flow-through is not recoverable from names, headers or the PRIDE text, so an SDRF with correct fraction identifiers and enrichment/modification parameters per file cannot be written without guessing.

## Possible unblock
Author contact (the submitting lab) for a file list, or the PD result files (not deposited). Reuse the channel maps above together with PXD040662.
