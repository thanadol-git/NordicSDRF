## Honesty choices (vs prior failed draft)

1. **Cell type.** Prior draft used `neuron`. The material analyzed is whole-fly homogenate (paper: 0.5–1 ml frozen adult flies dounced in RIPA; PRIDE organism part `whole body`). Neuronal expression (`elav-Gal4`) is the genetic condition, not an isolated sample cell type. SDRF uses `characteristics[cell type] = not available` and `organism part = whole body`.
2. **Biological replicate / source identity.** Design lists analytical sample IDs S1–S12 with group VMAT/Control only; it does not state that each ID is an independent biological source or how many fly cohorts underlie each prep. This annotation does **not** invent distinct animals or number bio-reps 1–6 within group. Each analytical sample is its own `source name`; `characteristics[biological replicate] = 1` on every row (placeholder required by the template). Treat S1–S12 as analytical samples pending an author run-to-biological-source key.
3. **Genotype labels** follow the paper/PRIDE contrast (TurboID-VMAT vs free cytosolic TurboID). `characteristics[deposited grouping]` keeps the literal design values `VMAT` / `Control`.
4. **Developmental stage** `adult` from Methods (adults 0–3 days after eclosion). Strain/disease `not available`.
