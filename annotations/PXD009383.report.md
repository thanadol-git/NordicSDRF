## Key decisions
- **Channel map (the main risk).** No deposited file or table gives a per-plex channel->sample map. Sources checked: PRIDE record and file list (no sample sheet), paper text, Supplementary Methods PDF (MOESM1), Table S1 (clinical, MOESM1), Table S4 (MOESM3, ratios only), Table S2 (MOESM2, IHC cohort, unrelated), Mascot .dat headers (no sample names), raw header, Fig 1A. Fig 1A shows the generic scheme for two matched pairs: forward tube 114=ER_A, 115=LR_A, 116=ER_B, 117=LR_B and reverse tube 117=ER_A, 116=LR_A, 115=ER_B, 114=LR_B. Methods: "each two pairs of samples were labeled with 4-plex iTRAQ in both orders (forward and reverse)". I applied this layout to G<n>F (forward) and G<n>R (reverse), i.e. G<n>F and G<n>R hold the same four samples. This is an **inference from a schematic**, not a stated per-file map. **Reviewers: attack this hardest.** ArrayExpress E-MTAB-6675/6676 are microarray records and were not expected to hold the iTRAQ map; no Zenodo/figshare link is cited.
- **Which patient pairs are in which group is not published**, so sources are named `G<n>_ER_A`, `G<n>_LR_A`, `G<n>_ER_B`, `G<n>_LR_B` (n=1..5; 20 sources, matching 10 ER + 10 LR). `individual`, `age`, `ancestry category`, `cell type` = `not available`. Table S1 lists age/TNM/smoking per ER/LR patient, but cannot be attached without the group map.
- `sex` = male for all rows: Table S1 gives Male for all 20 patients, true regardless of mapping.
- `phenotype` / `factor value[phenotype]` = early recurrence (ER, <10 months) vs late recurrence (LR, >30 months). Disease is the same (squamous cell lung carcinoma, MONDO:0005097) in all rows, so it is not the factor. This follows from the same Fig 1A inference (ER = A/B first of each pair).
- `technical replicate`: 1 = forward plex, 2 = reverse plex (same samples, swapped labels). `biological replicate` = 1 for every source (each source is a distinct patient tumour; replicates across F/R are technical).
- Modifications read from the deposited Mascot parameters (`MODS`, `IT_MODS`): Carbamidomethyl (C) fixed; iTRAQ4plex (K) and (N-term) and Oxidation (M) **variable** as searched (the iTRAQ reagent is chemically a fixed label, but the search declared it variable and the annotation follows the search). Tolerances 500 ppm / 0.5 Da are the Mascot TOL/ITOL values; the 500 ppm precursor tolerance is unusual for Orbitrap data but reported as deposited.
- Instrument: LTQ Orbitrap Velos, confirmed in RAW header (PRIDE and paper agree). Dissociation HCD (MS:1000422, beam-type CID); ms2 analyzer orbitrap (7500 resolution, Methods).
- Cleavage agent Trypsin/P comes from Mascot `CLE=Trypsin/P` and "tryptic digestion" in the Fig 1 legend; `reconcile` flagged it only because the PRIDE protocol prose does not say "trypsin". Retained.
- `alkylation reagent` = `not available` (not stated; Carbamidomethyl appears as Fixed in the search but the reagent is unstated). `collision energy` = 42 NCE from the raw header (HCD, Normalized Coll. Energy 42.0), checked on one file (G1F_F01) and assumed constant. Reduction: DTT (0.1 M in SDT lysis buffer).
- SCX fractionation: sample F01..F06 (G1: F01..F07) inferred from file names; the 7th G1 fraction is as deposited.
