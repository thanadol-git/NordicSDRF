# PXD024851 annotation evidence report

Status: Blocked: the 17 RAWs mix intact mucin reporter measurements and bottom-up glycopeptide runs with Lys-C, trypsin, Asp-N and desialylation preparations. Filenames cover several MUC reporters and glycoengineering states, but no deposited run design maps every file to its exact source and acquisition method. The result workbook does not provide a complete run map. The assay types need separate, source-backed annotation.

Sources: [PRIDE project](https://www.ebi.ac.uk/pride/archive/projects/PXD024851) and [file list](https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD024851/files/all). No SDRF has been approved for this accession.
