# PXD064483 SDRF annotation report

Status: validated annotation; independent review pending.

Dataset: Proteomic study of DLBCL cell lines and R-CHOP response (Aalborg University, Denmark; Biomedicines 2025, PMID 41301803). Label-free DDA on a Q Exactive HF-X, MaxQuant LFQ.

## Output
- `PXD064483.sdrf.tsv`: 72 rows x 32 columns (36 sources `sample_2`..`sample_37`, each with two injections `N_1`/`N_2` recorded as technical replicates 1 and 2).
- Templates: ms-proteomics v1.1.0 + human v1.1.0. The cell-lines template was deliberately not applied (see caveats).
- Technical values: Q Exactive HF-X (from raw headers), Trypsin, DDA, label free, fixed Carbamidomethyl (C), variable Oxidation (M) and Acetyl (Protein N-term) from the deposited MaxQuant summary.txt, fragment tolerance 20 ppm, TCEP/iodoacetamide. Single protease, so one cleavage-agent column.
- No fractionation; no factor value (no sample-level comparison can be encoded without the cell-line map).

## Validation
- `parse_sdrf validate-sdrf -t ms-proteomics -t human --use_ols_cache_only`: PASS.
- `python -m tools check --offline`: CLEAN. `python -m tools structure`: OK.
- `python -m tools reconcile`: one BLOCKER `cleavage_agent_unsupported`. Judged a false positive of the heuristic: the protocol sentence "Trypsin (1 ug) was added to each sample ... overnight" is the digest but contains no digest cue word. Reviewer should confirm.

## Caveats
1. Sample identity is not recoverable from the deposit. Files are numbered 2..37 (36 samples) and the xlsx `Cell_line_numbering_technical_dublicate.xlsx` lists 36 haematological lines in rows 2..37 (DLBCL, myeloma, Burkitt, B-NHL) but carries no explicit sample-number column. Row number = sample number is a plausible hypothesis but unverified, so cell line, cell type, disease and organism part are `not available`. The paper analyses only 16 DLBCL lines, so the deposit contains more than the paper. Authors should supply the mapping.
2. Instrument: raw headers say Q Exactive HF-X; PRIDE says Q Exactive HF and the protocol says QE+. Raw data was used.
3. Precursor tolerance and dissociation method are `not available` (not stated; not inferred). Age, sex, ancestry, individual are `not available` (cell lines).
4. MaxQuant version: deposited parameters.txt 1.6.17.0 vs paper 1.6.12.0.
5. `_1`/`_2` pairing as technical replicates is inferred from file naming and the paper ("duplicates"); raw headers show some files were re-acquired/renamed (e.g. 14_2.raw originally 14_1_2020...).
6. Independent review (Step 9.5) was not performed here; no subagents allowed. The review gate has not been run.
