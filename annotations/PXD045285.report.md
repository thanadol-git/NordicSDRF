# PXD045285 SDRF annotation report

Status: validated annotation; independent review pending (Step 9.5 reviewer not run; no isolated reviewer was available, so no review-gate receipt exists).

Dataset: "Periostin is a disulfide bonded homodimer and forms a complex with fibronectin in human skin" (Aarhus University; Biochemistry 2024, doi:10.1021/acs.biochem.4c00240, closed access).
Existing annotation: none in sdrf-annotated-datasets (checked, Step 0.5).

## Result
- 22 rows x 36 columns, one row per RAW file. Templates: ms-proteomics v1.1.0 + human v1.1.0.
- Groups: 7 dermal fibroblast gel bands (Dermal_Silvergel_Gelband_1,2,3,5,6,7,8), 7 lung fibroblast gel bands, 6 skin tissue gel bands (3 donors x upper/lower), 2 non-reduced immunopurified periostin runs (dermal, lung; EThcD).
- Factors: factor value[organism part] and factor value[gel band].

## Validation
- parse_sdrf validate-sdrf -t ms-proteomics -t human: PASS, no warnings (exit 0).
- python -m tools structure: OK. python -m tools check --offline: CLEAN (0 hallucinated).
- python -m tools reconcile: one BLOCKER, run_names_name_another_organ. Judged a false positive: it compares the first row's organism part (skin) against all run names, while every Lung_* row already says lung. PRIDE's own organismParts omit lung, so the structured field is the incomplete one.

## Key decisions and caveats
- Instrument differs by file, read from RAW headers (range reads, no full download): Orbitrap Eclipse for 7 Dermal gel runs, Lung_Silvergel_Gelband_4 and both IP runs; Q Exactive Plus for the other 12 (6 skin, 6 lung). PRIDE lists only Eclipse.
- Two builds were produced (gel/skin rows and IP rows, different search settings) with identical headers and the data rows concatenated; no cell was edited by hand.
- Gel/skin rows: Sequest HT, Trypsin (Full), 2 missed cleavages, 10 ppm / 0.6 Da, Carbamidomethyl C (fixed), Oxidation M and protein N-term Acetyl (variable), HCD, orbitrap MS2 (from msf files of 5 runs spanning each group). Single protease (trypsin); no Lys-C or second enzyme evidenced, so one cleavage-agent column.
- IP rows: StavroX settings (trypsin K/R, 10 ppm, 0.05 Da, Oxidation M variable, no static mods). Dissociation EThcD is taken from the run names. The two unused modification columns are "not applicable"; reduction "not applicable" (non-reduced), alkylation and MS2 analyzer "not available".
- Alkylation reagent for gel rows (Iodoacetamide (IAA), PRIDE:0000599) is inferred from the carbamidomethyl search setting and the PRIDE PTM list, not from protocol text. Reduction reagent not available.
- Not available (no per-sample evidence): age, sex, ancestry category, disease, individual for fibroblasts, skin cell type. The meaning of numbered gel bands is unknown (paper closed); band numbers are recorded verbatim.
- Crosslinking template not used: the disulfide links are native, so there is no chemical cross-linker to record. PRIDE's "chemical cross-linking" experiment type is therefore not reflected.
- Fibroblast origin (primary cells vs a named line) is unknown, so no cell-lines template and no cell line column.
- DDA is inferred (Sequest search of MS2; no DIA indicators). Collision energy omitted (NCE 27-28 seen in msf but not verified for all runs).
- msf settings were checked on 5 of 21 files; the rest are assumed identical.
