# PXD017597 annotation report

## Result

Annotated all 27 deposited RAW files for the comparative Giardia lamblia strain proteomics study.

This is a PRIDE keyword hit for “Roskilde”, but the project metadata identifies Switzerland rather than Denmark/Roskilde. It is included because the request was expanded to all nine search hits; no Roskilde affiliation is asserted here.

## Evidence

- PRIDE: https://www.ebi.ac.uk/pride/archive/projects/PXD017597
- Publication: PMCID PMC7332775; PMID 32338227
- Strains and biological/technical replicate structure are taken from the deposited filenames and publication methods.
- Three strains (A1, WBC6, H7), three biological replicates and three technical injections are represented.
