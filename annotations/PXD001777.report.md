## Key caveats
1. **Channel map missing (blocking-grade limitation).** No source gives which iTRAQ channel is unstressed control, stress-susceptible or resilient: paper closed access (abstract only), no supplementary, PRIDE mzTab/XML/MGF carry no channel labels. Source names are neutral placeholders ("F4-2 iTRAQ114"), and disease, strain, sex, developmental stage are `not available`. No group was invented. Reporter peaks confirm all four channels are populated (MGF check, 115 weakest). Do not use this file for group comparisons until a map is found (ask the authors, johan.palmfeldt@clin.au.dk).
2. Fraction identifiers of the three combined-fraction runs are approximations (first fraction of the pair: 2, 6, 8); the five non-original files had their fraction identifier set by a scripted patch after `build` (build numbers fractions by list position).
3. Title/protocol discrepancy: PRIDE protocol text says "fraction 3", title, file names, mzTab and XML say fraction 4. Followed the latter.
4. Prefrontal cortex comes from the paper abstract and PRIDE XML comment (PRIDE structured field says "brain"). Material type "tissue" is inferred.
5. Modifications from the mzTab (all listed as variable; no fixed). Carbamidomethyl C appears in only 7 PSMs, so the alkylation chemistry is uncertain; no reduction/alkylation reagent columns written. Precursor tolerance 9 ppm is as deposited in the Mascot parameters. MOD to UNIMOD mapping by chemistry.
6. Single protease (trypsin; mzTab lists Trypsin/P): one cleavage-agent column. Instrument and PQD fragmentation verified from the first 400 kB of four RAW files (range reads; no full download).
7. Only the F4-2 set (F4 = fraction 4, set 2) is deposited; the study also covered fractions 2 and 3.
