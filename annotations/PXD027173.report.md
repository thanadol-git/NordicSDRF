## Limitations and calls to attack in review

- The file list names '181130_P997_2_phospho.raw' but PRIDE holds '181130_C997_2_phospho.raw' (no other candidate); the deposited name is used.
- Region 'HC' annotated as hippocampal formation (UBERON) — the paper's 'total hippocampus' sample.
- Braak stage is carried as phenotype (clinical-metadata template has no staging column for AD); controls are labelled 'control' as in the file list (CTRL).
- The global runs used lysine-blocked (acetylated/d3-acetylated) samples and were searched as Arg-C by the authors; the digestion enzyme itself was trypsin.
