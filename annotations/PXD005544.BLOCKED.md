# PXD005544 — BLOCKED

## Exact blocker

The dataset is TMT 6-plex (13 plexes, 238 RAW files in 7-10 HILIC fractions x 2 injections per plex). Channel 126 is the pooled internal standard (stated in the paper), but no accessible source says which patient tumour (recurrence / recurrence-free, primary / metastasis) sits in channels 127-131 of each plex. Without that map an SDRF row would need an invented sample identity, so no SDRF was written.

## Evidence checked

- PRIDE v3 project record and complete `files/all` list (251 files: 238 RAW, 13 PD 1.4 `.msf`; every entry's `projectAccessions` = PXD005544). RAW names carry only the plex and fraction (`MHP_050716_Plex1_0101.raw`, `MHP_TMT_HILIC_041615_Plex5_0201.raw`), no patient ID. No sample sheet deposited.
- Paper (Pedersen et al., Oncoimmunology 2017, PMID 28638726, PMC5468003), read from the PMC HTML render: Methods state TMTsixplex, internal standard on 126, 34 discovery tumours plus a second cohort (10 primary tumours with matched metastases). No per-channel table in the text. The paper says only that the other channels hold patient samples.
- Paper supplement `koni-06-05-1305531-s001.zip` (Supplementary_materials.zip): not retrievable. The PMC download returns an anti-bot proof-of-work page, Europe PMC reports the article is not open access (supplementaryFiles error), and the Taylor & Francis supplement URL returns 403. Table S1-S3 are described as protein tables, so it may not hold a map anyway.
- Deposited PD 1.4 `.msf` (SQLite, read by HTTP range, MHP_050716_Plex1.msf): `FileInfos` (20 fractions), `ProcessingNodes`, `ProcessingNodeParameters`. The Reporter Ions Quantifier holds only the stock "TMT 6plex" method (channels 126-131, no sample names). Nothing there maps channels to patients. Other `.msf` files not read (same PD workflow assumed, not verified).
- Data Availability cites only PRIDE (PXD005544). No Zenodo, figshare, OSF, Dryad or GitHub deposit.

No deposited SDRF was used as evidence.

## Evidence needed to unblock

The paper's supplementary materials, or a submitter-provided sheet, listing for each of the 13 plexes which patient sample is in each of channels 127-131. Also needed: which plexes belong to discovery vs second cohort, and the outcome (recurrence status, primary vs metastasis) of each patient. Note 13 plexes x 5 channels = 65 slots against 34 + 20 = 54 reported samples, so repeated or extra channels must be explained.
