# PXD016530 annotation report

Phosphoproteome of whole brain from wild-type and *Jnk1* (*Mapk8*) knockout C57BL/6J mice at four ages. Paper: Sci Rep 2024 (PMC11096340).

## Templates
`ms-proteomics`, `vertebrates` v1.1.0.

## Rows and files
There are 120 rows: 2 genotypes × 4 ages (E15, P0, P21, 8-month adult) × 3 mice × 5 gel slices.
- The mouse number in the file name is the biological replicate within each genotype and age. Each age uses different mice, so the individual is `<genotype><n>_<age>`.
- Gel slices 1–5 are fractions.
- Two file-name typos (`Pold1`, `E151`) are read as `Pold` and `E15`.

## Values
- **Development and age:** developmental stage is embryonic day 15, postnatal day 0, postnatal day 21, or adult (8 months). Age is `0D`, `21D` and `8M`; it is `not applicable` for embryos. Sex is `not available`.
- **Enrichment:** TiO2 phosphopeptide enrichment.
- **Instrument:** LTQ Orbitrap XL, per the raw header and the protocol. CID.
- **Search:** Proteome Discoverer / Mascot, 10 ppm / 0.8 Da. Carbamidomethyl C fixed; Oxidation M and Phospho S/T/Y variable.
- **Replicates:** the protocol mentions two technical repeats, but only one run per slice is deposited.

## Validation
- `parse_sdrf` (CI style, warnings only) and the review gate pass.
- `tools reconcile`: every annotated value agrees with the deposit record.
