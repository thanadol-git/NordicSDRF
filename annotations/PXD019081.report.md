# PXD019081 SDRF annotation report

Status: validated annotation; independent review pending (no review gate run; no subagents allowed).

Dataset: A2M Thr654Cys/Thr661Cys mutant disulfide mapping (Aarhus University; Enghild lab), Orbitrap Eclipse, DDA; paper PMC8167298. No existing annotation in sdrf-annotated-datasets.

Templates: ms-proteomics v1.1.0 + human v1.1.0. The cell-lines template was not used: the sample is a purified recombinant protein (expressed in HEK293 Freestyle cells), not a cell lysate. Crosslinking template not used: this deposit maps native disulfides (PRIDE labels it XL-MS, but no cross-linker is described).

Design: 4 rows x 28 columns (4 RAW files, label free, one injection each). Each file is a different digest of the same sample: pepsin (no reduction/alkylation); trypsin; chymotrypsin; trypsin+chymotrypsin (IAA-alkylated, 6 M urea). Rows are distinguished by cleavage agent only; no factor value column added (no biological comparison).

Two protease case: the trypsin+chymotrypsin row has two `comment[cleavage agent details]` columns; parse_sdrf accepts this. The other rows carry `not applicable` in the second column. (Template lists the column as non-multiple; accepted nonetheless.)

Validation:
- parse_sdrf validate-sdrf -t ms-proteomics -t human --use_ols_cache_only: PASS
- tools structure: OK; tools check --offline: CLEAN
- tools reconcile: 1 BLOCKER, cleavage_agent_contradicted (PepsinA vs trypsin/chymotrypsin). Judged false positive: the record's protocol explicitly describes a pepsin digest and a pepsin RAW file is deposited.

Caveats:
- Byonic search settings are in a 557 MB zip that was not read (an attempted range read was not honoured and was aborted; partial data deleted). Therefore modification parameters, precursor/fragment tolerance and dissociation method are `not available`. Carbamidomethylation is likely for the three IAA-alkylated runs but is not recorded.
- Reduction is `not applicable` (protocol states none for pepsin; for the others none is mentioned) - inferred.
- Organism part, cell type, age: not available; sex and disease: not applicable (recombinant protein).
- Paper tolerances/mods describe XlinkX searches of other data, not used.
- Fraction/replicate: 1/1; the "1x5" in file names was not interpreted as replicates.
