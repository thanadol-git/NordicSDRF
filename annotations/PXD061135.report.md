# PXD061135 annotation report

## Study
"Enhancing tandem MS sensitivity and peptide identification via ion pre-accumulation in an Orbitrap mass spectrometer" (PRIDE-linked paper: Guzman et al., MCP 2026, doi:10.1016/j.mcpro.2025.101504, PMC12914409). HeLa S3 tryptic digest, label free, benchmark of pre-accumulation and phi-SDM at several peptide loads. The paper does not cite PXD061135 and describes an Astral Zoom, so it is weak context only.

## Templates
ms-proteomics + human + cell-lines v1.1.0 (DDA file); + dia-acquisition v1.1.0 (DIA file). Two sub-experiments, two SDRFs:
- PXD061135-dda.sdrf.tsv: 72 rows x 46 cols. 2022 Vanquish Neo 8-min DDA runs, HCD 28 NCE, MaxQuant search deposited.
- PXD061135-dia.sdrf.tsv: 49 rows x 50 cols. 2024 Evosep 200 SPD DIA runs, HCD 27 NCE, 32 m/z windows, Spectronaut search deposited.

## Scope deposited vs annotated
PRIDE lists 124 files (the files API caps pages at 100; pages 0 and 1 fetched): 121 RAW, Annotation-extended.xlsx, MQ_search.zip, 20240211_220652_fsdm.sne. All 121 RAW annotated (72 DDA + 49 DIA), including the 0 ng blank injection as a DIA row (source blank_0ng, sample type negative control, peptide amount 0 ng). Not annotated: undeposited runs that appear in the xlsx/.sne (nRNG, 100/250 ng).

## Key decisions
- Instrument Orbitrap Exploris 480 from RAW method headers; PRIDE says Orbitrap Astral, paper Astral Zoom (raw wins).
- Per-run settings (resolution, NCE, condition, amount, replicate) from the xlsx and raw method summaries. One DIA file missing from the xlsx (50ng_sRNG_Pton_fdsm0_01) was checked in its RAW header and assigned by name.
- Search settings from deposits: MaxQuant 2.0.3.0 (MQ_search.zip, BL8/PPT8/PT8 parameters.txt and summary.txt): Trypsin/P specific, 2 missed cleavages, Carbamidomethyl (C) fixed, Oxidation (M) and Acetyl (Protein N-term) variable, MS/MS tol. (FTMS) 20 ppm. Spectronaut 18.5 settings in the .sne agree on enzyme and modifications ("Digest Rule VALUES{Trypsin/P}", "Missed Cleavages 2", Fixed "$Carbamidomethyl (C)$", Variable "$Acetyl (Protein N-term)$Oxidation (M)$"). Used for both files.
- Factors: acquisition mode, peptide amount loaded, and for DDA MS2 resolution. DIA method directDIA (PRIDE data processing protocol).
- Source = condition x amount (x MS2 resolution for DDA); technical replicate = file-name suffix (1..n, now contiguous); biological replicate 1 throughout: all runs appear to be technical injections of one HeLa S3 lysate/digest.
- HeLa S3 = CVCL_0058, disease cervical carcinoma (PRIDE), sampling site uterine cervix.
