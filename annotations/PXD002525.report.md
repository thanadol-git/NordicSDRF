## Key decisions
- Sample unit: whole worms, stage x replicate (file name `<stage>rep-<n>.raw`; "two replicates for each stage" per PRIDE protocol). `biological replicate` = n from file name (inferred: whether replicates are independent cultures is not stated in the deposit).
- Developmental stage: WBls labels for L1-L3 (`L1 larval stage` WBls:0000106 etc.), `L4 larval stage` WBls:0000109, `dauer larva` (WBls:0000032), `embryo`. Post-dauer stages ("L1 post-dauer larva", "L4 post-dauer larva") are free-text descriptors: no exact WBls term for post-dauer L1 was found. Factor value[developmental stage] copies the characteristic.
- Genotype `daf-2(e1370)` stated in PRIDE sampleProcessingProtocol (temperature-sensitive mutant; grown at 15 C or 25 C for dauer). Strain name (e.g. CB1370) not stated -> `not available`. Growth temperature per sample is not given in the deposit, so not encoded.
- Organism part `whole body` (BTO:0001489, from PRIDE sample attributes). Disease `not available` (healthy model organism; template has no sentinel guidance - left as not available).
- Instrument LTQ Orbitrap Velos (MS:1001742): PRIDE, mzTab and the RAW header ("LTQ Orbitrap Velos MS", range-read of L4rep-2.raw) agree.
- Cleavage: Glu-C -> `glutamyl endopeptidase` MS:1001917 (stated in PRIDE protocol). Dissociation ETD (MS:1000598, stated). Acquisition DDA (PRIDE:0000627) — inferred from standard shotgun/ETD MS/MS acquisition; not explicitly stated.
- Modifications read from the deposited Mascot search (PRIDE-generated mzTab, L4 rep-2; MTD fixed_mod = "No fixed modifications searched"; variable: MOD:00855 trimethyl-K, MOD:00394 acetyl, MOD:00599 monomethyl, MOD:00493 formyl). Only one of 16 mzTab files was inspected; assumed the same search parameters across files.
