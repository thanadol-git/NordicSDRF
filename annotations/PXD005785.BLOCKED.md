# PXD005785 — BLOCKED

## Exact blocker

Multiplexed iTRAQ-8plex (3 kits, 8 channels each, hippocampus of 24 mice, 4 groups of n=6: Wt PBS, Wt LPS, Tg PBS, Tg LPS) with NO channel-to-sample/group map anywhere in the record, and no map from the 245 RAW files to kits/fractions beyond search-file groupings. Inventing a channel identity is not permitted.

## Evidence checked

- PRIDE project record and complete v3 files/all inventory (254 files: 245 RAW, 9 PD 1.4 `.msf`; all entries carry projectAccessions PXD005785).
- Paper PMC6232379 (Front Cell Neurosci 2018, PMID 30459560) full text and Europe PMC supplementary bundle: Figure S1A states only "3x iTRAQ 8plex", n=6/group, combined 1:1; Supplementary Methods (Data_Sheet_1.docx) give no channel layout; Table S3 (hippocampus) has only per-comparison ratios (no per-channel columns).
- Table S4 (CD11b+ proteome) header names channels (F1: 114 Control WT, 115 Sample WT, 116 TG, 117 TG; iTRAQ 4plex pools Wt1/Wt2/Tg1/Tg2), but no deposited RAW/msf can be assigned to the CD11b experiment (all 9 msf are configured as iTRAQ 8plex, 113-121), so even this arm cannot be tied to files.
- All 9 `.msf` files read by HTTP-range SQLite (FileInfos, ProcessingNodeParameters, WorkflowInfo): they give file-to-search groupings (highpH_1/2/3: LUM_00204-00245; hilic_1/2/3: LUM_00154-00203; highpH_hilic_1/2/3: FUS*/LUM*) and the 8plex tag list 113-121, but no sample or group names per channel. Search used Mascot/Sequest HT, Trypsin, iTRAQ8plex K/N-term, Carbamidomethyl C.
- Data availability statement cites only PRIDE; no Zenodo/figshare/GitHub layout files exist.

No deposited SDRF was used as evidence.

## Evidence needed to unblock

A submitter-provided table of iTRAQ channel (113-121) per kit versus mouse/group (Wt/Tg x PBS/LPS), plus kit/fraction assignment of each RAW file (and which RAW files belong to the CD11b+ 4plex experiment, if deposited).
