## Template choices
Human in vitro peptide rows cannot use cell-lines (cell line is required, no reserved word allowed), and the worm needs invertebrates, hence separate files. Factors: genotype (WT vs KO), recombinant CARNMT1 variant, gel region (worm; the only available variable, not a real comparison).

## Validation
- parse_sdrf validate-sdrf (--use_ols_cache_only): no errors for all four; celegans warns that strain `N2` is not in NCBITaxon.
- tools structure: OK for all; tools check: CLEAN (0 hallucinated) for all.
- reconcile: trex-gel BLOCKER cleavage_agent_contradicted for 14508/14510 (Lys-C vs PRIDE prose "trypsin"); kept, because the deposited docx (CARNMT1_MS_samples_4_PRIDE.docx) and paper state LysC for the RNF113A-GFP gel digests. Organism-part MAJOR flags (kidney for cultured cells, whole body for worm) kept deliberately, see below.
- Raw coverage: 20 of 20 .d folders, each once (names read from the 7z header by range request; sample ids match the docx and the .mgf names).

## Limitations
- Data file entries are `.d` folder names inside raw_files.7z, not separate PRIDE files. The .mgf peak lists were deliberately not used.
- Cell line: Flp-In T-REx 293 (CVCL_U427) per paper; `cell line` uses the BTO label "Flp-In-T-REx cell", Cellosaurus name/accession carry the identity. Sex female and organism part kidney come from Cellosaurus. Disease, cell type, age, medium, passage, storage: not available. KO clone (#1-#3) per sample not stated.
- Dissociation method not available (not stated; instrument model not checked against analysis.tdf).
- RNF113A-GFP rows are GFP-Trap immunoprecipitates from transfected cells; encoded in source name only.
- In vitro file: Amidated recorded as PP=Any C-term (docx: C-terminal Ile amidation). Organism Homo sapiens reflects the human-derived peptide.
- C. elegans organism part `whole body` is an assumption from whole-worm pellets; the nuclear fraction is in the source name.
- Modifications taken from the deposited docx and paper (PEAKS projects); mzid files were not parsed.
