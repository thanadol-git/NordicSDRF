# PXD009914 remaining runs

The accession has 22 deposited RAW files. `SEARCH.zip` contains eight exact MaxQuant search matches for the AdOx and untreated Chymotrypsin runs; those have a separate SDRF under review.

The other 14 runs comprise 11 Glu-C acquisitions and three Chymotrypsin acquisitions for anisomycin, cycloheximide, or 4NQO treatments. Their filenames identify the treatment, digestion, and replicate labels. The linked paper says it used both targeted and data-dependent methods for eEF1A methylation analyses, but does not map an acquisition mode to each of these 14 RAW files. The deposited search archive does not contain their search settings. A required acquisition-method value and the exact search modifications therefore remain unresolved for these runs; no values have been inferred from the eight-run search subset.

Sources: [PRIDE project record](https://www.ebi.ac.uk/pride/ws/archive/v2/projects/PXD009914), deposited `scratchpad/PXD009914/files.json` and `scratchpad/PXD009914/SEARCH.zip`, [linked paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC6109062/).
