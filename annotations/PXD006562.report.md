# PXD006562 annotation report

Extracellular matrix (ECM) of prostate tissue and of primary prostate fibroblast cultures from the same six prostate cancer patients. University of Turku. Paper: Ojalill et al., Prostate 2018 (PMID 29520855).

## Templates
`ms-proteomics`, `human` v1.1.0.

## Rows and files
There are 62 rows, one per raw file. The key is the deposited `Sample_mapping.xlsx`.
- **Tissue ECM** (`150806_PekkaR_<n>N/G-nr<k>`): normal prostate tissue, with a 0.5 M NaCl extract (`N`) and a guanidine-HCl extract (`G`) per patient. Tissue numbers map to patients as 5→P1, 8→P2, 10→P3, 3→P4, 2→P5, 12→P6. `nr<k>` is the technical replicate.
- **Fibroblast ECM** (S-numbers): decellularised ECM of fibroblasts from the cancer lobe (Ca) and the non-cancerous lobe (NC) of each patient. Repeated injections of the same culture are numbered as technical replicates.
  - P6 has two cancer-lobe cultures (`S17Rup` and `S17-INS`). Both are annotated as P6 cancer-lobe ECM under one source name.

## Values
- **Disease:** `prostate adenocarcinoma` for cancer-lobe fibroblasts; `normal` for non-cancerous-lobe fibroblasts and for the normal tissue samples.
- **Material type:** `tissue` for the tissue extracts, `cell` for the fibroblast ECM. The sample type and extraction columns record which ECM fraction each run is.
- **Instrument:** Orbitrap Velos Pro per the protocol text (PRIDE lists LTQ Orbitrap Velos). The CV accession used for Velos Pro (MS:1003096) should be checked by a maintainer. CID.
- **Search:** Proteome Discoverer 1.4 / Mascot 2.4, 5 ppm / 0.5 Da. Carbamidomethyl C fixed; Oxidation M, P and K and Acetyl protein N-term variable.
- **Age, sex, ancestry:** `not available` (sex is male by organ, but no per-patient metadata is deposited).

## Validation
- `parse_sdrf` (CI style, warnings only) and the review gate pass.
- `tools reconcile`: every annotated value agrees with the deposit record, apart from the instrument (the record says LTQ Orbitrap Velos; the protocol says Velos Pro).
