## Limitations and calls to attack in review

- Multiplexed rows of one RAW file share one assay name (the file name without extension), as the spec README requires for TMT runs; comment[label] distinguishes the channels.
- Label-free and TMT runs are in two SDRFs (PXD005074-lfq, PXD005074-tmt) because one file cannot mix label-free and TMT rows cleanly; the six LPI lanes are the same sources in both.
- The three lanes per strain come from one culture of each strain split over three flow-cell lanes (paper Fig 1), so they are annotated as separate sources with biological replicate 1; they are processing replicates, not independent cultures.
- No reduction/alkylation was done (surface shaving of live bacteria with trypsin); no cysteine modification is annotated although PRIDE lists iodoacetamide-derivatized residues.
- The label-free data were quantified with MaxQuant 1.5.0.30 (paper: variable acetyl (N-terminal) and oxidation (M), trypsin, 1 missed cleavage, 10 ppm first search); the label-free SDRF carries these modifications (Acetyl protein N-term added). The TMT SDRF follows the PRIDE Mascot settings.
