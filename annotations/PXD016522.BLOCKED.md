# PXD016522 — file series cannot be assigned to biological sources or fractions

The PRIDE file list contains 41 RAW files in A1–A14, B1–B14, E1–E11 and Off-Gel1–Off-Gel2 series. The publication and deposited protocol describe one giant squid mantle sample, four extraction buffers and gel sections, but do not map any RAW series or suffix to a specific extraction, gel section or preparation. A 41-row draft in `scratchpad/PXD016522/draft.sdrf.tsv` covers every RAW file and passes official cached-ontology, structure and offline checks. It has no hash-bound approval.

Independent review found that the draft's four source names and fraction identifiers treated unexplained filename tokens as experimental identities. It also found that "tryptic peptides" does not directly identify the digest reagent and that the evidence manifest incorrectly discounted reported de novo processing settings. The draft needs a deposited run map or equivalent explicit evidence before correction and another review. No SDRF is committed.
