# BLOCKED: PXD034351

No SDRF was produced because the current evidence does not support a complete multiplexed
sample/channel and temperature mapping.

Evidence checked:

- PRIDE project record: https://www.ebi.ac.uk/pride/archive/projects/PXD034351
- PRIDE file page: https://www.ebi.ac.uk/pride/archive/projects/PXD034351/files
- Publication: https://pubs.acs.org/doi/10.1021/acs.analchem.2c03506

The record establishes human material, ResT-PISA, TMT11/TMT16/TMT18 labelling, Orbitrap Fusion
Lumos acquisition, and RAW groups for lysate/cell and drug conditions. However, the inspected
deposit exposes RAW filenames and search parameters but no deposited SDRF or channel/sample map.
Because temperature points were pooled and multiplexed, filenames alone cannot establish which
reporter channel represents which sample, treatment, replicate, or temperature. Inventing that
mapping would make the SDRF structurally plausible but scientifically unsafe.

Validation: not applicable; no SDRF was generated.
