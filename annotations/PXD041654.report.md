# PXD041654 annotation report

## Scope

The SDRF covers all ten deposited raw archives from activated human CD4-positive T cells: five donor identifiers (D62, D69, D74, D83, and D89), each represented by A5 and G5 files.

## Evidence and decisions

- PRIDE metadata and methods identify human blood-derived activated CD4-positive T cells, tryptic FASP digestion, label-free UDSME acquisition, and the reported search modifications.
- The file names provide an exact donor and experimental-group map. `A5` and `G5` are retained verbatim as experimental-group factor values because the deposited material does not define those codes explicitly; no GABA assignment has been inferred.
- The detailed method describes a Synapt G2 Si HDMS with electrospray ionization, while PRIDE's controlled instrument metadata lists MALDI Synapt MS. The registered controlled term is used in the SDRF and the discrepancy is documented here.
