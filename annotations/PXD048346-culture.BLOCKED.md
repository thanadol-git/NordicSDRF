# PXD048346 PSB-D culture runs — annotation hold

Twelve accession-scoped `.raw` runs represent Arabidopsis PSB-D suspension-cell PUP-IT experiments. The [published Supplementary Data 2](https://static-content.springer.com/esm/art%3A10.1038%2Fs41467-025-56192-3/MediaObjects/41467_2025_56192_MOESM4_ESM.xlsx) names three mock and three dexamethasone-induced samples for each of two elutions, biotin and SDS. Exact Protein IDs and log2 LFQ values in the [deposited biotin](https://ftp.pride.ebi.ac.uk/pride/data/archive/2025/01/PXD048346/culture_biotin_search.zip) and [SDS](https://ftp.pride.ebi.ac.uk/pride/data/archive/2025/01/PXD048346/culture_sds_search.zip) MaxQuant outputs map all twelve labels to the accession's twelve B286 RAW files. The [run map](../results/denmark/PXD048346_culture_run_map.tsv) gives the one-to-one assignments and 320–869 exact protein-level matches per run.

The [paper's methods](https://pmc.ncbi.nlm.nih.gov/articles/PMC11747095/) explicitly say that **both biotin- and SDS-eluted proteins were digested with a Trypsin/LysC mix**. The active `ms-proteomics` template defines `comment[cleavage agent details]` as a single-value field. Encoding only Trypsin or only Lys-C would omit a documented digestion reagent; repeating the field conflicts with the template cardinality. No SDRF has been approved for these twelve runs. A schema-supported way to represent the mixed digest is needed before annotation can pass independent review.
