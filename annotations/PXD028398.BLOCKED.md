# PXD028398 — annotation blocked

No SDRF is emitted for this accession because the deposited evidence does not provide a complete raw-file-to-sample/design map for the heterogeneous deposit.

The fully loaded PRIDE file table exposes 187 files: 184 RAW acquisitions plus `parameters.txt`, `peptides.txt`, and `proteinGroups.txt`. The page header was inconsistent while loading (it temporarily showed 132 files / 130 RAW / 2 SEARCH before settling at 187 / 184 / 3), which is itself a manifest-quality warning. The RAW names span FITExP B16/LLC2 all-drugs, redox, PISA lysate all-drugs, PISA cell redox, and PISA lysate NADPH series, with condition, replicate, and fraction-like tokens embedded in aliases.

The linked paper establishes the broad design: mouse B16-F10 and LLC2 cells, Auranofin/TRi-1/TRi-2/DMSO treatments, expression/redox experiments with biological replicates, PISA experiments, and fractionation. It does not provide a checked, exhaustive mapping from all 184 deposited RAW files to exact source, assay, treatment, replicate, fraction, and label assignments. The deposited `parameters.txt` contains search settings (for example FDR, modifications, and match-between-runs options), not that design map; the other two deposited search outputs likewise do not substitute for a complete sample sheet.

Because the deposit combines multiple assay families, including redox data with labeling and fractionated runs, deriving one row per acquisition from aliases and aggregate publication counts would risk assigning files to the wrong sample or assay. That would violate the no-invention rule, so no SDRF is emitted.
