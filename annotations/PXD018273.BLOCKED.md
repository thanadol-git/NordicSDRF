# PXD018273 — BLOCKED

## Exact blocker

The 106 deposited files cannot be mapped to sample/condition (enrichment chemistry x binding solvent x replicate) from any deposited file or the paper:

- 48 Sciex TripleTOF 6600 acquisitions `Ignacio_A1..D12.wiff` (+ matching `.wiff.scan`) — names are plate positions only.
- 20 Q Exactive HF RAW files `QEHF2_07601..07628_IAD.raw`, `QEHF3_07300..07306_IAD.raw` — instrument run counters only.
- 2 Proteome Discoverer `.msf` files.

The design is stated only in aggregate (preprint bioRxiv 10.1101/2020.04.13.038810, Experimental design section): 36 HepG2/C3A digests (Zr-IMAC / Ti-IMAC / TiO2, Std vs optimized solvent, n=3) on the TripleTOF, and 20 samples (5 conditions incl. Fe-IMAC HPLC, n=4) on the QE HF. That is 36 or 48 wiff files against 36 samples, and no sentence or table links any file name to a condition. A file-to-condition assignment would be file-order guesswork.

## Evidence checked

- PRIDE v2 project record and complete file list (2 pages: 100 + 6 = 106 files; pages 2+ empty).
- bioRxiv preprint PDF (full text; no published JPR full text in Europe PMC): no wiff/RAW names, no mapping table, no supplementary table with file names.
- `.msf` StudyDefinition (HTTP range reads): `MagResyn_CSIR_SolventOpt.msf` names samples after converted MGF files (`Ti-IMAC_BC1_1`, `TiO2_BC5_2`, `Zr-IMAC_BC11_3`, ... 18 of them) which are not deposited and are not linked to any `Ignacio_*.wiff` name; `MagResyn_Zr-vs-Ti-vsFe-IMAC2.msf` names samples identical to the RAW file names (no condition). Neither carries a factor-value-to-file assignment.
- `.wiff` headers (A1, A12, B1): only acquisition method and path; no sample/condition names.
- PRIDE structured fields are also unreliable here (instrument TripleTOF 5600 listed; paper says 6600; no disease).

No deposited SDRF was used.

## Evidence needed to unblock

A submitter-provided run manifest (wiff / QEHF file -> chemistry, solvent, replicate) or the paper's supplementary sample table.
