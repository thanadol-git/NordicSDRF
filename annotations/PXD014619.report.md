## How the sample map was built

- `ProteomXchangeIDcodes.xlsx` (deposited) maps animal label + time point (e.g. "506 D1 P", "108Day5 p") to a RAW code 1-82. File `analysisNN[a|b].baf` carries code NN. Spot checks of the .baf header (HTTP range read, first 0.3-1 MB) agree: analysis24.baf is `Mudi24`, analysis60a.baf is `Mudi60a`; MaxQuant `summary.txt` uses the same `MudiNN` stems.
- Source name = `pig<animal>_<D1|Day5>`. Animal numbers repeat between D1 and Day5 sets, so the time point is part of the name.
- Files without suffix, `a`, `b` (and `analysis26a1`) are separate injections of one source, numbered 1..n as `comment[technical replicate]` in alphabetical order; the order is a label, not a recorded run order.

## Limitations and caveats (important)

- **Treatment group (CON vs LPS) is not recoverable.** The deposit's code sheet carries no group, the MaxQuant experiment names (RA1, GC1...) are plate/run codes, and the linked paper (Nguyen et al. 2018, Am J Pathol) is not the renal study and has no per-animal map in this record. `characteristics[disease]` is therefore `not available` and no treatment column is written; the only factor is the evidenced sampling time (`factor value[sampling time]` 1 day / 5 day). The study's intended comparison (LPS vs control) is missing from the SDRF and should be added when the authors supply the map.
- Sampling time "1 day"/"5 day" is taken from the code-sheet labels D1 / Day5 and the protocol ("d 1 and d 5"); the D1 group was euthanized right after delivery, so "1 day" is the submitter's label, not a measured age.
- Count mismatch: the code sheet lists 82 animals (58 D1, 24 Day5) and the protocol states n = 30 at birth and 12+12 at day 5. Codes 75-82 (Day5) have no deposited file; 74 sources are annotated. Several codes lack the un-suffixed or a/b injection (e.g. 25a, 31, 56b, 57a, 64-74 unsuffixed).
- Instrument: the model is not stated in the record. The `.baf` header reads "TIMS TOF" (acquisition control "Bruker otofControl", method "Proteomics Top 20 nanoonline"); the protocol says timsTOF in "tims-off" mode. The generic `Bruker Daltonics timsTOF series` (MS:1003123) was used instead of guessing Pro. The raw folder name contains "MudiCSF" while PRIDE and the protocol say plasma; plasma is used.
- Sex, strain/breed, age in days and developmental detail are not in the record. Developmental stage `neonate` is inferred from preterm pigs delivered by caesarean and sampled at birth and day 5 (preterm model, 88 percent gestation). Organism is PRIDE's Sus scrofa domesticus.
- Cleavage: trypsin per protocol (MaxQuant used Trypsin/P). Modifications are from the MaxQuant `parameters.txt`/protocol: carbamidomethyl C fixed; oxidation M and protein N-term acetyl variable. Fragment tolerance 40 ppm is MaxQuant's TOF default from `parameters.txt`; precursor tolerance and dissociation method are not stated (`not available`).
- Reduction TCEP 10 mM and chloroacetamide 50 mM come from the PRIDE sample protocol text only. Digestion was MStern PVDF membrane trypsin, 1:35, overnight; no fractionation (fraction identifier 1).
- Biological replicate is 1 for every source (each animal is its own source).
