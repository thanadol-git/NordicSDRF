# PXD040213 SDRF annotation report

## Study
"Geometric morphometrics and paleoproteomics enlighten the paleodiversity of Pongo" (Kubat et al., PLoS One 2023, PMID 38100471, PMC10723683). Paleoproteomics of dental enamel from 15 Late/Middle Pleistocene fossil Pongo teeth (Orbitrap Exploris 480, EASY-nLC 1200, 77 min DDA, digestion-free acid demineralisation protocol, StageTip desalting).

## Templates
ms-proteomics v1.1.0 + vertebrates v1.1.0 (non-human primate; no cell-line, DIA, clinical templates apply). Choice made non-interactively.

## Scope: deposited vs annotated
Deposited (24 files, all PRIDE pages read): 17 RAW, 3 MaxQuant zips, 3 FASTA, 1 README. Annotated: all 17 RAW (15 specimens + 2 lab blanks) = 17 rows x 34 columns. MaxQuant summary lists RAW files that are NOT deposited (labblank 1898 = LabBlank1; F8864 files 2089_frac1-4 and labblank 2088); these are not annotated.

## Key decisions
- Sample names from the deposited README-FileDescription.txt (file -> specimen), consistent with the paper (DU1177, ML5, SMF-8864, S2258). MaxQuant experiment names differ for some (S1128 vs README DU1128; S1177 vs DU1177; Pongo1/2/4/5/6 vs ML1/TH929/ML4/ML5/ML6; MA1838 vs TPKP-NE-128); README used, aliases listed in the manifest.
- Organism `Pongo sp.` (PRIDE NEWT 9603; paper: specimens are Pongo sp. or P. pygmaeus, proteomics cannot separate species). Organism part `tooth enamel` (paper/PRIDE BTO:0001844).
- Digestion-free protocol: cleavage agent `not applicable`; deposited MaxQuant enzyme mode Unspecific (no enzyme). No reduction/alkylation columns written (none in the protocol).
- Modifications read from deposited MaxQuant summary.txt of the final (PTM) run: Deamidated N,Q; Gln->pyro-Glu; Glu->pyro-Glu; Oxidation M,P,W; Phospho S,T; Arg->Orn (UNIMOD:372, looked up manually; search-params left it unmapped). No fixed mods (paper agrees). The initial broad search lacked Arg->Orn.
- Tolerances from paper: precursor 4.5 ppm (final search; first search 20 ppm), fragment 20 ppm (also in parameters.txt).
- HCD, NCE 30: paper and RAW method headers (read for one file in each of the 3 run groups plus 2 blanks: all Orbitrap Exploris 480, fixed normalized HCD 30%).
- Fraction identifier 1 for all: no fractionation described in the paper; MaxQuant fraction is 1 for 2040 and unset (32767) for the others. Technical replicate 1 and biological replicate 1 are placeholders (one injection per specimen).
- Lab blanks (labblank_1890, 2039): `negative control`, organism/part/disease/stage/sex `not applicable`; README says "Blank control". Whether they are extraction blanks or wash/solvent blanks is not stated, so no preparation reagents and no `buffer control` claim.
- Factor value[sample type] (study sample vs negative control) is the only supportable contrast; the paper's comparison of fossil taxa/sites is not given per file. Site per specimen is stated in the paper only for a few (SMF-8864 Sangiran, ML5 Tam Hay Marklot, S2258 Niah, DU1177 Duoi U'Oi); no site column written.
- tissue mass 25 mg: paper says approximately 25 mg enamel per specimen.

## Values not available / not applicable
developmental stage, sex, disease for specimens `not available` (teeth include deciduous and permanent; not per specimen). Blanks: `not applicable`. Acquisition dates not written (optional).

## Conflicts
- PRIDE organism "Pongo sp." vs paper species attributions: kept Pongo sp.
- MaxQuant experiment names vs README names (above).
- reconcile BLOCKER cleavage_agent_unsupported is a false positive: `not applicable` is the intended value for a digestion-free protocol.

## Inferred vs stated
Stated: instrument, HCD/NCE, tolerances, modifications (deposited summary), digestion-free, 25 mg. Inferred: fraction 1, replicates 1, factor choice, `not applicable` for blank metadata.
