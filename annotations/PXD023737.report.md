# PXD023737 annotation report

Mouse small-intestinal mini-gut organoids grown in crypt-like (ENRC) or villus-like (ENRI) medium: cellular proteome and secretome. University of Turku. Paper: Moulder et al., Front Mol Biosci 2024 (PMC11387180).

PXD025690 contains the same 46 raw files; both accessions get identical SDRFs.

## Templates
`ms-proteomics`, `vertebrates` v1.1.0.

## Rows and files
There are 46 rows. Groups come from the deposited MaxQuant summaries (`summary.txt`, `summary_SEC.txt`, `summaryV.txt`).
- **Cells:** `170407_ENR[C|I]<n>_400ng_<t>` is 3 biological replicates × 3 injections. The two `170410_..._400ng_2` files are later re-injections and are annotated as technical replicate 4.
- **Secretome (culture supernatant):** `170104_ENR[C|I]_<1|2|NC>_<t>_Sec` is 2 biological replicates × 3 injections. The two pooled supernatant runs are one pooled sample with technical replicates 1–2.
- **Velos runs:** `161229_..._SecVel3` are single earlier runs of the same supernatants on an Orbitrap Velos Pro. They are annotated as technical replicate 4 of each secretome sample.

## Inferences to check
- **`NC`:** read as a no-cell medium control (ENRC or ENRI medium incubated without organoids). The paper's filtering mentions "either media", but the code is not defined.
- **Velos dissociation:** set to CID. The method is not described for these runs.

## Values
- **Cell type:** intestinal epithelial cell. Material is `cell`, and the cellular component separates cells from secretome. Strain, age and sex are `not available`.
- **Instrument:** Q Exactive HF for the 2017 runs and Orbitrap Velos Pro for the 2016 runs, per the raw headers. PRIDE lists only Q Exactive.
- **Search:** MaxQuant 1.5.5.1. Carbamidomethyl C fixed; Oxidation M and Acetyl protein N-term variable.

## Validation
- `parse_sdrf` (CI style, warnings only) and the review gate pass.
- `tools reconcile`: one finding, kept as annotated: `instrument_contradicted` flags the six 2016 `SecVel3` runs, whose raw headers say Orbitrap Velos Pro.
