# PXD074049 SDRF annotation report

## Study
"Recombinant dimeric PICK1 protein inhibitors for long-term relief of chronic pain by AAV therapeutics" (Noes-Holt et al., Cell Rep Med 2026, doi:10.1016/j.xcrm.2026.102800, PMC13293952). Global (non-phospho) TMTpro 32-plex proteome of mouse L3-L5 dorsal root ganglia from male spared-nerve-injury (SNI) mice, 73-74 days after intrathecal AAV8-Di-C5 or AAV8-tdTomato; ipsilateral and contralateral DRGs per mouse. Orbitrap Ascend, RTS-MS3, 16 high-pH fractions. The companion phosphoproteome is PXD073925 (not annotated here). Not in community corpus.

## Templates
ms-proteomics v1.1.0 + vertebrates v1.1.0 (MS; mouse). No clinical/oncology/cell-line template: animal model, no patient data.

## Scope: deposited vs annotated
Deposited: 16 RAW (Fr1-Fr16), 16 RTS search TSVs, experimental_design_Global.tsv, PD_output.zip (19.6 GB; Proteome Discoverer 3.2 results). Annotated: all 16 RAW x 32 channels = 512 rows x 39 columns (16 sources x 2 technical replicates). Not annotated: search outputs.

## Key decisions
- Channel map: taken from the deposited experimental_design_Global.tsv (32 channels, each with group and replicate). Fraction number: taken from the `_FrN` token of each RAW file name (Fr1-Fr16); the paper confirms 16 HpH fractions. Neither is a guess.
- Labels: 16 regular (TMT126 ... TMT134N, technical replicate 1) and 16 deuterated TMTpro (TMT127D ... TMT135ND, technical replicate 2), written as NT=;AC=PRIDE (accessions as used in sibling annotation PXD073925).
- Tooling workaround: `sdrf-tools build` rejects the deuterated channel names (its channel regex has no D suffix). The regular and deuterated halves were therefore built in two passes (deuterated channels given placeholder regular labels), then merged by a script that replaced comment[label] and the suffix of assay name with the real deuterated label via a recorded one-to-one map (scratchpad phmap.json). No other cell was edited by hand.
- Sources: 16 (GCN4/tdT x ipsi/contra x replicates 1-4). The paper states that each deposit comprises two technical replicates, one with deuterated and one with non-deuterated labels; each D_<group> n channel is therefore the same source as <group> n, with comment[technical replicate]=2 (non-D = 1). The pairing is by index in the design file (D_<group> n with <group> n) and is not traced to a per-channel statement. PRIDE's protocol text instead says one sample carried both label types for normalisation: unresolved discrepancy, paper followed.
- Group names: tdT = AAV8-tdTomato control; GCN4 = AAV8-Di-C5 (inferred, see below). ipsi/contra = DRGs ipsilateral/contralateral to the SNI.
- factor value[treatment] and factor value[laterality]; treatment also in characteristics[treatment].
- Disease: neuropathic pain (all mice are SNI; no sham arm in this design file).
- Dissociation: CID (MS:1000133) with ion-trap MS2 (PSM table Activation Type = CID, paper "CID activation type"); quantitation in HCD MS3 (not encoded; single-valued column). Collision energy 34 NCE (paper, MS2).
- Tolerances 10 ppm / 0.6 Da: Sequest HT node of the deposited PD analysis (P59_R1634_Final_analysis.pdAnalysis). The paper's 20 ppm is the reporter integration tolerance (11 ppm in the analysis file), not used.
- Modifications from the pdAnalysis Sequest node: Carbamidomethyl C fixed; Oxidation M, Phospho STY, TMTpro K and N-term variable (matches paper wording). The Phospho search is in the same PD workflow although this is the global dataset.
- Cleavage agent Trypsin (PD "Trypsin (Full)"; paper digest used Trypsin plus Lys-C, which a single-valued column cannot hold).
- Reduction TCEP, alkylation chloroacetamide (paper), though PD names the fixed mod Carbamidomethyl.

## Values left not available / not applicable
developmental stage = not available (animals 7-12 weeks when ordered, age at sacrifice not stated). strain or breed = not available (paper lists C57BL/6NRj, C57BL/6JRj and C57BL/6JBomTac, and writes c57BL6/J for this cohort). Sampling time column omitted: the paper gives 73-74 days after i.t. injection (methods) and 84-85 days post-SNI (results), both ranges, not a single number + unit. No characteristics column for laterality exists in the templates; it is carried by factor value[laterality] only.

## Conflicts
- PRIDE structured fields list disease "B-cell adult acute lymphocytic leukemia" and tissue "spinal ganglion": the disease is wrong for this study (submitter dropdown) and ignored; tissue agrees with the paper.
- reconcile flagged (a) cleavage agent not named in the PRIDE record: the PRIDE protocol omits the enzyme; paper and PD parameters support Trypsin (false positive); (b) organism part "Recombinant": triggered by the title word, tissue is native DRG (false positive).
- The paper's methods describe non-deuterated reagents for the analysed samples (deuterated replicate not retained for analysis) while the deposit contains both; PRIDE's protocol text describes the deuterated label differently (see Sources).
- PRIDE's structured disease (B-cell adult acute lymphocytic leukemia) is overridden by neuropathic pain; contralateral DRGs are also labelled neuropathic pain because all mice had SNI (the contralateral side is the intact side of an SNI mouse).

## Inferred vs stated
Stated (deposit/paper): channel map, group names, fraction numbers, instrument, tolerances, modifications, male, strain, tissue, fractionation, NCE.
Inferred: GCN4 group = AAV8-Di-C5 treatment (paper says the pain-model mice received AAV8-Di-C5 or AAV8-tdTomato and GCN4-based peptides are the inhibitors; the deposit only says GCN4); pairing of D_ and non-D channels by index; all mice SNI and male (paper states the TMT mice were male SNI); DDA acquisition; material type tissue; sample type study sample.
