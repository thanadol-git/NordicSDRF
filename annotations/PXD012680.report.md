## Limitations and calls to attack in review

- The pulldown/IP bait is recorded in a custom column characteristics[bait] (with factor value[bait]); characteristics[enrichment process] is not used because it takes PTM/peptide-enrichment terms (EFO:0009090).
- Which GST-FET-NTD bait (FUS, EWSR1 or TAF15) each Study-1 gel band came from is not stated in the deposit; the bands are annotated as 'GST-FET-NTD pulldown, gel band N'.
- The assignment of Fusion_151126_15 (project 2205) to MLS 402-91 is by elimination (PRIDE: four cell lines; 2334 names the other three) and agrees with the BRG1 peptide counts in Table EV2.
- Dissociation is CID on every row: the paper states CID in the linear trap for Study 1 and ion-trap CID (collision energy 30) for Studies 2–3. For Study 4 the paper says Q Exactive HF with HCD, but the deposited RAW file Fusion_170926_34 is an Orbitrap Fusion run (RAW header and the .msf name) acquired with the method '300nlmin_Peptide ID IT CID', so Orbitrap Fusion / CID is annotated from the data file itself.
- PRIDE and the paper list a Q Exactive HF (Study 4, 200 mmu fragment tolerance), but no Q Exactive HF RAW file is deposited; the Study 4 file is an Orbitrap Fusion run, and the 0.5 Da fragment tolerance of the Fusion/FT data is annotated.
- Reduction/alkylation for the in-gel Study 1 samples is not described ('not available'); propionamide is the acrylamide adduct from the gel.
- Each run is a single IP or band; biological replicate is 1 for every row.
