## Templates

`ms-proteomics` v1.1.0 + `vertebrates` v1.1.0. Mouse brain tissue, label-free DDA on an Orbitrap Elite with CID and ion-trap MS2.

The deposit was split from the TMT arm because label, dissociation, MS2 analyzer, fragment tolerance and modifications differ.

## Design and file mapping

- **Individual mice: 38 rows, one per run.** Every run file `20150910_Peli1_<day>-<KO|WT><n>.raw` is mapped by its name to source `LF <KO|WT> <day> dpi mouse <n>`. Two names lack the hyphen or carry a timestamp: `20KO1` and `10-KO1_150912212641`. Group sizes are KO and WT, 5/7/7 at days 0/10/20, matching Supplementary Methods. The deposited Progenesis exports (`LF_data` sheet of the statistics workbook and `LF_Peptides.csv`) group exactly these runs under 0KO...20WT.
- **Reference pool: 26 rows.** The pool contains all 38 lysates and was prepared as 4 aliquots (REF1-REF4). Each aliquot was injected several times, each injection restricted to one of 12 precursor m/z selection windows (300-460 ... 1000-2000 m/z), and every run's survey scan still covers 300-2000 m/z. It is encoded as one source, `LF reference pool of all 38 mice`, with technical replicates 1-26 in sorted file order. The window is visible only in the file/assay name. The methods describe 24 runs; 26 are deposited (two re-runs, REF1_500-560 and REF2_300-460), and all 26 appear in the Progenesis export.
- Factor values are `factor value[genotype]` (Peli1 knockout / wild type) and `factor value[sampling time]` (0 / 10 / 20 day). Both are `not applicable` for the reference pool.
- Biological replicate is the mouse number within its condition (1-7); the reference uses `pooled`.

  - Round 1: 0 errors, 2 warnings. One was the instrument label, fixed to `Orbitrap Elite` (`MS:1001910`, checked in live OLS).
  - Round 2: 0 errors, 1 warning: `C57BL/6 x 129/Sv` in `characteristics[strain or breed]` is not in NCBITaxon. The column is free text; this is a mixed background.

  - `cleavage_agent_unsupported`: trypsin digestion is stated in the paper's FASP step.
  - `labelled_annotated_as_label_free`: the project registers both TMT and MS1 label-free quantification, and this file is the label-free arm.

## Limitations

- **No link to TMT pools.** The individual mice cannot be linked to the TMT pool sources, because pool membership is not deposited.
- **Sex, age, developmental stage.** Not reported per mouse (only "age- and sex-matched"); sex and developmental stage are `not available`.
- **Organism part.** Encoded as `cerebral hemisphere`; the tissue was the frontal part of the right hemisphere.
- **Disease.** `normal` at day 0 (before immunization) and `experimental autoimmune encephalomyelitis` (MONDO:0005134) at 10/20 dpi. The PRIDE entry "multiple sclerosis" was not used; the reference pool is `not applicable`.
- **Precursor windows.** The reference runs' precursor m/z selection windows have no SDRF column; they are in the file name only.
- **Search settings.** These come from the protocol text: Carbamidomethyl C fixed, Oxidation M variable, 10 ppm precursor (inherited "as for the TMT"), 0.7 Da fragment. No search parameter file was deposited. The search was run on a Progenesis-exported mgf; the SDRF lists the vendor raw files.
- **Alkylation reagent.** Not stated, so the column is omitted. `characteristics[genotype]` is an extra column outside the two templates.
