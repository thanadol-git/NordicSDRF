## Conservative choices

- **Cell line:** `python3 -m tools cellline lookup` found no Cellosaurus hit for MEF / mouse embryonic fibroblast. `characteristics[cell type]` is `embryonic fibroblast` (CL:2000042). `characteristics[cell line]` uses the class-level EFO label `MEF cell line` (EFO:0004037); `characteristics[cellosaurus accession]` and `[cellosaurus name]` are `not available`. No invented CVCL ids.
- **Sex / age / strain:** omitted. C57BL/6N in the paper is the expression-analysis mouse cohort, not evidenced for these MEF clones.
- **Developmental stage:** `embryo` (vertebrates example term) from 10.5 dpc MEFs. Not narrowed to a Theiler stage.
- **Organism part:** `embryo` as tissue of origin. The measured analyte is pepsin-extracted medium collagen, not a dissected organ.
- **Disease:** `normal` (non-disease-derived MEFs; the study is enzyme function, not a disease model).
- **Cleavage:** wet-lab used trypsin-LysC mix (Promega); search is trypsin-like. `comment[cleavage agent details]` is single-cardinality, so only `NT=Trypsin;AC=MS:1001251`. Lys-C is not given its own cell.
- **Modifications:** from the PRIDE data-processing protocol / manuscript search settings (no deposited `mqpar`/`msf` opened). One variable Oxidation `UNIMOD:35` with `TA=M,K,P` as searched; not rewritten as Hydroxyproline `UNIMOD:267`.
- **Reduction/alkylation reagents:** omitted. The protocol says the samples were alkylated (Shevchenko 2006, trypsin-LysC exception) but does not name DTT/IAA in this text.
- **Culture medium:** DMEM (`Dulbecco's Modified Eagle Medium`, NCIT:C185409) from the MEF culture methods. Collagen harvest replaced FBS with Panexin CD; the basal medium is still DMEM.
