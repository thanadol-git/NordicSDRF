# PXD065899 annotation report

Plate-method secretome of the keratinolytic fungus *Onygena corvina* grown on casein, feather meal or wool meal and sampled after 1, 2 and 3 days. NMBU, Ås. Paper: Appl Environ Microbiol 2025, PMC12724343 (open access).

## Templates
`ms-proteomics` v1.1.0.

## Rows and files
There are 27 rows: 3 substrates × 3 days × 3 plates.
- **Raw files:** the raw data is one `Siddhi_finaldata.tar.gz`. `comment[data file]` uses the 27 `.d` folder names from the deposited FragPipe manifest.
- **Name codes:** `CD<day>_<rep>` = casein, `WD<day>_<rep>` = wool meal, `FD1_<rep>` = feather meal day 1 and `F3<rep>` = feather meal day 3.
- **Please check:** the remaining feather set is labelled `FD15_<rep>`. The paper samples only at 1, 2 and 3 days, so it is annotated as feather meal day 2.

## Values
- **Sample:** organism `Onygena corvina`; secreted proteins (`extracellular region`).
- **Factors:** `growth substrate` and `time`.
- **Instrument:** timsTOF Pro (record and paper).
- **Search:** FragPipe 20.0 / MSFragger LFQ-MBR. The record does not give modifications, so the FragPipe LFQ-MBR defaults are encoded: Carbamidomethyl C fixed; Oxidation M and Acetyl protein N-term variable.

## Validation
- `parse_sdrf` (CI style, warnings only) and the review gate pass.
- `tools reconcile`: every annotated value agrees with the deposit record.
