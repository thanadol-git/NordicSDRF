# PXD024487 — annotation blocked

## Dataset

- **Title:** SPIN - Species by Proteome INvestigation
- **PRIDE record:** PXD024487
- **Publication:** Nat Commun 2022 (PMID 35513387)

## Evidence recovered

1312 RAW (Exploris 480 / QE, Evosep; DDA and DIA) in ~177 file-name patterns: archaeological bones of unknown species (Salpetermosen, FW plates, ID-numbered samples), reference bones of known species, species-specific high-pH spectral libraries, and method-optimisation runs (demineralisation, gradients, fractionation); ~356 non-RAW files (per-sample SPIN result .txt, libraries, FASTA).

## Why no SDRF was emitted

For most runs the source organism is the unknown being determined (SPIN species calls live in the paper supplement and per-run result files, not in a run -> sample table), so characteristics[organism] cannot be filled from the record. The many method-optimisation series also lack a deposited description of each code (e.g. FW plate/well codes, ID numbers, FrcOpt variants).

## Sources checked

PRIDE record and protocols; RAW file-name patterns.

## Unblocking requirement

A run -> sample table with the SPIN species assignment (or archaeological context) per bone, and a key to the method-optimisation codes. A partial SDRF of only the reference-species library and known-bone runs is possible on request.
