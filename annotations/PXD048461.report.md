# PXD048461 annotation report

Status: ANNOTATED. Independent review status: SEE "Review" section at the end (updated after each round).

## Study
Enamel sexing of mammoth from Kostenki (PRIDE title). Woolly mammoth (Mammuthus primigenius) enamel powders from 21 specimens of Kostenki 11-Ia (Russia), sexed palaeoproteomically by AMELX/AMELY peptides, LC-MS/MS on Evosep One + Orbitrap Exploris 480, DDA, MaxQuant 2.1.3.0 unspecific search. Submitter L. Le Meillour / F. Welker. PRIDE cites doi 10.1016/j.qeh.2024.100049 (Quaternary Environments and Humans), which is not open for reading here; the bioRxiv preprint of the same work (10.1101/2024.06.14.598638, "Ancient biomolecular analysis of 39 mammoth individuals from Kostenki 11-Ia") and its supplementary Table S3 were used.

## Templates
`ms-proteomics v1.1.0` + `vertebrates v1.1.0`. MS technology; the organism is a non-human mammal and no organism-specific template exists (vertebrates is the mammal template). No cell-lines, clinical, or dia template: bulk fossil tissue, DDA, no patients. Not annotated as `metaproteomics`.

## Scope (deposited vs annotated)
22 raw files deposited, 22 annotated (21 mammoth specimens + 1 extraction blank P0533). Non-raw files (mqpar.xml, MQtxt.zip, Sample_to_data_Kostenki.txt) are search/metadata files and have no rows. No files excluded. 22 rows x 38 columns.

## Key decisions
- File to sample: Sample_to_data_Kostenki.txt (deposited) maps P0491-P0532 to CGG_1_0182xx specimen IDs; P0533 = Extraction blank. Source names are the CGG IDs; the blank is "Extraction blank".
- Sex (characteristics[sex] and factor value[sex]): from preprint Table S3 "Biomolecular sex" for the 21 specimens flagged Proteomic analysis = Y: 5 female, 8 male, 8 N/A (-> `not available`). Six are genetically sexed (3 F, 3 M; matches the paper's "three male and three female"), the rest are confident proteomic calls (5 M, 2 F). The paper's 4 "possible" calls (below peptide thresholds) appear as N/A in Table S3 and are therefore `not available` here; this is conservative and is not independently derivable per specimen. Cross-check: mqpar experiment names carry _F (P0491, P0492, P0517) and _M (P0514, P0525, P0529), identical to Table S3. Sex is the compared variable, so it is the single factor value. The blank gets `not applicable`.
- Organism part `enamel` (UBERON:0001752); PRIDE gives BTO tooth enamel. Cell type, disease, strain: `not applicable` (acellular mineralised tissue; fossil; wild population). Developmental stage `not available` (paper: age/size of individuals unknown, adults and juveniles possible).
- Blank: sample type `negative control`, organism/organ part/sex etc. `not applicable`; keeps a row because the file exists and is a legitimate run.
- Cleavage agent: `unspecific cleavage` (MS:1001956). Sample prep is acid demineralisation with no protease; MaxQuant search is unspecific (enzymeMode 4, no enzymes). `sdrf-tools reconcile` raises a BLOCKER (cleavage_agent_unsupported) because the PRIDE text says "unspecific digestion" rather than naming a reagent; this is a false positive, since the term is a no-enzyme descriptor, not a reagent matched on a keyword.
- Modifications: from mqpar.xml only: variable Deamidated (N,Q), Phospho (S,T,Y), Oxidation (M,P); no fixed modifications. Reduction and alkylation reagents are `not available` (unstated in Methods; search declares no fixed Carbamidomethyl).
- Tolerances: precursor 4.5 ppm (mainSearchTol), fragment 20 ppm (FTMS MatchTolerance). Instrument, HCD 30% NCE, orbitrap MS2 (15,000 resolution), MS1 350-1400 m/z, first MS2 m/z 120 from Methods; PRIDE instrument agrees.
- LC method (Evosep 60SPD) not written: no suitable column (elution conditions is for MHC elution).
- Acquisition date was not written (only inferable from file-name prefix).

## Inferred vs stated
Stated: all values above with their sources. Inferred: `material type = tissue`; `sample type = study sample` / `negative control` role labels; `collision energy 30% NCE` reads "HCD set at 30%" as normalised CE. Not verified from raw files: instrument (raw headers not read; PRIDE field and Methods agree).

## Validation
- `parse_sdrf validate-sdrf -t ms-proteomics -t vertebrates`: "Everything seems to be fine".
- `sdrf-tools structure`: OK. `sdrf-tools check --offline`: clean.
- `sdrf-tools reconcile`: 1 BLOCKER (the false positive above).
