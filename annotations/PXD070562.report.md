## Limitations and judgement calls
- Meaning of C1, C4, NE is not stated in the deposit. Kept verbatim. NE is presumably plain nuclear extract (no pull-down) and C1/C4 presumably two catTFRE pull-down constructs/conditions; the protocol mentions a control plasmid with fewer TFBS, but which label is the control is not verified. Paper (doi 10.1016/j.jmb.2026.169959) full text was not read (paywalled/embargoed).
- Acquisition method DDA is inferred (timsTOF Pro, PEAKS DDA-style search, .mgf peak lists); not stated, and RAW .d.zip metadata (analysis.tdf) was not inspected. Dissociation method set to not available.
- Age and sex are Cellosaurus donor values (HOS 13Y female, MG-63 14Y male, U2OS 15Y female), not from the deposit. Cell line written as MG63 for MG-63 because the validator ontology lists do not resolve "MG-63"; Cellosaurus name column keeps MG-63.
- Cell type not available; organism part "bone" from Cellosaurus tissue. PRIDE sample attributes say "cell culture / malignant cell".
- Modifications: only fixed carbamidomethylation (stated); PEAKS variable modifications are not stated (PRIDE says no PTMs; "max PTMs 2"). Missed cleavages 1 not captured in a column.
- Digestion details, reduction/alkylation reagents, passage, medium, storage temperature not stated; omitted or not available.
- Data files are the deposited .d.zip archives (Bruker .d); .mgf and xlsx not listed as data files. Search results are an xlsx table, not parsable by search-params.
