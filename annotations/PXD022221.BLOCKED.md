# PXD022221 — annotation blocked

## Reason

This Uppsala mouse-brain deposit provides 42 MGF peak-list files, with
filenames limited to C, H, and R sample codes. The project protocol describes
three brain regions and two treatment arms, but no deposited sample sheet,
experimental-design file, or filename-to-region/treatment mapping identifies
which individual files belong to each group. There are no RAW files in the
public manifest.

Assigning C/H/R to biological conditions from initials would be an inference,
not a supported mapping. A sample manifest that links each MGF code to animal,
brain region, and treatment is needed before an SDRF can be made.
