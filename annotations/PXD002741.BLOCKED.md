# PXD002741 annotation blocked

Status: blocked; no SDRF emitted. Checked 2026-10-24/25. No existing annotation in sdrf-annotated-datasets (Step 0.5).

PXD002741 ("Quantitative Proteomics Reveals Metabolic Reprogramming during ETHE1 Deficiency, Part 1", Palmfeldt lab, Aarhus; Sahebekhtiari et al., Proteomics 2016, PMID 26867521) is an iTRAQ 8-plex study of control vs ETHE1-deficient mouse liver (Triton X-114 supernatant fraction, IEF into 12 fractions, LTQ Orbitrap, 26 Thermo RAW files named `JP18-3-1..12` and `JP18-3-excl-1..12`). Everything else is recoverable (Mus musculus, liver, LTQ Orbitrap, trypsin, iTRAQ8plex K/N-term fixed, Methylthio C fixed, Oxidation M variable, 5 ppm / 0.5 Da from the deposited PD/Mascot parameters), but the iTRAQ channel-to-sample map (which of channels 113-121 are control vs ETHE1-/- mice, how many animals, whether all 8 channels are used) is not available:

- The PRIDE project text and PRIDE-XML/mzTab (generated from the PD `.msf`) contain only the quantification method definition, no channel labels or sample names. A single sample, "iTRAQ, supernatant fraction", is declared.
- The paper is not open access (PMC id absent; Europe PMC `isOpenAccess=N`; Wiley PDF returns 403; Unpaywall lists only the publisher PDF). No supplementary or repository copy was reachable. PXD002742 (Part 2, membrane fraction) has the same generic text.
- The meaning of the `excl` runs (apparently an exclusion-list re-acquisition of the same 12 fractions) is also only inferred from file names.

Per the sdrf-annotate channel-map rule, inventing channel identity is not allowed, so no SDRF is written.
