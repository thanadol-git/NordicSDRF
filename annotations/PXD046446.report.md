# PXD046446 annotation report

## Scope

All 99 deposited RAW files are represented, with six TMT6plex reporter-channel rows per file (594 SDRF rows). The 60 biological samples span MCF-7 and T-47D cells, wild-type and ESR1 Y537S genotypes, full-medium controls, DMSO vehicle, estradiol treatment, and 6-hour or 24-hour harvests.

## Evidence and mapping

- The deposited `TMT6plex.pools.xlsx` provides the complete sample-to-pool and sample-to-channel map for pools 1-10.
- Small byte-range reads of every deposited RAW header recovered the author-entered pool and fraction labels (for example, `Pool.3_UNB` and `Pool.3.PHOSPHO_F4`), establishing the RAW-to-pool map without using file order.
- The publication methods support the Q Exactive HF-X, DDA/HCD acquisition, TMT6plex labelling, trypsin digestion, TCEP/iodoacetamide preparation, and search modifications. Phosphorylation is present only on RAW files whose embedded labels identify phosphoproteome fractions.
- Cellosaurus identities are MCF-7 (`CVCL_0031`) and T-47D (`CVCL_0553`).
- Evidence manifest: `annotations/PXD046446.evidence.json`.
