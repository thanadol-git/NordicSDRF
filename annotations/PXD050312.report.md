## Decisions and limitations

- Two-protease request not applicable: samples were not digested for MS. Hydrolysis proteases (Alcalase, Trypsin, Flavourzyme) are encoded as `factor value[enzyme combination]`; cleavage agent is `unspecific cleavage` (MS:1001956), matching the MaxQuant unspecific search. Alcalase and Flavourzyme have no PSI-MS term.
- Only 7 of the 8 samples described (6 fractions + 2 unfractionated) have a RAW: TF_1 (TF <1 kDa) is not deposited.
- Mapping of file suffix to membrane cut-off (1 = <1 kDa, 1-3, 3-5 kDa, unf = unfractionated) is inferred from the file names and the methods. Four hydrolysis replicates were pooled before fractionation, so one biological replicate, one injection each. `pooled sample` is not available (merge of replicates not clearly equal to a pooled sample).
- Organism part, developmental stage, strain, growth condition, material type: `not available`. PRIDE organism part (root) is not corroborated; source is potato protein concentrate (likely tuber juice but not stated).
- Precursor tolerance `not available`; HCD inferred from deposited file names (allSpectra.HCD.FTMS). Instrument confirmed by RAW header.
- Modifications from summary.txt: Carbamidomethyl (fixed), Oxidation M and protein N-term Acetyl (variable). Paper full text was not read.
- Factor value columns are custom (not in the template); the validator accepted them.
