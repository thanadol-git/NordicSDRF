The archive filename is claimed as data file, the .d run name as assay name.
- Four hemispheres were measured together on one slide in one run; per-animal data cannot be separated, so there is one row with biological replicate 1 as a placeholder and genotype recorded as mixed. Positions of the hemispheres on the slide are not mapped in the deposit.
- Sex and disease are not available; developmental stage is not available (only an age of 100 days is stated, not an EFO stage). The non-APPtg animals' genotype is not stated and is not assumed to be wild type.
- The deposited annotation_file_mock.txt only states that no lipid annotation was done; the dataset is for developing a data processing pipeline (MSI-visual).
