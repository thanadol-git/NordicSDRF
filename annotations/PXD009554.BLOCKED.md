# PXD009554 BLOCKED: no TMT channel-to-sample map

Status: blocked annotation; no SDRF produced. Independent review not applicable.

## Dataset
Aarhus University (Palmfeldt lab). "Major metabolic pathway alterations in the rat myocardium during development of Type 2 diabetes mellitus, part 1". Zucker diabetic fatty rat (ZDF fa/fa vs fa/+ lean controls) heart, 6/12/24 weeks; this deposit contains the 12-week validation set only. TMT10-plex, SCX/IEF fractionation, Q Exactive (Plus) (PRIDE field says Q Exactive), PD 2.1 + Mascot. Paper: Edhager et al., J Proteome Res 2018, PMID 29847139, DOI 10.1021/acs.jproteome.8b00276.

## Why it cannot be annotated
The file list gives 22 RAW files (`1703-Aved-RHP-test-3`, `1731-Aved-RHP-test-3newCE`, `1746..1764-Aved-RHP-12W-1..10`, `1786..1806-Aved-RHP-12W-Excl-1..10`), i.e. one TMT10 plex whose ten channels (126..131) each need a sample identity (genotype fa/fa vs fa/+, animal). No source gives that mapping. Ladder checked:
1. Paper: closed access (Europe PMC no PMCID, Unpaywall `closed`, ACS HTTP 403); abstract has no map.
2. Deposited files: read the 8.4 GB `Validation-12weeks-Merged-22files.msf` via HTTP range reads (SQLite over apsw VFS, about 100 MB transferred). `Workflows` quantification method `TMT10-plex-Aved-RHP-valid-12w-correction-factors` has only tag names/correction factors, no sample names. Remaining files are `F00572x.mgf` peak lists.
3. Sibling records PXD009538 / PXD009555: same generic protocol, no channel map. BioSamples text hit for the accession is a human, unrelated sample.
Assigning fa/fa vs fa/+ to channels would be invention (worst failure per the skill), so no SDRF was written.

## Verified technical facts (for a future annotation once the map is found)
From the deposited .msf (Mascot node): enzyme Trypsin, up to 2 missed cleavages; precursor tolerance 10 ppm; fragment tolerance 20 mmu; fixed Carbamidomethyl (C, UNIMOD:4), fixed TMT6plex on K and any N-term (UNIMOD:737; TMT10 uses same mass); variable Oxidation (M, UNIMOD:35). Single protease (no Lys-C), so one cleavage-agent column. Fractions: 12W-1..10 are a 10-fraction series and "Excl" 1..10 appear to be exclusion-list re-injections of fractions (inferred from names, not verified). Instrument model not range-read from RAW headers. Possible unblock: author contact (ave@clin.au.dk, johan.palmfeldt@clin.au.dk) or the paper's supplementary table.
