How the mapping was established:
- Construct per run: Supplementary Data 1 (MOESM4) column headers name the construct and MaxQuant raw file, e.g. "iBAQ NAA15-T406Y-V5 Rep1 (Raw file: 6_NMC_1)". Exp1 deposited names were renamed by appending the construct (e.g. `6_NMC_1` → `6_NMC_1_T406Ya`); the RAW header original path confirms each rename. Exp2 and Exp3 names also carry the construct.
- Same-sample injections: RAW headers show each Exp1/Exp2 pair was injected from the same autosampler vial, so a/b (or `_1`/`_2`) are repeat injections of one IP digest, not separate IPs. Supplementary Data 1 calls them "Rep1/Rep2"; Source Data reduces each experiment to one value per construct, consistent with that reading.
- Technical replicate numbers follow the injection suffix (a = 1, b = 2; `_1` = 1, `_2` = 2). Exp1 WT has a single deposited injection (`5_NMC_2`), numbered 1.

## Technical values
- Instrument: Q Exactive HF (MS:1002523) from all 14 RAW headers ("Q Exactive HF - Orbitrap MS") and the paper. PRIDE's structured field says "Q Exactive" (MS:1001911); overridden.
- DDA (PRIDE:0000627), HCD (MS:1000422): paper ("data-dependent mode", top 12, NCE 28%) and RAW method names (`...TOP12HCD...` Exp1/Exp3, `...TOP15HCD...` Exp2).
- Trypsin (MS:1001251): paper (FASP, Promega sequencing-grade trypsin); MaxQuant summary.txt Enzyme = Trypsin, Specific, for every run.
- Modifications from MaxQuant 1.6.2.6 summary.txt (all three searches, every run): Carbamidomethyl (C) fixed; Oxidation (M) and Acetyl (Protein N-term) variable. Read by HTTP range read of the ZIP members.
- Fragment tolerance 20 ppm: parameters.txt "MS/MS tol. (FTMS)" in all three searches.
- Reduction DTT (PRIDE:0000608), alkylation iodoacetamide (PRIDE:0000599): paper/PRIDE sample protocol.
- Unfractionated: `comment[fraction identifier]` = 1 for every run.

## Limitations
- Not deposited: the Exp2 MaxQuant search also includes `1_Ctrl-a` and `1_Ctrl-b` (control IPs), but those RAW files are not in the deposit, so they are not annotated. The Exp1 WT run is `5_NMC_2` (by name a second injection); no `5_NMC_1` is deposited or searched.
- Technical-replicate reading (inference from RAW headers): a/b pairs share a vial, so they are treated as repeat injections of one IP. The paper does not say this explicitly. In Exp2 the a and b injections used different instrument methods (`07b_ES803_AGC_TOP15HCD_60K-15K_2mmSH...` vs `07a_..._1mmSH...`); this is not captured in a column.
- MS method differences: the paper describes one method (top 12, MS1 120k, MS2 15k, m/z 375-1500, NCE 28%), but Exp2 RAW method names say TOP15 60K-15K. Scan range, resolution and collision energy are therefore not written. DDA and HCD hold for all runs.
- Precursor mass tolerance `not available`: not in the deposited parameters.txt; the paper says only "all other parameters were set to default values".
- Cell-line donor values are from Cellosaurus CVCL_0030, not from the paper: organism part uterine cervix, disease cervical adenocarcinoma (Cellosaurus NCIt C27677 "HPV-related endocervical adenocarcinoma" mapped to MONDO:0005153), age 30Y6M, sex female. Cell type `epithelial cell` comes from the sdrf-tools curated cell-line table (the Cellosaurus JSON has no cell-type field).
- Ancestry `not available`: Cellosaurus genome ancestry is admixed (African 64.7%, European ~32%), so no single HANCESTRO category applies.
- Passage number and culture medium `not available`: not stated in the paper. Biorepository `ATCC CCL-2` is from the paper.
- The V5 co-immunoprecipitation is not encoded as `characteristics[enrichment process]`: no term under EFO:0009090 fits co-IP (only phospho-enrichment, cell sorting and similar). The bait is carried by `characteristics[genotype]`.
- Exp3 RAW members use Deflate64 compression; their headers were read with the `inflate64` package (installed only under the scratch directory).
