# PXD013346 SDRF annotation report

Status: validated annotation; independent review pending.

Dataset: SUMOylation proteomic analysis of renal cortical collecting duct cells (Aarhus University; Wu, Aroankins, Cheng, Fenton; J Proteome Res 2019, PMID 31502464). Mouse mpkCCD14 cells expressing His-tagged SUMO1 or SUMO2 (Thr-to-Lys mutant); Ni purification, Lys-C digestion, then Glu-C on the remaining material, di-glycine remnant antibody enrichment; Q Exactive; MaxQuant 1.5.5.1.

## Output
- `PXD013346.sdrf.tsv`: 51 rows (one per RAW file, all 51 RAW files claimed once) x 36 columns. Templates: ms-proteomics, vertebrates, cell-lines (v1.1.0).
- Sources: 19 (SUMO1 Exp1-5 and SUMO2 Exp1-5, each as `-LysC` and `-LysC_GluC` peptide pool; SUMO1-Exp1 Lys-C+Glu-C was lost per Readme).
- Factors: `factor value[genetic modification]` (SUMO1 vs SUMO2 construct), `factor value[treatment]` (MG132 and PR619 vs heat shock).

## Evidence and provenance
- PRIDE project record (PXD013346) and file list (all entries carry this accession).
- Deposited `Readme.docx` (file -> experiment, enzyme, treatment, fraction). This is the source for sample/digest/treatment/fraction mapping.
- Q Exactive confirmed from the RAW header (HTTP range read of L1-SUMO-1.raw, first 256 KB).
- Search settings from the PRIDE data-processing text (MaxQuant 1.5.5.1). `MaxQuant_1.5.5.1.zip` holds only the program (central directory read by range); the `CCD-S1/S2.rar` search archives (12 GB each) were not opened. No mqpar was inspected.
- Paper is not open access (no PMC full text); Methods not read.

## Design decisions
- Two cleavage-agent columns: Lys-C then glutamyl endopeptidase (Glu-C). Lys-C-only rows carry `not applicable` in the second column; Lys-C+Glu-C rows carry both. parse_sdrf accepts this.
- Technical replicates: multiple injections of the same experiment/digest in the Readme are encoded as technical replicates. For the fractionated sets (SUMO1-Exp5 Lys-C A1-A4; SUMO2-Exp4 Lys-C B2-B4) the two files per fraction are two injections (technical replicate 1 = undated names, 2 = dated names; the order is an assumption).
- SUMO2-Exp4 Lys-C fractions are numbered 2-4 (fraction 1 lost, per Readme); this was set by a scripted post-process because `build` numbers by position.
- Biological replicate = Readme experiment number within each SUMO isoform.

## Caveats
1. Readme lists `L3.raw` and `G3.raw` twice under SUMO2-Exp3. The deposit also contains unlisted `L4.raw` and `G4.raw`, so the second entries were interpreted as L4/G4 (inferred).
2. Which names in the Readme are technical vs biological replicates (e.g. `L1-SUMO-1/-2`, `LyscKGG/2/3`) is inferred from naming; all treated as technical replicates of the experiment.
3. Precursor/fragment tolerances, dissociation method, cell line Cellosaurus accession, disease, developmental stage, sex, strain are `not available` (not stated in the accessible record; MaxQuant "default" tolerances not asserted).
4. Cell type given as `epithelial cell` (PRIDE sample attribute, CL:0000066), organ part `kidney`; the cortical collecting duct principal-cell identity is not asserted.
5. Treatment concentrations/durations (MG132, PR619, heat shock) and the exact His-SUMO construct residue numbers are not captured; `characteristics[genetic modification]` is free text. The di-glycine antibody enrichment is not encoded in a column (no suitable term).
6. Modifications come from PRIDE protocol prose, not the deposited search outputs: carbamidomethyl C (fixed); acetyl protein N-term, oxidation M, phospho S/T/Y, GlyGly (UNIMOD:121) K (variable). Lys-C/P specificity and the group-specific Glu-C searching are not represented.
7. `sdrf-tools reconcile` reports one MAJOR `cleavage_agent_incomplete` finding: it reads only the first cleavage column. This is understood as a design false positive, since Lys-C-only runs are truly Lys-C only.
