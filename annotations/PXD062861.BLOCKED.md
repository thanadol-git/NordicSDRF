# PXD062861

Status: blocked locally; no SDRF was produced.

The deposit contains two TMT10 sets, each measured as twelve fractions, for thyroid samples from female BALB/c nude mice exposed to 0 or 490 kBq iodine-131. The PRIDE record and deposited quantification/search parameter documents define the plex and search settings but not the animal/reference assignment for each reporter channel.

Required to unblock: the channel map for both TMT10 sets, identifying every animal, exposure group, pooled reference, and unused channel.
