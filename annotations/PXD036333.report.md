# PXD036333 report: BLOCKED (no SDRF produced)

Review status: not applicable. There is no SDRF to review, so no independent review round was run and no validation was performed.

## Study
Safranal-treated MDA-MB-231 (triple-negative breast cancer) acetylomics, TMT 11-plex, K-acetyl IP enrichment, Orbitrap Fusion Lumos, PD 2.4 + Mascot. Publication: Zarrineh et al., J Proteome Res 2022 (PMID 36173113), closed access.

## Scope
Deposited: 1 RAW (`LUM_05061_Mahshid.raw`), 2 mzML (one is a converted copy, `Mashid_acetylated.mzML`, same size) and 1 mzid.gz. Annotated: 0 of 1 runs. Excluded: all files, because the single multiplexed run has no channel-to-sample map.

## Why it is blocked
The protocol gives 3 time points (30 min, 12 h, 24 h) x 3 replicates plus 2 DMSO controls, i.e. 11 samples in 11 TMT channels, but no assignment of samples to channels. Templates that would have been used: ms-proteomics + cell-lines + oncology-metadata (TMT, MDA-MB-231, breast cancer). Not built, since any channel assignment would be fabricated.
