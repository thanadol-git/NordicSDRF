## Caveats
- Organism part is "hemolymph" (BTO:0000572); sample is the insoluble hemolymph clot, which is not an ontology term. Material type "organism part".
- Disease, developmental stage, strain: not stated in the record (not available). Sex "male" from the Methods. Treatment: lipopolysaccharide (65 ug/ml, all samples; concentration not encoded).
- Dissociation method CID is inferred from instrument type, not stated in the deposit.
- Tech replicate order is taken from the file-name suffix (-1..-4). Clot 3 and 4 file names carry an extra "-1" (e.g. TarantulaClot3-1-2); interpreted as the same biological sample, replicate 2.
- Raw files were not downloaded; only the PRIDE file list was used. Mascot .dat search files exist but were not parsed (modifications taken from paper text).
- Gel-embedded clot handling (stacking gel excision) not encoded as fractionation.
