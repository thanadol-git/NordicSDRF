# PXD005802 annotation blocked

PXD005802 is the University of Southern Denmark (Odense) deposit titled "Signaling and crosstalk of the angiotensin AT2-receptor and the receptor MAS". It comes from the Steckelings lab (Dept. Cardiovascular and Renal Research), and the samples were processed and run by the Larsen lab (Dept. Biochemistry and Molecular Biology). It was submitted 2017-01-30 and made public 2022-11-18. PRIDE lists no reference. Matching authors, title, cell type, treatment and protocol link it to Peluso AA, Kempf SJ, Verano-Braga T, ..., Larsen MR, Steckelings UM, "Quantitative Phosphoproteomics of the Angiotensin AT2-Receptor Signaling Network Identifies HDAC1 and p53 as Mediators of Antiproliferation and Apoptosis", Hypertension 2022;79(11):2530-2541 (PMID 36082664, doi:10.1161/HYPERTENSIONAHA.121.18620). No retrievable text of the paper cites PXD005802: a Europe PMC full-text search for the accession returns 0 hits. No upstream annotation exists: `bigbio/sdrf-annotated-datasets` `datasets/PXD005802` and `sandbox/PXD005802` both return HTTP 404.

## Blocker

This is a TMT-multiplexed study, and no channel-to-sample map exists in any reachable source. The abstract says human aortic endothelial cells were stimulated with the AT2-receptor agonist C21 (1 µM) for 0, 1, 3, 5 and 20 minutes. Nothing reachable says which time point (or replicate, or control) is in which TMT channel. All six deposited Proteome Discoverer searches quantify all 10 channels of a "TMT 10plex" method, while the search modification is `TMT6plex` (UNIMOD:737, the same mass for TMT6 and TMT10). So even the number of occupied channels (6 or 10) is not established. Without a map, `characteristics[...]`, `comment[label]`-to-sample and `factor value[time]` cannot be assigned to any (file × channel) row. Per the non-interactive rules, channel identities must not be invented, so no SDRF is emitted.

## What was established

- **Organism / material:** *Homo sapiens* human aortic endothelial cells (HAEC; PRIDE cell type CL:0002544). Treatment: C21 (compound 21, AT2-receptor agonist) 1 µM, 0/1/3/5/20 min (paper abstract; MeSH: Endothelial Cells, Humans, Receptor, Angiotensin, Type 2, Sulfonamides, Imidazoles, Thiophenes).
- **Sample processing (PRIDE protocol):** TMT labelling, then TiSH, a TiO2–SIMAC–TiO2 enrichment, splitting each set into unmodified, phosphopeptide (mono- and multi-phospho) and formerly N-glycosylated peptide fractions. The fractions were then separated further: the RAW-header sample IDs are 96-well-plate pool ranges, e.g. `Augusto_unmodified_A3toA5`, `Augusto_glyco_E2toE7`, `Augusto_monophospho_A2toA11_1`, `Augusto_multiphospho_7A`.
- **Instrument:** Q Exactive HF, from the RAW headers of 8 files (`UHF2539`, `UHF2548`, `QHF2556`, `QHF2564`, `QHF2565`, `QHF2574`, `QHF2580`, `QHF2586`), which read "Q Exactive HF - Orbitrap MS" with a Thermo EASY-nLC. PRIDE lists plain "Q Exactive" (MS:1001911), so the PRIDE field is wrong. Methods: `2Columns_90mingradient_HT_Top12_30K_200ms_TMT_nonmodified` (unmodified) and `2Columns_30mingradient_HT_Top12_30K_200ms_TMT_phospho_glyco` / `_TMT_multiphospho` (enriched fractions).
- **Files:** 49 RAW files and 6 PD 1.4 `.msf` files. Every PRIDE `files` entry carries PXD005802. `QHF2564.raw` is only 45,992 bytes (truncated; the msf records it as a 44-second acquisition). Each msf's `FileInfos` table maps RAW files to searches:
  - `UHF2547_unmod_1_augusto.msf`: UHF2539–UHF2547 (9 files)
  - `UHF2555_unmod2_Augusto.msf`: UHF2548–UHF2555 (8)
  - `QHF2564_glyco1_Augusto.msf`: QHF2556–QHF2564 (9)
  - `QHF2573_glyco2_Augusto.msf`: QHF2565–QHF2573 (9)
  - `QHF2586_phospho1.msf`: QHF2574–QHF2579 + QHF2586 (7)
  - `QHF2587_phospho2_Augusto.msf`: QHF2580–QHF2584, Qhf2585 + QHF2587 (7)

  That is 49 files, every RAW accounted for. The "1"/"2" split suggests two TMT sets (or two halves of one set's fractions). The headers do not say which: phospho1 and phospho2 carry the same well range (`A2toA11_1` / `A2toA11_2`).
- **Search (all six msf files, read by HTTP-range SQLite reads, not downloaded):** Mascot + SEQUEST HT. Settings: trypsin, 2 missed cleavages, precursor 10 ppm, fragment 0.02 Da (one node also lists 0.5 Da). Fixed: Carbamidomethyl (C), TMT6plex (K) and TMT6plex (N-term). Variable: Phospho (STY) in the phospho and glyco searches, plus Deamidated (N) in the glyco searches; none in the unmodified searches. Database: SwissProt / `uniprot-human_15112016.fasta`.

## Channel-map ladder (references/channel-map.md), all rungs checked

1. **Paper and supplementary:** not open access. Europe PMC reports `isOpenAccess=N`, `inPMC=N`, `hasSuppl=N`, and Unpaywall/OpenAlex report it as closed. The ahajournals.org article, full text and supplement URLs return the Cloudflare challenge page (HTTP 403). The Wayback Machine availability/CDX API returned HTTP 429 and then timed out. The MDC Berlin edoc record (22078) holds metadata only, and the SDU/KU research portals hold no full text. Searches for an AHA supplement found nothing: figshare (search on the DOI returns 3 unrelated hits) and Zenodo (0 hits for the DOI or PXD005802). Europe PMC has no preprint (PPR) version. The open-access review PMC11737475 (Souza-Silva 2025) cites the paper but gives no channel layout. Only the abstract and MeSH terms were usable, and neither contains a layout.
2. **Deposited PRIDE files:** only RAW and msf files; there is no sample sheet. All six msf files carry the byte-identical (same MD5) default PD "TMT 10plex" quantification method. Its channels are named only by reporter mass (126, 127_N … 131), with default ratios x/126 and no sample names. That is the generic default, not a map. The RAW-header sample IDs name well-plate fraction pools, not channel contents.
3. **Europe PMC supplementary:** not applicable, because the paper has no PMCID.
4. **External repositories in Data Availability:** the Data Availability statement could not be read (paywall). Crossref lists no relations or data links (only the publisher full-text URL), and Zenodo/figshare searches on PXD005802 and the DOI found nothing.
5. **Cross-validation:** not possible without a candidate map.

## What would unblock it

Any of the following would allow a complete, honest SDRF:

- the paper's Online Supplement (ahajournals.org, `doi/suppl/10.1161/HYPERTENSIONAHA.121.18620`) or the full Methods text, if it gives the TMT channel → time point/replicate layout per set;
- a table from the authors (Steckelings / Larsen, SDU Odense) giving, for each TMT set, channel → C21 time point (0/1/3/5/20 min) and replicate, and stating whether "1"/"2" are separate TMT sets.

The build would then use the `ms-proteomics` + `human` + `cell-lines` templates (HAEC primary cells) with TMT10plex labels. It would use `factor value[time]` and a per-row `comment[fractionation method]` / fraction identifier covering the unmodified, phospho and glyco enrichment fractions. All 49 RAW files would map through the msf `FileInfos` sets above. `QHF2564.raw` (truncated, 44 s) would need a note.
