The following templates do not apply: `dia-acquisition` (the RAW method is a Top10 data-dependent method), `cell-lines`, and `clinical-metadata`/`oncology-metadata` (the sample is an anonymous test pool, with no patients or cohort described). ## Design and file mapping

From the PRIDE sample-processing protocol: "A test pool of human cerebrospinal fluid was then split into six aliquots of 240 µl (103.2 µg each aliquot), and the samples lyophilized until dryness ... prior to TMTsixplex labelling ... The six identical samples, now labelled by separate TMT-labels, were combined". The peptidome was then isolated (following Hansson, Skillbäck et al.), desalted by OASIS clean-up, and fractionated by high-pH reversed-phase chromatography. "Following separate analysis, the fractions were pooled and injected for RPLC-MS/MS, allowing for fragmentation of singly charged precursors only."

The deposit contains exactly one RAW file, `20171024_EndoCSF_TMT_Rest_Charge1.raw`, plus a search-result table, `Identifications.tsv`. The RAW file is that single pooled-fraction injection. This is confirmed by the RAW header, which records the method `EndoPep_TOP10_60K-30K_2mmSH_IT3e6_IT250ms_120minRUN_TMT_Charge1.meth` with charge exclusion "unassigned, 2 - 8, >8", meaning only 1+ precursors were fragmented. The header also records the sequence folder `2017-10-24_QExHF_EndogenePeptider_TMT_Test`. The GitHub README describes the MGF converted from this same file as "the MS2 spectra for the singly charged features". The separate per-fraction analyses mentioned in the protocol were not deposited.

**How the channel map was established.** The protocol states that all six TMT6plex channels carry identical aliquots of the same CSF pool, so the channel-to-sample map is fully determined by the protocol text. No per-channel sample identity is needed or inferred. The aliquot number simply follows channel order and has no meaning beyond distinguishing the six tubes. All six channels are in use. The deposited `Identifications.tsv` and the authors' `readMGFcpp.cpp` test for all six TMT6 reporter ions (`tmt1`–`tmt6`, at 126.127726, 127.124761, 128.134436, 129.131471, 130.141145 and 131.138180 m/z). Channel labels use the TMT6plex vocabulary of the installed sdrf-pipelines (`TMT126`…`TMT131`; PRIDE:0000516, 0000517, 0000520, 0000523, 0000526, 0000529, all verified in OLS).

**Why six sources rather than one source with six technical replicates.** Each aliquot was split off, lyophilized and labelled separately before mixing, so each channel is a physically separate tube of the same material. An earlier build used one source (`CSF pool`) with technical replicates 1–6, and `sdrf-tools structure` rejected it (`technical-replicates-share-a-file`: rows sharing one run are channels of a plex). All six sources are marked `characteristics[pooled sample]` = `pooled` and `characteristics[biological replicate]` = `pooled`. The report and naming make clear that they are the same pooled material.

**Factor value.** None. This is a single-pool proof-of-concept with no compared variable (six identical aliquots), so no `factor value[...]` column is declared. This follows the skill's rule for reference/benchmark designs. The validator accepted the file without it.

## Technical values and their sources

- **Instrument**: `Q Exactive HF` (MS:1002523), from the RAW header ("Q Exactive HF - Orbitrap MS", "Method of Q Exactive HF", folder `..._QExHF_...`). PRIDE lists plain `Q Exactive` (MS:1001911); the RAW header outranks it.
- **Acquisition**: DDA (PRIDE:0000627). The RAW method is "FULL MS / DD-MS2 (TOPN)", TopN 10.
- **Dissociation / collision energy**: HCD (`beam-type collision-induced dissociation`, MS:1000422; the Q Exactive HF fragments only by HCD) and `32 NCE` from the RAW method ("(N)CE / stepped (N)CE nce: 32").
- **MS2 analyzer**: orbitrap (MS:1000484). dd-MS2 resolution is 30,000.
- **MS1 scan range**: `300m/z-1500m/z` (RAW method, Full MS "Scan range 300 to 1500 m/z").
- **ms min / max charge**: `1` / `1`. The RAW method's charge exclusion is "unassigned, 2 - 8, >8", so only singly charged precursors were selected. The protocol says the same ("fragmentation of singly charged precursors only").
- **Cleavage agent**: `not applicable`. This is an endogenous peptidome ("small endogenous peptides", "isolating the cerebrospinal fluid peptidome"), and no protease is named anywhere in the record.
- **Precursor mass tolerance**: `5 ppm`. The paper and README say "a tolerance of 10 ppm", but the code in `getIdentifications.R` matches `abs(MZ - monomass) < singleTol/2` with `singleTol = monomass*1e-5` (`makeAAdb.R`), so the window is ±5 ppm. The README states the same ("+ and - 5ppm relative to the theoretical mass").
- **Fragment mass tolerance**: `not applicable`. Identification used the precursor mass only (README: "Only the precursor mass is used for identification"). MS2 spectra were only used to check for TMT reporter ions, at ±10 ppm (`readMGFcpp.cpp`, `TOLERANCE = 1e-5`).
- **Modification parameters**: taken from the deposited analysis code (`makeAAdb.R` and the README modification table), which builds the mass database. A TMT6plex tag (UNIMOD:737) is added to every molecule, so it is written as `PP=Any N-term;MT=Fixed`. Carbamidomethyl-C (UNIMOD:4) and Oxidation-M (UNIMOD:35) are added as extra "amino acids" alongside the unmodified C and M, so both are Variable. At most one further PTM per molecule is drawn from the 11 Unimod "common, non-N-term" post-translational modifications: Biotin K (UNIMOD:3), Phospho S/T/Y (UNIMOD:21), Methyl D/E (UNIMOD:34), Sulfo S/T/Y (UNIMOD:40), Dioxidation M (UNIMOD:425) and Crotonyl K (UNIMOD:1363). All are written as Variable. Every UNIMOD accession was checked in OLS.

## Limitations

- **The paper's full text was not read** (subscription-only, no PMC copy, Unpaywall has no open-access location). Everything comes from the PRIDE protocols, the RAW header, the deposited `Identifications.tsv`, and the authors' GitHub code and README.
- **Donor demographics are unavailable.** The sample is "a test pool of human cerebrospinal fluid". The number of donors, their disease status, age, sex and ancestry are not stated anywhere read, and the PubMed MeSH headings (Amino Acids, Mass Spectrometry, Peptides, Proteomics) carry no Humans/Male/Female tags. These are written as follows:
  - `characteristics[disease]`, `characteristics[ancestry category]` and `characteristics[age]` are `not available`.
  - `characteristics[sex]` is `not applicable`, the campaign convention for mixed-donor pools, because the installed validator rejects `pooled` for this column.
  - `characteristics[individual]` is `pooled`.
  - That the pool contains more than one donor is inferred from the word "pool".
- `characteristics[cell type]` is `not applicable` (cell-free fluid).
- **Peptidome isolation and reduction/alkylation are not described in detail.** The PRIDE protocol cites the Hansson/Skillbäck CSF peptidome workflow without detail. No reduction or alkylation reagent is stated, so those columns are omitted, as is `characteristics[enrichment process]`. Carbamidomethyl-C appears only as a variable search option, and PRIDE's submitter-entered PTM list includes "iodoacetamide derivatized residue". Whether the sample was actually alkylated is not established.
- **High-pH reversed-phase fractionation** (PRIDE:0000564) took place, but the deposited RAW file is one injection of the recombined fractions. `comment[fractionation method]` is therefore omitted and `comment[fraction identifier]` is 1, rather than implying this is one fraction of a series. The number of fractions is not stated.
- **Not deposited.** The protocol's "separate analysis" of the individual fractions (presumably multiply charged runs) is not in PXD012872, so those runs are not annotated.
- **Modification parameters describe a mass-matching database, not a conventional search engine.** The authors identified singly charged molecules by precursor-mass lookup against a custom database, which also included HMDB CSF metabolites (amines, amino acids/peptides and analogues). The modification columns record what that database allowed: TMT on every molecule, plus at most one extra PTM. The metabolite part has no SDRF equivalent.
- **Acquisition date**: the sequence folder and file name say 2017-10-24, but `comment[acquisition date]` was not added.
- The aliquot numbering (1–6 in channel order) is a naming convention, not an evidenced assignment. The aliquots are identical by design.
