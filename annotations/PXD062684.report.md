## Limitations and decisions

- The sample-to-treatment map is NOT available: run names carry no dose, the deposit has no key, and the paper text gives only group sizes (PBS n=6; 1, 2, 4, 6 doses n=4 each; 9 doses n=6, 28 mice). Therefore `characteristics[treatment]` is `not available` and no factor value column is written. A supplementary table in the paper may hold the map; not retrieved. Recommend completing treatment (IFN-gamma dose count, 16.7 ug per dose, 8 h interval, vs PBS) and a factor value[treatment] once the map is found.
- Mouse identity per run is unknown (which runs are replicate crypt samples of the same mouse, and which are the 4 mice also sampled from mid/distal intestine). Each run is its own source with biological replicate 1; organism part is `small intestine` for all (proximal in most; the distal/middle samples cannot be identified).
- Instrument: protocol says "timsTOFfleX or timsTOFPro2" but also that the four experiments were run on timsTOF fleX, and PRIDE lists timsTOF fleX; annotated fleX for all rows (reconcile flags this MAJOR on the "Pro 2" wording). RAW headers (analysis.tdf) were not inspected.
- Sex female and strain C57BL/6J: paper Methods (9-11-week-old female C57BL/6J, Janvier) for the repeat-injection experiments; applied to all rows. Developmental stage, disease, cell type left `not available`.
- Dissociation method CID (MS:1000133) is the generic term for timsTOF PASEF, not stated in the deposit.
- Tolerances 20 ppm / 20 ppm and modifications (Carbamidomethyl C fixed; Oxidation M, N-terminal Acetyl variable), trypsin (stricttrypsin KR, 2 missed cleavages) read from deposited MSFragger `fragger.params`. The deposited `sdrf.tsv` inside MSFragger.zip was not used. Reduction (DTT) and alkylation (iodoacetamide) are in the protocol but optional columns were omitted.
- data file values are the `.d` directory names inside the zips; the zip archives are the PRIDE-listed files.
- Companion dataset PXD062610 (human biopsies) is separate and not covered.
