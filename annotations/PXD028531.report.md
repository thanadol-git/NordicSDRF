# PXD028531 annotation report

## Evidence used

- PRIDE metadata describes an Orbitrap Fusion Lumos TMT experiment and a protocol with tryptic digestion, chloroacetamide alkylation, and TMT11 labeling.
- Both deposited workbooks, `HIV_proteins.xlsx` and `U1_U937_cells_all_fractions.xlsx`, contain the same column-header channel maps for the three multiplexes B1–B3.

## Annotation scope

The SDRF represents all 36 deposited RAW files (12 fractions in each of B1, B2, and B3) crossed with the nine populated channels in each multiplex, giving 324 assay rows. The workbook explicitly maps every channel to **U1**, **U937**, or **Pool** and to the submitted condition strings **C**, **P**, **C-DON**, **P-DON**, or **Pool**. The protocol explicitly identifies B1–B3 as three batches; these identifiers are represented as biological-replicate values 1–3 and retained separately as the multiplex-set factor. The condition strings are retained verbatim; no compound or stimulation expansion was inferred.
