# PXD050784 SDRF annotation report

## Study
Label-free PISA (proteome integral solubility alteration) drug-target screening in HeLa and HepG2 lysates and ex-vivo rat organ lysates, Evosep + Orbitrap Exploris 480 DIA (Batth et al., Nat Commun 2024, doi:10.1038/s41467-024-53240-2).

## Templates
-human: ms-proteomics + human + cell-lines; -rat: ms-proteomics + vertebrates (v1.1.0)

## Scope: deposited vs annotated
1266/1311 RAW (inside 5 zips; comment[file container]). 288 HeLa/HepG2 runs -> PXD050784-human; 978 rat organ runs (cancer panel, metabolic panel, staurosporine tests) -> PXD050784-rat. Not annotated: 45 runs in Pilot_experiments.zip (TMT-10 TPP vs PISA on QE, U2OS LFQ, and a Lumos filter-vs-centrifuge test) - TMT channel layout and sample source not deposited.

## Sample map
HeLa/FileList.txt and HepG2/HepG2 FileList.txt (deposited) give replicate, drug and final concentration for the cell-line runs; all other runs are decoded from file names (organ, drug code, concentration, replicate). Drug codes expanded from the FileLists (e.g. RMC = RMC-4550, SHP = SHP099, LUMO/LOMU = lomustine).

## Key decisions
Water and DMSO runs recorded as vehicle controls (compound 'none (... vehicle control)', dose not applicable). _redo runs = technical replicate 2 of the same sample. Run date is part of the source name because some rat control series were run on two plates with the same replicate numbers. Incubation 10 min at 37 C from the preprint methods unless the file name gives 5/30/60 min or 4 C. Lys-C + trypsin, TCEP/CAA, DIA (DIA-NN), carbamidomethyl fixed. Rat: adult male Wistar (preprint methods). Folder (HeLa vs HepG2) taken as the cell line even though HepG2-folder files are named 'HELA'.

## Not available / not applicable
Concentrations of the rat cancer-drug panel and of staurosporine (codes ST100, ST10, ST-1MM/10MM/100MM, ST-HIGHCONC kept in comment[sample code]); 'WF' tissue code in the staurosporine test (organism part not available); rat age.

## Conflicts / overrides
HepG2-folder file names say HELA; folder name and HepG2 FileList used.

## Inferred vs stated
Incubation time/temperature for runs whose name gives none; DIA for all Exploris runs (only DIA settings described for LFQ; DIA-NN used); HepG2 identity of the HepG2 folder.

## For the reviewer to attack
Whether the HepG2-folder 'HELA' runs are really HepG2; staurosporine dose units.
