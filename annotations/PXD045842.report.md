# PXD045842 annotation report

## Study
Polak et al., Cell Rep 2023 (PMID 37889751, PMC10720265): ZC3H18/ZFC3H1/ARS2 and nuclear RNA decay. PXD045842 is the IP-MS deposit: MYC/GFP affinity enrichments from HeLa Kyoto cells, LF-DDA on Orbitrap Exploris 480, MaxQuant LFQ. PRIDE lists 50 files (one page of 100): 48 RAW + proteinGroups.txt + evidence.txt (no mqpar/summary/parameters).

## Templates
ms-proteomics + human + cell-lines (v1.1.0). Choice: HeLa Kyoto cell line, label-free MS; no oncology/clinical template since no patient data.

## Scope: deposited vs annotated
All 48 RAW files annotated (16 groups x 3 biological replicates, 1 row each, 48 x 41 columns).
Groups from file names: FL-WT(+D / -D), FL-MUT, NTD-WT, NTD-Mut, F1, F2, F7, each with suffix Bz or BSA.

## Key decisions
- Internal RAW header paths prove naming: PRIDE `FL-WT--D-*` = acquired as `FL_WT+D`, and `FL-WT-D--Bz-3` = `FL_WT+D_Bz_3`; `FL-WT-D-*` = `FL_WT-D`. Replicate numbers match the PRIDE names.
- Cell line HeLa Kyoto = CVCL_1922 (Cellosaurus API); age/sex are the Cellosaurus donor values (30Y6M, female).
- Only the FL-WT +D rows carry `treatment = doxycycline` (paper: constructs induced with 1 ug/mL doxycycline; reading "D" as doxycycline is an inference from the file name plus the paper). All other rows: `not available`.
- Instrument/HCD/NCE 30%/scan range 350-1500/MS2 Orbitrap read from RAW method headers of all 48 files (identical).
- Modifications read from deposited evidence.txt (first 30 MB): Oxidation (M), Acetyl (Protein N-term); no Carbamidomethyl present, so no fixed mod written.
- Cleavage: trypsin and Lys-C (paper). `build` has a single cleavage column, so a second `comment[cleavage agent details]` (Lys-C) column was inserted by `/home/thanadol/Documents/GitHub/sdrf-skills/scratchpad/PXD045842/add_lysc.py` (post-processing, rule 12). `reconcile` still flags Lys-C as missing because it reads only the first column.
- No factor value column: the compared variables are not defensibly traceable (see below).

## Not available / unresolved
- Meaning of `Bz` vs `BSA` suffixes and of `F1`, `F2`, `F7` is not stated in the paper, PRIDE record or RAW headers (the "50 fmol BSA" in RAW sample field is the same in all files). Kept only in source names; no sample property asserted for them.
- Which RAW groups use MYC vs GFP beads is not traceable.
- NTD = Z1 1-209 is likely (paper IP-MS WT vs MUT of Z1 1-209) but is not asserted in a column.
- Precursor/fragment tolerance, reduction, alkylation: no deposited parameter file; not available. Disease, culture medium, passage not stated.
- Paper describes only one MS comparison (Z1 1-209 WT vs MUT); the other 12 groups are undocumented.
