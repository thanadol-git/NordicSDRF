# PXD004499 annotation report

## Result

SDRF covering all 103 deposited RAW files. File names explicitly encode the D1/D2 batch, AD/OND/control cohort, biological sample number, and technical replicate.

## Evidence

- PRIDE project: PXD004499, `Human temporal neocortex brain LC-MS`.
- Submitter: Payam Emami Khoonsari, Uppsala University, Sweden; PI: Kim Kultima, Uppsala University Hospital, Uppsala.
- Material: human temporal neocortex; label-free shotgun proteomics.
- Disease groups: Alzheimer’s disease, other neurological disorders, and non-demented controls.
- Instrument: LTQ FT; digestion: trypsin; fixed carbamidomethylation and variable oxidation/deamidation.
- Reference: Musunuri et al., *Journal of Alzheimer’s Disease* (2016), PMID 27636840.
- Deposited files: PRIDE FTP archive `https://ftp.pride.ebi.ac.uk/pride/data/archive/2016/09/PXD004499/`.

## Conservative choices

Age, sex, and finer clinical metadata were not propagated because they are not available in the PRIDE project record. The numeric sample number is retained as the biological replicate identifier; `TechRep_*` is recorded as the technical replicate. Each deposited RAW is a single acquisition, so the fraction identifier is `1`.

## Validation

Structural validation: `parse_sdrf validate-sdrf --sdrf_file annotations/PXD004499.sdrf.tsv --template ms-proteomics --template human --skip-ontology`.
