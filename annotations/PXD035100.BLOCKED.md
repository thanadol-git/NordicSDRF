# PXD035100 — BLOCKED

## Exact blocker

The deposited PTMScan workbooks map all 50 RAW customer-sample IDs to biological condition labels, but they do not define the replicate semantics of the paired customer-sample IDs. Each condition label maps to two RAW files, while some labels also carry `-1`/`-2` suffixes and others do not. The checked evidence does not state whether the paired IDs are biological replicates, technical injections, duplicate enrichments, or another preparation split. SDRF requires an explicit biological-replicate value, so assigning those fields would require invention.

## Evidence checked

- PRIDE project record: `https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD035100`
- PRIDE file inventory: `https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD035100/files/all`
- Publication: `https://pmc.ncbi.nlm.nih.gov/articles/PMC9974509/` (DOI `10.1073/pnas.2216479120`)
- Deposited `Table1_Gothenburg_Q231531_pY_FINAL.xlsx`
- Deposited `Table3_Gothenburg_Q231531_STMix_FINAL.xlsx`

PRIDE lists 50 Orbitrap Fusion Lumos RAW files. The Table 1 workbook maps CS31866-CS31901 to conditions including control, EML4-ALK-V1, EML4-ALK-V3a, KIF5B-ALK, and TFG-ALK with doxycycline and/or lorlatinib. The 14 deposited Table 3 runs, CS31982-CS31995, are likewise mapped to the first seven condition labels in that workbook. Thus RAW-to-condition mapping is available.

The unresolved problem is within-condition identity. For example, both CS31870 and CS31871 are labelled `V1-naïve-1`, while CS31876 and CS31877 are both `V1-naïve-2`; `Control+dox`, KIF5B, and TFG pairs have no analogous replicate suffix. The main article describes inducible NL20 cell models and phosphoproteomics but does not define the CS-pair semantics. Treating pair order as biological or technical replicate order would be an unsupported assumption.

## Evidence needed to unblock

The original submission/acquisition design or a laboratory note that explicitly defines what each paired CS identifier represents and how the `-1`/`-2` suffix relates to biological replication. It must distinguish biological replicate, preparation/enrichment replicate, and repeated LC-MS injection for all condition families.
