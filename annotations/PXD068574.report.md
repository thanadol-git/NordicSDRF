# PXD068574 annotation report

Status: validated annotation; independent review pending.

## Result
15-row, 32-column SDRF. Templates: `ms-proteomics` v1.1.0 + `vertebrates` v1.1.0. Dataset: "Unilateral IRI induction in pigs" (Aarhus University, Rinschen lab); Sus scrofa, label-free DDA, Orbitrap Exploris 480 with FAIMS, trypsin. Not previously annotated in `sdrf-annotated-datasets` (no PXD068574 directory).

## Design
15 vendor RAW files, one per sample: 6 animals (run numbers 0013-0023) x kidney-cortex CTRL and IR, plus liver for animals 0019, 0021, 0023 (3 files). Factor: `factor value[disease]` = ischemia reperfusion injury (6 IR rows) vs not available (CTRL, Liver).

## Validation
- `parse_sdrf validate-sdrf -t ms-proteomics -t vertebrates`: PASS, no errors or warnings.
- `python -m tools check`: CLEAN. `structure`: OK.
- `reconcile`: one BLOCKER (`run_names_name_another_organ`) reported. The SDRF does record `liver` for the 3 `_Liver` runs; the check text ("every row says cortex of kidney") does not match the file, and the PRIDE field lists only kidney. Treated as a record/run-name disagreement that the SDRF already resolves in favour of the run names.

## Caveats
- Liver identity is inferred from run names only; the record never mentions liver. Whether liver is from IR animals is unknown.
- CTRL is not described (contralateral kidney vs sham unknown), so disease is `not available` for CTRL rather than "normal".
- Biological replicate = animal index inferred from run numbers.
- Sex, age, breed, developmental stage, cell type, mass tolerances: not available (not in record). No publication available.
- Modifications taken from the PRIDE prose (MaxQuant); the deposited FragPipe zip (1.4 GB) was not opened. FAIMS compensation voltages (-40/-55/-70 V) are not encoded as columns; files were split by CV only for searching.
- The FragPipe open-search PTM analysis (lysine PTMs) is not represented as modification parameters.
- Independent adversarial review (Step 9.5) has not been run; review-gate not executed.
