# PXD031945 annotation report

## Evidence used

- PRIDE metadata and the deposited protocol identify an HDX-MS experiment on SARS-CoV-2 receptor-binding domain (RBD), with and without Fab52 or Fab47, acquired on a Q Exactive Plus.
- The protocol specifies four deuterium-exchange times (0, 30, 300, and 3000 seconds), three replicates for each state/timepoint, and online pepsin digestion.
- RAW filenames encode the Fab run series, Apo versus RBD–Fab state, exchange time, and acquisition timestamps.

## Annotation scope

The SDRF represents all 46 deposited RAW files. It assigns replicate values by their ordered acquisition timestamps within each submitted state/timepoint/run-series group. The deposited files provide three replicates for every group except RBD–Fab52 at 0 seconds and 300 seconds, where only two RAW files are present; no missing third run is synthesized. The PRIDE project metadata identifies Homo sapiens, while the report records the deposited protocol’s SARS-CoV-2 RBD target.
