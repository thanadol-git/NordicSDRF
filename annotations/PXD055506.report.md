# PXD055506 annotation report

Status: validated annotation; independent review pending.

## Result

18-row, 39-column label-free DDA SDRF (one RAW file per row, no fractionation). Templates: `ms-proteomics` v1.1.0 + `plants` v1.1.0. Not previously annotated in `sdrf-annotated-datasets` (no PXD055506 directory).

Dataset: solid-state fermentation of brewer's spent grain (BSG) with Rhizopus oryzae, Aalborg University (Rusbjerg-Weberskov, Lübeck). Paper: Food Bioprocess Technol 18:9574-9593 (2025), doi 10.1007/s11947-025-03989-1.

Groups (sources): BSG biomass lysate x3, F-BSG biomass lysate x3, BSG protein extract x3, F-BSG protein extract x3, F-BSG 20 h x2, 40 h x2, 90 h x2. Factors: `factor value[treatment]` (fermentation vs control) and `factor value[sampling time]` (20/40/90 hour; `not available` for the other rows).

Technical: Q Exactive HF, DDA, HCD NCE 28, trypsin, MaxQuant 2.2.0.0 modifications (Carbamidomethyl C fixed; Oxidation M and protein N-term Acetyl variable) cross-checked against the deposited mzTab files.

## Validation

- `parse_sdrf validate-sdrf -t ms-proteomics -t plants`: pass, no errors or warnings (full ontology run).
- `python -m tools check --offline`: clean. `python -m tools structure`: OK.
- `python -m tools reconcile`: against the raw PRIDE record one BLOCKER (`cleavage_agent_unsupported`), because PRIDE prose never names trypsin; trypsin comes from the paper Methods (MaxQuant digestion setting). Against the PRIDE record plus that paper sentence it reports every value agrees.
- No independent adversarial review has been run (not permitted to spawn subagents here).

## Caveats and judgement calls

- Organism is single-valued: `Hordeum vulgare` on all rows. F-BSG proteins are largely fungal (R. oryzae, NCBITaxon 64495/Rhizopus arrhizus per PRIDE); this is not representable in one organism column. The fungal contribution is carried by a second `organism part` column (`mycelium`) and the growth condition text.
- `LyseExtract` = whole biomass lysed in iST Lyse buffer; `AcidPrec_Product` = alkaline-extracted, acid-precipitated protein extract. Inferred from run names and paper; not stated per file.
- F-BSG lysate/extract rows: fermentation time not assigned (paper says 4 days overall); `sampling time` is `not available`.
- `control` as the treatment label for non-fermented BSG is an inferred term (EFO control), as NCIT/EFO have no "no fermentation".
- Only one cleavage-agent column: the paper names only trypsin. PreOmics iST kits are commonly trypsin/Lys-C, but the deposit does not say so, so a second column was not added.
- Precursor and fragment tolerances, reduction and alkylation reagents are `not available` (not stated; no mqpar deposited). Developmental stage, strain/breed, cell type, material type are `not available`.
- Three mzTab result files are not SDRF rows. File order, replicate numbering and run-name mapping to replicates (R1-R3 -> biological replicate 1-3) follow run names.
- Organism part `germinated grain` is from the PRIDE structured field (BTO:0003365); malted barley grain is a reasonable but not paper-quoted description of BSG.
