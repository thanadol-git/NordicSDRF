## Design and file mapping
One SILAC experiment: nuclear extracts of HeLa S3 cells grown in heavy (13C6 15N2 Lys, 13C6 15N4 Arg) medium were pulled down with PtdIns(3,4,5)P3-conjugated beads and light extracts with control beads (paper Methods, stated), pooled and run in-gel digested. Rows: two channels per RAW file = `SILAC heavy` (PIP3 beads) and `SILAC light` (control beads) as separate sources. The four RAW files: `Inj01/02/03` (three injections of the same sample) = technical replicates 1-3, and `3Xinjection` (a second run with three times the peptide amount) = technical replicate 4. Factor: `factor value[treatment]` (PIP3 vs control beads). All 4 RAW files annotated.
