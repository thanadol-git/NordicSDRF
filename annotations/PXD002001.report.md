## Limitations

- Replicate-to-file mapping is inferred from file-name groups (three sets of 10, 11, 11 slices); no deposited mapping file. Which set is replicate 1/2/3 is an ordinal assumption.
- Fraction identifiers are ordinal slice numbers within each set (first set has 10 slices, others 11); the deposited MaxQuant output covers only the 10 files 130419_PaulaBusquet_SILAC_01-10, so modifications and tolerance were read from that search and assumed identical for the other 22 files.
- Carbamidomethylation is not a fixed modification in the deposited search (fixed modifications empty); reduction/alkylation reagents not stated, so those columns are absent.
- Precursor tolerance and dissociation method are not stated in PRIDE, the paper body or parameters.txt: not available. Fragment tolerance 0.5 Da comes from MaxQuant ITMS setting.
- Age 30Y and sex female come from Cellosaurus, not from the study. Cell type, developmental stage, passage, culture medium, storage temperature, ancestry: not available (culture medium is DMEM high glucose with 10% dialyzed FBS in the paper but not mapped to an NCIT term).
- Paper lists detailed LC-MS/MS methods only in the Supplementary Information, which was not read.
- The treatment value 'normoxia' is not found in NCIT/EFO (validator warning); 'hypoxia' kept as the exposure label.
- Heavy label (Arg10/Lys6) taken from paper; no SILAC label-swap is described, so heavy=hypoxia in all three replicates.
