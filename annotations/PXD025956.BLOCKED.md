# PXD025956 — BLOCKED

## Exact blocker

The TMT channel -> sample map (and the TMT plex) is not recoverable from any accessible source. The 48 RAW files are two TMT sets (`TMT_set1` / `TMT_set2`), each fractionated 12x for proteome (`..._LV_TMT_set{1,2}_frac_01-12.raw`) and for phosphoproteome (`..._LVset{1,2}_TMT_phospho_frac01-12.raw`). Six biological samples are named per genotype in the deposited tables (Ctrl-Sed1-3, Ctrl-Exc1-3; PKP2cKO-Sed1-3, PKP2cKO-Exc1-3), but nothing states which set carries which genotype, which TMT channel carries which sample, or whether the reagent is TMT6/10/11plex. Writing any of this would be a fabricated channel identity.

## Evidence checked

- PRIDE project record (title, description, protocols, TMT quantification method) and the complete file list (pageSize=100, page 0 = 52 files, pages 1-3 empty; 48 RAW, 4 SEARCH xlsx).
- Deposited Table-1..4 xlsx (processed MaxQuant output summaries, including Legends sheets): sample column names only (Ctrl-Sed1..3, Ctrl-Exc1..3, PKP2cKO-Sed1..3, PKP2cKO-Exc1..3); no channel numbers, no set assignment. The only hint is the header "Identification type LV Set2" in Table-1 (Control), which suggests but does not establish control = set2.
- Paper (van Opbergen et al., Circulation 2022, PMID 35491884, PMC9086182; NCBI efetch full text): TMT labelling, plex and channel assignment are deferred to the "Data supplement"; main text gives only n=3 per group, 12 phospho fractions, and the PRIDE accession.
- The Data supplement (Supplemental_Publication_Material.pdf, STable 1-6 xlsx): the PMC copy is behind a proof-of-work challenge, Europe PMC reports the article as not open access (no supplementaryFiles, rendering 403), and the publisher site (ahajournals.org) returned 403. The challenge was not circumvented.
- RAW headers were not used: they cannot reveal sample identity for TMT channels.

No deposited SDRF was used as evidence.

## Evidence needed to unblock

The Data supplement text (TMT labelling and sample-to-channel table) and the set1/set2 -> genotype assignment, e.g. the Supplemental_Publication_Material.pdf obtained manually from PMC9086182 or the journal, or a submitter statement (Navratan Bagwan / Alicia Lundby, University of Copenhagen), or a MaxQuant experimentalDesign/summary file listing reporter channels.
