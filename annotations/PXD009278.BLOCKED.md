# PXD009278 annotation blocked

PXD009278 contains 129 RAW files from a canine early-pregnancy study. The PRIDE README explicitly maps 80 named PRM sample files: nine cases and seven controls, each sampled on days 1, 8, 15, 22, and 29. It also identifies the calibration, intraday, and interday precision file groups.

However, 22 deposited shotgun files named `MS-15-008-*` and the calibration/precision standard files have no source-sample or standard-composition mapping. A whole-dataset SDRF would need to include those files; assigning them to animals, time points, or standards from filename order would be unsupported. No partial SDRF is emitted.

Evidence checked: PRIDE / ProteomeXchange PXD009278, its FTP README and 129-RAW-file manifest, and Valdés *et al.*, *Journal of Proteomics* (2019), PMID 30213709, DOI 10.1016/j.jprot.2018.09.004.

Unblock with the original MaxQuant experimental-design file and the PRM calibration/precision worksheet that maps every `MS-15-008-*`, `STD*`, `Intraday*`, and `Interday*` run.
