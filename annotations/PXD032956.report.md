## Study
Boulanger M, Aqrouq M, …, Olsen JV, Cartron G, Piechaczyk M, Bossis G. "DeSUMOylation of chromatin-bound proteins limits the rapid transcriptional reprogramming induced by daunorubicin in acute myeloid leukemias". Nucleic Acids Res 2023;51(16):8413-8433, doi:10.1093/nar/gkad581, PMID 37462077, PMC10484680 (Methods read). PRIDE contact at SDU Odense. HL-60 cells, triple-SILAC labelled (K0R0 / K4R6 / K8R10); SUMO-1 or SUMO-2/3 immunoprecipitation of endogenous SUMO conjugates, peptide elution, SDS-PAGE, in-gel trypsin digestion, Q Exactive / Q Exactive Plus, MaxQuant.

## Sample map
- **Experiment, fraction, label set** from MaxQuant `summary.txt` (read from inside `txt.zip` by HTTP range + raw-deflate): every file is a fraction 1–10 of experiment `SILAC1/2/3` or `SILAC1/2/3 Inpt`, multiplicity 3, labels Arg6;Lys4 (medium) and Arg10;Lys8 (heavy).
- **Channel → condition** from `txt.zip/Sup Table 3.xlsx` headers: SILAC1 `M/L (SUMO1/CTRL)`, `H/L (SUMO2/CTRL)` → L = control (anti-BrdU) IP, M = anti-SUMO-1 IP, H = anti-SUMO-2/3 IP, all untreated (the paper: SILAC1 samples "immunoprecipitated with control-, anti-SUMO-1 or anti-SUMO-2/3 antibodies and mixed only after elution"). SILAC2/3 `M/L (DNR/NT)` → L = untreated, M = daunorubicin (1 µM, 2 h), IP with SUMO-1 (SILAC2) or SUMO-2/3 (SILAC3); lysates mixed before IP.

- Input runs: the mixed lysates before IP (`enrichment process = none (input lysate)`).

## Key decisions
- Instrument per file from RAW headers: SILAC1 runs (QE5) = **Q Exactive Plus** (MS:1002634); SILAC2/3 runs (QE3) = Q Exactive (MS:1001911). The PRIDE protocol says Q Exactive HF and the PRIDE field says Q Exactive; RAW headers win.
- DDA, HCD NCE 30; fractionation SDS-PAGE (PRIDE:0000568), 10 gel slices = fraction 1–10.
- Labels SILAC light/medium/heavy; label modifications declared as variable: Label:13C(6) R (UNIMOD:188), Label:2H(4) K (UNIMOD:481), Label:13C(6)15N(4) R (UNIMOD:267), Label:13C(6)15N(2) K (UNIMOD:259).
- Search modifications from `summary.txt`/`parameters.txt`: Carbamidomethyl C fixed; Acetyl protein N-term, Deamidation N/Q, Oxidation M variable. Tolerances 4.5 ppm (MaxQuant main search default) and FTMS MS/MS 20 ppm (`parameters.txt`).
- Cell line HL-60 (Cellosaurus CVCL_0002), acute myeloid leukemia (MONDO:0018874), organism part blood; donor female, 36Y (Cellosaurus). DTT stated; NEM was present in the lysis buffer as a deSUMOylase inhibitor, but the alkylation agent for digestion isn't stated → `not available`.
- Factors: enrichment process (IP) and treatment.
