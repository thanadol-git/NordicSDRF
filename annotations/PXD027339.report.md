# PXD027339 annotation report

## Evidence used

- PRIDE project metadata describes 11 human glioblastoma stem-cell lines, analyzed in one TMT16 set with three cell lines run in duplicate.
- Deposited `HGCC_GBM_stem_cell_lines_TMT16_HiRIEF_IPG3-10_labelling_scheme.txt` supplies the channel-to-cell-line and laboratory-ID mapping.
- The project protocol specifies Lys-C/trypsin digestion, TMT labeling, HiRIEF fractionation (pH 3–10), and Q Exactive HF data-dependent acquisition.

## Annotation scope

The SDRF represents the 40 deposited RAW fraction files crossed with the 14 populated TMT channels (560 assay rows). The 133C and 134N channels are omitted because the deposited channel map explicitly marks them `no_sample`. Biological-replicate values 1 and 2 are retained only for the three cell lines marked as duplicate preparations in the deposited mapping. No unsupported treatment or disease-state assignment was inferred.
