# PXD017643 — BLOCKED

## Exact blocker

No deposited file or paper/supplement text maps the iTRAQ 8plex reporter channels (113-121) to the disease-group pools (PPMS, SPMS, RRMS relapse, RRMS remission, AD, NMOSD AQP4-IgG+, NMOSD AQP4-IgG-, healthy). Without that map the 42 RAW files cannot be written as (source, channel) rows. A channel-to-sample map cannot be written without inventing it. In addition, the design leaves open what the channel layout of Sets B and C is: Fig. S2a lists only 7 pools for Set B and Set C (no NMOSD AQP4-IgG-) in an 8-plex, and no source says which channel was unused or whether a different group occupied it.

## Evidence checked

- PRIDE v2 project record and the complete file list (pages 0-3 read; page 0 = 45 entries, pages 1-3 empty): 42 RAW (QHF2221-QHF2262, all `.raw`, Q Exactive HF) plus 3 Proteome Discoverer 1.4 result files (SetA.msf, SetB.msf, SetC.msf, 3-3.6 GB each). No SDRF-like, sample table, or manifest files are deposited. PRIDE sample protocol only says "iTRAQ 8plex ... fractionation by HILIC ... Q-Exactive" and refers to a manual.
- Paper: Elkjaer et al., Sci Rep 2021, 11:4132 (PMID 33603109, PMC7892884; PRIDE `references` entry, Data availability cites PXD017643). Discovery stage: CSF of each of 8 disease groups pooled into 3 technical-replicate pools, each pool labelled with one iTRAQ 8plex reagent, 3 sets (A, B, C) HILIC-fractionated and run on Q Exactive HF; PD 1.4. The text does not give the channel of each group. Group sizes per pool are in Supplementary Fig. S2a (Set A: PP 9, relapse 3, remission 11, SP 9, AD 7, NMOSD+ 5, NMOSD- 5, healthy 10; Set B: 10/3/11/9/7/5/-/11; Set C: 10/2/11/8/8/4/-/11) but that figure carries no channel labels for the iTRAQ part (channel labels appear only for the TMT 11plex plate in panel B, which belongs to the targeted stage, not this deposit).
- Supplementary files from Europe PMC (MOESM1 Fig. S1 legend, MOESM2 Fig. S2 image rendered and viewed, MOESM3 functional-analysis PDF, MOESM4 xlsx protein table, MOESM5 docx Table S2 protein list): none contains an iTRAQ channel map.
- RAW headers (first 1.5 MB by HTTP range, all 42 files): Q Exactive HF, Xcalibur method `AN_2Col_10-34in0.25%_HT_Top12(_Appextriger).meth`, source path `F:\Data\Arek_temp\QHF22xx.raw`; no set, fraction or channel information.
- SetA.msf and SetB.msf header regions (first 60 MB, SQLite; SetC read for the file list): the PD job spectrum-file lists give file-to-set membership (Set A = QHF2221-2235, 15 files; Set B = QHF2236-2247, 12 files; Set C = QHF2248-2262, 15 files), quantification method "iTRAQ 8plex" (reporter integration 50 ppm), Mascot 2.3.26 (Trypsin, 10 ppm precursor, 0.02 Da fragment, static carbamidomethyl C; dynamic iTRAQ8plex N-term/K/Y, oxidation M, deamidation NQ). No sample, group or channel-name strings (searched for Healthy, Remission, PPMS, NMO, Relapse, Alzheimer, Control). The reporter channel names stored in these msf files are plain numeric channels.

No deposited community SDRF was consulted.

## Evidence needed to unblock

A table from the submitters (Larsen lab, SDU) giving, for each of Sets A, B and C, which iTRAQ 8plex channel (113-121) holds which disease-group pool (and which channel is empty in Sets B and C). Optionally the intended fraction order per set (file order QHF2221-2235 / 2236-2247 / 2248-2262 is a plausible HILIC fraction order and is supported by the acquisition dates in the msf file list, but is not stated). With the channel map the dataset can be annotated directly: ms-proteomics + human (+ clinical-metadata), label iTRAQ8plex, 42 files x 8 channels, factor value[disease].
