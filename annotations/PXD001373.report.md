# PXD001373 annotation report

Status: validated annotation; independent review pending.

Label-free proteomics of *Pseudomonas aeruginosa* PAO1 wild type versus a Fap (functional amyloid) overexpression strain, at 7 h and 12 h, soluble and insoluble fractions. Aalborg University, Denmark. Paper: Herbst et al., J Proteome Res 2014, PMID 25317949 (abstract only; not open access).

## Templates
`ms-proteomics` v1.1.0.

## Rows and files
288 rows x 29 columns, one per raw file; all 288 deposited RAW files are claimed once.
- 48 lanes = 2 strains x 2 times x 2 fractions x 6 biological replicates. Each lane was cut into 6 gel pieces, so each lane has fraction identifiers 1-6.
- Strain, time, replicate, fraction and piece come from the run names `Strain_IncubationTime_Replicate_KindOfFraction_FractionNumber`, decoded by the deposited `NameDescription.txt`.
- `source name` is per lane, for example `PAO1_Fap-OE_12h_rep3_mem`. The soluble and insoluble fractions of one culture are separate sources that share a biological replicate number.

## Values
- Factors: `genotype`, `sampling time`, `cellular component`.
- Instrument: Q Exactive. Trypsin only, so there is a single cleavage-agent column.
- HCD, data-dependent. Search: MaxQuant 1.4.1.2, carbamidomethyl C fixed, oxidation M variable, 4.5 ppm precursor and 20 ppm fragment tolerance, taken from the PRIDE processing protocol.

## Validation
- `parse_sdrf validate-sdrf -t ms-proteomics --use_ols_cache_only`: no errors.
- `python -m tools check --offline`: clean.
- `python -m tools structure`: OK.
- `python -m tools reconcile`: every annotated value agrees with the deposit.

## Caveats (please check)
- "Fap overexpression" is inferred from the abstract. The deposit only says "overexpression mutant", and inducer and growth conditions are not stated (full text unavailable).
- The modifications were read from the PRIDE prose. `MaxQuant_Output.zip` (2.6 GB) was not opened. Acetyl protein N-term, which MaxQuant applies by default, is not recorded.
- The instrument was not verified from raw headers. No RAW files were downloaded.
- `organism part` is `not available` (whole cells).
- No existing annotation was found in sdrf-annotated-datasets.
