## Decisions and caveats
- Instrument: PRIDE dropdown lists Q Exactive HF; protocol text and the RAW header (range read, 200 kB) say Q Exactive HF-X; HF-X used.
- Digest: single protease (trypsin), so one cleavage agent column; no Lys-C step reported.
- Sample is recombinant human APP751 on Sepharose beads, incubated with mouse PDAPP cortex lysate. Organism is Homo sapiens (the analyte); organism part is not applicable. The mouse lysate is not annotated as a sample source.
- Factor genotype WT/KO comes from file names and the "PDAPP/KO animal" statement; which gene is knocked out is not stated in the deposit (keyword suggests Sorcs2). Left generic; verify against the paper.
- age, sex, disease, material type: not available (no evidence). Precursor/fragment tolerance and dissociation method: not available (not in deposit; not guessed).
- Modifications read from APP-WT.mzid (Carbamidomethyl C, Oxidation M, Acetyl protein N-term, Met-loss+Acetyl); Carbamidomethyl set as fixed from the protocol, others variable. PRIDE says "No PTMs included", which conflicts with the mzid; mzid used.
- Independent adversarial review (Step 9.5) was not run because subagents were disallowed; review-gate not tracked. Evidence manifest is in PXD067552.evidence.json.
