## Design and choices

- One row per RAW file; each of the 15 SEC fractions (F3, F5, ..., F55) is its own sample measured once, so fraction identifier is 1 and biological/technical replicate 1. The fraction was not a fractionation of one injection.
- Factor: factor value[SEC fraction] mirrors a custom characteristics[SEC fraction] column (values F3 etc.). Both are non-template columns and parse_sdrf accepted them. Fraction number is read from file names; the PRIDE text does not state the mapping explicitly.
- Single protease (trypsin), so one cleavage agent column.
- Modifications taken from mqpar.xml (Acetyl Protein N-term), not from the prose (which says N-terminal methylation); this discrepancy is flagged.

## Limitations

- organism part and developmental stage recorded as not available: the paper does not state a tissue (PRIDE dropdown says leaf/plant cell) or growth stage; harvest at 48 days (batch 1) is only in growth condition.
- The 90-min crude fractions (batch 2) are not part of this deposit (probably PXD058233, listed as related); only 60-min SEC fractions are here, and gradient length per file was not verified from RAW headers.
- Fragment tolerance 20 ppm is the MaxQuant FTMS default from mqpar.xml, dissociation HCD is inferred; RAW headers were not read.
- Reduction (TCEP) and alkylation (IAA) reagents not given as columns. No factor-level antioxidant activity values were encoded.
- Enrichment of the deposit's second FASTA (Brachypodium distachyon) is a search detail, not encoded.
