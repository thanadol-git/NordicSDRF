## Limitations (important)
- **Genotype and age are `not available` for every row.** The paper gives the design (WT vs Cstb-/-, P14/1/3/6 months, n=8 per group; 6 months n=6/6 for CB and HC, 9/7 for cortex) and the group sizes match the searched file counts (CB 60, HC 60, cortex 64), but no deposited file or table maps a RAW file or MaxQuant experiment to genotype or age (mqpar experiments are bare sample numbers; Table S10 holds only group-level statistics). Attempted a data-driven inference (Cstb LFQ intensity in proteinGroups.txt for HC) but zeros occur in many wild-type samples too, so it is not decisive; no inference was made. Consequently `characteristics[disease]`, `developmental stage`, `strain or breed` and the non-ontology columns `characteristics[genotype]` / `characteristics[age]` (added as explicit gaps) are `not available`. Submitters can fill them from the sample key.
- `characteristics[genotype]` and `characteristics[age]` are not in the vertebrates contract; they validated without error but are our additions.
- Source names are our own labels (CB_<n>, CTX_<n>, HC_<n>) from the mqpar experiment names; biological replicate set to 1 for every source because replicate grouping is unknown. Six cortex RAW files (EH1933-36, EH1938-39) are in the ZIP but not in the deposited MaxQuant search; they are named CTX_unsearched_<run> and may be QC/extra runs (unknown).
- `comment[data file]` holds the inner RAW name (e.g. EH2697.raw), which lies inside the ZIP archive.
- Instrument taken from PRIDE/protocol; RAW header not read. Dissociation HCD inferred from "high-energy collision-induced dissociation".
- Precursor tolerance 4.5 ppm from mqpar (protocol text says 6 ppm). Cleavage annotated as Trypsin; search used Trypsin/P.
- Optional gradient/LC columns omitted. Python network lookups failed in the venv sandbox (DNS), so ontology checks ran offline plus curl to OLS.
