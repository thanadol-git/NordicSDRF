## Decisions and caveats

- Fractions: the two phospho files per experiment (`_01`/`_02`) are annotated as fractions 1 and 2 because the deposited summary.txt assigns them Fraction 1/2 of one MaxQuant experiment. The physical nature is not stated; no fractionation method column was added. Proteome runs: fraction 1 (MaxQuant lists 4-6, a grouping quirk).
- Treatment F1/F3/F7/F10 expanded to fibroblast growth factor 1/3/7/10: inference from file tags and FGFR2 context; dose and source not stated. UT annotated "untreated" at the same time point.
- Cleavage: protocol is Lys-C followed by trypsin, the search used Trypsin/P; the template column is single-valued (a two-value build kept only the first), so Trypsin MS:1001251 is declared and Lys-C is not.
- Modifications read from deposited summary.txt (one search for all files): Carbamidomethyl C fixed; Oxidation M, Acetyl protein N-term, Gln->pyro-Glu, Phospho STY variable. The protocol text gives a different variable set for the proteome (deamidation, no phospho) than the file shows.
- Precursor tolerance 7 ppm and fragment 20 ppm from protocol text; collision energy 28 NCE from protocol.
- Age 54Y, sex female, disease, breast from Cellosaurus CVCL_0553, not from the deposit. Passage number, medium, storage temperature, ancestry omitted/not stated.
- FGFR2 knockout method not stated; WT rows written as "wild type".
- No publication/DOI in the PRIDE record; Methods come from the PRIDE protocol fields only.
