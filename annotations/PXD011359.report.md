## Scope: deposited vs annotated

## Sample map

## Key decisions
Each sample has 4 runs (_3_I, _3_II, _6_I, _6_II) on the same 260-min method (RAW headers). The record does not explain the codes, so they are kept in comment[run code] and treated as technical replicates 1-4. Disease of Lp30 progenitors 'not available' (the model develops AML, but the leukemic state of these sorted cells is not stated). Instrument Orbitrap Fusion from RAW headers (PRIDE: Fusion ETD).
