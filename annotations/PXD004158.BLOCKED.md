# PXD004158 — blocked: no per-file sample mapping is publicly available

## Sources checked

- PRIDE project record: https://www.ebi.ac.uk/pride/ws/archive/v2/projects/PXD004158
- PRIDE file manifest: https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD004158/files/all
- Linked PubMed record: https://pubmed.ncbi.nlm.nih.gov/27630166/

## Evidence available

PRIDE describes bovine IL-1-stimulated cartilage incubated with human serum, analysed by label-free SRM and tandem MS. The manifest contains 164 vendor RAW files named only with date and numeric aliases, for example `Camilla_H1506_066.raw` and `Camilla_H1508_109.raw`.

## Blocking gap

The linked article has no PMCID/open-access full text or public supplementary sample table. Neither PubMed nor the PRIDE project record maps the RAW aliases to cartilage condition, incubation time, species/material, assay type, or replicate. These values cannot be inferred from the filenames.

## Unblock requirement

Provide the study's sample sheet or another authoritative RAW-file-to-condition mapping, including which files belong to SRM versus discovery MS. Then a complete SDRF can be generated.
