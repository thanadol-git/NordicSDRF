# PXD013458 SDRF annotation report

## Study
"Methylated trypsin - Enhanced trypsin on a budget" (Heissel, Frederiksen, Bunkenborg, Hojrup; PLoS One 2019, PMID 31246970, PMC6597055). Host-cell-protein (HCP) analysis of three porcine trypsin preparations: Promega sequencing grade modified trypsin (PSG), enhanced (reductively methylated, benzamidine-purified) Sigma IX-S trypsin, and crude Sigma IX-S trypsin. 1 ug of each preparation was autodigested in triplicate, micropurified, and run on EASY-nLC II / Q Exactive HF.

## Templates
`ms-proteomics` v1.1.0 + `vertebrates` v1.1.0. Vertebrates because the sample organism is Sus scrofa. No cell-line, clinical or label-specific template applies. Choice made without user confirmation (non-interactive).

30 deposited files: 9 RAW (QEHF3_06611_SJF_0, 06612-06616, 06620-06622), 9 mgf peak lists, 9 X!Tandem .t.xml results, 2 fasta, SampleInfo.txt. All 9 RAW annotated (3 preparations x 3 replicates, label free, unfractionated). Excluded from `comment[data file]` by design: mgf, t.xml, fasta, SampleInfo.txt (derived or auxiliary, not vendor RAW). No raw file left out. PRIDE submission type is PARTIAL.

## Key decisions
- Sample identity from `SampleInfo.txt` (run number -> preparation, replicate). Note 06611 is stored as `QEHF3_06611_SJF_0.raw`.
- `factor value[treatment]` = the compared variable, mirrored by `characteristics[treatment]` (the licensed column; round-2 review asked for a mirrored characteristic). Values: Promega sequencing grade modified trypsin / reductively methylated benzamidine-purified Sigma IX-S trypsin / crude Sigma IX-S trypsin (names from SampleInfo.txt + Methods). parse_sdrf warns these free-text values are not found in NCIT/EFO; accepted, no ontology term exists for these preparations.
- Cleavage agent Trypsin (MS:1001251): the digested protein is trypsin autolysis; X!Tandem searched semi-tryptic. Search was semi-tryptic, which the single cleavage column cannot express.
- Modifications read from the deposited X!Tandem parameter block (all nine t.xml files, HTTP range; identical): Carbamidomethyl C fixed; Oxidation M, Methyl K (UNIMOD:34), Dimethyl K (UNIMOD:36) variable. X!Tandem "quick acetyl"/"quick pyrolidone" refinement flags were on (acetyl protein N-term, pyro-Glu); not written as they are refinement defaults, not declared parameters in Methods. (Judgement call.)
- Dissociation HCD (MS:1000422): not in the paper; read from the instrument method XML in the QEHF3_06612_SJF.raw header (Fragmentation_HCD NCE 28 on the MS2 event). Only one RAW header inspected.
- Instrument Q Exactive HF confirmed by RAW header and Methods; DDA ("Top 10 DDA"); MS2 analyzer Orbitrap (MS2 resolution 15 000 stated).
- Tolerances 10 ppm / 0.1 Da from the X!Tandem search (the paper's MaxQuant search tolerances are not stated; MaxQuant was used for a different part of the study, see below).

## Values left reserved
- `not available`: organism part, developmental stage, strain or breed, sex (commercial porcine trypsin; animal/tissue not stated).
- `not applicable`: cell type, disease (enzyme preparations).

## Conflicts
- Digestion: PRIDE protocol says 55 C for 1 h; paper Methods say 58 C for 2 h (HCP experiment, in 20 mM AMBIC pH 7.8). No SDRF column carries this; flagged only.
- Paper also describes MaxQuant searches (protein mixture, HeLa) of other experiments that are not part of this deposit; the deposit's searches are X!Tandem + PeptideShaker (PRIDE data processing text, deposited t.xml). PRIDE modifications CV terms (hydroxylation, carbamoylation) are not in the search parameters and were not used.

Verified (round-1 follow-up): the X!Tandem parameter block was read from all nine t.xml files and is identical in modifications, tolerances and semi-tryptic setting.
