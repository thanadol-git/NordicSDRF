# PXD037009 SDRF annotation report

## Study
Site-resolved ubiquitylation occupancy (stoichiometry via partially chemically di-glycinated SILAC standard) and turnover (TAK-243/MLN7243 time courses, proteasome-inhibitor combinations) in HeLa cells (Cell 2024, 10.1016/j.cell.2024.03.024).

## Templates
ms-proteomics + human + cell-lines v1.1.0

## Scope: deposited vs annotated
Partial: 822/968 top-level RAW (every run listed in the deposited ALL_EXPERIMENTS_SUMMARY.xlsx: pcGG degree batches, native Ub stoichiometry, Ub half-life, MG132/BTZ + MLN7243 GG-IP and proteome), one row per SILAC channel (2038 rows). Not annotated: 146 top-level RAW absent from the summary sheet (HeLa MLN7243 time-course UbIP, NIH-3T3 and other time-course GG-IP) and the RAW inside the 5 zips (CHX, HCT116 and NIH-3T3 time courses/proteomes, THL; ~177 runs).

## Sample map
ALL_EXPERIMENTS_SUMMARY.xlsx gives per run: fraction, experiment set, analysis, cell type, experiment type (GG-IP / proteome) and the content of the SILAC light/medium/heavy channels. Sheet names differ from deposited RAW names only by '%' and '+' -> '_' (verified for all 822).

## Key decisions
Instrument per run from the instrument tag (RAW headers checked: QE1/QE2 = Q Exactive HF, QE8 = HF-X, EXPL = Exploris 480). Cysteine block: CAA (TCEP) for the stoichiometry/pcGG experiments, NEM (DTT) for the time-course/inhibitor experiments, per protocol. SILAC medium Lys4/Arg6 and heavy Lys8/Arg10 assumed (isotopes not stated). Fractionation: SCX for '_scx' runs, otherwise high-pH RP. Experiment set number (E1, E2...) used as biological replicate. Rows flagged 'swapped labels' in the sheet kept as stated in its channel columns (note column copied). MaxQuant mods/tolerances from the record.
