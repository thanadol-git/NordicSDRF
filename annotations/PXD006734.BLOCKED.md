# PXD006734 — blocked: heterogeneous RAW files lack an experiment-level sample map

## Sources checked

- PRIDE project record: https://www.ebi.ac.uk/pride/ws/archive/v2/projects/PXD006734
- PRIDE file manifest: https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD006734/files/all
- Paper: https://pmc.ncbi.nlm.nih.gov/articles/PMC5563132/ (PMID: 28608391; DOI: 10.1002/pro.3213)
- Supplement bundle: https://www.ebi.ac.uk/europepmc/webservices/rest/PMC5563132/supplementaryFiles

## Evidence available

The paper documents multiple Arabidopsis Hsp21 experiments: purified 14N/15N protein mixed with isolated thylakoids; heat-stressed and control 14N/15N plants; thylakoid and stroma fractions; gel-band digests; and repeat/re-run acquisitions. It provides LTQ Orbitrap Velos Pro DDA, trypsin, 15N metabolic quantitation, 10 ppm precursor, and 0.05 Da fragment settings.

## Blocking gap

PRIDE contains 130 RAW files spanning filename families such as `KatjaThyl*`, `KatjaStroma*`, `161122_H_*`, `170118_V_*`, and gel-mix reruns. The paper and available supporting figures/tables do not map each raw file to its exact experiment, isotope state, heat treatment, fraction, gel band, or replicate. Inferring these assignments from aliases would mix biologically different analyses.

## Unblock requirement

Provide an authoritative raw-file sample sheet that assigns every deposited RAW file to experiment, material/fraction, isotope state, temperature treatment, gel fraction, and replicate.
