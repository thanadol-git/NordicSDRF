# PXD036333 annotation blocked

PXD036333 ("Acetylomics data of the Anti-Proliferative Activity of Safranal on Triple-Negative Breast Cancer Cell", MDA-MB-231, Orbitrap Fusion Lumos) is a single TMT 11-plex run (`LUM_05061_Mahshid.raw`, with `.mzML`, a converted `Mashid_acetylated.mzML` duplicate and `Mashid_acetylated.mzid.gz`). The design is stated only as counts: safranal at 30 min, 12 h and 24 h with three replicates each, plus two DMSO 12 h controls (9 + 2 = 11 channels). Nothing in the record says which TMT channel (126 ... 131C) holds which sample, and the order of replicates is not recoverable. Inventing the map would put wrong condition labels on every row, so no SDRF is emitted.

Evidence checked: PRIDE v3 project record and `files/all` (4 files, all with accession PXD036333); PRIDE sample/data protocols (counts only, no channel layout); Europe PMC for the paper (PMID 36173113, J Proteome Res 2022, doi 10.1021/acs.jproteome.2c00168; not open access, not in PMC, Unpaywall `closed`, so no Methods or supplement readable); the `Mashid_acetylated.mzid.gz` header (PD export with no sample or channel annotation); PRIDE keyword search and Zenodo search for a layout file (none found). The companion phosphoproteomics deposit PXD036323 uses the same design, and its protocol text is also count-only. Its deposited SDRF was deliberately not used as evidence.

Evidence needed to unblock: the paper's Methods or supplementary sample table giving the TMT channel for each safranal time point and replicate and for each DMSO control, or a submitter-provided channel sheet or PD study file.
