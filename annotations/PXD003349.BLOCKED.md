# PXD003349 — blocked: ten deposited RAW files lack a sample-guide mapping

## Sources checked

- PRIDE project record: https://www.ebi.ac.uk/pride/ws/archive/v2/projects/PXD003349
- PRIDE file manifest: https://www.ebi.ac.uk/pride/ws/archive/v3/projects/PXD003349/files/all
- Paper: https://pmc.ncbi.nlm.nih.gov/articles/PMC5065702/ (PMID: 27757071; DOI: 10.1186/s12014-016-9123-z)
- Additional file 1 workbook: https://www.ebi.ac.uk/europepmc/webservices/rest/PMC5065702/supplementaryFiles

## Evidence available

The paper describes the db/db kidney study as five healthy db/+ controls, five db/db vehicle mice, and five db/db insulin mice, each prepared as two technical replicates. Additional file 1f maps 26 deposited RAW files to those exact kidney and replicate identities: nine db/+, nine db/db vehicle, and eight db/db insulin files. The omissions within those named groups are explicit in the worksheet and match the available source rows.

## Blocking gap

PRIDE contains 36 vendor RAW files. Ten `140218_LL_LiraI_B*_6Dil_01.RAW` files are present in the manifest but have no row in Additional file 1f and no group, kidney, or replicate assignment in the PRIDE record or paper. A complete SDRF cannot silently omit these files, and assigning the `B` prefix by inference would be unsupported.

## Unblock requirement

Provide an authoritative mapping for the ten `B`-prefix RAW files, or repository confirmation that they are out of scope for PXD003349. Then the full manifest can be annotated and reconciled.
