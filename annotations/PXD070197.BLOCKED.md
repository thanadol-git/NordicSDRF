# PXD070197 — digestion reagent not documented

The depositor's SDRF describes 24 mouse dermal-fibroblast acquisitions across OTULIN WT/Y56A, 0/5-minute TNF, TNF/Met1 pull-down, and three biological replicates. All 24 samples were mapped to accession-scoped RAW ZIPs. The depositor SDRF misnames plate positions for runs S13–S24 as E13–E24; the archive files use F1–F12. Their run numbers and acquisition IDs give an unambiguous correction.

The first draft passed template validation (with time-format warnings), structure and offline checks. Project-record reconciliation and independent review rejected `NT=Trypsin;AC=MS:1001251` because the project does not name the digestion enzyme. The deposited peptide termini are 98.9% K/R-compatible, but that is indirect evidence. The independent FAIL report is `/tmp/PXD070197.independent-review.json`; the unapproved draft and evidence manifest remain in `scratchpad/PXD070197/`. No SDRF is approved or committed.

The reviewer also identified `0 min`/`5 min` sampling-time values as warnings; a resumed draft should use `0 minute`/`5 minute`. Completion requires a primary source naming the reagent, or a scientifically justified template-compatible representation of the undocumented reagent, followed by fresh validation and independent review.
