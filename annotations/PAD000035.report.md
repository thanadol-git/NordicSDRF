# PAD000035 annotation report

## Result

98-row affinity-proteomics SDRF for `FIDO_Olink.npx.csv`. Templates: `affinity-proteomics` v1.0.0 + `human` v1.1.0. Factor is `factor value[disease]`.

Not already in `bigbio/sdrf-annotated-datasets`.

## Evidence

- PRIDE: PAD000035, FIDO (Febrile Infant Diagnostic Assessment and Outcome). Submitter/PI Clare Mills, Queen’s University Belfast. Protocol paper: Umana et al., *BMJ Open* 2023, PMID 37730397, PMCID PMC10514651, DOI 10.1136/bmjopen-2023-075823 (trial NCT05259683). Infants ≤90 days with fever; residual EDTA plasma.
- Olink Explore Neurology and Inflammation (735 assays, ExploreVersion 3.8.1), one plate `ClareMills_QUB_PlateLayout1`, lots B23408 / B23405. PRIDE instrument field is Olink Explore 3072/384; two Explore 384 panels were used, so `comment[platform]` is `Olink Explore 384`. NPX provided intensity-normalised / log2 by Randox.
- Per-sample table `FIDO_Metadata_PRIDE.csv` matches all 98 NPX SampleIDs (sex, age band, infection type). Age is the deposited band (`<28D` / `>=28D`), not exact day of life. Developmental stage follows that split (`neonate` / `infant`).
- Infection type mapping: Bacterial → bacterial infectious disease; Viral_meningitus → viral meningitis; Viral_other → viral infectious disease; None → fever of unknown origin (undifferentiated febrile residual class in the deposit).

## Conservative choices

- Did not use PRIDE `bacterial sepsis` for the Bacterial class (the metadata does not split bacteraemia / meningitis / UTI).
- CSF pleocytosis was not added (not a standard template column; many N/A).
- Assay-level QC_Warning `EXCLUDED` / Normalization `Plate control` were not promoted to sample exclusion; every SampleID is a study sample.
- Samples without consent for future use were already removed by the submitter.

## Validation

Left for a separate review agent. Structural checks: 98 rows, 29 columns, no empty cells, unique `source name` and `assay name`.
