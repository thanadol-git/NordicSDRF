# PXD019488 SDRF annotation report

## Study
Identification of TbUnc119-interacting proteins by proximity-based biotinylation (Trypanosoma brucei, National University of Singapore; lab head Cynthia Y. He).

**Paper:** Pandey M, Huang Y, Lim TK, Lin Q, He CY. Flagellar targeting of an arginine kinase requires a conserved lipidated protein intraflagellar transport (LIFT) pathway in *Trypanosoma brucei*. J Biol Chem 2020;295(32):11326-11336. DOI 10.1074/jbc.RA120.014287, PMID 32587088, PMC7415996. The preprint is bioRxiv 10.1101/2020.05.07.083568.
- The paper's Data Availability statement cites PXD019488, so the link is verified.
- The PX record itself still says "Dataset with its publication pending".

## Scope, evidence and decisions
**Status: annotated.** The SDRF has 2 rows (2 label-free `.wiff` runs × 1) and 31 columns. Template: ms-proteomics only, because there is no protist organism template. This follows the earlier T. brucei SDRF PXD061390 and the Leishmania BioID SDRF PXD075501.

**Deposited vs annotated.** The PROXI record (`resultType=full`, accession checked) lists 10 files. The PRIDE FTP directory (`archive/2020/06/PXD019488/`) lists those 10 files plus `README.txt`.
- **Vendor RAW:** 4 files = 2 runs, as the campaign cache said (4 RAW / 10 files, TripleTOF 5600).
  - `3HA-BioID2-TbUnc119.wiff` (2.2 MB) + `3HA-BioID2-TbUnc119.wiff.scan` (185 MB).
  - `TbUnc119-BioID2-HA.wiff` (18 MB) + **`TbUNc119-BioID2-HA.scan`** (487 MB). This scan file is misnamed: it has a capital N and lacks `.wiff`, so vendor software will not pair it with its `.wiff` until it is renamed. The pairing is stated in the FTP README (search IDs 16/17 → files 15, 18, 19).
- **Peak lists, not annotated:** 2 `.mgf`, generated by ProteinPilot 5.0.
- **Search results, not annotated:** 2 Mascot `.dat` and 2 ProteinPilot `.group` files.
- `comment[data file]` = the `.wiff`. Annotated = 2/2 runs. Nothing was excluded.

**Run → sample map (STATED).** The submitter's deposited file names give the bait construct for each run. The FTP README ties each `.dat`/`.group` file to its own mgf/wiff/scan set. The two constructs are the ones the paper describes:
- `3HA-BioID2-TbUnc119`: the N-terminal BioID2 fusion.
- `TbUnc119-BioID2-HA`: the C-terminal BioID2 fusion.

Both are expressed in procyclic T. brucei (DIpAnt background), with cumate induction for 16 h and biotin added 8 h before harvest. Each construct is a single independent BioID experiment, so `biological replicate` = 1 and `technical replicate` = 1.
- The construct is carried in `characteristics[treatment]` and `factor value[treatment]`. This column is licensed by sample-metadata, which ms-proteomics extends.
- `sample type` = study sample.

**Original acquisition names (from the search outputs).**
- The 3HA `.dat` searched `180121_HYM_HA_UNC119_2ul.mgf`. This fits an N-terminally HA-tagged Unc119 sample acquired in January 2018.
- The HA `.dat` searched `180613_CYN_SPl3_UB_1hr_5ul.mgf`. Every TITLE line in the deposited HA `.mgf` reads `File:"180613_CYN_SPl3_UB_1hr_5ul.wiff"`, and every locus is 1.1.x, so the file holds a single wiff sample.
- That original name does not spell out the construct. The C-terminal assignment rests on the submitter's renaming alone (see Review status).

**Not deposited.** The paper's wild-type negative-control pulldowns, which were used to subtract background, have no run in the deposit. Only the two bait runs were submitted.

**Instrument and acquisition.** The instrument is the TripleTOF 5600 (MS:1000932). The PX field, the paper (AB SCIEX TripleTOF 5600, Eksigent nanoLC Ultra + ChiPLC-nanoflex trap-elute, Analyst 1.6) and Mascot `INSTRUMENT=ESI-QUAD-TOF` all agree.
- Acquisition was IDA → DDA (PRIDE:0000627).
- Dissociation is beam-type CID (MS:1000422); the MS2 analyzer is TOF (MS:1000084). Both are INFERRED from the instrument class.
- The `.wiff` headers were not read (binary).

**Search parameters (from both deposited Mascot `.dat` parameter blocks, which are identical).**
- Trypsin (Restrict P), 1 missed cleavage.
- Tolerances: precursor 100 ppm, fragment 0.4 Da.
- No fixed modifications. Variable: Acetyl (N-term), Methylthio (C) and Oxidation (M).
- These map to UNIMOD:1 (PP=Any N-term), UNIMOD:39 (TA=C) and UNIMOD:35 (TA=M), all Variable. The record IDs 1, 39 and 35 are confirmed by the unimod XML embedded in the `.dat`.
- The PX modification list (methylthiolated, monohydroxylated, acetylated residue) agrees.
- Methylthio C is entered as Variable, exactly as searched, even though the protocol alkylated with MMTS.

**Sample prep (paper).**
- Reduction: on-bead TCEP, 50 °C for 1 h → PRIDE:0000609.
- Alkylation: MMTS, 15 min at room temperature → PRIDE:0000605.
- Digestion: on-bead with trypsin, 2.5 µg, overnight.
- No fractionation, so `fraction identifier` = 1.

**Values left not available / not applicable.**
- `organism part` = not applicable (unicellular culture).
- `disease` = not applicable.
- No `cell type` column. The procyclic life-cycle stage has no CL term, and no licensed column carries it, so it is recorded here only.
- No strain column: ms-proteomics does not license `strain or breed`. The background is DIpAnt PCF, which carries the cumate- and tetracycline-inducible system.
- Collision energy and m/z ranges are omitted because they are not stated.

**Conflicts.** The paper Methods give Mascot 2.4.0 and the TREU927 Release-28 database. The deposited `.dat` headers show Mascot 2.6.1 and `180911_CYN_He_Database_20180911.fasta` (31,448 sequences), searched on 2018-09-11. The deposited search output was followed. No SDRF column depends on this.

**Ontology verification.** EBI OLS4 returned "upstream connect error" on 3 attempts. The terms were therefore checked against the live upstream OBO files:
- psi-ms.obo v4.2.18: MS:1000932 TripleTOF 5600, MS:1000422 beam-type collision-induced dissociation, MS:1001251 Trypsin, MS:1000084 time-of-flight.
- pride_cv.obo release 2026-11-23: PRIDE:0000605, PRIDE:0000609, PRIDE:0000627 and "study sample".
- NCBITaxon:5691 Trypanosoma brucei: from the PX record species terms.

**Validation.**
- `parse_sdrf validate-sdrf --template ms-proteomics --use_ols_cache_only` → "Everything seems to be fine". It ran structural checks only; it could not check ontology terms because the OLS dependencies are not installed.
- `sdrf_review.py` → [OK].

pending. A reviewer should challenge these points:
1. The `TbUnc119-BioID2-HA` → C-terminal construct mapping rests on the submitter's file rename. The original acquisition is named `180613_CYN_SPl3_UB_1hr_5ul`.
2. The misnamed scan file `TbUNc119-BioID2-HA.scan` is annotated as part of the `TbUnc119-BioID2-HA.wiff` run.
3. Methylthio C is Variable, as searched, rather than Fixed.
4. The beam-type CID and TOF entries are inferred from the instrument class.
5. The paper's WT control runs are absent from the deposit.
