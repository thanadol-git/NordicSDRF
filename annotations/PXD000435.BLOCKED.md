# PXD000435 — annotation blocked

PRIDE's complete file manifest for PXD000435 contains 252 derived files (MGF/mzTab and a PDF) but no vendor RAW, WIFF, or Bruker `.d` acquisition files. The linked open-access paper (PMCID: PMC4079953; PMID: 24947944) confirms that the potato apoplast samples were measured on an LTQ Orbitrap XL and later converted to mzML/MGF, but it does not provide the original raw-file archive.

An SDRF must put vendor acquisition files in `comment[data file]`; substituting converted MGF or mzTab outputs would be invalid. No SDRF is emitted.

Evidence checked: PRIDE PXD000435 project record and complete file manifest; Ali *et al.*, *BMC Genomics* (2014), DOI 10.1186/1471-2164-15-497 / PMCID PMC4079953.

Unblock with an accession, repository link, or deposited archive containing the original vendor raw files and their sample-to-run mapping.
