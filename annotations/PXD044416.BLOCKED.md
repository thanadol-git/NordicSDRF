# PXD044416 — blocked

## Exact blocker

The two deposited run-information workbooks contain a nearly complete sample map, but 15 deposited RAW-file coordinates do not match that map exactly. Resolving them would require treating conflicting dates, dilution factors, or patient run identifiers as depositor typos. Because this campaign forbids inferred sample/run mappings, a complete SDRF covering all 198 RAW files cannot be written safely.

## Evidence checked

- [PRIDE project PXD044416](https://www.ebi.ac.uk/pride/archive/projects/PXD044416) and [publication DOI 10.1183/23120541.00781-2025](https://doi.org/10.1183/23120541.00781-2025), PMCID PMC13152359: the study analyzes human bronchoalveolar lavage fluid after lung transplantation using paired label-free DDA and targeted PRM runs. The paper and its supplementary files were checked for a corrected file table; none supplies one.
- Complete [PRIDE file inventory](https://www.ebi.ac.uk/pride/ws/archive/v2/projects/PXD044416/files): 198 RAW files were enumerated, comprising 99 LFQ/DDA and 99 PRM files.
- Deposited [`Info_LFQ_data.xlsx`](ftp://ftp.pride.ebi.ac.uk/pride/data/archive/2026/06/PXD044416/Info_LFQ_data.xlsx): 99 rows give exact raw-file stem, patient experiment identifier, month, CLAD status, transplant type, and gender. Exact comparison with the PRIDE inventory leaves deposited `210608_QExHF_LA_MS755_rx444_2xdil.raw` absent from the workbook, while workbook row `210608_QExHF_LA_MS755_rx536_2xdil` has no deposited LFQ RAW counterpart.
- Deposited [`Info_PRM_data.xlsx`](ftp://ftp.pride.ebi.ac.uk/pride/data/archive/2026/06/PXD044416/Info_PRM_data.xlsx): 99 rows give the same biological metadata for targeted files, but 14 filenames conflict with the deposited RAW names:
  - For experiments 15, 61, 70, 160, 200, 224, and 227, the workbook names files dated `210609`, while PRIDE contains otherwise corresponding files dated `210608`.
  - For experiments 327, 342, 343, 351, 387, 640, and 650, the workbook names `4xdil` files, while PRIDE contains otherwise corresponding `2xdil` files.
- The workbook and inventory comparisons were performed as exact string-set comparisons after adding only the omitted `.raw` extension to LFQ workbook stems. No fuzzy matching was used.

## What would resolve it

A corrected depositor run-information table that uses the exact 198 filenames present in PRIDE, or an explicit author statement mapping the 15 conflicting inventory filenames to their intended workbook rows. Matching by shared `rx` number while silently changing date/dilution is not acceptable evidence.
