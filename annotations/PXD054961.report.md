RAW files `N1-N8`, `P2-P8`, `T1-T8` (23; a trailing `x` on some names is unexplained and ignored). **The letter-to-group mapping N = NG, P = PTDM, T = T2DM is inferred from the file names and the paper's group names** (the deposited `Data_info.csv` is only an empty SDRF stub).
