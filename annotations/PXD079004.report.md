## Design and file mapping (deposited sample key)
The deposited `SampleKey_Tubules_ReplicateComparison.txt` describes each of the 48 RAW files: tubules (mouse kidney, collagenase-extracted) after an ex-vivo perifusion experiment, with the final treatment and chamber number. File names `run<12|13|14|18|19>_ch<n>_tubule[_male|_female]_<AAH2O2|ctrlH2O2|AA>.raw`. Per run: run12 (chambers 1-4 AAH2O2, 5-8 ctrlH2O2), run13 (1-3 AAH2O2, 4-8 ctrlH2O2 - the key says "AAH2O2 chamber 1-4" but there are only 3 AAH2O2 and 5 ctrlH2O2 files, so the key's chamber 4 line is `ctrlH2O2` in the file name: **the file name is followed**), run14 (1-4 AAH2O2, 5-8 AA), run18 and run19 (chambers 1-6 male tubules, 7-12 female tubules, all AAH2O2). One RAW file per chamber sample; all 48 annotated. Source name `run<k>_ch<n>`; `comment[sample preparation batch]` = perifusion run; `characteristics[biological replicate]` = chamber number (1-12) (**chambers are the independent samples; mice per chamber are not stated**).
Factor: `factor value[treatment]` using the codes as written in the key. **The codes are not defined in PRIDE:** AA and H2O2 plausibly stand for amino acids and hydrogen peroxide (and `ctrl` for the control buffer), but this is not stated, so the codes are kept verbatim in `characteristics[treatment]` and not expanded. Sex is taken from the file names (`male` / `female`) and from the key ("Female tubules"); runs 12-14 do not state sex (`not available`).

## Technical values
Orbitrap Exploris 480 (PRIDE record and protocol), FAIMS standard resolution at alternating CV -40 and -61 V, 400 ng peptides, 60 min gradient. DIA with Spectronaut v19.1 directDIA; window scheme, dissociation and tolerances are not given in this record (`not available`). Trypsin; SP3; TCEP/chloroacetamide. Spectronaut: fixed Carbamidomethyl C; variable Oxidation M and protein N-terminal Acetyl. No fractionation. Raw headers not read.

## Limitations
- Strain, age and developmental stage `not available` (the PRIDE text only says "mouse kidneys"). Disease `not applicable` (not a disease study).
- `renal tubule` as the organism part (the PRIDE record lists "Kidney tubule cell"; the tubule extraction is a mix of segments, with proximal tubule dominating, per the project title).
- The perifusion time course and the intermediate stimuli are not in the record, so `sampling time` is omitted and the treatment codes describe only the final treatment.
