# PXD003495 — blocked

## Exact blocker

The deposited workbook supplies most reporter-channel-to-strain assignments for four TMT10 plexes, but it omits every `126` denominator channel and does not map the four plex identifiers (`A4`-`D4`) to the four groups of 18 RAW files. Completing an SDRF would require assuming both the identity of each `126` sample and that chronological RAW acquisition groups correspond to plexes 1-4 in workbook order.

## Evidence checked

- [PRIDE project PXD003495](https://www.ebi.ac.uk/pride/archive/projects/PXD003495): the protocol states that four TMT10 sets were analyzed, with about 20 fractions per set, and that each set contained biological duplicates of one wild type and four mutants. The data-processing description says ratios were calculated against one wild-type control within each plex, but it does not identify the denominator strain/channel row or connect a plex to RAW filenames.
- [Publication DOI 10.1093/molbev/msw028](https://doi.org/10.1093/molbev/msw028), PMCID PMC4868123: the full article and deposited publication supplement were checked. They support the organism, growth conditions, strains, and four-set duplicate design, but do not contain a Proteome Discoverer run/fraction table or complete reporter-channel layout.
- Complete [PRIDE file inventory](https://www.ebi.ac.uk/pride/ws/archive/v2/projects/PXD003495/files): 72 RAW files form four date/counter groups of 18 files each (`QE_140206_01-18`, `QE_140221_06-23`, `QE_140224_08-25`, and `QE_140618_03-20`). Filenames contain no `A4`/`B4`/`C4`/`D4` plex identifier and no explicit fraction label.
- Deposited `Strain ID and genotype MS labeling  Anna Knöppel.xlsx`: the checked sheet explicitly maps listed channels to strain IDs and genotypes for plexes 1-4. Every listed position is expressed as a ratio to `126`, but there is no row for `126` in any plex. The sheet also has no RAW filename or acquisition-date column.
- No additional design-bearing PRIDE files are deposited; the only non-RAW project file is the mapping workbook above.

## What would resolve it

An author/depositor table that (1) explicitly identifies the strain/sample in channel `126` for each plex and (2) maps each of the four plexes to its exact 18 RAW files in fraction order. A statement that the date groups follow plex-number order would also resolve the run mapping if accompanied by the complete `126` assignments. Neither denominator identity nor plex order may be reconstructed from ratio notation or chronology alone.
