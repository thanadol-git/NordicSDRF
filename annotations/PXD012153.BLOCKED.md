# PXD012153 — annotation blocked

Proteome of PANC-1 pancreatic ductal cells persistently infected with coxsackievirus B1 (strains ATCC and 10796) vs non-infected cells. University of Turku. Paper: Lietzén et al., iScience 2019 (PMC6699423).

## What is known
- **Runs:** samples 1–9, each injected about 3 times. Some injections were repeated (`_1b`). Q Exactive HF.
- **Design:** the paper compares non-infected cells with cells persistently infected with two CVB1 strains (ATCC and 10796). Samples were collected 300, 315 and 322 days post-infection, giving 3 groups × 3 biological replicates.
- **Search:** MaxQuant against human SwissProt plus enterovirus sequences. Carbamidomethyl C fixed; Oxidation M and Acetyl protein N-term variable.

## Why it is blocked
The file names only give sample numbers. No deposited text maps samples 1–9 to infection group. I have since opened `MaxQuant.7z`: its `summary.txt` uses the raw file names as experiment names, so it does not contain the key either.

## What would unblock it
A table mapping samples 1–9 to infection group and collection day.
