# PXD037803 annotation report

## Result

Annotated 118 of 167 deposited RAW files for the multi-protease benchmark. The SDRF contains only files with an explicit sample/system/enzyme assignment and a correct applicable PSI-MS cleavage-agent term.

## Exclusions

- 24 deposited RAW files have no matching row in `info.csv`.
- 25 elastase RAW files were excluded because the evidence specifies pancreatic/generic elastase, while the applicable ontology source only exposes a leukocyte-elastase term. Substituting that term would misidentify the enzyme.

## Evidence

- PRIDE: https://www.ebi.ac.uk/pride/archive/projects/PXD037803
- Publication: DOI `10.1371/journal.pcbi.1010457`; PMCID `PMC9891523`
- Deposited design: `info.csv`
- Per-file cleavage agents from `info.csv` and the publication take precedence over the generic trypsin wording in the project summary.
