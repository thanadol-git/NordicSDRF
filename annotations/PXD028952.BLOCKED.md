# PXD028952 - BLOCKED (not annotated)

Study: Staehr et al., J Am Heart Assoc 2022 (PMID 35289188, PMC9075430), "Migraine-associated mutation in the Na,K-ATPase ... cardiac metabolism". Mouse (alpha2+/G301R vs WT), 10-plex TMT, HILIC 24 fractions x 2 TMT sets, Q Exactive, Proteome Discoverer 2.1 (Sequest + Mascot).

Deposit: 48 RAW files (PRIDE v2 file list, page 0 = 50 entries, page 1 empty: 48 RAW + 1 .msf + 1 .pdResult). RAW names: Vladimir_Brian/Brain_GB1-12, Vladimir_brain_GC1-12, Vladimir_Brain_saet2_GF1-12, Vladimir_Brain_saet2_GG1-12.

## Why it cannot be annotated defensibly

1. TMT channel-to-sample map is not recoverable. The paper says only that channels 127N, 127C, 128N, 128C, 129N, 129C carried samples and 131 a pool, in 2 sets; it never says which channels are WT vs alpha2+/G301R, nor how many mice. Supplementary Data S1-S4 (xlsx, fetched via Europe PMC supplementaryFiles) are IPA protein tables with no channel/sample key; supplement PDF (s002) has no TMT channel key. The deposited .msf StudyDefinition (read by HTTP range, first 4 MB) has two FileSets with no sample names, factors or channel assignments (NextSampleNumber=1). Inventing a genotype per channel is forbidden.
2. Run-to-fraction map is not recoverable. The msf FileSets group 24 RAW files per TMT set (set 1 "Vladimir_": GB1-12 + GC1-12; set 2 "Vladimir_Brain_saet2_GF": GF1-12 + GG1-12), but no deposited file or text states the HILIC fraction number of each file. Acquisition timestamps are interleaved (e.g. GB10 02/04 00:55, GC1 02/04 08:42, GB11 02/04 23:24, GB12 02/05 00:37), so neither name order nor run order is a defensible fraction order. The RAW internal sample label also disagrees with the file name (Vladimir_Brain_saet2_GG12.raw carries sample name "GC12").
3. Tissue conflict between deposit and paper. File names, msf study name ("Vladimir Migraene Mus", files dated Feb 2019) and the PRIDE organism part say brain; the paper and PRIDE abstract describe left ventricle (heart) proteomics, and PRIDE lists Homo sapiens plus Mus musculus although the search was mouse only. Which tissue the RAW files contain cannot be settled from the record.

## Evidence that was obtained (for whoever resolves this)
- RAW header (GG12, first 3 MB): Q Exactive (Thermo QEXACTIVE), method 72min_TMT_10plex_Flat.meth, 72 min run.
- msf workflow: template TMT-based quan SEQUEST HT + Mascot + Percolator, PD 2.1.0.81.
- Search parameters (Sequest/Mascot) were not read from the 12 GB msf beyond the first 4 MB; paper/PRIDE text gives trypsin, 1 missed cleavage, carbamidomethyl C fixed, TMT K/N-term, Met oxidation and deamidation variable, 8 ppm / 0.05 Da.

## What is needed to unblock
The submitter's sample key (genotype per TMT channel per set, mouse count/sex/age, tissue actually analysed) and the fraction number per RAW file, or a deposited PD result file exposing these. Then annotate with ms-proteomics + vertebrates, 48 x (6 sample channels + 131 reference) rows.
