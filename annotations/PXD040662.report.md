## Design and file mapping
Two TMTpro16 plexes, Set A and Set B. **Channel maps are read from the deposited result tables** `HV_SetA.xlsx` / `HV_SetB.xlsx` (header rows list the group for each of the 16 channels). Set A: 1-2 T47D, 3 BT474, 4 MCF-7, 5-6 MDA-MB-231, 7 BT549, 8 Hs 578T, then the same lines in co-culture with NPCs (9-10 T47D/NPC, 11 BT474/NPC, 12 MCF-7/NPC, 13-14 231/NPC, 15 BT549/NPC, 16 HS578T/NPC). Set B: 1-3 231, 4-6 MCF-7, 7-8 HS-578T, 9-10 HS-578T/NPC, 11-13 231/NPC, 14-16 MCF-7/NPC. Channels are taken in TMTpro order (126, 127N … 134N). "/NPC" = breast cancer cells after one week in co-culture with hESC-derived neural progenitor cells (PRIDE description). 32 sources x files = 416 rows.
**File-to-set mapping:** `a27236…a27264` (14 files) = Set A and `ea10765…ea10776` (12 files) = Set B, from the sample-name strings in the RAW headers (`hv_A_*` vs `HV_B_*`). The header names are unreliable for fraction numbers (several repeat, e.g. `hv_A_03b` x3), so `comment[fraction identifier]` follows the order of the files within each set and is **inferred**. Factor: `factor value[treatment]` (monoculture vs co-culture).

## Technical values
Orbitrap Eclipse + FAIMS (CV -40/-60/-80 V), hrMS2 with HCD NCE 36, MS1 400-1600 m/z at 60,000 (PRIDE protocol); 12 non-adjacent high-pH super-fractions (of 24) per plex; trypsin; DTT/iodoacetamide; Comet pipeline (50 ppm precursor tolerance; fragment tolerance not read): TMTpro (UNIMOD:2016) on K and N-term and carbamidomethyl C static, Met oxidation variable. The PRIDE text gives the TMTpro mass for both TMT and carbamidomethyl (copy error); the standard +57.021 carbamidomethyl is used.

## Limitations
- `reconcile` reports `organism_contradicted` (Sus scrofa) because the protocol says "Trypsin Porcine": false positive.
- Age is the Cellosaurus donor age; all lines are from female patients; disease `breast cancer` for all rows. Whether the co-culture rows contain hESC-NPC proteins is not stated (cells were processed after one week; the title says the breast cancer cell proteome was analysed).
- Set A has 14 RAW files for 12 fractions; the two extras are re-runs/tests (header labels repeat).
