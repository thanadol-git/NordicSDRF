# PXD019082 annotation report

Status: validated annotation; independent review pending.

## Result
4-row, 29-column SDRF (ms-proteomics v1.1.0 + human v1.1.0), one row per RAW file. Not previously annotated in sdrf-annotated-datasets (no PXD019082 directory). Dataset: Aarhus University (Enghild lab), disulfide mapping of recombinant human A2M Q975C and C3 Q1013C by pepsin digest, Orbitrap Eclipse DDA, Mascot. Paper: Harwood et al., Biochemistry 2020, PMID 33301305.

Design: 2 mutants x (non-reduced, TCEP-reduced). Factors: `factor value[genotype]`, `factor value[treatment]`. TCEP is also recorded per row in `comment[reduction reagent]` (PRIDE:0000609); non-reduced rows are `not applicable`.

## Validation
- `parse_sdrf validate-sdrf -t ms-proteomics -t human`: passes; one warning, `TCEP reduction` is not found in NCIT/EFO for `characteristics[treatment]` (free-text value kept).
- `tools structure`: OK. `tools check --offline`: CLEAN.
- `tools reconcile`: one BLOCKER `cleavage_agent_unsupported` for PepsinA. This is a false positive: the PRIDE protocol explicitly says "pepsin ... overnight digestion"; the reconcile enzyme list evidently has no pepsin pattern. Kept.

## Caveats
- Single protease (pepsin), so one cleavage-agent column; the Mascot search used nonspecific cleavage.
- Recombinant proteins: organism part, cell type, age, sex, ancestry, disease are `not available`/`not applicable`. The expression host was not verified (paper not open access).
- Precursor/fragment tolerances, dissociation method and fractionation were not stated in the deposit and the RAW files were not read; those columns are omitted or `not available`.
- Modifications come from the PRIDE prose only (no search output deposited): variable dehydro-Cys. Carbamidomethylation was not stated, so it is not annotated.
- PRIDE tags the project as cross-linking; the work is disulfide mapping, so the crosslinking template was not applied.
- `characteristics[genotype]` and `[treatment]` values are free text describing the mutant and TCEP reduction.
- Independent adversarial review not yet run.
