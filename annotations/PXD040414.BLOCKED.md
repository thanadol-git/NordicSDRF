# PXD040414 BLOCKED

Dataset: "Nicotine administration augments abdominal aortic aneurysm progression in rats" (Hadzikadunic et al., Biomedicines 2023, doi:10.3390/biomedicines11051417, PMC10216524). Not in the community corpus.

## Reason
TMT 16-plex dataset (Orbitrap Eclipse, FAIMS, Proteome Discoverer 2.4, rat) with no recoverable TMT channel to sample map. Writing an SDRF would require inventing channel identities.

- Deposit: 16 RAW files (JaneStubbe012023_A3..A10, B3..B10), one 9.7 GB `.pdResult`, checksum.txt. No sample table, no mapping file, no README.
- Paper and PRIDE protocol: only say samples were "randomly labelled with 16-plex TMT; mass tag 126 was a pool of all samples (internal control)". Proteomics compares nicotine (n = 12) vs untreated (n = 13) non-aneurysmal aortas, i.e. 25 samples + 1 pool = 26 channels, so more than one TMT plex is implied. The paper never states how many plexes, which samples went in which plex, or which channel carried which rat or group.
- The A/B raw-file prefixes plausibly mean two plexes x 8 high-pH fractions, but this is an inference from file names only and is not stated anywhere.
- Supplementary Tables S1-S3 (MDPI) hold processed protein results, not channel assignments; Europe PMC exposes no usable supplementary files.
- The channel map could exist only inside the deposited `.pdResult` (SQLite, 9.7 GB, not read here; it would also need to carry group labels, which is not guaranteed).

## What would unblock
The submitter's TMT labelling sheet (channel -> rat ID -> vehicle/nicotine, plex -> RAW files), or the sample/channel tables extracted from the `.pdResult`.

## Facts established (for a future annotation)
Organism Rattus norvegicus (male Sprague-Dawley); organ part abdominal aorta (non-aneurysmal, formalin-fixed); instrument Orbitrap Eclipse (paper; PRIDE lists Orbitrap Fusion Lumos MS:1002732, conflict); trypsin; TMTpro 16-plex; PD search: carbamidomethyl C fixed, TMTpro fixed, deamidation and Met oxidation variable. Factor: nicotine 1.25 mg/kg/day vs saline vehicle.
