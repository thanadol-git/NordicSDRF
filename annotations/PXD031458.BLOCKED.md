# PXD031458 — annotation blocked

## Dataset

- **Title:** Novel Targeted Proteomic Profiling of Potential Biomarkers in Postural Orthostatic Tachycardia Syndrome (POTS)
- **PRIDE record:** PXD031458
- **Publication:** Johansson M. et al., Sci Rep 2022, DOI [10.1038/s41598-022-24729-x](https://doi.org/10.1038/s41598-022-24729-x), PMCID [PMC9681882](https://pmc.ncbi.nlm.nih.gov/articles/PMC9681882/)

## Evidence recovered

- 130 files of type RAW in PRIDE are all `.mzML` conversions (`…_diaPASEF_S1-A1_1_1438.mzML`); no Bruker `.d` acquisitions are deposited. Also a Spectronaut `.sne` and a protein-group CSV.
- Study: 65 POTS patients and 65 matched healthy controls, plasma, timsTOF Pro diaPASEF, Spectronaut directDIA.
- File names carry only a plate position and run number; the samples were double-blinded and no deposited or published table maps a file to case or control.

## Why no SDRF was emitted

Two independent blockers: the repository precedent (PXD017968) does not annotate depositions that contain only converted peak lists, and even with the mzML files there is no file → POTS/control map, so the disease factor cannot be assigned per row.
