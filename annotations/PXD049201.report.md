# PXD049201 evidence and remaining blocker

The deposited `Identified_proteins.xlsx` supplies a complete TMT10 channel map in its `Found in Sample` headers. The accession-scoped `scratchpad/PXD049201/channel_map.tsv` extracts and checks 40 channels: 28 distinct mice (seven in each WT/KO × LPS/unchallenged group), eight repeat channels labeled `TR2`, and four normalization-mix channels. Each of the four TMT pools has ten distinct labels and maps to three deposited RAW fractions, for 12 RAW files in total.

The PRIDE sample protocol states that every sample was digested sequentially with Lys-C and Trypsin. The current `sdrf-tools build` implementation emits only the last value when two `comment[cleavage agent details]` rows are supplied in `technical.tsv`; an accession-scoped probe in `scratchpad/PXD049201/probe.sdrf.tsv` confirmed that Lys-C is silently dropped. An SDRF that lists only Trypsin would omit part of the documented preparation, so no approved SDRF was created for this accession.

The three fraction suffixes per pool (`_X`, `_2`, `_4`) also lack an explicit elution-order key in the deposited file list. The map preserves exact filenames without assigning an unsupported order.

Sources: [PRIDE project record](https://www.ebi.ac.uk/pride/ws/archive/v2/projects/PXD049201), deposited `scratchpad/PXD049201/Identified_proteins.xlsx`, and accession-matched `scratchpad/PXD049201/files.json`.
