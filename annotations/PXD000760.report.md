## Design

Two SILAC triplex (Arg0/Arg6/Arg10) experiments on HepG2-SF cells, each analysed for cell lysate (IC) and albumin-depleted culture medium (EC), 4 replicates pooled per group, SDS-PAGE bands digested with trypsin, TripleTOF 5600 DDA.
- Triplex A (120705_* files; 22 EC bands, 25 IC bands): light trans-vaccenic acid, medium elaidic acid, heavy cis-vaccenic acid.
- Triplex B (2012_09_* files; 30 IC bands, 18 EC bands): light trans-vaccenic acid, medium oleic acid, heavy cis-9,trans-11 CLA.
- Setup assignment of every file was verified from the rawfile lists in the deposited Mascot Distiller XMLs (HTTP range reads; 47 + 48 = 95 = all deposited .wiff). No raw files downloaded.
- 12 sources (setup x compartment x channel), factor value[treatment].

## Validation

- parse_sdrf validate-sdrf (ms-proteomics+human+cell-lines, --use_ols_cache_only): no errors; 3 warnings (trans-vaccenic acid, cis-vaccenic acid, cis-9,trans-11 conjugated linoleic acid not found in NCIT/EFO).
- tools structure: OK; tools check --offline: CLEAN; tools reconcile: all values agree with the record.

## Caveats

- Digestion is trypsin only (no second protease); one cleavage column.
- Disease (hepatoblastoma), age (15Y), sex (male) are Cellosaurus-derived for Hep-G2, not stated in the deposit; the cell line is the serum-free adapted HepG2-SF, recorded as HepG2 / CVCL_0027.
- Fraction identifiers are inferred from file numbering. In triplex B IC the "dilute" reruns (13, 16, 17, 21) were treated as replacing those bands, and ICrerun_24-30 as bands 24-30.
- Biological replicate = 1 with pooled sample = pooled (4 replicas pooled before mixing); technical replicate 1.
- characteristics[cellular compartment] (cell lysate / culture medium) is an extra, non-template column used to distinguish IC from EC.
- Label modifications (Label:13C(6), Label:13C(6)15N(4) on R) are listed as variable on every row (repo convention), though only the matching channel carries each. The in-gel alkylation reagent is not stated (propionamide = acrylamide adduct), so alkylation reagent is omitted.
- Dissociation method and fractionation method (SDS-PAGE bands) not recorded (not stated / no verified term).
- Instrument taken from the protocol text, not verified from wiff headers.
