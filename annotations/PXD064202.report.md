# PXD064202 annotation report

iPSCs and iPSC-derived astrocytes from a CLN3 Batten disease patient (homozygous 1-kb deletion) and two healthy-control fibroblast lines. Bjørås/de Sousa lab, NTNU. Paper: J Biomed Sci 2026, PMC13173811 (open access).

## Templates
`ms-proteomics` v1.1.0 and `human` v1.1.0.

## Rows and files
There are 36 rows: 3 donors × 2 iPSC clones × 3 independent differentiations × 2 stages (iPSC, astrocyte).
- **Donor key:** file tags `AG`, `AT` and `J` are decoded by the deposited `GroupsSample.txt` (Control vs Patient) and the paper's Methods:
  - `AG` = Coriell AG05836 (Cellosaurus CVCL_2B58: female, 44Y).
  - `AT` = ATCC PCS-201-012 adult dermal fibroblasts.
  - `J` = the male CLN3 patient.
- **Replicates:** the digit after the clone is the differentiation round and is used as the biological replicate.
- **Not deposited:** the MaxQuant search also contains GPC-stage runs and other donors (`Ec`, `CLN5`) that are not in this deposit and are not annotated.
- **Label mismatch:** MaxQuant's `GroupsSample.txt` labels the run deposited as `ATc1_1_Astro_Slot1-39` as `ATc1_2_Astro_Slot1-39`. The deposited file name is kept.

## Values
- **Sample:** cell type `induced pluripotent stem cell` or `astrocyte`; disease `normal` or `CLN3 disease`.
- **Genotype:** `CLN3 1-kb deletion (exons 7-8), homozygous` for the patient.
- **Sex and age:** sex and age of the ATCC donor and the patient's age are `not available`.
- **Factors:** `disease` and `cell type`.
- **Instrument:** timsTOF Pro 2, from `analysis.tdf` and the PRIDE protocol. PRIDE's instrument field says timsTOF Pro.
- **Search** (deposited MaxQuant `summary.txt`):
  - Carbamidomethyl C fixed.
  - Oxidation M, Acetyl protein N-term and Phospho STY variable.
  - This differs from the protocol text, which mentions deamidation; the deposited search output is followed.
  - Tolerances are not stated, so they are set to `not available`.

## Validation
- `parse_sdrf` (CI style, warnings only) and the review gate pass.
- `tools reconcile` flags `organism part = skin` for cultured iPSC material. This is kept deliberately: all lines were reprogrammed from dermal fibroblasts (skin biopsy / AG05836 / PCS-201-012), so skin is the anatomical source.
