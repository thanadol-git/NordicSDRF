# PXD002439 annotation report

## Scope

All 36 directly deposited RAW files are represented.

## Evidence and decisions

- PRIDE identifies naturally presented HLA-DR peptides from bronchoalveolar-lavage cells and EBV-transformed B cells; the analysis therefore uses unspecific cleavage rather than a digestion enzyme.
- The raw names provide submitted BAL, B-cell, HLA-DR, and PAT group labels. The deposited CSV files are Mascot search exports, not a raw-to-source map, so PAT/HLA-DR labels are retained literally rather than assigned to BAL or B-cell material.
- Qp2/Q3 run names are represented with Q Exactive acquisition; the V1 run is represented with LTQ Orbitrap Velos, consistent with the deposited method's instrument set.
