# PXD071972 SDRF annotation report

## Study
Orbitrap Astral Zoom benchmarking: 300 and 500 samples-per-day DIA of HEK293T lysate plus three-species (human HeLa / yeast / E. coli) mixes for quantification (Guzman et al., Mol Cell Proteomics 2026, PMID 41520856).

## Templates
ms-proteomics + human + cell-lines v1.1.0

## Scope: deposited vs annotated
913/913 RAW: 321 x 300SPD HEK293T runs (Vanquish Neo), 550 x 500SPD HEK293T runs (Evosep Eno), 18 x 300SPD and 24 x 500SPD species-mix runs (M1, M2, REF methods; two mix ratios).

## Sample map
raw_file_mapping.txt (deposited) gives the search set and replicate per file. It reassigns eight 500SPD M1/M2 runs whose names say 05Y50H45E (with a _2025110312xxxx re-acquisition stamp) to the 25Y50H25E mix, and the 300SPD 05Y50H45E_02_20251031164409 run to replicate 3; the mapping is followed.

## Key decisions
Mix runs use the Pierce HeLa digest as the human part (organism Homo sapiens, HeLa) with yeast and E. coli as spiked compounds (CT=mixture, QY = percentage of the mix), as in PXD002952. Run number -> technical replicate; one lysate -> biological replicate 1. Acquisition settings decoded from file names (400-800 / 400-600 m/z with 4 Th windows and 2.0 ms maxIT; reference = 300 x 2 Th windows 380-980 m/z, 1.5 ms). 300SPD benchmark runs are the 400-800 m/z 4 Th method per their names. Fixed CAM, variable Met-ox and protein N-term acetyl as searched.
