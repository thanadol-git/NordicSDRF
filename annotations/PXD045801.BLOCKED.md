# PXD045801 — annotation blocked

## Dataset

- **Title:** A YTHDF-PABP axis is required for m6A-mediated organogenesis in plants
- **PRIDE record:** PXD045801
- **Publication:** Arribas-Hernandez lab, EMBO J 2023 (PMID 38009565, PMC10702811)

## Evidence recovered

- 36 RAW in 5 IP-MS sets; RAW headers: Q Exactive. The 5 deposited PD .msf files carry per-run study factors.
- Readable: 2019 Set2 (Neg_Ctrl, ECT2_mCherry, ECT2_mCherry_d1/d5/d7, 3 each); DT set (HA_contr x3, HA x2 + one blank factor, mCH_contr x3, mCh x3); DueT set (Col-0 WT, 'E1FT 12-1', 'E1FT 17-15', 'E1FT 21-7'); 2020 set (Col-0 WT mock IP, 'e3E3V-K 11-2/16-4/26-6', SF5/Reg50/NY20/NY21/Reg27/Reg58 '-TCA').
- Deposited RAW are only a subset of each .msf file set (e.g. 2019 runs 23-25 and 32-34; DT runs 01-06).

## Why no SDRF was emitted

The 12 Tankmar runs (S20-S31) only carry 'Sample number' in their .msf, with no bait or genotype. Several factor codes (E1FT, e3E3V-K, Reg/NY/SF lines) are line identifiers not explained in the paper or PRIDE. A full annotation would require guessing; a partial one would leave a third of the runs and most bait/genotype values unresolved.

## Sources checked

PRIDE project + file list, RAW headers, first 40 MB of all 5 .msf files (study factors and file sets), paper full text (PMC).

## Unblocking requirement

A run -> bait / genotype / tag table (especially for MathiasTankmar S20-S31 and the line codes E1FT, e3E3V-K, Reg/NY/SF).
