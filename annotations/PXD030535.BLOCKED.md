# PXD030535 annotation blocked

PXD030535 ("Metal removal capability of two cyanobacterial species in autotrophic and mixotrophic mode of nutrition"; submitter B. Nowruzi, Islamic Azad University, Tehran) is not a proteomics dataset. It studies extracellular polymeric substance (EPS) production and metal biosorption in *Nostoc* sp. N27P72 and *Nostoc* sp. FB71. The only MS work described is GC-MS small-molecule profiling of EPS composition. PRIDE classes it as an "Unsupported dataset by repository".

No MS data files are deposited. The PROXI record lists 4 files:
- `IMG_20200327_0001.pdf`, labelled "raw": a scanned image
- `Tables.docx`, labelled "search engine output"
- `final revised ghorbani.docx`: the manuscript draft
- `fig. 7.jpg`

There is no raw, peak-list or identification file, so there are no runs to annotate. The instrument is given as 7000A Triple Quadrupole GC/MS, and the PTM field reads "No PTMs". Publication: "pending" in the PX record, and no paper is linked.

This is closely related to **PXD030537**: same submitter, title and abstract. It is a later resubmission (announced 2022-05-31, vs 2022-01-24 for PXD030537), and it shares the same `IMG_20200327_0001.pdf` and `fig. 7.jpg` file names. Byte identity was not checked, and PXD030535 adds two .docx files, so it is classed as blocked rather than duplicate.

**Evidence checked:** ProteomeCentral PROXI record (`resultType=full`), including datasetFiles, instruments, species, publications and the description.

**To unblock:** nothing in this deposition can be unblocked. An SDRF would need actual peptide/protein MS raw data, which this GC-MS study does not have.
