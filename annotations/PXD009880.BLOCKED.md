## Why it is blocked
Every RAW file is a 6-plex TMT run, so each needs six channel-to-sample assignments (patient vs control, biological replicates, which study/cell line). Inventing them is prohibited (channel-map.md 6.1). Ladder checked:
1. Paper + supplement: full text is not open access (Europe PMC isOpenAccess=N, not in PMC; Unpaywall gives no PDF). Abstract has no design.
2. PRIDE files: SupplTableS1.Allquantifiedproteins.xlsx holds only per-protein ratios/t-tests (Study 1, Study 2) with no channel or sample labels. Mascot .dat header (read by HTTP range, first 3 kB) has search parameters only, no channel labels. No PD StudyInformation or sample sheet deposited.
3. Europe PMC supplementary: none (no PMCID).
4. External repositories: no Data Availability statement accessible; none cited in PRIDE record.
5. Cross-validation: not possible without a map.
Also unresolved: the pairing of fractions (IEF, ~8 fractions per TMT set) to injections is inferable from file names, but the sample (patient/control, number of lines and replicates) per channel is not.
