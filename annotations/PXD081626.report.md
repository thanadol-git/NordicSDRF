# PXD081626 annotation report

Adult zebrafish cerebrospinal fluid (Jurisch-Yaksi lab, NTNU; MS by PROMEC). Paper: Communications Biology 2026, "Brain defence by the extracellular matrix protein Cochlin", PMC13582957. Not in the community corpus.

## Templates
`ms-proteomics` v1.1.0, `vertebrates` v1.1.0 and `dia-acquisition` v1.1.0.

## Rows and files
There are 4 rows, one per `.d.zip`. Each is CSF pooled from four adult **nacre** fish (paper), so the rows are pools 1–4 with `pooled sample = pooled`. The DIA-NN log shows these four files were searched together with 14 other runs from the same session that were not deposited.

## Values
- **Acquisition:** **DIA-PASEF**, from the PRIDE protocol and paper, consistent with the library-based DIA-NN 2.2 search in the deposited log.
  - The submitter's own `sdrf.tsv` inside `results.zip` says DDA and MaxQuant. That file is auto-generated and wrong on both points.
  - Scan window is 100–1700 m/z. Isolation window width is `not available` because diaPASEF windows are variable.
- **Instrument:** **timsTOF Pro 2**, from `analysis.tdf` (serial 1875087.10477). The protocol says timsTOF Pro.
- **Sample prep:** TCEP/CAA; trypsin.
- **Search:** from the DIA-NN command line: `--unimod4` (Carbamidomethyl C fixed); Oxidation M and Acetyl protein N-term (`*n`) variable; 20 ppm MS1 and MS2.
- **Not stated:** sex is `not available` (pools; the CSF fish sexes are not stated).
