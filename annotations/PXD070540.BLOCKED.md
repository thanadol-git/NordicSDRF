# PXD070540 — annotation blocked

## Dataset

- **Title:** Plasma Proteomics Identifies Insulin Resistance Signatures Predictive of Cardiometabolic Disease Risk
- **PRIDE record:** PXD070540
- **Publication:** Preprint only (Kjærgaard, Kurgan et al., Research Square, doi:10.21203/rs.3.rs-8585654/v1); no PubMed record is linked in PRIDE.

## Evidence recovered

- 1003 RAW, all Orbitrap Astral + FAIMS (CV -45 V), Evosep ONE 60 SPD, 8 cm PepSep, DIA (200 x 3 Th windows).
- Sample prep (PRIDE): neat plasma digests (TCEP/CAA, trypsin + Lys-C 1:100), Mag-Net SAX membrane-particle enrichment, and more workflows. The four Spectronaut .sne files name Undepleted, SAX, PCA and Agilent depletion workflows.
- Run batches, from file names: plates X1913/X1929/X1946 (`..._R1315_S<n>`, 496 runs), X1954/X1971/X1976 (`..._R1366_S_<nnn>`, 249 runs), and X2395 plates E00000314/315/316 (well IDs A1-H12 plus pool QC runs `_poolN_k`, 258 runs). The E00000314 plate is named in the Agilent-depletion .sne file.
- Cohort: 161 individuals defined by clamp-derived insulin sensitivity, plus a male exercise-intervention subset (pre/post).

## Why no SDRF was emitted

No deposited file links a run (S<n> / S_<nnn> / plate well) to a participant, a workflow, or the exercise time point. Sex, age, insulin-sensitivity group and intervention status are needed for the factor values and are not public. They are clinical data from a Danish cohort. Only one plate can be tied to a workflow (E00000314 = Agilent depletion). The other two run series cannot be told apart between the Undepleted, SAX and PCA workflows from their names alone. An SDRF would therefore have hollow factor values, and the workflow column would be a guess.

## Sources checked

PRIDE project record and file list; Spectronaut .sne file names; Research Square preprint rs-8585654.

## Unblocking requirement

The authors (Deshmukh lab, NNF CBMR) would need to provide a run -> workflow -> sample table: the plate/well or S-number for each run, workflow, sample/participant code, time point (exercise pre/post) and sex. The per-run tables inside the .sne files (2-3 GB each, Spectronaut-only) would at least give the workflow per run, if someone can open them.
