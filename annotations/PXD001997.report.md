# PXD001997 SDRF annotation report

Status: validated annotation; independent review pending (no isolated reviewer was available; review-gate not run, no self-approval).

Dataset: GCDII (granular corneal dystrophy type 2) post-LASIK patient corneas vs healthy controls, Aarhus University (Enghild lab), TripleTOF 5600+, label-free DDA. Paper: Poulsen et al., Proteomics 2016 (PMID 26864644).

Templates: ms-proteomics v1.1.0 + human v1.1.0. 36 rows x 34 columns: 12 individuals (P1-P6 patients, C3-C8 controls) x 3 technical replicate injections, one .wiff each, no fractionation. Factor: disease.

Validation: parse_sdrf validate-sdrf PASS; `python -m tools structure` OK; `tools check` CLEAN; `tools reconcile` one MAJOR (disease_with_control_arm) which is a false positive because control rows are "normal".

Two cleavage-agent columns (CNBr then trypsin) were accepted by parse_sdrf. A second semi-tryptic search was used for P1 cleavage analysis only; it is not recorded as a separate digest.

Caveats:
- Age, sex, ancestry, cell type and dissociation method are `not available` (no per-sample data in the record; full text not retrieved).
- Biological replicate numbers are ordinal within group (inferred); controls are labelled C3-C8 in the deposit.
- Modifications are taken from the protocol prose and PRIDE PTM list; the Mascot .dat/.mzid files were not parsed. "Hydroxylation of proline" is recorded as Oxidation on P. Met->Hse/Hsl are recorded with PP=Any C-term, TA=M.
- Instrument from protocol text (5600+) overrides PRIDE field (5600); raw .wiff headers not read.
- Only .wiff files used as data files; .wiff.scan, mgf, mzid, dat excluded.
