# PXD030482 SDRF annotation report

Status: validated annotation; independent review pending

Dataset: Plasma proteomics of hibernating and active wild Scandinavian brown bears (Ursus arctos arctos), Aalborg University, Denmark. Paper: Data Brief 2022, doi:10.1016/J.DIB.2022.107959.

## Result
- `PXD030482.sdrf.tsv`: 113 rows x 37 columns (one row per RAW file, all 113 RAW files mapped once; 38 plasma samples from 14 bears; 2-3 technical replicates each).
- Templates: ms-proteomics v1.1.0 + vertebrates v1.1.0. No existing annotation was found in sdrf-annotated-datasets (Step 0.5), so this is a new annotation.
- Design: factor value[hibernation state]: 56 hibernating (Winter) and 57 active (Summer) runs (computed from the tables; see file). Sex, age (2Y/3Y), individual (bear ID), season and sampling year come from the deposited Filename_description.xlsx.

## Validation
- `parse_sdrf validate-sdrf -t ms-proteomics -t vertebrates`: passes ("Everything seems to be fine").
- `python -m tools check --offline`: CLEAN; `structure`: OK; `reconcile`: all values agree with the PRIDE record.

## Caveats and judgement calls
- Cleavage agent recorded as Trypsin (what the protocol describes). MaxQuant searched with Trypsin/P, semi-specific; this is a search setting, not a second protease, so only one cleavage-agent column is used.
- Modifications come from the PRIDE processing prose (no mqpar.xml deposited), not from search parameter files.
- Precursor/fragment mass tolerances are not stated: `not available`.
- Winter = hibernating and Summer = active is inferred from the description (samples per hibernation/active state, two winters and two summers).
- Triplicates treated as technical replicates (biological replicate = 1 per source); the deposit does not say whether they were independent preps.
- disease and developmental stage are `not available` (bears are wild and "subadult" was not mapped to an ontology term). Custom characteristics columns added: age, individual, season, sampling year, hibernation state.
- Paper full text was not fetched; RAW files were not downloaded and instrument metadata was not verified from raw headers.
- Independent review (Step 9.5) has not been done; review-gate not run.
