# PXD036231 annotation blocked

PXD036231 (Imam Hossein University, Tehran; venom peptides of the scorpions *Buthotus saulcyi*, *Odontobuthus doriae* and *Androctonus crassicauda*) is a PRIDE "Unsupported dataset by repository" (MS:1002857) submission. It deposits no mass-spectrometry data files.

The PROXI record lists 22 files:
- **18 `.tif` images** labelled "Associated raw file". They are pictures of gels and chromatograms: Tricine/SDS-PAGE, 2D, IEF, HPLC, and MALDI-TOF MS spectra for bands P1-P2 (*O. doriae*), P3-P4 (*B. saulcyi*) and P5 (*A. crassicauda*).
- **3 Mascot result PDFs** (`Mascot-Amino_acid-Peptide_*.pdf`).
- **`Peptides.dat`** (search engine output) and **`Peptides.txt`**.

There is no instrument data file (`.raw`, `.mzML`, `.mgf`, `.wiff`, `.d`, `.t2d` or similar). An SDRF needs one row per MS data file, and no file here can be the `comment[data file]`. Using screenshots of spectra as data files would be fabrication. The PX instrument field ("LTQ") also conflicts with the MALDI-TOF MS that the description and file names state, and the per-band sample structure (5 gel bands from 3 species) has no matching runs.

**Evidence checked:** the ProteomeCentral PROXI record (`resultType=full`, revision 2, 2023-11-14), which gives the full file list, the description, the instrument, the species (Scorpioninae, NCBITaxon 259447, genus level only) and the publication. The payload summary and file names are in scratch/PXD036231. The PRIDE v3 API and the FTP listing were not needed, because PROXI already enumerates all files. The linked paper (Jahangirian et al., J Biomol Struct Dyn 2023, PMID 36927377) is an in-silico docking/MD study. I did not check whether it cites the PXD, because that does not change the outcome.

**To unblock:** the authors would have to deposit the MALDI-TOF(/TOF) spectra as instrument files or peak lists (e.g. `.t2d`, `.mzML`, `.mgf`), one per gel band. Until then the dataset cannot be annotated.
