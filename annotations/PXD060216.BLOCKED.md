## Evidence recovered

Two 7z archives as RAW: TMT_experiments.7z (21.6 GB: 2 TMT16 plexes x 24 fractions on Orbitrap Eclipse - TMT_FFPE S3 and TMT_FFPE_FF_FFref S1) and diaPASEF.7z (301 GB, timsTOF HT .d runs); plus FragPipe/DIA-NN result archives.

## Why no SDRF was emitted

Every data file sits inside a 7z archive, so file names can only be read from the archive header (done for the TMT archive and the result archives). No channel -> sample table for the two TMT plexes and no run -> patient / region / FFPE-vs-FF table for the diaPASEF runs is deposited; the only places that might hold sample names (FragPipe abundance tables) are inside a solid LZMA stream that cannot be read without downloading and unpacking the archive.

## Sources checked

PRIDE record and protocols; 7z headers of TMT_experiments.7z, TMT_results.7z and diaPASEF_results.7z.
