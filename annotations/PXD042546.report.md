# PXD042546 SDRF annotation report

## Study
"Spectral library search for improved TMTpro labelled peptide assignment in human plasma proteomics" (Palstrøm NB, Campbell AJ, Lindegaard CA, Cakar S, Matthiesen R, Beck HC; Proteomics 2023, doi:10.1002/pmic.202300236, PMID 37706597). Odense University Hospital (Beck lab). Europe PMC: not open access, no PMC full text; only the abstract plus the PRIDE protocols were available. A TMTpro-specific spectral library was built from highly fractionated TMTpro-labelled human plasma (un-depleted, MARS14-depleted, ProteoMiner-enriched), abdominal aortic aneurysm (AAA) wall and intraluminal thrombus, and the Pierce HeLa protein digest standard; ten TMTpro plasma runs (`Sample_1..10`) were used to evaluate the library.

## Templates
ms-proteomics v1.1.0 + human v1.1.0. `cell-lines` was tried and dropped: it requires a `cellosaurus accession` column and forbids `not applicable` in `characteristics[cell line]`, but only the HeLa rows are a cell line (tissue and plasma rows make up 960 of 1104 rows). `characteristics[cell line]` is kept as an informational column (`HeLa-S3` / `not applicable`). No DIA, clinical or oncology template: the library samples carry no per-donor clinical data.

## Scope: deposited vs annotated
`files/all`: 162 files, all carrying `projectAccessions` = PXD042546. 79 RAW, 79 mzXML (PEAK), 11 `.msf`/`pep.xml` search files, 3 library files (`.msp`, `.sptxt`, `.zip`).
- **Annotated: 69 library RAW files × 16 TMTpro channels = 1104 rows.**
- **Not annotated: `Sample_1.raw` … `Sample_10.raw` (10 RAW).** These are TMTpro-16 plasma runs (Orbitrap Eclipse, method `HCD_OTOT_120k30kTurbo_FAIMS_200minTMT`) with one Proteome Discoverer `.msf` each. The paper is closed, the PRIDE protocol does not describe them, and no channel→sample map was found (PRIDE files, protocols, Europe PMC abstract). Annotating 160 channels without donor identities, disease state or reference/pool channels would mean inventing sample identity, so they are left out. The per-file `.msf` (SQLite) is the place to look if a later pass wants to try to recover PD's study-factor table.

## Sample map (library RAW → sample)
File names are `SpecLIB_<sample>_<plate well>`; the well number is the high-pH fraction (3–12):
| prefix | sample | fractions |
|---|---|---|
| `AAA_vaeg` | AAA wall ("væg" = wall) | D3–D12 (10) |
| `AAA_naervaeg` | AAA "nærvæg" (wall adjacent to the aneurysm; Danish "near wall") | F3–F12 (10) |
| `AAA_thrombe` | AAA intraluminal thrombus | H3–H12 (10) |
| `FD_Plasma` | un-depleted plasma | A6–A12 (7) |
| `MARS` | MARS14-depleted plasma | B3–B12 (10) |
| `ProteoMiner` | ProteoMiner-enriched plasma | C3–C12 (10) |
| `HeLa` | Pierce HeLa protein digest | A3–A12 (10 fractions, 12 files) |

HeLa A4 and A5 exist twice (`SpecLIB_HeLa_A4.raw` and `SpecLIB_HeLa_A4_20220627084853.raw`, same for A5); the time-stamped copy is annotated as technical replicate 2 of the same fraction. A6–A10 exist only time-stamped and are technical replicate 1.

Protocol: "seven µg of each tryptic sample digest was tagged with TMTpro 16-tags (126-134N) in 1:1 ratio". This is read as each library sample being split across all 16 TMTpro tags, so every channel of a file carries the same sample (one `source name` per sample type, 16 rows per file).

## Key decisions
- Instrument: **Orbitrap Exploris 480** (MS:1003028) for all 69 library files, from the RAW headers (range-read, methods `10B/12B/14B_120_min_80ACN_FAIMS_120K_TurboTMT_30K_200AGC.meth`). PRIDE lists Exploris 480 + Eclipse; the Eclipse belongs only to the unannotated `Sample_*` runs.
- DDA (PRIDE:0000627), HCD (MS:1000422), Orbitrap MS2 (method name: "120K … TurboTMT 30K").
- Trypsin (MS:1001251), DTT (PRIDE:0000608), IAA (PRIDE:0000599): stated in the protocol for both plasma and tissue.
- Modifications from the stated FragPipe 19.1 "TMT16" workflow defaults: Carbamidomethyl C fixed (UNIMOD:4), TMTpro K fixed (UNIMOD:2016), TMTpro peptide N-term variable, Oxidation M variable (UNIMOD:35). No deposited FragPipe parameter file, so these are **inferred from the named template**, not read from a params file.
- Disease: AAA tissue and thrombus = abdominal aortic aneurysm (MONDO:0005350); HeLa = cervical adenocarcinoma (MONDO:0005153); plasma = `not available` (donor status not described).
- Organism part: artery wall (UBERON:0000415); thrombus = blood clot (UBERON:0010210); plasma = blood plasma (UBERON:0001969); HeLa = `not applicable`.
- Cell line: Pierce HeLa protein digest standard = **HeLa-S3** (EFO:0002791), per the annotator brief (vendor standard is S3, not parental HeLa).
- Factors: organism part and enrichment process (plasma pre-treatment).

## Not available / not applicable
developmental stage, sex, age, ancestry (pooled/unspecified donors); fractionation method (well-plate fractions are evident, but the paper's method — presumably high-pH RP — is not in the available text); precursor and fragment mass tolerance (FragPipe defaults not deposited); cell type for HeLa (`not available`), cell type for tissue/plasma (`not applicable`).

## Conflicts / overrides
PRIDE instruments list two models; RAW headers assign Exploris 480 to all library runs. PRIDE modifications list only "iodoacetamide derivatized residue".

## Inferred vs stated
Stated: sample types, depletion/enrichment, reduction/alkylation/digestion, TMTpro 16-plex, FragPipe TMT16 template. Inferred: (1) the "1:1 across 16 tags" reading (one sample per file); (2) `naervaeg` = wall adjacent to the aneurysm; (3) well number = fraction number; (4) technical-replicate assignment of the two duplicate HeLa fractions; (5) modification list from the FragPipe template defaults; (6) biological replicate 1 for every sample (a single pooled digest per sample type).

## Validation
`parse_sdrf validate-sdrf --use_ols_cache_only -t ms-proteomics -t human`: no errors; warnings only for free-text `characteristics[enrichment process]` values (`no enrichment`, `MARS14 depletion`, `ProteoMiner enrichment`) and the HCD label/accession that can't be checked offline. Every NT/AC term was checked against OLS4 live: MS:1003028, MS:1001251, MS:1000422, PRIDE:0000627, PRIDE:0000608, PRIDE:0000599, UNIMOD:4, UNIMOD:35, UNIMOD:2016, EFO:0002791, MONDO:0005350, MONDO:0005153, UBERON:0000415, UBERON:0010210, UBERON:0001969.
