## Limitations

- Sex not available: PRIDE description says female mice, the linked paper says male mice (for the spatial transcriptomics cohort); unresolved so left blank.
- Age: only the cohort range (8-13 months, PRIDE) exists; per-animal ages not given, so not recorded.
- File-name genotype tags conflict with mqpar: 3xTg animals 6812 (one file), 6815, 7565, 7765 have "WT" in the RAW file name, "AD" files map to mqpar 4xTg, "HT" to PolB. mqpar/DE xlsx grouping used; file names may be mislabels, or the mqpar may be.
- Instrument: PRIDE lists Q Exactive HF, but the protocol text and RAW header (range read of one file) say Q Exactive; Q Exactive used.
- Dissociation method not stated in deposit (not available). Reduction/alkylation reagents not stated (PRIDE has iodoacetamide PTM tag only; columns omitted). FASP digestion with trypsin; mqpar enzyme Trypsin/P.
- Tolerances from mqpar: main search 4.5 ppm, FTMS MS/MS match 20 ppm.
- Strain only given for WT (C57BL/6J); transgenic strain background not stated. genotype column is an extra (non-template) characteristic.
- Second run per animal presumed technical replicate; deposit does not explain the pairing (could be separate sections/hemispheres).
