- Raw-file-to-tissue mapping is inferred: the paper reports 31561 (oesophagus) and 32962 (rib) MS/MS spectra submitted; the deposited MaxQuant summary.txt lists Seba1 = 31561 and Seba2 = 32962. Filenames do not name tissues.

- Modifications read from deposited mqpar.xml: Carbamidomethyl C fixed; variable Oxidation (M), Pro->Hyp (encoded as Oxidation on P), Deamidation (NQ), Acetyl (K), Gln->pyro-Glu, Glu->pyro-Glu (N-term). Acetyl (Protein N-term) appears only in a first-search list with first search disabled, so it is not included.
- Tolerances: mainSearchTol 5 ppm; FTMS MS/MS 20 ppm (parameters.txt/mqpar.xml).
- Organism: Loxodonta africana (paper; PRIDE NEWT:9785 agrees). Organism part values: esophagus (UBERON:0001043), rib cartilage element (UBERON:0006288), the closest UBERON class to the cartilaginous rib terminal portion.
- Developmental stage `fetal` is a free value because EFO has no suitable stage term (HsapDv fetal stage is human-specific); it produces the validator warning.
