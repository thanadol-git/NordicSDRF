# PXD014792 — annotation blocked

- **Title:** PRMT5 methylome profiling uncovers a direct link to splicing regulation in human acute myeloid leukemia (Nature Struct Mol Biol 2019, PMID 31611688, PMC6858565; paper itself cites the twin deposit PXD013611). Odense/SDU, Orbitrap Fusion Lumos, TMT 11plex, MS3 SPS.
- **Deposit:** 170 PRIDE files (read over both pages): 164 RAW (95 `LUM_NNNNN.raw`, 36 `LUM_NNNNN_PVS.raw`, 17 `LUM2_NNNNN_KS.raw`, 16 `SRSF1_IP_tmt_{beads,kit}_2hours_NN_{1,4}ul.raw`), two PD `.pdResult`, two pepXML `.xml`, FASTA, and `label_description.txt` (300 bytes).
- **Why blocked:**
  1. No explicit TMT channel-to-sample map. `label_description.txt` only says that for the protein-expression/"dionex_hyperFr"/"dimeIP" sets the 11-plex label 129N is ignored and "the rest of the labels are in the correct order"; for the SRSF1 IP set it says labels 128N and 131C ... (sentence is cut off, no sample names). The paper states 4 sgNegCtrl + 3 sgPRMT5-1 + 3 sgPRMT5-2 replicates (TMT10plex) and an SRSF1-IP vs IgG design with and without PRMT5 (11-plex), but never says which channel holds which sample. Supplementary Table 1.1 (Nature MOESM3) lists columns sgNegCtrl_1-4, sgPRMT5-2_1-3, sgPRMT5-1_1-3; this is only an output column order, not a stated channel assignment, and using it would be an inference.
  2. No RAW-to-experiment crosswalk. File names do not say which of the three 2D-LC hyperfractionation series, the methyl-arginine (mme/sdme) immunoaffinity enrichment, or the (1 µl vs 4 µl injection) SRSF1 IP runs each `LUM_*`, `LUM_*_PVS`, `LUM2_*_KS` file belongs to, nor fraction numbers. The PD result headers in `protein_expression_analysis.xml` list file order only (148 files, F1.x) without experiment labels; the `.pdResult` SQLite tables carry no study/sample-name table (checked via ranged reads: WorkflowInputFiles, ProcessingNodeCustomData, SettingsValues, schema list).
  3. SRSF1 IP sample identities (IgG vs SRSF1 IP, control vs PRMT5 sgRNA, replicate assignment, the two unused channels) are not stated anywhere retrievable; Supplementary Table 4 was not opened as it holds only interactor statistics.
- **Checked:** PRIDE project JSON, full files list, `label_description.txt`, both PD pepXML headers (TMT 11plex, Mascot, fixed TMT6plex K/N-term, Carbamidomethyl; variable Oxidation, Deamidated, Methyl/Dimethyl R), `.pdResult` SQLite schema and file table by HTTP range reads, Europe PMC full text (methods, Results, Data availability), Nature supplementary xlsx (MOESM3-MOESM9; Source data), PXD013611 file list (same files: LUM_019.pdResult/pep.xml; no extra map).
- **Unblocking requirement:** the submitter's (Shliaha/Jensen) channel-to-sample table per experiment (hyperfractionation sets, methyl-peptide IP, SRSF1 IP) plus a RAW-file to experiment/fraction/injection crosswalk (e.g. PD study definition or the Supplementary Note sample sheet).
