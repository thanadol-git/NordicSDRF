## Key decisions
- Organism = `Hominidae` (NCBITaxon:9604, matches PRIDE's organism). STATED species is Gigantopithecus blacki, but NCBITaxon has no entry (NCBI taxonomy esearch: 0 hits; OLS only VTO terms) and `parse_sdrf` rejects the species name as not in NCBITaxon. Family-level term is the most specific validating term; species is in this report only.
- Organism part: `enamel` (UBERON:0001752), `dentine` (UBERON:0001751); from Methods and file names.
- Treatment / factor: demineralization acid is the designed comparison (HCl vs TFA on enamel) -> `characteristics[treatment]` and `factor value[treatment]` = `Hydrochloric Acid` / `Trifluoroacetic Acid` (NCIT:C76716, NCIT:C84228 labels; concentrations 1.2 M / 10 %, 3 C, 24 h are in the source name only, no ontology term for demineralization). `factor value[organism part]` = enamel vs dentine (confounded with nothing but acid for dentine, which was only HCl).
- Blank (row 4): `sample type = blank` (PRIDE:0001016); organism/part/disease/stage/strain/sex/treatment and both factors `not applicable`. The paper mentions a negative extraction blank and injection (system wash) blanks; the file name does not say which. It is annotated rather than excluded because no required column forbids reserved words.
- Cleavage agent: `unspecific cleavage` (MS:1001956). Protocol is digestion-free (no protease); both searches were unspecific (MaxQuant Enzyme mode "Unspecific", PEAKS enzyme None). reconcile flags this as BLOCKER `cleavage_agent_unsupported` because the record never names a "digest reagent"; this is a deliberate, record-supported choice ("We did not use an enzymatic protease ... digestion mode was set to unspecific") and not an enzyme-role mismatch.
- Modifications (all Variable, no fixed): Oxidation M (UNIMOD:35), Oxidation P (= hydroxyproline, UNIMOD:35 on P), Deamidated N and Q (UNIMOD:7), Gln->pyro-Glu (UNIMOD:28, N-term, Q), Glu->pyro-Glu (UNIMOD:27, N-term, E), Phospho STY (UNIMOD:21, TA=S,T,Y). Read from MaxQuant summary.txt (variable list) and PEAKS pep.xml search_summary, not from prose. No Carbamidomethyl declared Fixed in either search, so none asserted; `reduction reagent` and `alkylation reagent` = `not available` (Methods silent).
- Tolerances 10 ppm / 0.05 Da: paper and PEAKS parameters (parent_error 10, delta 0.05). CONFLICT: MaxQuant parameters.txt has MS/MS tol (FTMS) 20 ppm. Chose paper+PEAKS because dentine/blank were searched by PEAKS only and the value must be uniform; flagged for review.
- Dissociation HCD (MS:1000422), Orbitrap MS2 analyzer (MS:1000484): from MaxQuant msms.txt (1403 rows, all HCD/FTMS, files 1332 and 1333 only). Extended to 1334/1335 (same method series; inferred).
- Instrument Q Exactive HF-X (MS:1002877): raw headers for 1332, 1334, 1335 say Q Exactive HF-X (decoded utf-16-le); 1333_Enamel_TFA header request returned only 4096 bytes with no model string, so that file rests on paper, PRIDE and the identical run series. PRIDE field agrees.
- Acquisition: DDA (PRIDE:0000627); inferred from MS/MS scan events and the paper's reference to a standard QE HF-X method (no explicit "DDA" statement).
