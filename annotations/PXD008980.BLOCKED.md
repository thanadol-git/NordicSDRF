# PXD008980 annotation blocked

PXD008980 is an IMR-90 lung-fibroblast adenovirus type 2 infection study using SILAC label-swap biological replicates. Its 40 deposited RAW files form four ten-fraction sets named `MS-15-006-3`, `MS-15-006-4`, `MS-15-006-8`, and `MS-15-006-9`.

The paper establishes that the deposited data represent the 6- and 12-hour post-infection samples; each time point has an infected/mock, heavy/light label-swap replicate. It does not assign the four deposited set codes to either time point or label swap. The PRIDE README and the 40-file archive list only preserve filenames and a common search ZIP. Assigning those code groups would therefore fabricate the source-to-data mapping required by an SDRF.

Evidence checked: PRIDE / ProteomeXchange PXD008980, its FTP README and 40 RAW-file manifest, and Valdés *et al.*, *PLOS ONE* (2018), PMID 30252905, DOI 10.1371/journal.pone.0204522.

Unblock with the original sample sheet, MaxQuant experimental-design file, or confirmation mapping sets 3, 4, 8, and 9 to time point, infection state, and SILAC label.
