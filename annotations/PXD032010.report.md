# PXD032010 SDRF annotation report

Status: validated annotation; independent review pending

- Dataset: A2ML1 bait region mapping and glycan determination (Aarhus University, Enghild lab). Paper: Nielsen et al., Nat Commun 2022, PMID 35641520.
- Output: `PXD032010.sdrf.tsv` (9 rows x 31 columns), template `ms-proteomics v1.1.0`. Evidence: `PXD032010.evidence.json`.
- Step 0.5: no existing PXD032010 directory in sdrf-annotated-datasets; annotated from scratch.

## Design
Recombinant human A2ML1 (HEK293-F) treated with different proteases; 9 label-free DDA RAW files, one row each. Seven rows (`20210316_NSN_L1*`) are bait-region cleavage experiments on a Q Exactive Plus (PD 2.5 search). Two rows (`a2ml1_trypsin*`) are glycosylation mapping on an Orbitrap Eclipse (Byonic 3.7.13): trypsin alone, and trypsin plus chymotrypsin (two `comment[cleavage agent details]` columns; parse_sdrf accepts this). The compared variable is `factor value[protease]` (free text).

## Validation
- `parse_sdrf validate-sdrf -t ms-proteomics`: passed ("Everything seems to be fine").
- `python -m tools structure`: OK. `python -m tools check --offline`: 18 terms checked, 0 hallucinated, CLEAN.
- `python -m tools reconcile` (PRIDE prose says only "see article"; also run with paper methods as record): 4 findings, judged false positives and kept: (a) 3 cleavage-agent "contradictions" because the tool's digest vocabulary does not know thermolysin, elastase or unspecific cleavage; the paper lists those proteases and the file names match; (b) instrument: the deposit has two instruments, confirmed by RAW headers (range reads of the first 300 kB only; no full RAW downloads). PRIDE's single instrument (Orbitrap Eclipse) is wrong for the 7 L1-series files.
- The file was built with `sdrf-tools build`, then a small script (`scratchpad/PXD032010/finalize.py`) set per-row repeated columns (cleavage, dissociation, modifications) because `build` only takes run-constant values for those. Not reviewed independently.

## Caveats and uncertain values
1. Row `20210316_NSN_L1.raw` is encoded as trypsin / factor "trypsin (inferred by elimination)". The paper's 7 proteases and 7 file suffixes match for all but this file. Confirm with the submitter.
2. PPE (porcine pancreatic elastase) and cathepsin G have no MS CV term; encoded as `unspecific cleavage` (MS:1001956), which matches the authors' no-enzyme search. The true protease is in the factor value.
3. HNE encoded as `leukocyte elastase` (MS:1001915).
4. Organism part, cell type, disease, material type set to `not applicable` (purified recombinant protein) - inferred.
5. Byonic N-glycan search (132 human N-glycans) is not representable in the modification columns. Paper says Q/N deamidation but PD settings list N only; the PD settings were used.
6. EThcD supplemental HCD (10%) not encoded. Skin-extract gel-slice experiment has no files in the deposit and is not annotated. Simultaneous vs sequential trypsin/chymotrypsin is not stated.
7. No reduction/alkylation columns (not described for in-solution digests).
8. Independent review (Step 9.5) was not performed: this run could not spawn a fresh reviewer. The gate is not satisfied.
